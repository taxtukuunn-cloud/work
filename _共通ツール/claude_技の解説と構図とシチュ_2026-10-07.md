- **構図**：`ear_soft` の組（座りは良好）。寝姿は `ear_prone_above` 一種類なので同じMODで続けない。

### オナニー
- **狙い**：相手の得意技を自分でなぞらせ、体が覚えていることを自覚させる。
- **手順**：自分の指で → 相手の指に替えられる → 本物の得意技で。
- **決まり**：ペニスを握る・しごく自慰にしない。果てるのも触れずに。絵は通常の敗北の絵を使い回す（10-03 決定）。

## 3. そのほかの責め（ゲームの攻撃タイプと、設計メモで使っている責め）

攻撃タイプ名はゲームにある名前だけを使う（通常攻撃・おっぱい・パイズリ・ぱふぱふ・フェラ・手コキ・足コキ・脇コキ・ハグ・ふとももコキ・膝コキ・尻コキ・尻尾コキ・髪コキ・キス・スマタ・素股・魔法責め・触手・触手コキ・耳責め・乳首責め・強制自慰・パンチラ・息・本番）。

### 3-0. 前を使う責めの位置づけ（案・未決定）
- 手・足・胸・口・太ももなど、おちんちんを直接責める技は「オスの快感を相手に握られる」責め。脈打って出る普通の射精はここで起こる。
- 後ろ・乳首の責め（ところてん → メスイキ）と対にする。前の責めは「出させてもらう／出させてもらえない」の管理、後ろの責めは「出なくてもイく」への作り替え。
- 1本の敗北シナリオで両方使う時は、前で搾られる → 出なくなる → 後ろでメスイキ、の順に並べると流れが一本になる。

### 手コキ
- **狙い**：速さ・握り・止める位置のすべてを相手が握る、管理の責め。顔を見ながら言葉責めを続けられる。
- **手順**：指先で根元から先へなぞる → 軽く握る → ゆっくり上下 → 親指で先を円くなぞる → 速める → 根元を握って止める → 息が落ち着いたら再開。

- **セリフ**：数を数える、「まだ」「いいわよ」の一言で支配する。握ったまま世間話をして、片手間であることを見せる。
- **絶頂**：許しを得てから。出した後も手を止めず、敏感なまま続けて搾精に繋げる形もある。
- **構図**：`hj_pov_close`、`hj_lying_beside_front`（添い寝）、`hj_stand_side`、`hj_behind_seated`（背後から）、`lap_sit_front_hj`。

### 足コキ
- **狙い**：見下ろされ、手も使ってもらえない屈辱の責め。「足で十分」と扱われることが効く。

- **シチュ**：椅子や玉座の足もと／机やワゴンの下で隠れて／ヒールを脱いで見せるところから。

### おっぱい（押し当てる・見せる）
- 色仕掛け寄りの技。腕や背中に押し当てる、胸元を見せる、身を乗り出して谷間を近づける。触れさせずに、重みと柔らかさだけを伝える。

### パイズリ

- **セリフ**：「見える？　全部隠れちゃったわね」「ほら、出てきた。……また隠すわよ」「柔らかいのに負けちゃうの？」
- **絶頂**：寄せたまま谷間の中で出させ、胸を開いて見せる／出した後も挟んだまま揺らし続ける（搾精へ）。寸止めなら、胸を開いて冷たい空気に晒す。

- **シチュ**：勝負の席で机の下から／寝台で「ご褒美」として／油や蜜、泡を使う湯殿。

### ぱふぱふ
- **狙い**：顔を胸で包み、**匂いと柔らかさと温かさで頭の中を満たす**責め。視界・音・息が全部相手になる。考えることをやめさせる、甘い朦朧。

  - **匂いを覚え込ませる**：気持ちよさと匂いを結びつける。後の場面で、すれ違った時の残り香だけで力が抜ける。結末（日常への残り方）に使いやすい。

- **セリフ**：「ほら、おいで」「吸って。……いい匂いでしょう？」「全部忘れていいのよ」「あら、自分から来たわね」
- **同時技の相方**：手コキ（授乳の形の膝枕）、乳首責め、頭の上からの囁き（耳責め）。

- **狙い**：触れずに、あるいはほとんど触れずに崩す。言葉の意味より声の質で効かせる。快楽洗脳の入口。

- **描写**：声が頭の中で響く、耳の奥の濡れた音、首筋から背中への鳥肌、腰の力が抜ける。左右で違う声（双子・複数）だと逃げ場がなくなる。

- **構図**：`ear_soft` の組（座った主人公の後ろ／横から）。寝姿は `ear_prone_above`。

### 魔法責め（淫紋・女装・貞操帯・尿道・脳イキ など）
ゲームにない責めの受け皿になる攻撃タイプ。中身ごとに書き分ける。

**淫紋**
- 肌に浮かぶ印。累積スタックを目に見える形にする。段階ごとに、浮かぶ → 広がる → 光る・疼く → 完成。
- 描く・刻む手順（筆、指、舌、口づけ）そのものを責めにする。場所は下腹・胸・うなじなど。
- 相手が近づく・声をかけるだけで熱を持つ、という日常への残り方が結末に使える。

**女装**
- 一枚ずつ着せる手順が責め。脱がせる → 下着 → ストッキングを足首から撫で上げる → 服 → 小物 → 鏡で見せる。着せるたびに布越しに撫でる。
- 描写：布の滑り、締めつけ、スカートの頼りなさ、鏡の中の自分。「似合う」と褒められて否定できない。呼び方が変わる。
- 決まり：着せた後は最後まで着せたまま（脱がさず、ずらす）。ウィッグは基本なし。女装ありMODは28本すべてに着せる場面を入れる。メスの開花と直結させる。

**貞操帯**
- 前を封じる管理の責め。はめる → 鍵をかける音 → 鍵を胸元や首に下げて見せる。
- 描写：反応しても収まる場所がない窮屈さともどかしさ（痛みにはしない）。前が使えないので、後ろと乳首の感覚だけが育つ。メスイキへの近道として使える。
- 結末：鍵の在りかが相手の手の中、という日常。

**尿道**
- 細い管・ゼリー・細い尾や針管で内側から責める。ゆっくり、少しずつ、痛みなし。十分に濡らす。
- 描写：内側を通っていく異物感と温かさ、内側から前立腺に届く感覚。出口をふさがれているので、漏らすことも出すこともできない。
- 後ろと同時に責めると、前立腺を内と外から挟む形になる。

**脳イキ**
- 触れられずに達する。声・視線・暗示・媚毒で。何も出ない絶頂として書く。
- 「触られていないのに」という驚きと、体が相手の言葉だけで動く怖さと甘さ。

### 触手・触手コキ
- **狙い**：手が足りない同時責めを成立させる。全身を一度に責められ、どこに意識を向ければいいか分からなくなる。
- **手順**：手首・足首に巻きつく → 持ち上げる／開かせる → 細い先で乳首をなぞる → 前を包んで扱く（触手コキ）→ 後ろをほぐして細く入る。
- **描写**：ぬめり、体温（温かい・冷たい）、吸盤や粘液、太さが変わる感触。操っている相手は手を使わず、腕を組んで眺めている。
- **決まり**：責め手の体の一部か、責め手が操るものとして描く（蔦・尾・影・糸・粘体・水流・羽根も触手扱い）。後ろに入れる時はほぐしの手順を踏む。後ろの責めは、ところてん → メスイキの流れに乗せる。
- **構図**：`bound_tentacle_stand`、`hold_behind_tentacle`、`tentacle_legs_watch`、`bound_wrap_hj`。下半身が人でない相手は下書きが当たりにくい。

### アナル舐め（攻撃タイプは暫定でキス）
- **狙い**：いちばん見られたくない所を、いちばん親密な口で責める。羞恥が主役。指より柔らかく温かく、力では拒めない。得意技（★）にしているキャラも多い（蛇・淫魔・吸血鬼・蜂など舌に特徴のある相手）。
- **手順**：腰を上げさせる／脚を開かせる → 息を吹きかける → 周りを舌先で円くなぞる → 中心を平たい舌で舐め上げる → 舌先を尖らせて入口をつつく → 少しずつ差し入れる → 出し入れ・中で動かす。
- **描写**：濡れた音、吐息の熱、舌のざらつき。入口がひくつくのを自分で止められない。「そんな所を」という羞恥が、舐められるたびに「もっと」にすり替わる。相手の顔が見えない体勢が多いので、声と音と感触で書く。
- **相手のセリフ**：味や反応を実況する（「ここ、ひくひくしてる」「舌を締めつけてくるわ」）。口を離すたびに喋り、また塞ぐ、のリズム。
- **絶頂の扱い**
  - 入口だけを舐める間は漏れない（焦らし・ほぐしの役）。
  - 長い舌で奥まで届く相手（蛇・淫魔など）が前立腺を押す時は、指と同じくところてん → メスイキの流れに乗せる。
- **ほぐしとして成立する**（10-07 決定）：アナル舐めで十分にほぐせば、指を使わずにそのまま挿入へ進んでよい。舌でも段階は踏む（周り → 入口 → 舌先を差し入れる → 奥まで → 「もう入る」と確かめる）。ゲーム上は、アナル舐めの技でも `$ほぐし` を進める（指ほぐしと同じ扱い）。
- **同時技の決まり**：同じ部位どうしは同時には組まない（アナル舐め＋逆アナル・ペニバン・指を同時にはしない。舐めてから挿入、の順はよい）。相性がよいのは、アナル舐め＋乳首（尾や手で）、アナル舐め＋別の相手のキス、アナル舐め＋手コキ。
- **構図**：`rimjob_standing_side`（立たせて後ろから・横）、`rimjob_lying_side`（寝かせて・横）。相手の顔が隠れやすいので、横からの視点で相手の目元を残す。構図LoRAの `alt_anilingus` は停止中（使わない）。
- **シチュ**：壁や柱に手をつかせて後ろから／仰向けで膝を抱えさせて、脚の間から見上げてくる／「自分で開いて見せなさい」と両手で広げさせる／蜜や酒を垂らして舐め取る。
- **結末の例**：舐められないと眠れない／舌の感触で目が覚める／毎朝の「舌の儀」。

### 道具（アナルバイブ・アナルパール・ローター・ゼリー）
- **狙い**：入れたまま・付けたまま放っておける責め。相手の手と口が空くので、言葉責めや別の責めと重ねられる。
- **アナルバイブ**：ほぐしてから入れ、強さを相手が握る。揺れや音に合わせて強弱を変える。服を戻して「そのまま過ごしなさい」。
- **アナルパール**：一粒ずつ入れて数える。抜く時がいちばん効く（一粒ごとに入口が開く）。ゆっくり一粒ずつ／まとめて、で書き分ける。
- **乳首ローター**：服の内側に留める。止められない細かい震え。絶頂は何も出ないメスイキ。
- **ゼリー**：注いで中を満たす。温かさと重さ、動くたびに中で揺れる感覚。前立腺を内側から押す。
- **決まり**：後ろに入れるものはほぐしの後。後ろの道具は、ところてん → メスイキの流れに乗せる。
- **結末**：入れたまま日常を過ごさせる、が作りやすい。

### エネマグラ（10-07 追加。攻撃タイプは本番）
- **どんな道具か**：前立腺を押すための、小さな曲がった器具。振動も電池もない。入れると、お尻の締まり（本人の筋肉の動き）で勝手に揺れて前立腺を押し、外に残る持ち手が会陰も押す。
- **狙い**：**自分の体が自分を責める**。相手は手を触れていない。感じると締まり、締まると押され、押されるとまた感じる。止め方が分からないまま、手も使わず、動きもせずに達する。メスイキを覚えさせるための道具。
- **バイブとの違い**：バイブは相手が強さを握る、機械の震え。エネマグラは静かで、動かしているのは本人の体。「されている」ではなく「自分でしてしまっている」になる。
- **手順**：指か舌でほぐす → 潤滑 → ゆっくり入れる → 吸い込まれるように位置が収まる → 「動かないで。力を抜いて」→ 呼吸を合わせる（吸って締める、吐いて緩める）→ 奥が小さく震え始める → 腰と太ももが勝手に震える → 波が来る → 波が引かずに重なる。
- **描写**
  - 小ささと的確さ：指より細いのに、一点だけを外さない。
  - 静けさ：音がない。聞こえるのは自分の息と相手の声だけ。
  - 時間：すぐには来ない。じわじわ温まり、ある所から急に深くなる（長い描写に向く）。
  - 体の勝手な動き：入口がひくつく、中が吸い込む、腰が小刻みに震える、足の指が丸まる。止めようと力を入れると、それが次のひと押しになる。
  - 会陰：外からも同じ場所を押され、内と外で挟まれる。
- **相手の役（2つの型。キャラの性格で選ぶ。途中で切り替えてもよい）**
  - **抱きしめる型**（10-07 決定）：入れた後、相手が主人公を抱きしめる。安心感を抱かせて抵抗を無くす。エネマグラは力を抜くほど深く効くので、安心して体を預けた分だけ気持ちよくなる、という理屈が通る。
    - 形：正面から胸に抱く／背後から腕を回す／添い寝で腕枕／膝の上に抱える。
    - 描写：相手の体温、心音、匂い、ゆっくりした呼吸に自分の呼吸が合っていく。背中や頭を撫でられる。震えが全部相手に伝わっていて、隠せない。腰が跳ねても腕の中で受け止められる。
    - 心理：「怖くない」「力を抜いていい」と思った瞬間に波が来る。安心することと、イくことが結びつく。抵抗する理由がなくなる。
    - セリフ：「大丈夫。力を抜いて」「怖くないわ。ちゃんと抱いててあげる」「震えてるの、全部わかるわよ」「いい子。そのままイっていいのよ」
  - **見ている型**：手を触れずに見ている（お茶を飲む、頬杖をつく）。呼吸を指導し、実況する。「私は何もしてないわよ。あなたのお尻が自分でやってるの」。
  - どちらの型でも、相手の手と口は空いているので、乳首責め・キス・耳責めを重ねられる。
- **絶頂**：ところてん → メスイキの流れにいちばん素直に乗る。締まるたびにとろとろ漏れ続け、出なくなった後は波だけが重なる。メスイキの回数を数えられる。気絶・アヘ顔の山場に繋げやすい。
- **メスの開花**：「道具と自分のお尻だけでイける体になった」ことを才能として褒める。
- **入れたまま**：服を着せて歩かせる・座らせる・給仕させる。歩くたび、座るたび、笑うたびに押される。結末（日常への残り方）に使いやすい。
- **ゲームでの仕組み**（10-07 決定）
  - 技が当たると、受けた側（主人公か男モンスター1体）が「装着」の状態になる。装着の間、**相手のターン終了ごとに、その受けた側のスタックが+1**進む。回数の上限はない（外れるまで毎ターン）。
  - **解除は「付けた相手を倒す」だけ**。その敵カードが場を離れたら外れる。
  - **抜ける時にも快感がある**：付けた相手が倒れて外れる瞬間、入口を通る感覚で達しかける演出を入れる（説明文と主人公・男モンスターの反応。相手の捨てゼリフ「抜く時がいちばんいいでしょう？」など）。倒したご褒美が快感になってしまう皮肉。スタックは増やさない（演出だけ）とするのが無難（増やすかどうかは実機で調整）。
  - 作り方の見込み：付けた敵カードの効果（エンドフェイズ開始時の誘発効果）として書く。装着の印は受けた側の変数に持つ。すでに装着中の相手に当てても重ねない。男モンスターが場を離れたら、その分は消える。
  - 命中時の加算：装着と同時に+1（案）。あとは毎ターンの+1で進める。
  - 攻撃時のセリフは、スタック段階に加えて「装着中かどうか」でも変える（装着中は「まだ入ってるわね」と触れる）。
  - 未確認：場を離れた時に外す処理と演出を、どのタイミングで呼べるか（実機確認）。
- **オナニー**（10-07 決定）：得意技がエネマグラの相手なら、「自分で入れて、手を離して、じっとしている」自慰になる（ペニスを使わない決まりにそのまま合う）。見つかった後、相手は**抱きしめるか、言葉責めをするか（両方でもよい）を同時に行う**。この決まりはエネマグラのオナニーだけに使う（ほかの技のオナニーには広げない）。主人公は自慰を続けたまま、相手がそれを支える／導く形。
  - 抱きしめ：後ろから抱いて「続けていいのよ」。一人でしていた時には来なかった波が、抱かれた途端に来る。
  - 言葉責め：呼吸の指導（吸って、締めて、吐いて）、実況、採点。「一人でここまでできたの？ えらいわね」「今、締めたでしょう」。
  - 区切りの例：一人で（波が来そうで来ない）／抱きしめられて・声をかけられて（初めて波が来る）／相手に入れ直されて（波が重なる）。
- **持たせやすいキャラ**：医師・施術師・研究者・メイド・調教師など、道具と手順に詳しい相手。
- **構図**：器具は体の中で見えない。抱きしめる型は `lie_beside_hug_chest`（添い寝で頭を胸に抱く）、`stand_embrace_back`、`hug_seated_chest`、`kneel_behind_hug`（後ろから抱く）。見ている型は `lie_beside_pov`、`pov_loom`、`nipple_side_lying`。主人公目線の時は、断面図の小窓（方針のみ・未実装）の対象にできる。

### 寸止め・焦らし
