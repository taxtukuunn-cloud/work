# 累積スタックの見せ方：メスイキMOD方式（2026-10-07 調査・並べ方はAに決定）

ユーザーの希望：状態異常（累積スタック）を、メスイキMOD（kuruMOD）のように管理したい。
実機の画面（ユーザー提供）：プレイヤーのステータスに「【♥おっぱいが弱い♥】(解除不能)」が受けた回数だけ並ぶ。

## メスイキMODの仕組み（Driveにある本体カードの写しを読んで確認）
読んだファイル：`kuruMOD_Mesuiki_weapon_BustGrowthBra.txt`（育乳ブラ）、`kuruMOD_Mesuiki_condition_BustFeminization.txt`。

- 画面に並んでいるのは、ゲームの状態異常ではなく、**装備魔法カード**。名前を付けただけの中身のないカード（condition カード）を、受けた側に装備させている。
  ```
  default
  @初期設定
      &カード名,♥おっぱいが弱い♥
      &カード画像,#…/….png
      属性設定,闇属性
      タイプ設定,装備魔法
      レアリティ設定,R
  ```
- 付け方（育乳ブラの効果2）：
  ```
  &状態異常カードID,kuruMOD_Mesuiki_condition_BustFeminization
  効果生成デッキ内,&状態異常カードID,味方
  %状態異常カード,=,自分デッキ.?ID:&状態異常カードID
  装備付与,装備者,%状態異常カード
  装備者.$おっぱいが弱い,+=,1
  効果除外,%状態異常カード
  ```
  デッキ内にカードを作る → 取り出す → 受けた側に装備させる → 数は受けた側の変数にも足す → カード本体は除外する。除外してあるので外せず、画面に「(解除不能)」と出る。
- 育乳ブラ自体も装備魔法。相手に装備させ（`装備付与,効果対象,自分`）、**自分のターンのメインフェイズ開始時**に強制誘発で上の処理を毎ターン行う。
  → 今日決めたエネマグラの「装着 → 毎ターン+1」と同じ形。

## 分かったこと
- 「MODで新しい状態異常の名前は作れない」は、ゲーム組み込みの状態異常の話。**装備カードを使えば、好きな名前をステータスに並べられる**（古い記録の補足）。
- 数は今までどおり受けた側の変数（`相手プレイヤー.$〜`・`相手.$〜`）で数え、装備カードは「見える印」として足す、という二本立てになっている。今の作りに足すだけで済む。
- 受けた側ごとに付くので、主人公と男モンスターで個別に持つ今の決まりと合う。
- プレイヤーにも付けられる（実機の画面で確認）。

## 決定（ユーザー・10-07）
**A. 1点ごとに1枚**（メスイキMODと同じ）。スタックが1増えるたびに、印のカードを1枚、受けた側に付ける。+3の技は3枚、+2の技は2枚。主人公は最大12枚、男モンスターは最大6枚並ぶ。

## 作り方
### 1) 印のカード（MODごとに1つ。`<コード>_condition.txt`）
```
default
@初期設定
    &カード名,<スタック名>
    &カード画像,#<コード>/<既存の絵>.png
    属性設定,闇属性
    タイプ設定,装備魔法
    レアリティ設定,R
```
- 名前はそのMODのスタック名（「鱗の刻印」「通過駅」など）。飾りを付けるなら「♥鱗の刻印♥」。
- 画像は新しく作らず、そのMODの既存の絵を使う。

### 2) スタックを足している所に足す処理（受けた側が `相手` の時。+3 の例）
```
&印カードID,<コード>_condition
$印の残り,=,3
while,$印の残り,>,0
{
 効果生成デッキ内,&印カードID,味方
 %印カード,=,自分デッキ.?ID:&印カードID
 装備付与,相手,%印カード
 効果除外,%印カード
 $印の残り,-=,1
}
相手.$<スタック名>,+=,3
```
- 数える・段階を決める・上限で敗北させる処理は、今までどおり変数（`相手プレイヤー.$〜`・`相手.$〜`）で行う。印のカードは見せるためだけ。
- 魔法・罠・召喚時の「+n」も同じ処理を通す（対象の決め方は今までどおり）。
- 同じ処理を何度も書かないよう、各カードに `@印を付ける`（`$付ける数` と対象を渡して呼ぶ）を置く形にする。

### 3) エネマグラ（装着 → 毎ターン+1）
- メスイキMODの育乳ブラ・あなるばいぶは、装備魔法そのものが毎ターンの処理を持つ。ただし**装備を外す命令は、この2枚には無かった**（あなるばいぶも同じ作りで、外す処理なし）。
- 決定は「付けた相手を倒したら外れる」なので、毎ターンの処理は**付けた敵モンスターのカード側**に持たせる（そのカードが場を離れれば止まる）。「装着中」は受けた側の変数で持ち、外せない装備カードは付けない。
- 毎ターン増える+1は、上の 2) の処理で印を1枚ずつ足す。
- 抜ける時の快感の演出は、付けた敵モンスターの `@戦闘破壊`・`@効果破壊` で出す（どちらも未検証の受け口）。

## 数字の表示をやめる（ユーザー・10-07）
- 印がステータスに並ぶので、スタックが増えた時の数字の表示は要らない。次のものを消す。
  - `説明,（<対象名>の<スタック名> {値}／<上限>）` の行と、そのための `$表示用` の行。
  - ロゼッタのハートのゲージ（`@ゲージ表示`・`アラート,…メス堕ち度 {値}／20…`）と、それを呼ぶ `イベント実行,ゲージ表示`。
  - セリフや説明の中で、今の数や残りの数を数字で言っている所（「あと三つ」「七つ目」など）。数字ではなく、様子で言う（「また濃くなった」「もう胸まで届いている」）。
- 残すもの：段階ごとのセリフの変化。段階が上がった時だけ、数字のない一言を入れてよい（例「刻印が胸まで広がった」）。
- 技そのものが数える責め（アナルパールを一粒ずつ数える、口移しの一杯目・二杯目など）は、スタックの数ではないのでそのまま。

## ロゼッタMOD：上限を20から12へ（ユーザー・10-07）
ロゼッタを印の試作にも使う。上限をほかのMODと同じ12にそろえる。

| 主人公：前立腺の段（ロゼッタは尻尾） | 7〜13（前半≦10／後半≧11） | 5〜8（前半5〜6／後半7〜8） |

- 1回の攻撃・効果で増える量は、今の本文の数字を読んでから、12に合うように決め直す（一覧にしてユーザーに見せる）。目安は、今の量×0.6を四捨五入、最低1。
- 印のカード：`Rosetta_condition.txt`、名前は「♥メス堕ち♥」（案）。
- 敗北シナリオの中身と、責めの順番（乳首 → 尻尾 → ペニバン）は変えない。

## 実機で確かめること
- `効果生成デッキ内`・`装備付与`・`効果除外` が、`@効果` の外（`@戦闘`・`@戦闘後`）でも動くか。メスイキMODは `@効果` の中で使っている。動かなければ、得意技の加算を攻撃時の誘発効果（onAttack）に移す。
- `装備付与` の対象に `相手プレイヤー` を直に書けるか（画面ではプレイヤーに付いているので、付くこと自体は確か）。
- 男モンスターに付けた印が、そのモンスターが場を離れた時にどうなるか。
- 12枚並べた時のステータス画面の見え方。
- 主人公側のカード（魔法の破壊など）で印が外されないか（除外済みなので外れない見込み）。
- 敵側へ寝返った後のカードに印が残るか。

## 進め方（案）
1つのMODで試作 → 実機確認 → 共通ツールで全MODへ。
