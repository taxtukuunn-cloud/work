### 共通の約束
- **短くしない**。直した後の本文が、直す前より短くなったら、やり直す。敗北イベント全体5000字以上、プレイ描写6000字以上の決まりがあるMODは、それも守る。
- **話の流れ、場面の順番、結末、印（結末で授けられる物）、絵を出す位置は変えない**。本文の体勢は、その場面で出る絵と食い違わせない。

- 直している途中で不具合（話者の抜け、if の閉じ忘れ、「【未記入】」など）を見つけたら、直して報告に書く。

## 4. スタックの直す点
細かい作り方は `資料\claude_スタックの見せ方_メスイキMOD方式_2026-10-07.md`。手本は、ゲーム本体の `CSV\Card\kuruMOD_Mesuiki_weapon_BustGrowthBra.txt` と `kuruMOD_Mesuiki_condition_BustFeminization.txt`（読むだけ）。

1. **印のカード**：MODごとに `<コード>_condition.txt` を作る（名前はスタック名）。スタックが1増えるたびに、受けた側に1枚付ける（作る → 取り出す → 装備付与 → 除外）。数える・段階を決める・上限で敗北させる処理は、今までどおり変数で行う。
2. **数字の表示をやめる**：「（〇〇 5／12）」の説明、ゲージ、セリフの中でスタックの数を言っている所。数字ではなく様子で言う文に直す。技そのものが数える責め（パールを一粒ずつ、口移しの一杯目）は残す。
3. **ロゼッタだけ**：上限を20から12へ（境目は資料の表）。増える量は今の数字を読んで案を出し、見せてから直す。
4. **まずロゼッタだけで入れて、実機確認を待つ**。印を付ける命令が攻撃の処理（`@戦闘`・`@戦闘後`）の中で動くかが、まだ分かっていない。ユーザーが実機で動くと確かめるまで、ほかのMODには広げない。

## 5. 直した後に自分で確かめること（MODごと）
- 本文の字数（セリフと説明）が、直す前より減っていない。
- 本文に半角カンマと `$ % & # { } < >` が無い。
- `{` と `}` の数が合っている。`if` の後は必ず `{ }`。
- セリフの前に、正しい `話者` がある。
- 文字コード・改行・BOMが元と同じ。
- 直す対象でない節が、元と一字も違わない。
- 「射精」「出す」が、後ろの責め・乳首責めの場面に残っていない（相手の射精は別）。
