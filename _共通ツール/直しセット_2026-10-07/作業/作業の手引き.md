# 全MODの敗北シナリオを直す手引き（2026-10-07・第4段）

1つのMODの敗北シナリオ（ふつう28本）を、決まりに合わせて書き足す・言い換える。
**本文を考えて書くのはあなた。入れる作業は道具（apply_mod.py）がする。** 道具は必ず「直す前の控え」から入れ直すので、何度動かしても安全。

## 0. 先に読むもの（これだけでよい。大きな資料を全部読み直さない）
1. この手引き（決まりは2章にまとめてある）。
2. 見本：`見本_抜粋.py`（N119 の直し方・量・言い回しの手本。全体を見たい時だけ `patches\N119_Venus_MOD.py`）。
3. そのMODの設計書：tools.zip の中の `brief.md`、MODフォルダの `tools\brief.md`・`brief.md`・設計メモ・執筆ガイド・README のどれか。**口調、一人称、呼び方、部位の呼び方の表、場所、小道具はこれに従う。** 長ければ、登場人物と呼び方の表、技の表だけでよい。
   zip の中は `python -c "import zipfile;print(zipfile.ZipFile(r'<zip>').read('tools/brief.md').decode('utf-8'))"` で読める（書き換えない）。
4. 技の細かい書き方で迷った時だけ、`..\資料\claude_技の解説と構図とシチュ_2026-10-07.md` のその技の項を読む。
5. dump は自分専用の場所に出す：`python dump.py <MOD> <鍵...>` の出力をそのまま読むか、`%TEMP%` などへ保存する（`dump\` フォルダはもう一人と上書きし合う）。

## 1. 絶対に守ること
- 書き換えてよいのは、そのMODだけ。ゲーム本体（D:\GAME\…）は読むだけ。**削除・権限の変更はしない。**
- MODのファイルを直接いじらない。`patches\<MOD>.py` を書いて `apply_mod.py` で入れる。
- **短くしない**（どの本も直す前より長くなること）。話の流れ・場面の順番・結末・印・絵の行の位置は変えない。
- セリフ・説明の本文に、半角の `, $ % & # { } < >` を入れない（全角の、！？を使う）。改行は `\n`（バックスラッシュ＋n）。
- 登場人物は全員20歳以上。主人公は160cm・細身・一人称「僕」（MODの決まりで「わたし」等に変わる所は元のまま）。敵上位・逆転なし。痛み・暴力・凌辱・流血なし。**相手キャラはアヘ顔なし**。主人公が責める・主人公が女性に挿入する描写は入れない。幼さを示す語（少年・子供・幼い・ロリ・少女・ショタ・童顔・男の子など）、「小柄」「華奢」「すっぽり」は使わない。MODの設計書で禁じた語（例「いい子」）も使わない。
- **大きさ（ふたなり・ペニバン・張形などのセンチ）は、カードの本文が正しい**（ユーザー決定：全体を一回り大きくした）。設計書・scen・読む用の小さい数字に合わせて直さない。足す文で大きさに触れる時は、カードの本文の数字を使う。
- **主人公のアヘ顔と気絶は、MODの設計書に「アヘ顔なし」「意識ははっきり」とあっても入れてよい（設計書のその決まりは無視する。ユーザー決定）**。入れ方は2章の表どおり（気絶は1本1回まで・顔面騎乗では気絶させない）。相手キャラのアヘ顔なしは変わらない。
- ハートや三点の書き方は、そのMODの本文に合わせる（❤か♡か、「・・・」か「……」か）。

## 2. 直す点（当たる場面だけ。当たらない本は P に入れない）
| 項目 | 当たる場面 | 直し方 |
|---|---|---|
| ところてん → メスイキ | 後ろの責め（指、尻尾・触手・舌で前立腺、アナルバイブ・パール・ゼリー、ペニバン、逆アナル） | 前に触れられないまま漏れ出すところてん（「漏れる」「垂れる」「押し出される」。飛ばない・脈打たない・押されている間だけ・出てもすっきりしない）を何度か → 薄く少なく → 出なくなる → 何も出ないメスイキ（波が引かず何度でも）。ところてんを「射精」「出す」と書かない |
| 乳首では出さない | 乳首責めだけで達する所 | 何も出ないメスイキに。射精・ところてんをしていたら書き直す。同時技で漏れる時は、奥を押されたせいにする |
| メスの才能の開花 | ペニバン、逆アナル、乳首責め、指ほぐし | 体が先に覚える（腰が迎える・締める・声が甘くなる）→ 弱さでなく「才能」と褒められる。主人公は 否定 → 戸惑い → 受容 → 誇り。結びに誇りの一文 |
| 体のメス化 | 女装、ペニバン、逆アナル、乳首責めの本 | 相手の魔力（そのMODの世界の言い方で：魔力・蜜・淫紋・薬・香油・スタンプなど）で少しずつ変わる。乳首（ぷっくり・色づく）、お尻（ほぐさなくても開く・自分から濡れる）、前（小さく柔らかく、出るものが薄く）、肌・腰・太もも、声、魔力の向き。**女体化ではない**（胸は平ら・性器は男性のまま・顔と背丈そのまま）。頭・中ほど・終わりで同じ所に触れて進み具合を見せる。結末で「もう戻らない」。**MODの設計書の「体は変えない」より、こちらを優先する（ユーザー決定）** |
| 逆アナルの射精 | ふたなり・男の娘の逆アナル | 相手の中出しを頂点に：前触れ → 予告 → 奥に注がれる熱 → その熱で主人公もメスイキ → 余韻。何度でも続く（「絶倫」と書かない）。蜜・ゼリー・酒を注ぐ技は **そのまま**（変えない） |
| ペニバンの書き分け | ペニバン | 相手は冷静なまま。受け入れ方を稽古として仕込む（入る時は吐いてゆるめる・抜ける時に締める等）。**何も注がれない** |
| 気絶 | ペニバン、逆アナル、相手の得意技としての触手・尻尾の挿入（ユーザー決定 10-08） | 山場に入れてよい（1本1回まで。全部の本でなくてよい）。苦痛でなく甘くほどける。落ちる所は文を途中で切る → 目覚め（その場で／時間が飛んで）→ 気絶するほど感じたことを才能と褒める。顔面騎乗では気絶させない |
| 主人公のアヘ顔 | 敗北シナリオの山場 | 入れてよい。鏡か相手の実況で気づかせ、直そうとしても直せない崩れ方。バトル中のセリフには入れない |
| アナル舐め | アナル舐めの後に挿入する場面 | 舌でほぐせば、指を挟まなくてよい（今ある指ほぐしは消さない） |
| 顔面騎乗 | 顔面騎乗の場面 | 「息はできる」を「息は相手が握る」に（浅く甘く詰まらせ、腰を浮かせて一息だけ許す）。朦朧を主眼に、独白が短く途切れる。気絶・苦悶なし。乳首責めと同時 |
| ぱふぱふ | ぱふぱふの場面 | 匂いを足す（谷間にこもった肌の匂い＋責め手ごとの香り。花・蜜・ミルク・酒・白檀・湯上がり・森・紅茶など、キャラに合う一つを決めて、そのMODの全本でそろえる）。気持ちよさと結びつけて覚えこませ、結びの残り香に。息は苦しくしない |

- **前に触れず、得意技だけ（声・息・見るだけ・抱擁・口づけ・音など）で達する2回目も、何も出ないメスイキにする**（ユーザー決定 10-08）。射精の行は `フラッシュ,ピンク` に替える。**耳だけ（囁き・耳舐めだけ）で達する2回目も同じく、何も出ないメスイキにする**（ユーザー決定 10-08）。

### 変えないもの（ユーザー決定）
- **前の責め（手・足・胸・口・太ももなど）での射精はそのまま**。**主人公が相手の中に入ったまま（挿入して）達する場合も前の責め**として射精のままでよい（ユーザー決定 10-08）（カウントダウンの射精など）。前の責めだけの本は直さない。
- 蜜・ゼリー・酒を注ぐ技の逆アナル、エネマグラ（入れない）、スタックの数を言うセリフ（そのまま）、責め手の口調。

### よくある形（本編踏襲のMOD：積み上げ → 寸止め2回 → カウントダウン → 得意技だけの2回目 → 結び）
- カウントダウンが前（手・足・胸）なら、その射精は変えない。
- **得意技だけの2回目で前に触れていないなら、何も出ないメスイキにする**。後ろの責めなら、その前に「残りがところてんで押し出される → 薄く → 出なくなる」を挟む。
- **本文を、ところてん・何も出ないメスイキに言い換えた絶頂は、どれも、その絶頂の `射精` の行を `フラッシュ,ピンク` に替える**（画面の演出と本文を合わせる）。途中の絶頂は `('cmd_after', '目印の行', '射精', ['フラッシュ,ピンク'])`（目印の行＝その絶頂の直前の、主人公の声などの行。その後で最初の `射精` が替わる）。前の責めで本当に射精する絶頂の `射精` は残す。
- 最後の絶頂は、**その節の最後の `射精` の行を `フラッシュ,ピンク` に替える**：操作 `('last_cmd', '射精', ['フラッシュ,ピンク'])` を足す（ユーザー決定）。カウントダウンの `射精` は残す。2回目が前の責めで本当に射精する本では替えない。
- 2回目の後の相手のセリフ（「ちゃんと出せたね」「たくさん出ました」等）、主人公のセリフ（「でちゃうぅ」等）も、何も出ないメスイキに合わせて言い換える。

## 3. 量の目安
- 1本につき +400〜1,200字（N119 は平均 +600字）。足すのは2〜6か所。前後のつながりが自然になるように。
- 同じ責め手の4本は、言い回しを少しずつ変える（コピーの連発にしない。共通の決まり文句は2〜3種を使い分け）。

## 4. 手順（1つのMODを2人で分担する）
- 担当は依頼文に書いてある（例：パート a ＝ m1・m2・m3・e1 の16本、パート b ＝ e2・e3・boss の12本）。**自分の担当の鍵だけ**を書く。
- 自分のファイルは `patches\<MOD>__<パート>.py`（例 `patches\N41_Nekomata_MOD__a.py`）。もう一人のファイルには触らない。
1. `python dump.py <MOD> <鍵> <鍵> ...`（担当の鍵だけ出せる。`dump\<MOD>.txt` にも出る）。
2. 設計書を読み、当たる本と直し方を決める。ぱふぱふの香りは、設計書に香りの指定があればそれ、無ければキャラに合うものを決めて報告に書く。
3. `patches\<MOD>__<パート>.py` を書く（形は下）。
4. `python apply_mod.py <MOD> --dry --part <パート>` で確かめる。NOT UNIQUE・SHORTER・BADCHAR が出たら直す。
5. **本番の書き込み（--dry なし）はしない**。二人分がそろってから、取りまとめ役が行う。
6. 最後に、下の「報告」を返す。

## 5. patches の書き方
```python
P = {}
P['btl_m1'] = [            # 鍵 ＝ @敗北_ の後ろ
  ('after',   r'元の行（字下げなし・一字一句そのまま）', [r'説明,足す行', r'話者,%名前', r'セリフ,足す行']),
  ('replace', r'元の行', [r'セリフ,言い換えた行']),
  ('before',  r'元の行', [...]),
  ('cmd_after', r'セリフ,目印の行', '射精', ['フラッシュ,ピンク']),
  ('last_cmd', '射精', ['フラッシュ,ピンク']),
]
```
- 文字列は必ず `r'...'`（`\n` を2文字のまま残すため）。
- 元の行は、その節の中で一つだけ当たること（当たらない・二つ当たると止まる）。`画像` などの命令行には当てない。
- **話者に注意**：`話者,` は次の `話者,` まで続く（`説明` をはさんでも続く）。足したセリフの話者が変わる時は `話者,%名前` / `話者,相手プレイヤー` を入れ、足し終わりで元の流れの話者に戻す（N119 の見本を参照）。
- 命令の行（画像・SE・射精など）は、`last_cmd` 以外で足したり消したりしない。

## 6. 報告（最後の返事。400字〜1,200字程度）
- `apply_mod.py` の最後の出力（DONE の行と、その下の注意の行）。
- 直した本の数／直さなかった本とその理由（前の責めだけ、など）。
- 責め手ごとに1〜2行：何を足し、何を言い換えたか。
- 決めた香り（ぱふぱふ）、入れた気絶・アヘ顔の本。
- 設計書と新しい決まりが食い違った所、迷った所、見つけた不具合（話者の抜け等）。
