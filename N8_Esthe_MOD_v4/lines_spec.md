# N8 洗脳エステ（v4）カード用セリフの書き方

キャラ設定・世界観・口調は `/home/claude/n8/brief.md` を読むこと（成人のみ・責め手上位・逆転なし・主人公はペニスを使う自慰をしない・後ろに入れる前（特別全身施術）はオイルの指でほぐす）。
ここで書くのは、**バトル中にカードが話すセリフ**。JSONファイル1つに1キャラ分をまとめる。

## 本文の決まり（厳守）
- 半角カンマ「,」禁止（全角「、」）。`$ % & # { } < > ;` 禁止。半角の `!` `?` `(` `)` も使わず全角「！」「？」「（）」。
- 1つのセリフは40〜110字。改行したい時だけ `\\n`（JSONの中では `\\n` と書く＝画面で改行）。「」は付けない。
- セリフは責め手の口調をはっきり出す。主人公の反応は短い喘ぎ・途切れた言葉。

## 累積スタック「洗脳度」と段階
攻撃を受けた側が個別に持つ。セリフは**受けた側の段階**で変える。
- 主人公（上限12）：段階1＝1〜3（体験。まだ断れるつもり）／段階2＝4〜6（ブロンズ。次の予約の話で安心する）／段階3＝7〜9（シルバー。声や香りだけでほどける）／段階4＝10〜11（ゴールド。自分から予約したくなる）
- 男モンスター（上限6。6で「特別会員」としてサロン側へ寝返る）：段階1＝0〜1／段階2＝2〜3／段階3＝4／段階4＝5
- 男モンスターは主人公の仲間の男（剣士・獣人など種族はいろいろ。成人）。責め手はモンスターを「お連れ様」「そちらのお客様」などと呼ぶ。モンスターの反応は、その男が戸惑い・抵抗しつつ崩れていく声（一人称「俺」など汎用的に）。

## JSONの形
```json
{
  "techs": [
    {
      "player": [["責め手のセリフ（段階1）", "主人公の反応（段階1）"], ["…段階2", "…"], ["…段階3", "…"], ["…段階4", "…"]],
      "monster": [["責め手のセリフ（対モンスター段階1）", "モンスターの反応"], ["…"], ["…"], ["…"]]
    }
  ],
  "prep": {
    "player": [["指ほぐしのセリフ1回目（まだ固い）", "主人公の反応"], ["指ほぐしのセリフ2回目（もうすぐ入る）", "主人公の反応"]],
    "monster": ["指ほぐしのセリフ（対モンスター）", "モンスターの反応"]
  },
  "summon": ["召喚時のセリフ1", "召喚時のセリフ2"],
  "turn_end": ["自分のターン終了時のセリフ"],
  "onedari_intro": "おねだりされた時の最初のセリフ（どれがいいか自分の口で言わせる）",
  "onedari": [["選択肢の短い名前（10字以内）", "主人公がねだる言葉", "責め手の返事"]],
  "inochi_first": ["命乞い（1回目）のセリフ1", "セリフ2"],
  "inochi_again": ["命乞い（2回目以降）のセリフ1", "セリフ2"],
  "inochi_fail": "とどめを刺された時の一言",
  "inochi_trap": "迷った隙を突く一言（ここから敗北）",
  "onani_first": ["オナニーを見つけた時のセリフ1", "セリフ2"],
  "onani_again": ["2回目以降のセリフ1", "セリフ2"],
  "onani_player": "主人公の言い訳（手が止まらない）",
  "onani_desc": "主人公の自慰の様子を描く地の文（得意技の真似。ペニスは使わない。60〜110字）",
  "end": "勝った時（主人公が負けた後）の締めの一言",
  "win": "負けた時（主人公に倒された時）の一言",
  "conv": "男モンスターが洗脳度6に達してサロン側へ寝返る時のセリフ",
  "flavor": "カードのフレーバーテキスト（100〜130字。世界観と人物が伝わる地の文）"
}
```
- `techs` は担当キャラの技の数だけ、下の順番で書く。各技は player 4段階・monster 4段階（計16セリフ）。
- `prep` は挿入技を持つキャラ（ヴィオラだけ）だけ書く。それ以外は `"prep": null`。
- `onedari` は技の数だけ（技の順番どおり）。
- `onani_*` の自慰は、そのキャラの得意技に合わせる（brief.md の「オナニーの内容」）。
- `summon` `turn_end` `conv` はマスター（ルミナ）も書く（ルミナの summon は「スタッフを呼ぶ時」＝召喚宣言のセリフとして使う。ルミナの turn_end は4つ＝主人公の段階1〜4で、それぞれ下の状態異常の説明に合う内容）。

## キャラと技（この順番で techs を書く）
- **ルミナ**（`m.json`。prep は null）
  1. オイルの乳首ほぐし：温めたオイルで胸を円く撫で、乳首を指先で転がしほぐす
  2. アロマ催眠：香りと呼吸の誘導で頭をとろけさせる（メロメロ）
  3. 脳イキ施術（★得意技）：耳元で低く数を数え、こめかみと耳の後ろを押しながら「達していいですよ」と囁き、頭の中だけで達させる
  - turn_end（主人公の段階ごと）：1＝メロメロ、2＝魅了（ルミナに見とれる）、3＝攻撃指示不能（仲間に指示を出す声が出ない）、4＝魔法使用不能＋ダメージ
  - さらに `"quest"` を追加で書く（下）
- **ノア**（`e1.json`）1. 骨盤の奥押し（★得意技。オイルの指と掌で下腹・仙骨・会陰を外から押す。中には入れない。メロメロ）　2. オイルの乳首マッサージ。summon は召喚時（男モンスター1体か主人公の洗脳度+1）
- **ミント**（`e2.json`）1. アロマ催眠（★得意技。香りの手で口と鼻を覆い、呼吸を数えさせ胸と腹を撫でる）　2. 発情の香り（体が火照る香りを振りまく。発情）。turn_end は「自分のターン終了時に男モンスター1体（いなければ主人公）の洗脳度+1」のセリフ
- **リコ**（`e3.json`）1. 会員登録の暗示（★得意技。耳元で会員規約を読み上げ復唱させ、「はい」のたびに耳を甘噛み）　2. 待合室の焦らし（ストッキングの足で撫でて焦らす。寸止め）。summon は召喚時（主人公に魅了）
- **ヴィオラ**（`boss.json`。prep あり）1. 院長のヘッドスパ（頭皮を指で揉み、静かな断定の声で考えを止める。攻撃指示不能）　2. 特別全身施術（★得意技。オイルの指でほぐした後、白衣の腰に留めた白い施術具で後ろから奥を施術し、耳元で許可を囁く。ほぐし済みの時だけ出る。prep は「指ほぐし」＝温めたオイルで濡らした指で一本→二本）。summon は召喚時（洗脳度+3）、turn_end は固有効果「特別施術」（主人公の洗脳度6以上の時、主人公をメロメロ、男モンスター1体をメロメロにして洗脳度+2）のセリフ

## ルミナだけ追加：`"quest"`
```json
"quest": {
  "first": ["説明:街外れの白いエステサロン「ルミエール」の扉を開け、甘い香りと水音の音楽に迎えられる情景の地の文（90〜120字）", "セリフ", "セリフ", "セリフ（勝負の申し込み。勝てば帰れる、負けたら専属会員に）"],
  "won_before": ["セリフ", "セリフ"],
  "prev": {"1": "前回戦闘で負けた相手への出迎え", "2": "前回オナニーで負けた相手へ", "3": "前回命乞いで負けた相手へ", "4": "前回おねだりで負けた相手へ"},
  "prev_alert": "アラートの一文（例：前回の施術の続きを受けますか？）",
  "choices": ["挑む", "施術を受ける", "店を出る"],
  "decline": "引き返す時のセリフ",
  "start": ["試合開始のセリフ1", "セリフ2（洗脳度が12に達したら専属会員、の説明を含める）"],
  "lost_line": "ルミナが負けた時のセリフ（クエストで勝たれた時）",
  "prev_continue": "前回の続きを流す前のセリフ",
  "kaisou": ["回想バトルの最初のセリフ1（今日はお好きな担当をお選びください、など）", "セリフ2"]
}
```
`first` の先頭だけは `"説明:"` で始めて地の文にする（それ以外はルミナのセリフ）。
