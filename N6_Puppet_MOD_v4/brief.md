# N6 人形師（コード Puppet）敗北シナリオ執筆ブリーフ（v4・2026-09-25）

あなたはベストセラー作家として書く。主人公（プレイヤー。名前なし）が街外れの人形師の屋敷「糸繰り館」でカードバトルに負け、銀の操り糸と暗示で少しずつ「人形」に仕立て直されていく「敗北シナリオ」を書く。

## 絶対条件
- 責め手（人形師と人形たち。全員成人女性）が常に上位。主人公は受け身のみ。**逆転なし**。主人公は挿入しない・責め返さない。
- 責め手は常に服を着ている。責め手自身が自慰したり、受け身になったりしない。
- 暴力・流血・アヘ顔・凌辱的な描写はなし。「甘く、静かに、逃げ道を塞がれていく」支配。命令された姿勢のまま、着せられた服のまま、言わされた台詞のまま快楽に震える。
- **人形たちは成人の人形**。幼さを示す語（少年、少女、ショタ、ロリ、幼い、子ども、女の子、男の子、小さな子 等）は絶対に使わない。
- **後ろに何かを入れる時（人形の芯・指）は、必ずその前に油で濡らした指で一本ずつほぐす描写を入れる**（一本→二本、入口が柔らかくなるまで）。「人形の芯」は象牙色のなめらかな器具（20cm程度）。
- 主人公のペニスを使う自慰は書かない（オナニー負けは下の「オナニーの内容」の自慰から始める）。
- **着せ替え**：人形の服（レースのドレス、手袋、ストッキングなど）を着せられた後は、最後まで着たまま話を進める（脱がさない。責めに必要な部分だけずらす・めくる）。
- 「人形化度」：糸と暗示で「自分は人形」という常識が書き込まれていく度合い。12で完全な人形＝敗北。手首に糸→手足が勝手に動く→自分を人形だと思い始める→意思のない人形、と段階的に進む。

## 構成（1本の合計7,000字以上。セリフ,と説明,の本文だけで数える）
ファイルは3つの部分に分け、**区切りの行 `##PLAY` と `##END` を入れる**（ゲームには入らない印）。
1. **導入（`##PLAY` の前）：400字程度（300〜600字）**。冒頭行は画像行。どう負けたか（経路）、なぜこの責めなのか、どこへ連れて行かれたか。
2. **プレイ描写（`##PLAY` と `##END` の間）：6,000字以上（目標6,500〜7,500字）**。途切れさせず一連のシーンで。責め手の責め中のセリフ、主人公の喘ぎ声、快楽に対する心理描写、体や神経の反応、道具の動き（銀の糸の張りと引き、糸を巻く指、ドレスのレースと留め具、オルゴールの旋律、金の針と縫い目の光、人形の芯の冷たさ、指の本数と角度）を細かく書く。**その責め手の得意技を主役にする**。絶頂は2〜4回（各絶頂の前に `射精` 行を置いてよい。触れずに達するなら置かない）。途中で後日談に飛ばない。
3. **結び（`##END` の後）：600字以内**。責め手の締めのセリフと、その後の短い余韻。
- 弱点付与・GAME OVER・BGMは別処理なので書かない。
- 文章の質：五感（硝子の飾り棚、何百もの人形の視線、蝋燭の灯り、糸の鳴る音、布の擦れる音、濡れた音）、比喩、緩急、責め手ごとの口調の個性。同じ責め手の4本は、場所・時刻・小道具・絶頂の区切り方・結末の印を変えて、読み比べて別物にする。

## 書式（厳守。ゲームのスクリプトとしてそのまま読み込まれる）
1行に1コマンド。使ってよい行は次だけ：
```
画像,#Puppet/Puppet_lose_<経路>_<責め手>.png,1
話者,%ドロテア          （%イト %ネル %リラ %エリス も同様。責め手が喋る前に必ず入れる）
話者,相手プレイヤー    （主人公が喋る前に入れる）
セリフ,本文
説明,本文            （地の文・情景・心の動き）
フラッシュ,ピンク
射精
ウェイト,1
##PLAY
##END
```
- **本文に半角カンマ「,」を絶対に使わない**（全角「、」を使う）。
- 本文に `$ % & # { } < > ;` を使わない。半角の `!` `?` も避け、全角「！」「？」を使う。ハートや音符などの記号は使わない。半角の ( ) も使わず全角（）。改行したい時だけ `\n` を使ってよい（1行2〜3文まで）。
- 1行の本文は長くても120字程度。セリフは「」を付けない。
- 冒頭行は必ず `画像,#Puppet/Puppet_lose_<経路>_<責め手>.png,1`。ほかの画像ファイル名は使わない。
- 空行・コメント・見出し・`@` 行は書かない。`##PLAY` `##END` はそれぞれ1回だけ。

## 経路（どう負けたか）の軸
- **btl（戦闘負け）**：糸と暗示の責めに崩れ、人形化度が満ちて倒れる。その責め手の流儀で人形に仕上げられる。
- **onani（オナニー負け）**：勝負の最中、疼きに耐えられずその責め手の得意技を真似た自慰を始めてしまい、見つかる。自分から手を伸ばした恥が軸。見られる・記録される・管理される。**プレイ描写の最初は、下の「オナニーの内容」の自慰（ペニスは使わない）から始め、途中で責め手が引き取る。**
- **inochi（命乞い負け）**：追い詰めた時、相手が「糸を切ってあげる」などと取引を持ちかけ、手を止めてしまう。それは罠で、情けを代償に糸が増やされ、約束・所有に変えられる。
- **onedari（おねだり負け）**：自分の口で「動かしてください」「着せてください」などと具体的に請う。それが記録され、日課・約束になる。

## オナニーの内容（onani ルートの冒頭。ペニスは使わない）
- ドロテア（操り糸）：見えない糸に引かれているように自分の手を動かし、命じられた順番どおりに乳首と太ももをなぞる。人形の動きを自分で真似てしまう
- イト（乳首の糸結び）：服のほつれ糸を乳首に巻き、きゅっと引いては緩める
- ネル（着せ替え）：着せられたドレスのまま、レースの上から胸と太ももを撫で、留め具の締め付けを確かめる
- リラ（子守唄）：手を使わない。耳に残った子守唄を口ずさみ、旋律に合わせて体が揺れ、触れずに達しかける
- エリス（人形の芯）：油で濡らした指で後ろを一本ずつほぐし、芯を沈められた奥の冷たさを探る
