# N12 乳首開発サロン（コード Salon）敗北シナリオ執筆ブリーフ

サキュバスデュエル（M向けカードゲーム）の個人用MOD。**登場人物は全員20歳以上の成人**。個人利用のみ。
主人公（プレイヤー。名前なし、二十代の小柄で華奢な男の冒険者）がサロンの女性スタッフとのカードバトルに負け、責められて堕ちていく「敗北シナリオ」を書く。

## 絶対条件
- 責め手（女性スタッフ）が常に上位。主人公は受け身のみ。**逆転なし**。主人公は挿入しない・責め返さない。
- 責め手は常に服を着たまま責める。責め手自身が自慰したり、受け身になったりしない。
- 暴力・流血・アヘ顔・凌辱的な描写はなし。色仕掛け・焦らし・言葉責め・管理が中心。優しく丁寧な口調のまま逃げ道をふさいでいく。
- 未成年を連想させる語（少年、ショタ、幼い等）は使わない。

## 世界観
街モルゲンの路地裏にある会員制の「乳首開発サロン ヴェルヴェット」。
カウンセリングから始まり、初回施術、貞操帯での管理、そして乳首だけで果てる体へ。会員証のランクは「カウンセリング会員 → 施術会員 → 鍵預かり会員 → 正式会員」。
- 部屋：受付と待合室（ラベンダーの香り、革のソファ）／カウンセリングルーム（白いテーブル、カルテ）／施術室（白いリクライニングの施術台、柔らかな照明、姿見）／器具室（吸引カップ・クリップ・貞操帯が棚に並ぶ）／支配人室（奥の深紅の部屋、天蓋つきの施術ベッド）／鍵の保管棚（小さな銀の鍵がずらりと並ぶ）
- 貞操帯：股間だけを覆う小さな金属製の檻と、腰に回す細い帯。小さな銀の鍵で開く。鍵はサロンが預かる。貞操帯の中では勃起できず、疼きだけが溜まる。
- 吸引カップ：透明な小さなカップ。ポンプで乳首を吸い上げ、ぷっくり腫れさせる。
- ゲージ「感度」：責められるたびに上がる。24で完成（敗北）。

## 登場人物（口調をはっきり書き分ける）
- **カレン**（29・オーナー）：赤茶のセミロングに緩いカール、琥珀の瞳。黒のタイトなサロンドレスに白い短いジャケット。妖艶で几帳面。落ち着いた営業スマイルの丁寧語。「〜ですね」「〜しましょうね」「カルテに書いておきますね」。何でも記録し、次回の予約を必ず入れる。
- **エマ**（26・乳首担当）：金髪ボブ、青い瞳、白い施術服に薄手の白手袋。テクニシャン。手順を説明しながら責める丁寧口調。「まずは〜。次に〜。はい、ここからが本番です」。指先の技術に誇りを持つ。
- **ココ**（25・舌担当）：ピンクブラウンのツインテール、紫の瞳、淡いピンクの施術服。甘えた小悪魔。からかう甘い口調。「〜だよ♡」「ねぇねぇ」「かわいー」。舌先を見せつける。
- **ルル**（28・器具担当）：紫の長いストレート、灰色の瞳、黒い器具係の制服と黒い手袋。冷静で道具を愛でる。淡々とした説明口調。「〜です」「〜します」「この子（器具）は優秀です」。数値や圧を読み上げる。

- **主人公**：内心の声や短い反応。「っ……」「や、やめ……」→ だんだん「もっと……」と自分から求める。

## 経路（どう負けたか）の軸
- **btl（戦闘負け）**：施術（戦闘中の責め）に崩れて、感度が満ちて倒れる。そのまま施術室へ運ばれる。
- **onani（オナニー負け）**：バトル中、貞操帯の中の疼きに耐えられず自分で触ろうとして（あるいは乳首を自分でいじって）スタッフに見つかる。自分から手を伸ばした恥が軸。見られる・記録される・管理される。
- **inochi（命乞い負け）**：とどめを刺せる場面で「鍵を返してあげる」という言葉に手が止まる。その一瞬の情けを、貞操帯の追加や鍵の契約で返される。
- **onedari（おねだり負け）**：バトル中に自分から「もっと開発して」と具体的に請う。それが記録され、日課・契約になる。

## 構成（1本5,500〜6,500字を目標。最低5,000字。セリフと説明の本文だけで数える）
1. 冒頭：責め手のセリフ2行＋CG表示（下の「画像」行）
2. その経路で負けた経緯の振り返り
3. 場所の移動と情景（部屋を具体的に）
4. 責め手の道具・手法の提示
5. 段階的な責め（抵抗 → 崩れる → 自分から求める）
6. その経路特有の「言わせる・選ばせる・差し出させる」場面
7. **絶頂を2〜4回**（ここに一番文字数を使う。乳首だけで、または貞操帯の中で漏れるように果てる。各絶頂の前に `射精` 行を置いてよい）。絶頂の1回ごとに「カルテの項目」「会員ランク」「鍵の番号」など意味づけを与えて段階を作る。
8. 責め手の締めのセリフ（会員証・鍵・次回予約の授与）
9. 後日談（2日目、3日目…と日常への侵食。日ごとに1段落）
10. 自分からサロンへ戻る場面（責め手の出迎えで締める）
- 弱点付与・GAME OVER・BGMは別処理なので書かない。

## 書式（厳守。ゲームのスクリプトとしてそのまま読み込まれる）
1行に1コマンド。使ってよい行は次だけ：
```
画像,#Salon/Salon_lose_<経路>_<責め手>.png,1
話者,%カレン          （%エマ %ココ %ルル %セラ も同様。責め手が喋る前に必ず入れる）
話者,相手プレイヤー    （主人公が喋る前に入れる）
セリフ,本文
説明,本文            （地の文・情景・心の動き。話者に関係なく出せる）
フラッシュ,ピンク
射精
ウェイト,1
画面色変化,ピンク,1
画面色解除,1
```
- **本文に半角カンマ「,」を絶対に使わない**（全角「、」を使う）。
- 本文に `$ % & # { } < > ;` と半角の `\` 以外のバックスラッシュ表現を使わない。改行したいときだけ `\n` を使ってよい（1行2〜3文まで）。
- 1行の本文は長くても120字程度。セリフは「」を付けない。
- 冒頭行は必ず `画像,#Salon/Salon_lose_<経路>_<責め手>.png,1`。途中で同じ画像行をもう一度入れてもよい。ほかの画像ファイル名は使わない。
- 空行・コメント・見出し・`@` 行は書かない。ファイルにはコマンド行だけ。
