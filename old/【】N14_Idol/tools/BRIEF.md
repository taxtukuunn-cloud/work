# N14「アイドル事務所」敗北シナリオ 執筆ブリーフ

同人カードゲーム「サキュバスデュエル」の個人用MOD（非配布・個人利用のみ）。完全M向け：主人公が負けると、敵の女性たちに一方的に責められて堕とされる。**登場人物は全員20歳以上の成人**。

## 絶対条件
- 責め手（女性）が常に上位。主人公は快楽攻撃をしない・反撃しない・挿入しない。逆転なし。アへ顔や暴力的な凌辱の描写はしない（甘く、逃げ場なく、丁寧に堕とす）。
- 責め手は常に服を着ている（衣装やスーツのまま）。責め手自身が受け身・自慰をすることはない。
- 主人公の一人称は「僕」。二十代の小柄で華奢な青年。カードで戦う冒険者で、街モルゲンで事務所に目をつけられた。
- 物語の軸：デビューを餌に洗脳され、**女装のアイドル**としてステージに立たされる。衣装・メイク・ウィッグ・レッスン・契約・ステージが責めの道具。
- 主人公に与えられる芸名は **「ひより」**（全ルート共通。付けるのはナナ、または事務所）。

## 舞台：芸能事務所「ステラ・プロダクション」（街モルゲンの大通り裏、白い三階建て）
部屋：鏡張りのレッスンスタジオ／衣装室（トルソーと衣装の列）／楽屋（化粧前の電球の鏡、隅に小さな撮影機）／防音のボイストレーニング室と録音ブース／メイクルーム／社長室（黒檀の机、契約書、万年筆）／地下の小劇場（ステージ、客席、照明）。
※ 世界観はファンタジーの街だが、事務所の中は現代的な芸能事務所でよい（撮影機・録音機・照明は魔導具という扱い）。

## 敗北の経路（導入の軸）
- **btl（戦闘負け）**：カードバトルで押し切られ、デビュー度が満ちて崩れる → そのまま「レッスン」に連れていかれる。
- **onani（オナニー負け）**：バトル中、楽屋に控えていた主人公が我慢できず自慰し、それが楽屋の撮影機に録画されて事務所じゅうに共有される。軸は「自分から手を伸ばした恥」「見られる・記録される・管理される」。
- **inochi（命乞い負け）**：とどめを刺す寸前、相手の「デビューさせてあげる」「見逃して」という甘い命乞いに手が止まった。その一瞬の情けが「契約の条件」にされる（「迷った＝同意した」と書類にされる）。
- **onedari（おねだり負け）**：戦闘中に主人公が自分の口で「デビューさせて」と請い、具体的に何をしてほしいか言わされた。その言葉が記録され、日課・約束になる。

## 1本の構成（この順で。字数配分の目安つき）
1. 冒頭：責め手のセリフ2行 → `CG` 行（1回だけ。画像表示の位置）
2. 経緯の振り返り（その経路でどう負けたか）……400字
3. 事務所の部屋への移動と情景 ……400字
4. 責め手の道具・手法の提示 ……300字
5. 段階的な責め（抵抗→崩れる→自分から求める）……1,200字
6. 経路特有の「言わせる・選ばせる・差し出させる」場面 ……600字
7. **絶頂を3回以上（ここに一番字数を使う）** ……1,800字。絶頂のたびに `射精` 行を入れる（ドライオーガズムなど射精しない絶頂は `射精` 行なしでよいが、`射精` 行は合計2回以上）。絶頂1回ごとに「レッスン番号」「衣装の番号」「契約の条項」「録音テイク番号」などの意味づけをして段階を作る。
8. 責め手の締めのセリフ（印・衣装・契約・約束の授与）
9. 後日談：二日目、三日目、五日目、一週間後…と日ごとに1段落。日常が侵食される。
10. 主人公が自分から事務所へ戻る場面 → 責め手の出迎えのセリフで締める。

- **1本 5,500〜6,500字**（`セリフ,` `説明,` の本文のみで数える）。5,200字未満は不可。
- 同じ責め手の4本は、経路ごとに導入・部屋・小道具・決めゼリフ・後日談を変え、使い回しに見えないようにする。

## 出力の書式（厳守）
UTF-8 のテキスト。1行1コマンド。使ってよい行は次だけ：
```
話者,自分          ← 以降のセリフは責め手（そのルートの責め手）
話者,相手          ← 以降のセリフは主人公
セリフ,本文
説明,本文          ← 地の文（主人公の一人称視点のナレーション）
CG                 ← 敗北CGを出す位置。1本に1回だけ
射精               ← 射精の演出
SE,&&怪しい光SE
SE,&&注ぐSE
フラッシュ,ピンク
フラッシュ,白
```
- 本文に **半角カンマ `,` と `$ % & # { } < >` を使わない**（読点は全角「、」）。
- 1つの `セリフ,` `説明,` の中で改行したいときは `\n`（半角バックスラッシュ＋n）を使う。1行の中の `\n` は2つまで。長い地の文は `説明,` を複数行に分ける。
- 主人公の心の声は `セリフ,（……）` の形。
- 責め手以外の人物（ナナが別ルートに顔を出す等）は **セリフを持たせない**。出すなら `説明,` の地の文で描写する。
- 見出し・コメント・空行以外の余計な行を入れない。
