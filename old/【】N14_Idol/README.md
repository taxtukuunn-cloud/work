# N14 アイドル事務所（コード Idol）MOD

芸能事務所「ステラ・プロダクション」。プロデューサーのナナにスカウトされ、デビューを餌にレッスン・衣装・契約で女装アイドル「ひより」に仕立てられていく。登場人物は全員20歳以上。個人利用のみ。

## 入れ方
- `Card/` の中身 → ゲームの `CSV/Card/`
- `EventList/FieldFaces/Idol.txt` → `CSV/EventList/FieldFaces/`（街モルゲンにナナが出る）
- 画像 → Saveと同じ階層の `Picture/Idol/`（`install_images.bat Idol "<ゲーム>\Picture"`）。**画像は未生成（51枚）**。

- ゲージ：`自分プレイヤー.$デビュー度`（0〜24、減らない）。24で即敗北。段階：研修（1〜5）→衣装合わせ（6〜11）→最終調整（12〜17）→デビュー決定（18〜23）。
- デビュー度8以上でHP1以下になった男モンスターは「デビュー済みアイドル」として敵側へ（`コントロール変更,相手,自分所属`）。
- カンナの「契約書」：自ターン終了時、デビュー度12以上なら相手の男モンスター1体をランダムに敵側へ（1試合1回）。

## 敗北シナリオ（28本・各5,500〜6,350字、合計約15.7万字）
- マスターの `@敗北_<経路>_<責め手>` に28本すべて、各モンスターの `@敗北_<経路>` に自分の4本。
- `@敗北後` が `自分プレイヤー.$敗北経路`（1戦闘／2オナニー／3命乞い／4おねだり）×`自分プレイヤー.$最後の責め手`（1〜3ナナの技／4アキ／5サヤ／6レイ／7カンナ）で振り分け。二重再生は `$$Idol_再生済` で防止（`@試合開始` で0に戻す）。
- 共通の結末：主人公は女装アイドル「ひより」としてデビューさせられる。責め手ごとの結末：
  ナナ技1＝レッスンで意思を失いデビュー／技2＝衣装で拘束され着替えられない／技3＝ステージ上で絶頂すると約束／アキ＝姿勢矯正で従順に／サヤ＝暗示の録音で目覚めるたびに従う／レイ＝メイクとウィッグで別人に／カンナ＝専属アイドル契約
- 弱点：戦闘・命乞い・おねだり＝その責めの攻撃タイプ、オナニー＝強制自慰（各50）。
- 保存：`$$Idol_敗北回数` `$$Idol_前回敗北経路` `$$Idol_前回最後の責め手` `$$Idol_オナニー回数`。2回目以降は前回の経路に触れて出迎え、「誘いに乗る」で `@前回続き` → 前回と同じ敗北シナリオへ。
- 読む用：`Idol_敗北シナリオ集_読む用.txt`（ゲームには入れない）

## 企画からの変更点
- 衣装合わせ：企画は装備魔法。安全のため通常魔法（男モンスター1体にメロメロ2ターン）で実装（N3・N8と同じ）。
- 命乞い負けの弱点「命乞いで迷いやすくなる」は実装手段が未確認のため、責めの攻撃タイプ弱点で代用。
- ゲージは減らさない（まとめ資料10章）。レイの年齢はキャラ設定シート（25歳）に合わせた。
- コマンドは公式見本に合わせて `話者,` `画像,` を使用。

## 実機で確認が必要な点
1. マスターのカードでモンスターの敗北シナリオを流すときの `話者生成,%アキ,#Idol/Idol_e1.png,女` → `話者,%アキ`（N8と同じ未確認点）。
2. モンスターの `@敗北後` が発火するか（しなくても、マスターの `@敗北後` が7責め手すべてを振り分ける）。
3. `イベント実行,敗北_…` で別セクションを呼んだあと、呼び出し元に戻って弱点付与・保存が続くか。
4. カンナの `コントロール変更,効果対象,自分所属`（効果の対象を寝返らせる書き方）。止まる場合は case,2 のその行を削除。
5. `@戦闘後` の寝返り（`相手.HP` `相手モンスター.?性別:男`）。
