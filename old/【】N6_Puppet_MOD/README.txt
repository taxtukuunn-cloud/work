N6 人形師（Puppet）MOD
======================
街外れの糸繰り館。人形師ドロテアの銀の糸で、主人公が少しずつ「人形」に仕立て直されていく。
ゲージ：人形化度（0〜24。減らない。24で即敗北）。登場人物は全員20歳以上。個人利用のみ。

■ 入れ方
- Card/ の中身（14ファイル） → ゲームの CSV/Card/
- EventList/FieldFaces/Puppet.txt → CSV/EventList/FieldFaces/
- 画像 → Saveと同じ階層の Picture/Puppet/（install_images.bat Puppet "<ゲーム>\Picture"）
- 街モルゲンにドロテアが出る。

下級1 ×3  Puppet_mons_e1     糸人形イト：四肢の糸引き＝魔法責め／乳首の糸結び＝乳首責め。召喚時 男モンスター1体に攻撃指示不能
下級2 ×3  Puppet_mons_e2     衣装人形ネル：お人形の着せ替え＝魔法責め／関節固定の矯正＝ハグ。命中時 魅了1
下級3 ×3  Puppet_mons_e3     オルゴール人形リラ：子守唄の暗示＝耳責め／旋律の乳首弾き＝乳首責め。自分ターン終了時 人形化度+1

男モンスターはHP1以下になると「新しい人形」として敵側へ（コントロール変更,相手,自分所属）。

■ 企画からの変更点
- ゲージは減らさない（まとめ資料10章）。
- 「人形は動かない」「ネル」の攻撃力低下は、攻撃力変更コマンドが未確認のため 攻撃指示不能／魅了 に置換。
- 操り糸は装備魔法の予定だったが、安全のため通常魔法で実装（+人形化度1）。
- 第一段階の状態異常は、毎ターン攻撃指示不能だと強すぎるため魅了1に変更。

4. @前回続き とフィールドイベントの開始前選択肢。
