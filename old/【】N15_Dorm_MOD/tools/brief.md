# N15「常識改変の社員寮」（コード Dorm）執筆ブリーフ

サキュバスデュエル（M向けカードゲーム）の個人用MOD。**登場人物は全員20歳以上の成人**。フィクション。
主人公（男・成人の冒険者）は常に責められる側。**敵側が常に上位・責め手**。主人公が女性に挿入する・逆転する・敵が受け身になる描写は一切なし。アヘ顔・凌辱（暴力）なし。色仕掛けと「常識のすり替え」で、穏やかに逃げ場をなくしていく作風。

## 世界観
街モルゲンの外れにある、ある商会の社員寮「さくら寮」。和風の木造寮（畳の個室、長い板張りの廊下、大浴場、食堂、玄関の点呼台）。
寮の敷地には**常識改変の結界**が張られていて、中に入った男は「寮の規則」を少しずつ“当たり前”だと感じるようになる。規則の核は
**「男子寮生は女子の制服を着て過ごすのが当たり前」「寮母と先輩の指導には素直に従うのが当たり前」**。
主人公は冒険の依頼（寮の調査／一晩の宿）で寮に入り、カードバトルで抗うが、負けると寮生として取り込まれる。

- 寮の制服（男子寮生用＝女子制服）：白いブラウス、胸元の赤いリボン、紺のプリーツスカート、黒のハイソックス。下着は女物のショーツとキャミソール。夜は薄桃色のネグリジェ。
- 寮生として与えられる名前：**「スズ」**（「スズちゃん」「スズさん」）。序盤は「新人さん」と呼ばれる。
- 共通モチーフ：寮規則の冊子（第〇条）、朝の着付け、朝礼、挨拶の復唱、夜の点呼、身体検査、寮生手帳、名札。**文字の出る小物は画像に出さないが、文章では自由に使ってよい**。
- 常識改変の演出の核：**最初は「おかしい」と思う → 規則を聞かされる → 体が先に従う → 「おかしい」と思う理由が思い出せなくなる → 「当たり前」と自分で言う**。セリフの逆転（「こんなのおかしい」→「当たり前です」）を必ずどこかに入れる。

## 敗北経路（4種）の軸
- **btl 戦闘負け**：規則に崩れる。バトルの責めそのものに耐えきれず、その責め手の流儀で「当たり前」にされる。
- **onani オナニー負け**：個室で我慢できず自慰し、夜の点呼でばれる。「規則違反の自慰」を見られ・記録され・管理される恥が軸。
- **inochi 命乞い負け**：相手の命乞い（「規則ですから」と冷静に諭される）でとどめを刺せず手が止まった一瞬を、「規則違反」として罰される。罰が契約・所有に変わる。
- **onedari おねだり負け**：自分の口で「規則に従わせてください」と請う。欲しいものを具体的に言わされ、それが日課・記録になる。

## 1ルートの構成（5,000〜7,000字。セリフと地の文の本文だけで数える）
1. 冒頭：責め手のセリフ2行＋ `[CG]`
2. その経路で負けた経緯の振り返り（バトルの最後の場面）
3. 場所の移動と情景（寮のどこか：個室・廊下・着付け部屋・点呼台・大浴場・秘書室・寮母室など）
4. 責め手の道具・手法の提示
5. 段階的な責め（抵抗→崩れる→自分から求める）。常識が「おかしい」→「当たり前」へ逆転していく
6. その経路特有の「言わせる・選ばせる・差し出させる」場面
7. **絶頂（2〜4回。ここに一番文字数を使う）**。絶頂ごとに意味づけ（規則の第〇条を身に付けた、点呼の記録に「済」、名札が付け替えられる、など）。絶頂の直後の行に `[絶頂]`
8. 責め手の締めのセリフ（寮生手帳・名札・制服・鍵などの授与）
9. 後日談（2日目、3日目、一週間後…と日常への侵食。日ごとに1段落）
10. 主人公が自分から戻る／自分から規則を口にする場面、責め手の出迎えで締める
11. 最後の行は地の文で「——GAME OVER」

## 書式（厳守。自動変換するので崩さない）
1行＝1要素。次の4種類だけ：
- `サクラ「本文」` のように **話者名＋「本文」**（話者名は サクラ／ハナ／マナ／サキ／ミズキ／主人公 のいずれか。主人公は「主人公」と書く）
- `＊本文` ＝地の文（全角アスタリスクで始める）
- `[CG]` ＝この場面のCGを表示（冒頭に必ず1回。場面が大きく変わるところで2〜3回まで追加可）
- `[絶頂]` ＝絶頂の演出（白フラッシュ）。絶頂の描写の直後に置く
- 空行は可（無視される）

本文の禁止事項：
- **半角カンマ「,」禁止**（全角「、」を使う）。半角の `$ % & # { } < > ; \ /` も禁止。
- 半角英数字は避ける（数字は漢数字か全角）。
- 1要素の本文は**120字以内**（長くなるなら要素を分ける）。改行は自動で入るので本文内に改行記号は書かない。
- 「」の中にさらに「」を入れない（引用は『』）。
- 地の文は主人公視点の三人称寄り（「彼」ではなく「僕」の一人称でもよいが、ルート内で統一）。
