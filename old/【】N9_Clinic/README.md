## 敗北の流れ（2026-09-23 改訂：N12・ロゼッタで実機確認済みの形に変更）
最初の版は、敗北シナリオを別ファイル（`Clinic_lose_*.txt`）にして `@敗北後` から `外部イベント実行` で呼び、画像をイベントの途中で `&` に入れていた。これはN6・N13・N12などで「アイコンと敗北CGが出ない」原因と分かった書き方なので、画像を作る前に次の形へ作り直した。
- **28本はすべてマスター（`Clinic_master.txt`）の `@敗北_<経路>_<責め手>` に集約**。`Clinic_lose_*.txt` は廃止（ゲームに入れない）。
- **再生はフィールドイベントの `バトル開始` の直後**：`if,is敗北,==,true` → `イベント実行,敗北再生`。マスター・モンスターの `@敗北後` は削除。`$$Clinic_再生済` で1回だけ。
- **画像はすべて `@初期設定` の `&` 変数**：敗北CGは `&敗北CG_<経路>_<責め手>`（28個）、話者アイコンは `&立ち絵_master/e1/e2/e3/boss`。
- `@敗北再生` の頭：`BGM,&BGM_敗北` → `背景,&背景` → `画像,&カード画像,1` → `フェードイン,1`。**敗北CGの直後にも `フェードイン,1`**（28か所）。戦闘中の `@オナニー` の画像の後にも `フェードイン,1`。
- 話者：ミヤビは `話者,自分`。アヤ・レン・ミサ・カズハは `話者生成,%アヤ,&立ち絵_e1,女` → `話者,%アヤ`。主人公は `話者,相手プレイヤー`。
- 責め手ID（`$$Clinic_最後の責め手`）：1〜3 ミヤビの技／4 アヤ／5 レン／6 ミサ／7 カズハ。経路（`$$Clinic_敗北経路`・`$$Clinic_確定経路`）：1戦闘／2オナニー／3命乞い／4おねだり。`バトル開始` の前に 1／0 に戻す。オナニー負けは `死亡理由,==,オナニー` でも判定。
- `@おねだり後` で経路を戻すのは `相手プレイヤー.HP,>,0` の時だけ。
- 最後は `ゲームオーバー` ではなく `説明,GAME OVER`（ロゼッタと同じ）。
- 弱点：戦闘・命乞い・おねだり＝その責めの攻撃タイプ、オナニー＝強制自慰（各50）。
- 保存：`$$Clinic_敗北回数` `$$Clinic_前回敗北経路` `$$Clinic_前回最後の責め手` `$$Clinic_オナニー回数` `$$Clinic_命乞い回数`。2回目以降は前回の経路に触れて出迎え、「治療の続きを受ける」で `@前回続き` → 前回と同じ敗北シナリオ。
- `tools/build.py` の `check_images()` が、直接パスの画像・`@初期設定` 外での画像変数の定義・`外部イベント実行` を見つけたらビルドを止める。

## オナニー／命乞い／おねだり負け21本の軸（2026-09-23 追加）
- **オナニー負け**：待合室で自分から手を伸ばした恥が軸。カメラ映像・計測・記録で「自分の手では届かない」ことを体に覚えさせ、処置でしか満たされなくする。
  - m1 映像を見せながら触診→自己処理禁止指示書／m2 12分探した分を12分揉む→我慢タイマー／m3 留置ブジー→毎朝固定が日課／e1 体温計を入れてから触る約束／e2 自分で扱く秒数を計測し「停止」で止まる体に→記録用紙／e3 出口を指で管理→自己射精禁止の処方／boss 自分の指と比べさせて「届かない」を固定
- **命乞い負け**：とどめを刺せなかった迷いを、同意・契約・所有に変えられる。
  - m1 同意書の条項ごとに体で確認印→自分で「無期限」と書く／m2 ひと撫でごとに拒否を聞かれ一度も言えず→治療拒否権放棄書／m3 受け取ったブジーを自分の手で入れる→毎晩報告／e1 担当患者リストバンド＋絶頂の数だけシール／e2 「停止」に従った手→正常値が出るまで検査継続（事実上無期限）／e3 専用の棚と専属調剤／boss 医療判断代理同意書（体の判断を全部委ねる）
- **おねだり負け**：自分の口で言った言葉が記録され、それが予約の言葉になる。
  - m1 触ってほしい場所を一つずつ言わされ、予約時に読み上げ／m2 お願いを録音し処置中に流す→録音を持ち帰る／m3 ブジーの深さを数字で自分で言う／e1 「お尻でお熱はかって」の合言葉を毎朝録音／e2 停止回数を自分で申請し、減らせず増やしてしまう／e3 処方箋を全部自分の言葉で書かせる／boss 希望を録音し、予約時に一語も欠かさず読み上げる（減らす希望は不可）

## 原稿の追加・修正のしかた
- 原稿は `src/lose/<経路>_<責め手>.txt` に置いて `python tools/build.py` を実行するだけ（原稿があれば仮版より優先される）。
- 原稿の書式：`名前：セリフ`（ミヤビ／アヤ／レン／ミサ／カズハ／僕）、それ以外の行は地の文（説明）、`!CG` `!フラッシュ` `!SE` `!SE 激` `!暗転`、`//` はコメント。半角カンマは自動で全角に置き換え、`$ % & # { } < >` はエラーで止まる。
- 経路の軸：オナニー＝待合室で自慰→診察室へ連行（見られる・記録される）／命乞い＝迷いを「治療拒否の撤回」「同意」にされる／おねだり＝治療名と場所を自分の口で言わされ、それが予約の言葉になる。
- 企画どおり e1・e2・e3・boss の onani／onedari は、もう一方の責め（体温計・感度測定・尿道ゼリー・内側からの前立腺刺激）で書く。
- 書いてみた実感：本番原稿は書き上げ時点で4,000字前後になりやすい。絶頂を3段以上・後日談を日ごとに1段落と決めてから書くと一度で届く。
