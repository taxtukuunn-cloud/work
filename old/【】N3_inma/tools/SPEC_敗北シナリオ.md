# N3「男の娘淫魔」(コード Inma) 敗北シナリオ執筆仕様

サキュバスデュエル（M向けカードゲーム）の個人用MOD。主人公（成人男性）がカードバトルに負けた後の敗北イベントを書く。
**登場人物は全員20歳以上の成人。** 完全M向け：責め手（淫魔側）が常に上位で、主人公は一切逆転しない・責め手に挿入しない・快楽攻撃をしない。アヘ顔・痛み・流血・汚物・凌辱的暴力はなし。色仕掛けと甘い支配で堕とす。

## 世界観
深夜の路地で男の娘淫魔リリムに出会い、契約の「淫紋」（下腹部の素肌に浮かぶ、左右対称の炎模様＋上部にハート、ピンク〜紫のグラデーション）を刻まれる。淫紋が育つほど体が「眷属」へ変わっていく。戦闘中は淫紋度（0〜24）が上がり、24で完全に負ける。
舞台：路地の奥の扉から入る「淫魔の館」。月明かりの寝室、紫の灯り、天蓋付きの寝台、甘い香り。上級ヴァルの場面は館の最奥「玉座の間」。

## 主人公
20代の小柄で華奢な青年の冒険者。一人称（地の文・セリフとも）「僕」。地の文（説明）は主人公の一人称視点。戦闘に負けたばかり。最初は抵抗するが、段階的に崩れ、最後は自分から求める。

## 経路（4種）の軸
- **btl（戦闘負け）**：淫紋が疼いて崩れる。責めに屈して、その責め手の流儀で堕とされる。
- **onani（オナニー負け）**：戦闘中、淫紋が疼いて我慢できず自慰してしまい、紋が光って居場所を知らされ、リリムに見られた。自分から手を伸ばした恥が軸。見られる・記録される・管理される。
- **inochi（命乞い負け）**：とどめを刺す直前、リリム（またはその責め手）が「代わりに契約して」と条件を出し、同意して手を止めた隙に淫紋を刻まれた。一瞬の情けが契約・所有に変わる。
- **onedari（おねだり負け）**：自分から「もっと紋を濃くして」と請うてしまった。自分の口で欲しいものを具体的に言わされ、それが記録・日課になる。

## 話者のルール（重要）
- ファイル内で話せるのは **`話者変更,自分`（=その責め手）** と **`話者変更,相手`（=主人公）** の2人だけ。
- m1〜m3 の「自分」はリリム。e1 はナギ、e2 はルカ、e3 はピオ、boss はヴァル。
- それ以外の人物（例：ナギの場面に出てくるリリム）の言葉は `説明,` の中に「」で書く（例：`説明,背後でリリムが「いい顔」と笑った。`）。

## 構成（1本 5,800字前後を目標。セリフ・説明の本文のみで数えて **5,000字以上必須**）
1. 冒頭：責め手のセリフ2行 → `画像表示,#Inma/Inma_lose_<経路>_<責め手>.png,1`
2. その経路で負けた経緯の振り返り（上の「経路の軸」を具体的に）
3. 場所の移動と情景（淫魔の館）
4. 責め手の手法・道具の提示（責め手は常に責める側）
5. 段階的な責め（抵抗→崩れる→自分から求める）
6. その経路特有の「言わせる・選ばせる・差し出させる」場面
7. **絶頂を3回以上**。1回ごとに意味づけ（例：「一つ目の紋」「契約の第一条」「一口目」など）を与え、ここに一番文字数を使う。絶頂の直前に `フラッシュ,ピンク` や `SE,&&怪しい光SE`、射精する絶頂の行の後に `射精` を入れてよい（射精は各ファイル2〜3回まで。ドライ絶頂もあり）
8. 責め手の締めのセリフ（印・約束・契約の授与）
9. 後日談：「二日目」「三日目」「一週間後」…と日常への侵食を1段落ずつ（説明で）
10. 自分から館へ戻る場面 → 責め手の出迎えのセリフで締める（最後の行は責め手のセリフ）

※ GAME OVER 表示・BGM・弱点付与・変数保存は組み立て時に追加するので**書かない**。

## 書式（厳守。守らないとゲームが止まる）
- 使ってよい行は次だけ（1行1命令、行頭にスペース不要）：
  - `話者変更,自分` / `話者変更,相手`
  - `セリフ,本文`
  - `説明,本文`
  - `画像表示,#Inma/Inma_lose_<経路>_<責め手>.png,1`（冒頭の1回だけ）
  - `画像全削除`
  - `フラッシュ,ピンク` / `フラッシュ,白`
  - `SE,&&怪しい光SE` / `SE,&&注ぐSE`
  - `射精`
- 本文に **半角カンマ `,` 禁止**（読点は全角「、」）。本文に `$ % & # { } < >` 禁止。
- 1つのセリフ・説明は長くても120字程度。改行したいときは本文中に `\n`（バックスラッシュ＋n の2文字）を書く。1行に `\n` は2つまで。
- 主人公の心の声は `セリフ,（……）` のように全角括弧で。
- ♡ や ❤ は使ってよい。「…」「――」も可。
- 一つの話者変更の後に、同じ人物のセリフを何行か続けてよい。

## 書き分け
- 同じ責め手の4本は、経路ごとに導入・言わせる場面・後日談を**完全に別の話**にする（一言差分にしない）。
- 4経路の違いの例：btl=紋の疼きに負けて倒れる／onani=自慰を見られた恥と「見せて」「記録」／inochi=「契約書」「条件」「約束の代償」／onedari=自分の言葉で「濃くして」と言わされ、毎晩の日課として言わされ続ける。
- 淫紋の描写（熱、脈打つ、光る、広がる、ハートが濃くなる）を全ルートで効果的に使う。
- 表現は官能的で具体的に。ただし主人公が責め手に挿入する描写・反撃・逆転は絶対に書かない。
