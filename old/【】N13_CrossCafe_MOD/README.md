# N13 女装喫茶のオーナー（コード CrossCafe）MOD

裏通りの女装喫茶「カフェ・ミュゲ」。オーナーのマリアに負けると、エプロン→メイク→フルコーデ→看板娘と、店の女の子に仕立てられていく。
ゲージ：女装度（0〜24。24で敗北。減らない）。登場人物は全員20歳以上。個人利用のみ。

## 入れ方
- `Card/` の中身 → ゲームの `CSV/Card/`
- `EventList/FieldFaces/CrossCafe.txt` → `CSV/EventList/FieldFaces/`（街モルゲンにマリアが出る）
- 画像 → Saveと同じ階層の `Picture/CrossCafe/`（`install_images.bat CrossCafe "<ゲーム>\Picture"`）。**画像は未生成（51枚）**。
- **セリフや画像が出ないとき**：`Card/` は公式ドキュメントどおり `話者,` `画像,` で書いてある。N1・N3・N7と同じ `話者変更,` `画像表示,` の版を `Card_旧書式/` に入れてあるので、動く方を使う（中身は同じ）。

## 敗北シナリオ（28本・各5,000〜5,340字）
- マスターに `@敗北_<経路>_m1〜m3`（12本）、各モンスターに `@敗北_<経路>`（4本ずつ）。
- 誰が最後に責めたかは `自分プレイヤー.$最後の責め手`（1〜3マリアの技／4ユイ／5リン／6ノゾミ／7ミレイ）、経路は `自分プレイヤー.$敗北経路`（1戦闘／2オナニー／3命乞い／4おねだり）で共有。
- `@敗北後` は全カード共通の振り分け。自分の話は `イベント実行`、他のカードの話は `外部イベント実行,Card/…` で呼ぶ。`$$CrossCafe_再生済` で二重再生を防ぐ（マスターとモンスターのどちらの `@敗北後` が呼ばれても1回だけ流れる）。
- 弱点：戦闘・命乞い・おねだり＝最後の責めの攻撃タイプ、オナニー＝強制自慰（各50）。
- 保存：`$$CrossCafe_敗北回数` `$$CrossCafe_前回敗北経路` `$$CrossCafe_前回最後の責め手`。2回目以降は前回の経路に触れて出迎え、「誘いに乗る」で `@前回続き`。
- 読む用：`CrossCafe_敗北シナリオ集_読む用.txt`（ゲームには入れない）

## 企画からの変更点
- 衣装チェンジの「ランダム」は、乱数コマンドが未確認のため順番（メロメロ→発情→攻撃指示不能）にした。対象は相手プレイヤー。
- ウィッグは企画では装備魔法。安全のため通常魔法（対象の男モンスターに魅了2ターン）。
- 閉店後の指導の攻撃指示不能は相手プレイヤーに付与。
- 命乞い負けの弱点「迷いやすくなる」は実装手段が未確認のため、攻撃タイプ弱点で代用。ゲージは減らさない。

## 実機で確認が必要な点
1. `話者,` `画像,`（Card）と `話者変更,` `画像表示,`（Card_旧書式）のどちらで動くか
2. `外部イベント実行,Card/CrossCafe_mons_e1,敗北_btl` でモンスターの話を呼んだときの話者（「自分」がマリアになるか、ユイになるか）
3. モンスターの `@敗北後` が発火するか（どちらでも1回だけ流れるように作ってある）
4. `自分プレイヤー.$最後の責め手` などの共有変数がモンスターから書き換わるか
5. `@戦闘後` の寝返り判定。止まる場合はこのブロックを削除してよい
6. `is前回プレイヤー勝利` と、フィールドイベント中の `@前回続き`
