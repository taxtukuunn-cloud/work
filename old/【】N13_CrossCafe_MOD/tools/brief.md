# N13「女装喫茶のオーナー」（コード CrossCafe）執筆ブリーフ

サキュバスデュエル（完全M向けカードゲーム）の個人用MOD。主人公がカードバトルに負けたあとの「敗北シナリオ」と、戦闘中のセリフを書く。
**登場人物は全員20歳以上の成人**。個人利用のみ。

## 絶対ルール
- 責め手（女性店員）が常に上位。主人公は受け身で、快楽で責め返したり逆転したりしない。主人公は挿入しない。
- 責め手は常に責めるだけ（自慰・受け身・自爆にしない）。暴力・流血・アヘ顔・凌辱的な描写はなし。甘く、優しく、でも逃がさない支配。色仕掛け・言葉責め・焦らしにこだわる。
- 主人公は二十代の青年（冒険者）。一人称「僕」。**「少年」「子ども」など未成年を連想させる語は使わない。**
- 地の文（説明）は主人公の一人称視点。

## 世界観
街モルゲンの裏通りにある女装喫茶「カフェ・ミュゲ」（鈴蘭の意味）。**スタッフ（責め手）は全員女性**。客席で接客するのは、彼女たちが男性客やアルバイトから仕立てた「女装ウェイトレス」たち（全員成人男性）。
オーナーのマリアはカードの腕も立ち、「私に負けたら、うちで働いてもらうわ」とデュエルを挑む。負けた主人公は、エプロン→メイク→フルコーデ→看板娘と、段階的に店の女の子に仕立てられていく。
- 制服：黒のロング丈クラシックなワンピース、白いフリルエプロン、白いヘッドドレス、黒タイツ、ストラップ付きの靴。着付けではコルセット（胸下から腰）を締める。ウィッグは長め。
- 店の決まり：店内では女の子の名前（源氏名）で呼ばれる。語尾や所作を直される。「いらっしゃいませ、お嬢様／ご主人様」。
- ゲージ「女装度」（0〜24）：1〜5エプロン／6〜11メイク／12〜17フルコーデ／18〜23看板娘／24で完成＝敗北。

## 敗北の4経路（どの責め手でも、この「軸」で導入と転換を書く）
- **btl（戦闘負け）**：デュエル中の責めと衣装に耐えきれず崩れた。責め手の技そのものが主役。
- **onani（オナニー負け）**：デュエルの途中、店の**更衣室**で我慢できず自慰してしまい、それが**防犯カメラ**で店員たちに共有された。「見られる・記録される・管理される」恥が軸。
- **inochi（命乞い負け）**：とどめを刺す直前、責め手に「お店を手伝ってくれるなら許してあげる」等と命乞いされ、迷って手が止まった。その一瞬の情けを「お客様対応ができる子」「接客向き」と言い換えられ、研修・契約・所有に変えられる。
- **onedari（おねだり負け）**：デュエル中、自分から「もっと可愛くして」とおねだりしてしまった。自分の口で欲しいものを具体的に言わされ、それが記録され、日課になる。

## 1本の構成（5,000〜6,500字。数えるのはセリフ・説明の本文のみ）
1. 冒頭：責め手のセリフ2行 → 画像表示（指定のファイル名）
2. その経路で負けた経緯の振り返り
3. 場所の移動と情景（各責め手の部屋を使う）
4. 責め手の道具や手法の提示
5. 段階的な責め（抵抗→崩れる→自分から求める）。女装の段階（エプロン→メイク→コルセット→ウィッグ・フルコーデ→源氏名）を責めに絡める
6. その経路特有の「言わせる・選ばせる・差し出させる」場面
7. **絶頂を2〜4回**（ここに一番文字数を使う。1回ごとに意味づけ：「一着目」「一筆目」「一礼目」など）
8. 責め手の締めのセリフ（印・道具・約束の授与。例：名札、合鍵、口紅、コルセットの鍵）
9. 後日談（二日目、三日目、一週間後…と日常への侵食。1日1段落）
10. 自分から店に戻る場面 → 責め手の出迎えのセリフで締める

※GAME OVER表示・弱点付与・セーブはこちらで付けるので書かない。
※**書き始める前に、絶頂の回数と各段階の場面を決めてから書く**。初稿は短くなりがちなので、責めと絶頂を厚く。

## 書式（厳守。これ以外のコマンドは使わない）
1行1コマンド。行頭の空白は不要。
```
話者,自分            ← 責め手がしゃべる
話者,相手            ← 主人公がしゃべる（心の声は（ ）で囲む）
セリフ,本文
説明,本文            ← 地の文（主人公の一人称）
画像,#CrossCafe/CrossCafe_lose_btl_m1.png,1   ← 冒頭で1回だけ。ファイル名は担当表のとおり
フラッシュ,ピンク     ← 絶頂の直前など（ピンク／白）
SE,&&怪しい光SE
射精                 ← 絶頂のたびに
画像全削除           ← 後日談に入る前に1回
```
- 本文は1行60〜120字程度。改行したいときは `\n` と書く（1行に最大1回まで）。
- **本文に半角カンマ「,」禁止**（全角「、」を使う）。**本文に `$ % & # { } < >` 禁止**。半角の ! ? も避け、全角 ！？ を使う。
- `セリフ` の前には必ずその話者の `話者,自分` か `話者,相手` を置く（話者が変わるときだけでよい）。
- 1ファイルに `射精` は2回以上。
