# N11 スライム調教（コード Slime）MOD

街外れの古井戸の底に続く「翠の洞」。スライムの女王ジュレアと巣のスライムたちにぬるぬるに包まれ、ゼリーで体の内側まで調教される。
ゲージ：粘液度（0〜24。24で敗北。減らない）。登場人物は全員20歳以上。個人利用のみ。

## 入れ方
- `Card/` の中身 → ゲームの `CSV/Card/`
- `EventList/FieldFaces/Slime.txt` → `CSV/EventList/FieldFaces/`（街モルゲンにジュレアが出る）
- 画像 → Saveフォルダと同じ階層の `Picture/Slime/`（`install_images.bat Slime "<ゲーム>\Picture"`）。**画像はまだ作っていない**（51枚）。

- **分裂**（ヴィスカ）：戦闘で破壊された時、1試合に1度だけ蘇る。蘇るとHPが半分になり、粘液度+2。効果ダメージで倒した場合は蘇らない。
  - 仕組み：`@戦闘破壊` で戦闘による破壊を記録 → 死亡時の強制誘発（墓地ゾーン）で `蘇生` → 蘇ったカードの「場に出た時」の効果で1500ダメージと+2。
- **寝返り**：粘液度8以上で攻撃を受けた男モンスター、またはHP1以下になった男モンスターは「スライム調教済み」として敵側へ移る（`コントロール変更,相手,自分所属`。企画どおり「または」で判定）。
- 粘液度が24になると、攻撃ではその場で、魔法ではマスターのターン終了時に敗北する。

## 敗北シナリオ（28本、各5,250〜5,380字。合計約14.9万字）
- ジュレアの技3種 × 4経路の12本はマスターに、モンスターの4本ずつは各モンスターの `@敗北_<経路>` に入っている。
- `@敗北後` は `自分プレイヤー.$敗北経路`（1戦闘／2オナニー／3命乞い／4おねだり）と `自分プレイヤー.$最後の責め手`（1〜3ジュレアの技／4アオ／5アカ／6モモ／7ヴィスカ）でシナリオを選ぶ。
  - マスターの `@敗北後` からモンスターのシナリオを呼ぶときは `外部イベント実行` を使う。モンスターの `@敗北後` が呼ばれた場合はそのまま流す。
  - 同じシナリオが2回流れないよう、`自分プレイヤー.$再生済` で止めている。
- 弱点：戦闘・命乞い・おねだりで負けた場合はそのシナリオの責めの攻撃タイプ、オナニーで負けた場合は強制自慰（いずれも50）。
- 保存する変数：`$$Slime_敗北回数` `$$Slime_前回敗北経路` `$$Slime_前回最後の責め手` `$$Slime_オナニー回数`
  - 2回目以降は、前回の負け方に触れて出迎える。「誘いに乗る」を選ぶと `@前回続き` が流れ、敗北扱いになる。
- 全シナリオを読み物としてまとめたもの：`Slime_敗北シナリオ集_読む用.txt`（ゲームには入れない）

## 企画からの変更点
- 名前が未定だったキャラに名前を付けた：マスター＝ジュレア、上級＝ヴィスカ。
- アオの口調は、企画の「たどたどしい口調」から「明るく人懐こい大人のお姉さんの口調」に変えた（幼く見えないようにするため）。
- ゲージは減らさない（まとめ資料10章の方針に合わせた）。
- コマンドは公式ドキュメントに合わせて `話者,` と `画像,` を使っている。

## 実機で確認が必要な点
1. `@戦闘破壊` と、死亡時の強制誘発（`効果場所設定,3,墓地ゾーン`）→ `蘇生,自分,自分所属` の順番と動き。分裂しない場合も、それ以外の処理には影響しない。
2. `外部イベント実行,Card/Slime_mons_e1,敗北_btl` でモンスターのシナリオを流したとき、話者の立ち絵が誰になるか。
3. モンスターの `@敗北後` が発火するか。発火しなくても、マスター側で7人分すべて振り分けられる。
4. `自分プレイヤー.$〜` の値がモンスター・魔法から正しく積み上がるか（N1・N7と同じ確認事項）。
5. `@戦闘後` の寝返り。止まる場合はこのブロックを削除してよい。
