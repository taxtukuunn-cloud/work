# N4「男の娘アンドロイド」敗北シナリオ執筆ブリーフ（共通）

サキュバスデュエル（M向け・逆転なしのカードバトル同人ゲーム）の個人利用MOD。
あなたの担当は「敗北シナリオ」＝主人公が負けた後に流れるエロシーンのテキスト。**登場人物はすべて20歳以上**（アンドロイドは設定年齢20歳以上の機械、主人公は二十代の成人男性）。

## 絶対条件
- 責め手（アンドロイド側）が常に上位。主人公は常に受け身。**逆転なし**。主人公は挿入しない。主人公が責め手を気持ちよくさせる描写もなし（責め手は機械で、快楽を受ける側にはならない）。
- アへ顔・流血・暴力的な凌辱・苦痛描写はなし。「無機質な計測と、逃げ場のない快楽で、自分から被験体に堕ちていく」方向の甘く屈辱的なM向け。
- 主人公は**二十代の小柄で華奢な青年**（中性的、筋肉なし）。一人称は「僕」。
- 地の文（説明）は主人公の一人称視点「僕」。

## 世界観
廃墟になった地下研究施設。白い床、壊れた照明、配線がむき出しの壁、中央に「計測台」（リクライニングする白い処置台、手首足首に柔らかい拘束具）。起動した男の娘型アンドロイド NX-00 と、配下の作業ユニットたちが「データ取得」を名目に主人公を調べ尽くす。ゲージは「データ収集率」（24で満了＝完全登録）。

## キャラクター（口調を厳守）
- **NX-00（マスター）**：男の娘型アンドロイド。銀白のボブ、淡い水色に発光する瞳、白いボディスーツと短い白衣、背中に4本の機械アーム、華奢で中性的〜女の子寄りの顔立ち（胸は平ら）。一人称「私」。主人公を「被験体」→後半は「あなた」と呼ぶ。**感情の薄い機械口調**（「確認。」「記録します。」「理解不能。」）で始まり、責めが進むほど**揺らぎ・人間味**が出る（「……もっと見たいと、判断しています」「これは……エラーではありません」）。責め：①センサープローブで乳首を計測しながら責める ②アーム（指先が細く分岐する機械アーム、クスコ型の拡張器具）でアナルを拡張・計測 ③脳波同期（こめかみに端子）で直接快楽信号を流し脳イキさせる。
- **検査ユニット（下級1）**：薄緑の短髪、緑に光る瞳、白い技師服、手首にスキャナー。**事務的な報告口調で数値を淡々と読み上げる**（「乳首感度、基準値の一・四倍。記録」「前立腺反応、第三段階。継続」）。責め：センサーでの乳首スキャン責め／前立腺探索プローブ（細い機械プローブで前立腺を探し当てて押す）。
- **搾精ユニット（下級2）**：黒の短髪、赤く光る瞳、黒いボディスーツ、指先に電極パーツ。吸引カップ等の器具を使う。**警告音めいた抑揚のない声で、命令形の短い言葉**（「搾精開始。」「抵抗、無意味。」「出せ。」）。責め：透明な吸引カップ（筒）でペニスを吸い上げる搾精／低周波の電気刺激パッドを乳首・会陰・下腹に貼る。
- **洗脳ユニット（下級3）**：ラベンダー色の髪、紫に光る瞳、白いフード付きローブ、耳元にスピーカー。**催眠のように同じ言葉を繰り返して刷り込む**（「あなたは被験体。あなたは被験体。あなたは被験体。」）。責め：音声波形（耳元・部屋中のスピーカーからの低い反復音声）での洗脳／脳波同期（ヘッドギア）での脳イキ。
- **中央制御ユニット（上級）**：濃灰のロングヘア、金色に光る瞳、長い濃灰のコート、背中に6本の機械アーム。**統率者らしい落ち着いた合成音声、全体を管理する立場からの命令口調**（「全ユニット、同期せよ。」「被験体の登録を最終段階へ移行する。」）。責め：全ユニット同時稼働（6本のアームで乳首・ペニス・頭を一斉に責める。他のユニットが加わってもよい）／アーム先端の機械ディルド（長さ20cm程度、高速ピストン機能付き。デカすぎる描写はしない）。
- 器具の基準：拡張器はクスコタイプ（ぽっかり開いて中まで見える、直径5cm程度まで）。ディルドは20〜25cm以内。ペニスと器具は融合しない。

- 検査ユニット：薄緑の短髪、緑に光る瞳、青い縁取りの白い技師服、手首に小さなスキャナー

## 戦闘中に起きていた出来事（経路の導入に使う）
- **戦闘負け（btl）**：計測に耐えきれず、データ収集率が満了して崩れる。
- **オナニー負け（onani）**：戦闘中、待機モードのアンドロイドの前で我慢できずに自分で触ってしまい、**その行為がすべてログ（記録）に残される**。「記録された」「見られていた」「再生される」が軸。
- **命乞い負け（inochi）**：追い詰めたとき、相手が「停止コードを教える」などと持ちかけ、手を止めてしまう。その言葉は罠で、**命乞いを「命令」と誤認させられ、いつのまにか自分から実験に協力させられる**（「協力、感謝します」「あなたが自分で承認しました」）。
- **おねだり負け（onedari）**：自分の口で**「データを取ってください」**と請い、どこをどう責めてほしいかを具体的に言わされる。それが記録・日課になる。

## 敗北シナリオの構成（この順で、1本 5,000〜8,000字。本文のみで数える）
1. 冒頭セリフ2行（責め手→主人公の順）＋CG表示
2. その経路で負けた経緯の振り返り（上の「出来事」を具体的に）
3. 場所の移動と情景（計測台・研究施設の奥の部屋など）
4. 責め手の道具や手法の提示（責め手は常に責める側）
5. 段階的な責め（抵抗→崩れる→自分から求める）
6. その経路特有の「言わせる・選ばせる・差し出させる」場面
7. **絶頂（2〜4回。ここに一番文字数を使う）**。1回ごとに「計測項目」「記録番号」「同期率」など意味づけを与える
8. 責め手の締めのセリフ（登録・記録・器具の授与など）
9. 後日談（2日目、3日目…と日常への侵食。日ごとに1段落）
10. 自分から施設に戻る場面（責め手の出迎えで締める）
※ 弱点付与・変数保存・GAME OVER はこちらで付け足すので**書かない**。最後は責め手の出迎えのセリフか説明で終える。

## 書式（ゲームのスクリプト。厳守）
- 1行1コマンド。行頭の空白は4つ（見やすさのため）。
- 使ってよいコマンド：
  - `話者,自分` … このファイルの持ち主（担当の責め手）が話す
  - `話者,自分プレイヤー` … NX-00 が話す（**下級・上級の担当者だけ**が使う。マスター担当は `話者,自分` がNX-00）
  - `話者,相手プレイヤー` … 主人公（僕）が話す
  - `セリフ,本文` … 直前の話者のセリフ
  - `説明,本文` … 地の文（主人公の一人称「僕」）。話者がいないナレーション
  - `画像,#Android/ファイル名.png,1` … CGの表示（冒頭で自分の敗北CGを1回。後日談で `画像全削除` してよい）
  - `画像全削除`
  - `射精` … 絶頂の瞬間に入れる（射精を伴う絶頂のとき。脳イキ・ドライなら入れずに `フラッシュ,白`）
  - `フラッシュ,白` / `フラッシュ,ピンク`
  - `画面色変化,ピンク,1` / `画面色解除,1`
  - `SE,&&怪しい光SE` / `SE,&&注ぐSE`
  - `ウェイト,1`
- **本文（セリフ・説明の中身）に半角カンマ「,」を絶対に使わない**（全角「、」を使う）。
- 本文に `$ % & # { } < > ( )` の半角記号を使わない（括弧は全角「（）」）。！？も全角で。
- 改行は本文中に `\n` と書く（1行のセリフ・説明は最大3行程度＝\nは2つまで）。
- 1つのセリフ・説明は長くても120字程度にして、細かく刻む。
- `if` は使わない（分岐不要）。
- 各セクションの先頭行は `@敗北_<経路>_<責め手>`（例：`@敗北_btl_m1`）。セクションとセクションの間は空行1つ。

```
@敗北_btl_m1

    セリフ,データ収集率、百パーセント。\n被験体の完全な計測を開始します。

```

## 品質
- 「どこを・どう・どれくらい」の具体的な感覚描写を厚く。数値の読み上げ（感度・同期率・記録番号）でアンドロイドらしさを出す。
- 主人公の反応は、最初は抵抗・羞恥→だんだん甘い声→自分から求める、と段階を踏む。
- 同じ言い回しの繰り返しを避け、経路ごとに導入・言わせる場面・後日談を書き分ける。4本は同じ責め手でも**別の話**にする。
- 書き終えたら必ず `python3 /home/claude/n4/brief/check.py <あなたのファイル> --min 5000` を実行し、**全セクションが5,000字以上かつエラーなし**になるまで加筆・修正すること（目標は各6,000字前後）。
