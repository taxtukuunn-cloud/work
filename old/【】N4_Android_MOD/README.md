# N4 男の娘アンドロイド（コード：Android）MOD

廃墟の研究施設で起動した男の娘型アンドロイド NX-00（人肌の合成皮膚・背中に機械アーム）と配下のユニットに「データ取得」の名目で調べ尽くされるMOD。ゲージは「データ収集率」（0〜24、24で即敗北）。

## 入れ方
1. `CSV/Card/` の中身 → ゲームの `CSV/Card/`
2. `CSV/EventList/FieldFaces/Android.txt` → ゲームの `CSV/EventList/FieldFaces/`
3. 画像 → Save と同じ階層の `Picture/Android/`（install_images.bat を使う。画像がないと処理が止まる可能性あり）

## カード
| ファイル | 名前 | 技（攻撃タイプ） | 効果 |
|---|---|---|---|
| Android_master | NX-00 | センサープローブ計測（乳首責め）／アーム拡張計測（本番）／脳波同期（魔法責め） | 攻撃ごとに収集率+2 |
| Android_mons_e1 | 検査ユニット | 乳首スキャン（乳首責め）／前立腺探索プローブ（本番） | 召喚時：収集率+1、魔法使用不能 |
| Android_mons_e2 | 搾精ユニット | 吸引搾精（触手コキ）／低周波電気刺激（魔法責め） | 自分ターン終了時：100ダメージ、収集率12以上で攻撃指示不能 |
| Android_mons_e3 | 洗脳ユニット | 音声波形（耳責め）／脳波同期（魔法責め） | 召喚時：男モンスター1体に魅了 |
| Android_mons_boss | 中央制御ユニット | 全ユニット同時稼働（触手）／高速ピストン（本番） | 召喚時：収集率+3。【全ユニット同期】ターン終了時に下級1体につき+1（最大+3） |
| Android_magic_1〜5 | データスキャン／システム介入（罠）／拘束フィールド（永続）／予備電源（サーチ）／洗脳プログラム | | |

- 収集率の4段階（1〜5／6〜11／12〜17／18〜23）で、敵のセリフ・主人公の反応・追加効果が変わる。
- 収集率8以上で攻撃を受けた男モンスターは「登録済み被験体」として敵側へ移る（`コントロール変更`）。
- 収集率24到達：攻撃時はその場で、召喚時効果・魔法ではマスターのターン終了時に即敗北。

## 敗北シナリオ（28本・各5,300〜5,900字）
各カードの中に `@敗北_<経路>_<責め手>` として入っている。`@敗北後` が経路（戦闘／オナニー／命乞い／おねだり）と最後の技から振り分け、終わったあとに弱点付与・記録保存・GAME OVER を行う。

| 経路 | 弱点 |
|---|---|
| 戦闘負け | 敗北時の責めの攻撃タイプ |
| オナニー負け | 強制自慰 |
| 命乞い負け | 責めの攻撃タイプ＋次回から命乞いの選択肢が時間制限つきになる（負けるほど短く） |
| おねだり負け | 責めの攻撃タイプ |

保存する変数：`$$Android_敗北回数` `$$Android_前回敗北経路`（1〜4） `$$Android_前回最後の責め手`（1〜3=NX-00の技、4=検査、5=搾精、6=洗脳、7=中央制御） `$$Android_命乞い弱点`

## 必要な画像（Picture/Android/）
立ち絵：Android_master / e1 / e2 / e3 / boss、背景：Android_bg、技：Android_atk_m1〜m3 / atk_e1 / e2 / e3 / boss、魔法：Android_magic_1〜5、特殊：Android_inochigoi / onanie / onedari、敗北：Android_lose_<btl|onani|inochi|onedari>_<m1|m2|m3|e1|e2|e3|boss>（28枚）

## 書き方の注意（N1・N7と違う点）
公式「サキュバスデュエルMODドキュメント」と見本の `kuruMOD_TSuccu_master.txt` に合わせ、話者は **`話者,〜`**、画像は **`画像,〜`** で書いている（まとめ資料の `話者変更` `画像表示` は公式のコマンド一覧にない）。

## 実機で確認が必要な点
1. `@前回続き` で下級・上級の敗北シナリオを再生するときは `外部イベント実行,Card/Android_mons_e1,…` を使っている。このとき `話者,自分` がユニットではなくNX-00になる可能性がある。
2. `コントロール変更,相手,自分所属` で、男モンスターが敵側へ移るか。
3. モンスターがとどめを刺したとき、そのモンスターの `@敗北後` が呼ばれるか。
4. `時限選択肢` が時間切れになったとき「迷う」側へ進むか。

## tools/
- `gen.py`：カード一式を生成する（敗北シナリオは `tools/lose/*.txt` から読み込む）
- `check.py`：構文チェックと字数カウント（`python3 check.py <txt> --min 5000`）
- `BRIEF.md`：敗北シナリオの執筆ルール（キャラの口調・構成・書式）
