# N7 淫紋の神官 MOD 一式（試作・実機未検証）

## 2026-09-22 追記5：攻撃でゲージが増えない場合がある
- おねだりで固定した攻撃の種類が別のカードの技にない場合などは、どの技にも当てはまらずゲージが増えなかった
- どの技にも当てはまらなかった攻撃は、@戦闘 の最後で +1 して表示する（24到達でその場で敗北）


## 2026-09-22 追記4：マスターの技名が出ない
- `技名表示` の後に `話者変更` があると技名が消える。N7マスターだけ各技の中で「技名表示 → 技CG → 話者変更,自分」の順だったので、「話者変更 → 技名表示 → 技CG → セリフ」に修正


## 2026-09-22 追記3：if と else の書式
- `if` の後は必ず `{ … }` で囲む（波括弧なしの1行 if は公式の書式ではなく、そこで処理が止まる可能性が高い）→ 240か所を修正
- `else` は `}else{` を1行で書く（`}` `else` `{` を別の行に分けない）


## 2026-09-22 追記2：ゲージの持たせ方
- ゲージ（指名度・淫紋度）は、敵マスターのカード変数 `自分プレイヤー.$指名度` に持たせる（既存MODと同じ書き方）。モンスター・魔法からも `自分プレイヤー.$指名度,+=,N` で同じ値を増やす
- ゲージは減らさない（マスターのターン終了時の-1を削除）
- 24に達したら、攻撃時はその場で、それ以外はマスターのターン終了時に敗北


## 2026-09-22 追記：ゲージが溜まらない問題
- マスターの `@初期設定` にゲージを0に戻す行が残っていた（`@初期設定` はカードの能力値を読み込むたびに実行されるため、戦闘中も0に戻っていた可能性が高い）→ 削除。0に戻すのは戦闘開始前と `@試合開始` だけ
- ゲージが増減するたびに「（指名度 8／24）」のように現在値を表示するようにした


## 入れる場所（公式ドキュメントに合わせて修正）
- `Card/` の中身 → ゲームの `CSV/Card/` に入れる
- `EventList/FieldFaces/<コード>.txt` → ゲームの `CSV/EventList/FieldFaces/` に入れる（モルゲンの街にマスターが表示される）
- `Picture/<コード>/` → ゲームの **Saveフォルダと同じ階層** にある `Picture` フォルダの中に入れる（`Picture/Host/Host_master.png` のようになる）
- 以前の版の `Eventlist/<コード>.txt` は書式が違っていたので削除してください

## 2026-09-22 の修正（公式MODドキュメントに合わせた）
- 攻撃タイプをゲームにある名前（キス・乳首責め・耳責め・本番・魔法責め・ハグ）にした。画面の技名は「技名表示」で元の名前を出す
- 攻撃タイプの変更を `@戦闘` の先頭に移した（`@攻撃宣言` はマスター専用で、モンスターでは呼ばれないため）
- 攻撃時は「技名表示 → 技CG → 責め手のセリフ → 主人公の反応（ゲージの4段階）」の順
- モンスターの召喚時・ターン終了時の効果は、効果の仕組み（場に出た時・エンドフェイズ開始時）で動かす
- ゲージは `$$<コード>_<名前>` にしてファイル間で共有（`$` はそのファイルの中でしか使えないため）。戦闘開始時に0に戻す

## カードの書式（既存MODで確認済み・2026-09-22修正）
- 各カードの `@初期設定` に、`&カード名`・`&カード画像,#<コード>/<ファイル>.png`・`レベル設定`・`攻撃力設定`・`最大HP設定`・`属性設定`・`タイプ設定`・`性別設定`・`レアリティ設定`・`攻撃エフェクト設定`・`効果設定,1,explain,効果説明`・`効果設定,0,explain,フレーバー` を入れた
- 画像はすべて `#<コード>/<ファイル>.png`（Pictureフォルダ内のMODフォルダ）で参照する。`&&〜` は本編に内蔵された素材を指す書き方なので、MODの画像には使わない
- BGMは本編の `&&戦闘BGM` / `&&敗北BGM`、演出は本編にある `&&キスエフェクト` / `&&セクシーエフェクト` / `&&怪しい光SE` に統一
- 魔法・罠は `タイプ設定,通常魔法 / 永続魔法 / 通常罠`、`効果設定,1,play,説明`（罠は `強制誘発`）、`@効果` は `switch,効果ID` → `case,1 { … }` の形
- 罠の攻撃宣言時の発動は `誘発効果設定,1,onAttack` ＋ `効果条件設定,1,トリガー能動カード.所属,!=,自分所属`
- 永続魔法の毎ターン処理は `効果設定,2,forceTrigger,…` ＋ `誘発効果設定,2,エンドフェイズ開始時`、自壊は `効果破壊,自分`
- 街バトル用に、使っている全場面に `@戦闘_街バトル` → `イベント実行,戦闘` のような受け口を追加（既存MODと同じ形）

## 実機で確認が必要な点
1. `$淫紋度` がカード間で共有されるか（下級・上級・魔法から加算している）。共有されない場合は `$$` 変数か別方式に変更する
2. 魔法・罠カードのカード属性（種別・コスト・発動タイミング）の定義場所（CSV側）。スクリプトは `@効果` のみ記述
3. 罠の「攻撃宣言時に発動」の書き方（現状は `@効果` のみ）
4. `状態異常付与,相手,魔法使用不能,1` の末尾ターン数指定
5. `@ターン終了宣言` の状態異常付与が主人公側の男モンスターに向くか
6. `@前回続き` を `イベント実行,前回続き` で呼べるか、`@フィールドイベント` 内の選択肢で開始前に分岐できるか
7. `@敗北後` がマスター以外（モンスターカード）でも発火するか
8. `話者変更,自分プレイヤー` で魔法カードのセリフが神官の声になるか
9. `効果除外,自分`（聖水の自壊）の書き方
10. `Eventlist/Inmon.txt` の書式
11. 画像名 `&&Inmon_lose_*` などの参照形式（`&&` はファイル直接参照の想定）

エラーが出たら、その行とメッセージを貼ってもらえれば修正します。
