# N10 Lab 敗北シナリオ 執筆ブリーフ

## 書式
- 1ルート＝ `@敗北_<経路>_<責め手>` の1セクション。`scenarios/<責め手>.txt` に4本ずつ書く。
- 使う行：`話者,自分`（シオリ）／`話者,%ミナセ` `%クロエ` `%ハク` `%LX01`／`話者,相手`（主人公）／`セリフ,` `説明,` `射精` `画像,&敗北CG_<経路>_<責め手>,1`
- 最後の行は `主人公攻撃タイプ弱点付与,<攻撃タイプ>,50`（onani は 強制自慰）。
- 本文に半角カンマ・`$ % & # { } < >` を使わない。セリフと説明の本文だけで5,000字以上。

## 人物
- 主人公：一人称「僕」。二十代・小柄で華奢。抵抗→崩れる→自分から求める。
- シオリ（31）：銀髪・赤い瞳・白衣。冷徹、数字で語る。主人公を「きみ」。被験体番号 L10の001。
- ミナセ：報告口調「〜します。記録します」。数値の読み上げ。
- クロエ：一定の案内口調「〜してください」。拘束と誘導音声。
- ハク：楽しげな実況「おっ、いいねえ」。検体番号を付ける。
- LX-01：カタカナ混じりの合成音声。主人公を「部品」扱い。
- 責め手は常に責める側。逆転なし。主人公は挿入しない。

## 構成（5章の型）
冒頭セリフ2行＋CG → 経緯の振り返り → 場所の移動 → 道具・手法の提示 → 段階的な責め → 経路特有の「言わせる・選ばせる・差し出させる」 → 絶頂3〜4回（各回に条件名などの意味づけ）→ 締めのセリフと持ち帰らせる物 → 後日談（2日目〜6日目を1段落ずつ）→ 自分から戻り、責め手が出迎える。

## ルートの軸
- btl：装置に崩れる／onani：待機室で自慰しモニターに映される／inochi：「協力すれば解放する」を信じて手を止め、協力＝被験体になること／onedari：「実験してください」を自分で言い、録音される。

## 結末
m2 拡張が完了する／m3 前立腺の反応が固定される（電子音で反応）／e1 データで責められ続ける／e2 拘束具で管理される／e3 検体番号を与えられる／boss 試作機に組み込まれる。

## 弱点
m1 乳首責め／m2 本番／m3 魔法責め／e1 乳首責め（onedariは手コキ）／e2 魔法責め（onedariは耳責め）／e3 本番（onedariは魔法責め）／boss 触手（onedariは触手コキ）／onani はすべて強制自慰。

## 字数のコツ
初稿は3,000字前後になりやすい。書く前に絶頂の段数と各段の場面を決め、責めと絶頂を最も厚く。後日談は日ごとに1段落。
