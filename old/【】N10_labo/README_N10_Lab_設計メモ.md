## 企画からの変更点
- **大型機「自動運転」**：企画の「破壊時に開発度−3」は、ゲージを減らさない方針と矛盾するため削除。破壊すると自動運転（毎ターン+1・攻撃力+300）が止まる、を対処法にした。破壊時は停止のセリフだけが出る。
- **第一段階の「魔法使用不能（弱）」**：確率処理のコマンドが未確認のため、マスターのターン終了時には付けない。代わりにミナセ召喚時・大型機召喚時・電源遮断で付与。
- **計測装置**：企画は装備魔法。N8と同じく、安全のため通常魔法（男モンスター1体に寸止め2ターン）で実装。
- **命乞い負けの弱点「命乞いで迷いやすくなる」**：実装手段が未確認のため、N8と同じく責めの攻撃タイプ弱点で代用。

## 敗北シナリオの仕組み
- マスターのカードに28本すべてを `@敗北_<経路>_<責め手>` として持つ。
- `@敗北処理` → `@敗北再生` が `$$Lab_敗北経路` `$$Lab_最後の責め手` で振り分け、前回分として `$$Lab_前回…` に保存。
- 経路：1戦闘／2オナニー／3命乞い／4おねだり。責め手：1〜3シオリの技／4ミナセ／5クロエ／6ハク／7LX-01。
- 弱点：戦闘・命乞い・おねだり＝その責めの攻撃タイプ、オナニー＝強制自慰（各50）。
- 2回目以降は前回の経路に触れて出迎え、「実験の続きを受ける」で `@前回続き` → 前回と同じ敗北シナリオへ。
