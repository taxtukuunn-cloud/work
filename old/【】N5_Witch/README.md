# N5 魔女の薬屋（Witch）MOD

森の奥の薬屋「翠の瓶」。魔女ミルティの薬と衣装で、主人公の体が少しずつ男の娘へ変わっていく。
ゲージ：変化度（0〜24。24で敗北）。登場人物は全員20歳以上。個人利用のみ。

## 入れ方
- `Card/` の中身 → ゲームの `CSV/Card/`
- `EventList/FieldFaces/Witch.txt` → `CSV/EventList/FieldFaces/`
- 画像 → Saveと同じ階層の `Picture/Witch/`（install_images.bat を使う）
- 街モルゲンにミルティが出る。

## 企画からの変更点
- オルガ固有効果：企画は「男モンスター全体の攻撃力を段階×100下げる」だったが、攻撃力を下げるコマンドが未確認のため「変化度12以上の時、自分ターン終了時に男モンスター全体へメロメロ2ターン（1試合1回）」に置換。
- ドールの「次のターン攻撃力低下」も同じ理由でメロメロ1ターンに置換。
- 命乞い負けの弱点「命乞いで迷いやすくなる」は実装手段がないため、責め技の攻撃タイプ弱点で代用。
- ゲージは減らさない（まとめ資料10章の方針）。

## 実機で確認が必要な点
1. `@戦闘後` の寝返り判定（`相手.isMonster` `相手.性別` の書き方と `コントロール変更,相手,自分所属`）。動かない・止まる場合はこのブロックを削除してよい。
2. モンスターの `@敗北後` が発火するか（しない場合もマスターの `@敗北後` が $最後の責め手 で7責め手すべてに振り分ける）。
3. `外部イベント実行,Card/Witch_lose_…,イベント` の中で `話者変更,自分／自分プレイヤー／相手` が期待どおりの人物になるか。
4. `@前回続き` とフィールドイベントの開始前選択肢。
5. 魔法の効果でゲージが24に達した場合、敗北シーンは最後に攻撃した責め手のものになる。

## v2 の変更（敗北時にアイコン・画像が出ない問題の対策。N4・N12・N11 で実機確認済みの形）
- 敗北シナリオ28本を別ファイル（Witch_lose_*.txt）からマスターの `@敗北_…` に移した。**旧版の Witch_lose_*.txt はもう使わない**（残っていても動作に影響はないが、削除してよい）。
- 敗北の再生は、フィールドイベントの `バトル開始` 直後（`if,is敗北,==,true`）とマスターの `@敗北後` の両方から `@敗北処理` を呼ぶ。`$$Witch_再生済` で1回だけ流す。モンスターの `@敗北後` はマスターへ渡す（`外部カードイベント実行,敗北後,自分プレイヤー`）。
- 最後の責め手・負け方は `$$Witch_最後の責め手`・`$$Witch_敗北経路` にも記録（バトル開始前に1に戻す）。オナニー負けは `死亡理由` でも判定。
- `@敗北処理` の頭で `BGM` → `話者変更,相手プレイヤー` → `画像表示,&カード画像,1` → `フェードイン,3` → `背景変更,&背景`。
- 画像はすべて `@初期設定` の `&img_<ファイル名>` 変数にして `画像表示,&img_…,1`。敗北CG・オナニーCGの直後に `フェードイン,1`。
- 敗北シナリオ内の主人公は `話者変更,相手プレイヤー`。モンスターは `話者生成,%ポーラ,&img_Witch_e1,女` → `話者,%ポーラ`。
- `@おねだり後` で負け方を戻すのは相手プレイヤーのHPが残っている時だけ。
- カードが参照する画像49枚は、画像生成バッチの出力名とすべて一致（Witch_onanie は1枚共通、命乞い・おねだりCGは参照していない）。
