# N1 ホストクラブ（v4）カード用セリフの書き方

キャラ設定・世界観・口調は `/home/claude/host/brief.md` を読むこと（成人のみ・責め手上位・逆転なし・主人公はペニスを使う自慰をしない・挿入の前は指でほぐす）。
ここで書くのは、**バトル中にカードが話すセリフ**。JSONファイル1つに1キャラ分をまとめる。

## 本文の決まり（厳守）
- 半角カンマ「,」禁止（全角「、」）。`$ % & # { } < > ;` 禁止。半角の `!` `?` も使わず全角「！」「？」。
- 1つのセリフは40〜110字。改行したい時だけ `\\n`（JSONの中では `\\n` と書く＝画面で改行）。「」は付けない。
- セリフは責め手の口調をはっきり出す。主人公の反応は短い喘ぎ・途切れた言葉。

## 累積スタック「指名度」と段階
攻撃を受けた側が個別に持つ。セリフは**受けた側の段階**で変える。
- 主人公（上限12）：段階1＝1〜3（初めての客）／段階2＝4〜6（指名が入る）／段階3＝7〜9（専属席）／段階4＝10〜11（もう店のもの）
- 男モンスター（上限6。6で「専属ホスト見習い」として店側へ寝返る）：段階1＝0〜1／段階2＝2〜3／段階3＝4／段階4＝5
- 男モンスターは主人公の仲間の男（剣士・獣人など種族はいろいろ。成人）。責め手はモンスターを「そっちのお兄さん」「お連れさん」などと呼ぶ。モンスターの反応は、その男が戸惑い・抵抗しつつ崩れていく声（一人称「俺」など汎用的に）。

## JSONの形
```json
{
  "techs": [
    {
      "player": [["責め手のセリフ（段階1）", "主人公の反応（段階1）"], ["…段階2", "…"], ["…段階3", "…"], ["…段階4", "…"]],
      "monster": [["責め手のセリフ（対モンスター段階1）", "モンスターの反応"], ["…"], ["…"], ["…"]]
    }
  ],
  "prep": {
    "player": [["指ほぐしのセリフ1回目（まだ固い）", "主人公の反応"], ["指ほぐしのセリフ2回目（もうすぐ入る）", "主人公の反応"]],
    "monster": ["指ほぐしのセリフ（対モンスター）", "モンスターの反応"]
  },
  "summon": ["召喚時のセリフ1", "召喚時のセリフ2"],
  "turn_end": ["自分のターン終了時のセリフ"],
  "onedari_intro": "おねだりされた時の最初のセリフ（どれがいいか自分の口で言わせる）",
  "onedari": [["選択肢の短い名前（10字以内）", "主人公がねだる言葉", "責め手の返事"]],
  "inochi_first": ["命乞い（1回目）のセリフ1", "セリフ2"],
  "inochi_again": ["命乞い（2回目以降）のセリフ1", "セリフ2"],
  "inochi_fail": "とどめを刺された時の一言",
  "inochi_trap": "迷った隙を突く一言（ここから敗北）",
  "onani_first": ["オナニーを見つけた時のセリフ1", "セリフ2"],
  "onani_again": ["2回目以降のセリフ1", "セリフ2"],
  "onani_player": "主人公の言い訳（手が止まらない）",
  "onani_desc": "主人公の自慰の様子を描く地の文（得意技の真似。ペニスは使わない。60〜110字）",
  "end": "勝った時（主人公が負けた後）の締めの一言",
  "win": "負けた時（主人公に倒された時）の一言",
  "conv": "男モンスターが指名度6に達して店側へ寝返る時のセリフ",
  "flavor": "カードのフレーバーテキスト（100〜130字。世界観と人物が伝わる地の文）"
}
```
- `techs` は担当キャラの技の数だけ、下の順番で書く。各技は player 4段階・monster 4段階（計16セリフ）。
- `prep` は挿入技を持つキャラ（レン・暁）だけ書く。それ以外は `"prep": null`。
- `onedari` は技の数だけ（技の順番どおり）。
- `onani_*` の自慰は、そのキャラの得意技に合わせる（brief.md の「オナニーの内容」）。
- `summon` `turn_end` `conv` はマスター（レン）も書く（レンの summon は「ホストを呼ぶ時」＝召喚宣言のセリフとして使う。レンの turn_end は4つ＝主人公の段階1〜4で、それぞれ下の状態異常の説明に合う内容）。

## キャラと技（この順番で techs を書く）
- **レン**（`m.json`）
  1. ディープキス（★得意技）：舌を絡め、唾液を流し込む
  2. 乳首と耳の囁き：膝の上で乳首をつまみながら耳を甘噛み・囁く
  3. VIPルームの指名：キスで口を塞いだまま、自身で貫く（【同時】キス＋男の娘逆アナル。ほぐし済みの時だけ出る。prep は「指ほぐし」＝ローションの指で一本→二本）
  - turn_end（主人公の段階ごと）：1＝魅了（見とれる）、2＝メロメロ（骨抜き）、3＝攻撃指示不能（仲間に指示を出せない）、4＝魔法使用不能＋ダメージ
  - さらに `"quest"` を追加で書く（下）
- **ヒナタ**（`e1.json`）1. ディープキス　2. 舌での乳首責め（★得意技）。summon は召喚時（主人公かモンスターの指名度+1）
- **ユウ**（`e2.json`）1. 耳元の囁き（★得意技。復唱させる・耳舐め）　2. 乳首つまみ。turn_end は「自分のターン終了時に男モンスター1体（いなければ主人公）をメロメロにする」時のセリフ
- **ソラ**（`e3.json`）1. 貞操帯の焦らし（★得意技。檻をはめ、鍵を回して見せる。寸止め）　2. 入口だけの指（指で後ろの入口をほぐす。挿入はしない）。summon は召喚時（主人公に魔法使用不能）
- **暁**（`boss.json`）1. 指と器具のアナル開発（指と小さな器具でほぐし広げる）　2. 専属契約の夜（★得意技。【同時】自身で貫きながら乳首を責める。ほぐし済みの時だけ出る。prep は指ほぐし）。summon は召喚時（指名度+3）、turn_end は固有効果「専属契約」（主人公の指名度6以上の時、男モンスター1体をメロメロにして、その指名度+2）のセリフ

## レンだけ追加：`"quest"`
```json
"quest": {
  "first": ["説明:店に入る情景の地の文（90〜120字）", "セリフ", "セリフ", "セリフ（勝負の申し込み。勝てば帰れる、負けたら…）"],
  "won_before": ["セリフ", "セリフ"],
  "prev": {"1": "前回戦闘で負けた客への出迎え", "2": "前回オナニーで負けた客へ", "3": "前回命乞いで負けた客へ", "4": "前回おねだりで負けた客へ"},
  "prev_alert": "アラートの一文（例：前回の続きから指名を受けますか？）",
  "choices": ["挑む", "指名を受ける", "店を出る"],
  "decline": "引き返す時のセリフ",
  "start": ["試合開始のセリフ1", "セリフ2（指名度が12まで上がったら専属、の説明を含める）"],
  "lost_line": "レンが負けた時のセリフ（クエストで勝たれた時）",
  "prev_continue": "前回の続きを流す前のセリフ",
  "kaisou": ["回想バトルの最初のセリフ1（今夜は好きな展開で指名してあげる、など）", "セリフ2"]
}
```
`first` の先頭だけは `"説明:"` で始めて地の文にする（それ以外はレンのセリフ）。
