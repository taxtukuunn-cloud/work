## 新しい仕組み
- **得意技と累積スタック「指名度」**：各キャラの得意技（★）だけが指名度を積む。指名度は攻撃を受けた側が別々に持つ。
  - 主人公：12で敗北。段階 1〜3／4〜6／7〜9／10〜11
  - 男モンスター：6で「専属ホスト見習い」として店側へ寝返る。段階 0〜1／2〜3／4／5
  - 攻撃時のセリフは、受けた側の段階で4段階に変わる（主人公向けと男モンスター向けで別）。
