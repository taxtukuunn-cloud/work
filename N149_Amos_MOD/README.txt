1. CSV\Card\*.txt → ゲームの CSV\Card\（Amos_recall.txt も必ず一緒に）
2. CSV\Eventlist\Quest\Amos.txt → ゲームの CSV\EventList\Quest\
3. 画像ができたら ゲームの Picture\Amos\ へ（画像が無いと画像の行で止まる可能性あり）
4. 回想の栞の共通画像 MOD\_共通ツール\Picture\RecallUI\recall_panel.png を Picture\RecallUI\ へ（1回だけ）
