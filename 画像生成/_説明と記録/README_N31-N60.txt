N31〜N60 画像生成（場面40枚の追加）  2026-09-27
======================================================
個人利用のみ。登場人物はすべて20歳以上の成人。

■ 何が増えたか
これまで N31〜N60 の prompts\<コード>.json は「立ち絵5・魔法5・背景1（＋女装娘）」だけでした。
N1〜N30 と同じ形にするため、各MODに次の40場面を足しました（30MOD × 40 ＝ 1,200件。合計 1,536件）。
  技CG      <コード>_atk_m1〜m3 / e1〜e3 / boss                         7枚
  敗北CG    <コード>_lose_(btl|onani|inochi|onedari)_(m1〜m3|e1〜e3|boss)  28枚
  オナニーCG <コード>_onanie_master / e1〜e3 / boss                      5枚
名前はカードの &画像_ と同じ（N1〜N30 と同じ付け方）。

場面の中身は、各MODの敗北シナリオ28本・技（cfg.py）・構成表から1本ずつ場面を選んで英語にしたものです。
  ・主人公は受け身だけ。責め手は服を着たまま。2人だけの絵。
  ・女性の挿入はペニバン（または道具）、NH・ふたなりの挿入は本人の体（シナリオどおりのときだけ）。
  ・オナニー（敗北のオナニー経路・オナニーCG）は、相手の得意技をなぞる自慰で、ペニスは触らない。相手は遠くで見ているだけ。
  ・女装させるシナリオ（Harem・Casino・Train・Oiran・Lingerie・Revue）は主人公に衣装を着せる（gen.py の女装補正が効く）。
gen.py はそのまま（主人公LoRA・絵柄LoRA・相手の顔の補正・男の娘の補正も自動で効きます）。

■ 使い方
1. 生成_N31-N60.bat … 30MODの件数を表示 → y で撮影（撮り済みは飛ばす。全部で約8.5時間。立ち絵を撮り済みならその分短い）
   一部だけ：生成.bat で MODコード（例 Onsen,Oiran）と名前の一部（例 lose_btl）を入れる。撮り直しは y・候補4。
2. 一覧で目視 → 崩れた画像を消す → 生成.bat で撮り直し（これまでと同じ運用）
3. 完成フォルダへ集める.bat → 完成\<コード>\ → 各MODの Picture\<コード>\ へ

■ 場面を直したいとき
N31-N60_場面\scene_data\<コード>.py の文を直して、場面プロンプトを作り直す_N31-N60.bat（MODコードを入力）。
その MOD の40場面だけ作り直され、立ち絵・魔法・背景・女装娘はそのまま残ります。
  ・書き方は N31-N60_場面\SPEC_scene_data.md
  ・作る前の元ファイルは prompts_場面追加前\<コード>.json（最初の1回だけ保存）
