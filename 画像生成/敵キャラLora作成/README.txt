敵キャラ LoRA 学習セット (キャラごとに1つのLoRA)
==============================================

■ フォルダ構成
  dataset\                元画像の置き場。新しいキャラの画像はここに入れる
  train\<キャラ名>\img\   学習用の切り抜き画像 + タグ(.txt)
  train_config.toml       全キャラ共通の学習設定
  train_all.bat           全キャラを順番に学習するバッチ
  prompts.txt             キャラごとの生成用プロンプト(元の服装)
  output\                 完成したLoRAの保存先 (学習時に自動で作られる)

■ トリガーワード = ファイル名から付けたキャラ名
  circle_boss / circle_e1 / circle_e2 / circle_e3 / circle_master
  host_boss / host_e1 / host_e2 / host_e3 / host_master

■ 学習の手順
  1. train_all.bat をメモ帳で開き、先頭の SD_SCRIPTS と BASE_MODEL の2行を書き換える
  2. train_all.bat をダブルクリック
     → train 内のキャラを順番に学習し、output に <キャラ名>_v1.safetensors ができる
     → すでに完成ファイルがあるキャラは飛ばすので、キャラを足したあと再実行すれば新キャラだけ学習する
  3. 5エポックごとの途中ファイルも保存されるので、強度 0.7〜1.0 で試して一番良いものを選ぶ

  1キャラだけ学習したい場合や kohya_ss の GUI を使う場合は、
  学習画像フォルダに train\<キャラ名>\img を指定し、train_config.toml の数値を入力してください。

■ タグの考え方
  髪型・髪色・目の色はタグに入れていません (トリガーワードに覚えさせるため)。
  服装はタグに入れてあるので、生成時に別の服へ着せ替えできます。

■ 注意
  ・どのキャラも元画像が1枚なので、ポーズ・表情・アングルが固定されやすいです。
    特に circle_e2 と circle_master は「上から見下ろした構図」1枚だけなので、
    普通の正面立ちが出にくくなります。正面の立ち絵を足すのがおすすめです。
  ・仮LoRAで別アングルを生成 → 良いものを dataset に追加 → 再学習、で精度が上がります。
  ・NoobAI の v-pred 版を使う場合は train_config.toml の該当2行の # を外してください。
  ・パスに日本語が入っているとエラーになる環境があります。その場合はこのフォルダを
    丸ごと英数字だけの場所へコピーしてください (設定にパスは書いていないのでそのまま動きます)。
  ・dataset\10_tekichara と旧設定は最初の試作です (circle_boss と同じ内容)。不要なら削除してください。
