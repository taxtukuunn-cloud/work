# 責め手ごとの言い方（おちんちん／お尻）
- パトラ（艶っぽい大人の余裕・わたし／ルーキーくん・あなた・「くすくす」「〜かしら」「〜わよ」）：おちんちん（煽る時だけ「ペニス」）／お尻
- ツインスネイク（ギャル口調・あたし／アンタ・「きゃはは」「〜っしょ」「〜じゃん」）：チンポ／お尻
- ポイズンラミア（囁く妖しい口調・わたし／あなた・「くすくす」「んふふ」）：ペニス／お尻
- 蛇笛の吹き手 サディーヤ（無口・短い文・わたし／あなた・「・・・ふふ」）：おちんちん／お尻
- コブラ娘（尊大・わし／おぬし・「〜じゃ」「〜のう」「クク」）：いちもつ／尻（奥のしこりは「前立腺」とも「栓」とも言う）
- 累積スタック：「毒牙の痕」（単位：個）。牙が肌に甘く沈むと、小さな二つ並びの赤い点が浮く（甘く痺れる媚毒・痛みはない）。数え方は「〜個目の痕」「毒牙の痕が十二個」。段階は一噛み→毒が回る→巻かれる→脱力→十二個で「蛇の巣の番」
- 主人公→相手の呼び方：パトラさん／ツインスネイクさん／ラミアさん／サディーヤさん／コブラ娘さん。パトラの連れる小さな蛇たちは「蛇たち」「小蛇」
- 戦闘経路（N68）：主人公が一度は振りほどく・這って逃げる→そのたびに脚・尾・蛇が「しつこく」巻き直す（「蛇ってしつこい生き物なの」）を2回以上入れる
- オナニー経路（N68）：パトラが脚を組み替えながら「わたしの脚を目で追いながら、両手で」と実況する（ラミア・コブラ娘の回もパトラが観客席・椅子から実況）。主人公の両手は★得意技の形（耳・乳首・口・体を揺らす・毛布で巻いて後ろ）でペニスには触れない
- パトラ（艶っぽい大人の余裕・「くすくす」「〜かしら」・わたし／ルーキーくん・あなた）：おちんちん／お尻（主人公のお尻の穴は「お尻の穴」）
- ツインスネイク（くだけたギャル・「きゃはは」・あたし／アンタ）：チンポ／お尻
- ポイズンラミア（囁く妖艶・「くすくす」「うふふ」・わたし／あなた）：ペニス／お尻
- サディーヤ（無口で短い・「・・・ふふ」・わたし／あなた）：おちんちん／お尻
- コブラ娘（尊大・「クク」・わし／おぬし・〜じゃ）：いちもつ／尻の穴（前立腺は初出で位置を言い、以後「奥のしこり」）
- 累積スタック：媚毒の「毒牙の痕」（二つ並んだ小さな紅い点。痛みはなく、甘く痺れる）。数え方は「七つ目の痕」「毒牙の痕が十二個」。十二個で「蛇の巣の番」
- 主人公からの呼び方：パトラさん／ツインスネイクさん／ラミアさん／サディーヤさん／コブラ娘さま
- 命乞い（inochi）共通：情けで手を止めた主人公に「毒を抜いてあげる」と口づけ（または唇での吸い出し）→それが次の痕になり、最後の十二個目になる
- おねだり（onedari）共通：「お尻でつぶされたい？脚を絡められたい？」と選ばされ、ねだった言葉をそのまま毎朝（毎晩）自分で口にする日課になる
- 補足（命乞い・おねだり担当）：主人公からコブラ娘への呼び方は上の行に合わせて「コブラ娘さん」に統一。パトラの小蛇二匹には「シロ」「ユキ」という名がある（白い小蛇。乳首を甘噛みする役）
