# 制作エンジン（男性受けゲームの販売数上位300本）

調べた日：2026-11-21

## 調べ方

- **対象**：DLsite で「男性受け」（genre 156）タグが付いたゲームのうち、販売数の上位300本。一覧は主要サークルの調査で作ったもの。
- **体験版のファイル一覧**：体験版 ZIP は丸ごとダウンロードせず、HTTP の範囲指定で末尾のファイル一覧（中央ディレクトリ）だけを読んだ。読めたのは269本。31本は体験版がないか、ZIP 以外の形式だった。
- **判定に使ったファイル名の特徴**：

| エンジン | 判定に使った特徴 |
|---|---|
| ツクールMZ | `js/rmmz_core.js`、暗号化素材の `.ogg_` `.png_` |
| ツクールMV | `js/rpg_core.js`、`www/` フォルダ、`.rpgmvp`、`.rpgsave` |
| ツクールVX Ace | `.rgss3a`、`RGSS30x.dll` |
| ツクールVX | `.rgss2a` |
| ツクールXP | `.rgssad` |
| WOLF RPGエディター | `.wolf`、`Data/BasicData/` |
| Unity | `UnityPlayer.dll`、`_Data/` |
| Unreal Engine | `.pak`、`Engine/Binaries` |
| Godot | `.pck` |
| 吉里吉里 | `.xp3` |
| NScripter | `.nsa` |
| GameMaker | `data.win` |
| DXライブラリ（自作プログラム） | `.dxa` |

- **体験版がない作品**：作品説明にエンジン名が書いてあれば、それを使った。

  - SLG：Unity が中心。

| 2020〜22 | MV 37本、Unity 15本 |
| 2023〜26 | MZ 33本、Unity 29本、MV 20本、Unreal 5本、Godot 3本 |

## 読み取れること

- RPGツクールは今も最大勢力。直近では MV から MZ への移行が進み、WOLF は減っている。
- 2023年以降は Unity が約3割まで増えた。ACT、Live2D、リズムゲーム、カードといった RPG 以外のヒットの増加と重なる。
- 1本あたりの販売数の中央値は、エンジンによる差がほとんどない（どれも約1万本）。売れ行きを左右しているのはエンジンではなく、中身（形式・アニメ・物量）とみられる。
- Unreal は3D作品（アンダーザウィッチなど）で使われているが、本数は少ない。

## 限界

- 対象は上位300本だけで、市場全体の内訳ではない。
- 体験版と製品版でエンジンが違う可能性は確認していない。
- 実行ファイル1つに固めた作品（Enigma Virtual Box など）や自作エンジンは、14本が判定できなかった。
