# N24 メイド長の屋敷（Maid）画像一括生成バッチ

N23（Heels）と同じ仕組み・同じ設定（Anima 3ローダー／832×1216／er_sde・simple／36step／CFG4.5）。
全52枚を、カードが参照するファイル名（`Maid_atk_m1.png` など＝`必要な画像一覧.txt` と同じ）のまま `output\Maid\` に保存する。登場人物は全員20歳以上。個人利用のみ。

## LoRA（本編の絵柄）
- 全MOD共通の設定 `Downloads\Lora用\lora_settings.json` に従う（2026-09-26 時点：`sdduel_style-000006`・強さ0.6・有効）。実行時の最初に「LoRA: …」と表示される。
- 一時的に外す：`run_maid.bat <キー> --no-lora`／強さを変える：`run_maid.bat <キー> --lora-strength 0.5`

## 使い方
0. **まず `test_maid.bat` で試し撮り**（主な5枚＝立ち絵シオン・キス・逆アナル・ガーター・自慰を2候補ずつ `output\Maid\_candidates\` に作る。約4分。本番の画像は上書きしない）
   - `_c1` が本番と同じシード（本番でこの絵になる）。見るところ：主人公が小柄・筋肉なし・紺髪で目隠れか／責め手の胸が平らか／2人の取り違えがないか
   - 主人公の体格が崩れる時は `run_maid.bat Maid_lose_btl_m1 --batch 2 --lora-strength 0.5` と比べ、0.5の方が良ければ `lora_settings.json` の strength を 0.5 に
   - 試し撮りの候補は本番に使わない（本番は次の手順で作り直す）。気に入った候補は `pick_maid.bat` で採用してもよい
1. **`gen_maid_all.bat` をダブルクリック**（ComfyUIが起動していなければ起動し、準備を待ってから52枚を順に生成。1枚約20秒・全部で約20分。途中で止めても、もう一度実行すれば続きから）
2. 崩れた画像の撮り直し：`run_maid.bat Maid_atk_m3 --random --batch 4` → `output\Maid\_candidates\` から選んで `pick_maid.bat Maid_atk_m3 2`
   - まとめて撮り直す：`fix_maid.bat`（崩れやすいキーを3候補ずつ。中のキー一覧は自由に書き換えてよい）
3. ゲームへ：`install_maid.bat "D:\GAME\SuccubusDuel本体\RJ01149693\SuccubusDuel_sub\サキュバスデュエル\Picture"`（`Picture\Maid\` にコピー）
