# 責め手ごとの言い方（おちんちん／お尻）
- 試験官（明るく軽い「〜だよ」・「あなた／新人マスターくん」）：おちんちん／お尻
- アーチャー（くだけた・「くすくす」）：チンポ／お尻
- 大剣使いの守護傭兵（武人口調・「ククク」・「お前」）：ちんぽ／尻
- ミント（事務的・「受験者さん」・「記録します」）：おちんちん（採点・記録を読み上げる場面では「陰茎」と言う）／お尻
- サキュバススナイパー（冷静な命令口調・「あなた」）：おちんちん／お尻
- 共通：累積スタックは「不合格印」（単位：個）。採点表に赤い判で押され、同じ印が主人公の胸元（鎖骨の下）にも浮く。主人公の地の文は「おちんちん」
- 命乞い（inochi）共通：「今日は採点しないであげる」の紙＝「試験補助員登録用紙」。署名（名前・拇印）で補助員に登録され、取り消し欄はない。十二個目の不合格印は射精の直後に浮き「永久不合格」と言う
- おねだり（onedari）共通：選んだ科目・細目を書いた紙（受験申込書／面接票／宿帳の裏／試験記録／的の裏）を、以後の日課として本人が読み上げる
