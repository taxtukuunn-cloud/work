# N11 スライム調教（コード Slime）敗北シナリオ執筆ブリーフ（v4・2026-09-26）

サキュバスデュエル（M向けカードゲーム）の個人用MOD。**登場人物は全員20歳以上の成人**（主人公も成人）。スライム娘たちは「成熟した大人の女性の姿をしたスライム」。個人利用のみ。
あなたはベストセラー作家として書く。主人公（プレイヤー。名前なし）が街外れの古井戸の底に続く洞窟「翠の洞」でカードバトルに負け、スライムの女王と巣の娘たちに温かい粘液で包まれ、体の内側まで溶かされて巣の一部にされていく「敗北シナリオ」を書く。

## 絶対条件

- 幼さを示す語（少年、少女、ショタ、ロリ、幼い、子ども、子供、女の子、男の子、小さな子、いい子、良い子、坊や、舌足らず、ちっちゃい 等）は絶対に使わない。「子」を含む比喩も避ける（「様子」「椅子」のような普通の語は可）。褒める時は「上手ねぇ」「素直ねぇ」などにする。

- 主人公のペニスを使う自慰は書かない（オナニー負けは下の「オナニーの内容」の自慰から始める）。
- 「粘液度」：粘液が体に広がり、染み込み、溶け合っていく度合い。12で巣の一部になって敗北。段階：
  - 1〜3：足元に広がる（「いらっしゃい」）

## 構成（1本の合計7,000字以上。セリフ,と説明,の本文だけで数える）
ファイルは3つの部分に分け、**区切りの行 `##PLAY` と `##END` を入れる**（ゲームには入らない印）。
1. **導入（`##PLAY` の前）：400字程度（300〜600字）**。冒頭行は画像行。どう負けたか（経路）、なぜこの責めなのか、どこへ連れて行かれたか。
2. **プレイ描写（`##PLAY` と `##END` の間）：6,000字以上（目標6,500〜7,500字）**。途切れさせず一連のシーンで。責め手の責め中のセリフ、主人公の喘ぎ声、快楽に対する心理描写、体や神経の反応、粘液の動き（温度、とろみ、色、脈、形の変化、濡れた音、体の中で膨らむ感覚、指の本数と角度）を細かく書く。**その責め手の得意技を主役にする**。絶頂は2〜4回（各絶頂の前に `射精` 行を置いてよい。前立腺や乳首だけで出さずに達する時は置かない）。絶頂のたびに「一層目」「二杯目」「一巡目」などの意味づけをする。途中で後日談に飛ばない。
3. **結び（`##END` の後）：600字以内**。責め手の締めのセリフと、その後の短い余韻（肌に残る色、体内に残るゼリーの核、小瓶、合図の言葉など）。
- 弱点付与・GAME OVER・BGMは別処理なので書かない。
- 文章の質：五感、比喩、緩急、責め手ごとの口調の個性。同じ責め手の4本は、場所・時刻・小道具・絶頂の区切り方・結末の印を変えて、読み比べて別物にする。

## 書式（厳守。ゲームのスクリプトとしてそのまま読み込まれる）
1行に1コマンド。使ってよい行は次だけ：
```
画像,#Slime/Slime_lose_<経路>_<責め手>.png,1
話者,%ジュレア        （%アオ %アカ %モモ %ヴィスカ も同様。責め手が喋る前に必ず入れる）
話者,相手プレイヤー    （主人公が喋る前に入れる）
セリフ,本文
説明,本文            （地の文・情景・心の動き）
フラッシュ,ピンク
射精
ウェイト,1
##PLAY
##END
```
- **本文に半角カンマ「,」を絶対に使わない**（全角「、」を使う）。
- 本文に `$ % & # { } < > ;` を使わない。半角の `!` `?` も避け、全角「！」「？」を使う。ハートや音符などの記号は使わない。半角の ( ) も使わず全角（）。改行したい時だけ `\n` を使ってよい（1行2〜3文まで）。
- 1行の本文は長くても120字程度。セリフは「」を付けない。
- 冒頭行は必ず `画像,#Slime/Slime_lose_<経路>_<責め手>.png,1`。ほかの画像ファイル名は使わない。
- 空行・コメント・見出し・`@` 行は書かない。`##PLAY` `##END` はそれぞれ1回だけ。

## 経路（どう負けたか）の軸
- **btl（戦闘負け）**：ぬるぬるに崩れ、粘液度が満ちて倒れる。その責め手の流儀で巣の一部にされる。
- **onani（オナニー負け）**：勝負の最中、疼きに耐えられずその責め手の得意技を真似た自慰を始めてしまい、見つかる（粘液が反応して増え、形を覚える）。自分から手を伸ばした恥が軸。見られる・記録される・管理される。**プレイ描写の最初は、下の「オナニーの内容」の自慰（ペニスは使わない）から始め、途中で責め手が引き取る。**
- **inochi（命乞い負け）**：とどめの直前に相手が「もう出してあげる」「今日は帰してあげる」と持ちかけ、手が止まった。その情けを「飲み込まれ」、罠・約束・所有に変えられる。
- **onedari（おねだり負け）**：自分の口で「包んでください」「入れてください」などと具体的に請う。それが日課・合図の言葉として巣に記録される。

## オナニーの内容（onani ルートの冒頭。ペニスは使わない）

- アオ（乳首吸い）：指を粘液で濡らし、乳首を吸われるように摘んで引き、離し、また摘む

- モモ（桃ゼリーの耳ふさぎ）：耳に残ったゼリーを指でなぞり、耳の穴を指先で塞いで囁きを思い出し、触れずに体を揺らす
- ヴィスカ（前立腺を揺らす）：粘液で濡れた指で後ろの入口を撫で、一本ずつほぐして奥の一点を探す
