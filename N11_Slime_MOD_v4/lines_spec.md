# N11 スライム調教（v4）カード用セリフの書き方

キャラ設定・世界観・口調は `/home/claude/n11/brief.md` を読むこと（成人のみ・責め手上位・逆転なし・主人公はペニスを使う自慰をしない・後ろに入れる前は粘液の指でほぐす・尿道には何も入れない）。
ここで書くのは、**バトル中にカードが話すセリフ**。JSONファイル1つに1キャラ分をまとめる。

## 本文の決まり（厳守）
- 半角カンマ「,」禁止（全角「、」）。`$ % & # { } < > ;` 禁止。半角の `!` `?` `(` `)` も使わず全角「！」「？」「（）」。
- 1つのセリフは40〜110字。改行したい時だけ `\\n`（JSONの中では `\\n` と書く＝画面で改行）。「」は付けない。
- セリフは責め手の口調をはっきり出す。主人公の反応は短い喘ぎ・途切れた言葉。

## 累積スタック「粘液度」と段階
攻撃を受けた側が個別に持つ。セリフは**受けた側の段階**で変える。
- 主人公（上限12）：段階1＝1〜3（足元に広がる）／段階2＝4〜6（全身が濡れる）／段階3＝7〜9（体の内側に入り込む）／段階4＝10〜11（溶け合って境目がなくなる）
- 男モンスター（上限6。6で「スライム調教済み」として巣の側へ寝返る）：段階1＝0〜1／段階2＝2〜3／段階3＝4／段階4＝5
- 男モンスターは主人公の仲間の男（剣士・獣人など種族はいろいろ。成人）。責め手はモンスターを「お連れさん」「そっちの人」などと呼ぶ。モンスターの反応は、その男が戸惑い・抵抗しつつ崩れていく声（一人称「俺」など汎用的に）。

## JSONの形
```json
{
  "techs": [
    {
      "player": [["責め手のセリフ（段階1）", "主人公の反応（段階1）"], ["…段階2", "…"], ["…段階3", "…"], ["…段階4", "…"]],
      "monster": [["責め手のセリフ（対モンスター段階1）", "モンスターの反応"], ["…"], ["…"], ["…"]]
    }
  ],
  "prep": {
    "player": [["指ほぐしのセリフ1回目（まだ固い）", "主人公の反応"], ["指ほぐしのセリフ2回目（もうすぐ入る）", "主人公の反応"]],
    "monster": ["指ほぐしのセリフ（対モンスター）", "モンスターの反応"]
  },
  "summon": ["召喚時のセリフ1", "召喚時のセリフ2"],
  "turn_end": ["自分のターン終了時のセリフ"],
  "onedari_intro": "おねだりされた時の最初のセリフ（どれがいいか自分の口で言わせる）",
  "onedari": [["選択肢の短い名前（10字以内）", "主人公がねだる言葉", "責め手の返事"]],
  "inochi_first": ["命乞い（1回目）のセリフ1", "セリフ2"],
  "inochi_again": ["命乞い（2回目以降）のセリフ1", "セリフ2"],
  "inochi_fail": "とどめを刺された時の一言",
  "inochi_trap": "迷った隙を突く一言（ここから敗北）",
  "onani_first": ["オナニーを見つけた時のセリフ1", "セリフ2"],
  "onani_again": ["2回目以降のセリフ1", "セリフ2"],
  "onani_player": "主人公の言い訳（手が止まらない）",
  "onani_desc": "主人公の自慰の様子を描く地の文（得意技の真似。ペニスは使わない。60〜110字）",
  "end": "勝った時（主人公が負けた後）の締めの一言",
  "win": "負けた時（主人公に倒された時）の一言",
  "conv": "男モンスターが粘液度6に達して巣の側へ寝返る時のセリフ",
  "flavor": "カードのフレーバーテキスト（100〜130字。世界観と人物が伝わる地の文）"
}
```
- `techs` は担当キャラの技の数だけ、下の順番で書く。各技は player 4段階・monster 4段階（計16セリフ）。
- `prep` は挿入技を持つキャラ（ジュレア・アカ・モモ・ヴィスカ）が書く。アオだけ `"prep": null`。
- `onedari` は技の数だけ（技の順番どおり）。
- `onani_*` の自慰は、そのキャラの得意技に合わせる（brief.md の「オナニーの内容」）。
- `summon` `turn_end` `conv` はマスター（ジュレア）も書く（ジュレアの summon は「娘たちを呼ぶ時」＝召喚宣言のセリフとして使う。ジュレアの turn_end は4つ＝主人公の段階1〜4で、それぞれ下の状態異常の説明に合う内容）。

## キャラと技（この順番で techs を書く）
- **ジュレア**（`m.json`。prep あり＝技2のゼリー注入の前。粘液の指で一本→二本）
  1. 全身ぬるぬる責め（★得意技）：温かい翠の粘液の体で全身を抱き包み、隙間なく撫で回す
  2. アナルゼリー注入：ほぐした後、温かいゼリーを少しずつ奥へ満たす（ほぐし済みの時だけ出る）
  3. ゼリーの繭：全身を半透明のゼリーの繭で包み、形を覚えさせて脈打たせる（発情）
  - turn_end（主人公の段階ごと）：1＝ぬるぬる、2＝発情、3＝攻撃指示不能（仲間を呼ぶ声が粘液に吸われる）、4＝魔法使用不能＋ダメージ
  - さらに `"quest"` を追加で書く（下）
- **アオ**（`e1.json`。prep は null）1. 乳首吸い（★得意技。ひんやりした唇と粘液の口で乳首に吸い付き、吸っては離す）　2. 全身へのぬるぬる包み込み（ひんやりした青い体で全身を包む。ぬるぬる）。summon は召喚時（主人公にぬるぬる）
- **アカ**（`e2.json`。prep あり＝熱い粘液の指で一本→二本）1. 発情粘液の口移し（★得意技。熱い赤い粘液を口移しで飲ませる。発情）　2. アナルへの侵入（ほぐした後、熱い赤い粘液が奥へ入り込む。ほぐし済みの時だけ出る）。turn_end は「自分のターン終了時に男モンスター1体（いなければ主人公）の粘液度+1」のセリフ
- **モモ**（`e3.json`。prep あり＝とろとろの桃ゼリーの指で一本→二本）1. 桃ゼリーの耳ふさぎ（★得意技。甘いゼリーで両耳を満たし、中に「ずーっと一緒」と囁く）　2. アナルゼリー注入（ほぐした後、桃のゼリーを奥へ注ぐ。ほぐし済みの時だけ出る。ぬるぬる）。summon は召喚時（男モンスター1体か主人公の粘液度+1）
- **ヴィスカ**（`boss.json`。prep あり＝紫の粘液の指で一本→二本）1. 全身包み込みの調教（紫の粘液で全身を包み込み、動きを止める。攻撃指示不能）　2. 内側から前立腺を揺らす（★得意技。ほぐした後、紫の粘液で奥を満たし、前立腺を包んで波のように揺らす。ほぐし済みの時だけ出る）。summon は召喚時（粘液度+3）、turn_end は固有効果「太古の淵」（主人公の粘液度6以上の時、主人公を魔法使用不能、男モンスター1体を発情させて粘液度+2）のセリフ

## ジュレアだけ追加：`"quest"`
```json
"quest": {
  "first": ["説明:古井戸の底から続く翠の洞を下り、光る粘液と甘い匂いに迎えられる情景の地の文（90〜120字）", "セリフ", "セリフ", "セリフ（勝負の申し込み。勝てば帰れる、負けたら巣の一部に）"],
  "won_before": ["セリフ", "セリフ"],
  "prev": {"1": "前回戦闘で負けた相手への出迎え", "2": "前回オナニーで負けた相手へ", "3": "前回命乞いで負けた相手へ", "4": "前回おねだりで負けた相手へ"},
  "prev_alert": "アラートの一文（例：前回の続きを受けますか？）",
  "choices": ["挑む", "包まれに行く", "地上へ戻る"],
  "decline": "引き返す時のセリフ",
  "start": ["試合開始のセリフ1", "セリフ2（粘液度が12に達したら溶け合って巣の一部、の説明を含める）"],
  "lost_line": "ジュレアが負けた時のセリフ（クエストで勝たれた時）",
  "prev_continue": "前回の続きを流す前のセリフ",
  "kaisou": ["回想バトルの最初のセリフ1（今日は好きな娘に包まれていいわよぉ、など）", "セリフ2"]
}
```
`first` の先頭だけは `"説明:"` で始めて地の文にする（それ以外はジュレアのセリフ）。
