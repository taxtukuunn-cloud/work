# N4 男の娘アンドロイド（v4）カード用セリフの書き方

キャラ設定・世界観・口調は `/home/claude/n4/brief.md` を読むこと（成人のみ・責め手上位・逆転なし・主人公はペニスを使う自慰をしない・挿入（拡張器・機械ディルド）の前は指でほぐす）。
ここで書くのは、**バトル中にカードが話すセリフ**。JSONファイル1つに1キャラ分をまとめる。

## 本文の決まり（厳守）
- 半角カンマ「,」禁止（全角「、」）。`$ % & # { } < > ;` 禁止。半角の `!` `?` `(` `)` も使わず全角「！」「？」「（）」。
- 1つのセリフは40〜110字。改行したい時だけ `\\n`（JSONの中では `\\n` と書く＝画面で改行）。「」は付けない。
- セリフは責め手の口調をはっきり出す。主人公の反応は短い喘ぎ・途切れた言葉。

## 累積スタック「収集率」と段階
攻撃を受けた側が個別に持つ。セリフは**受けた側の段階**で変える。
- 主人公（上限12）：段階1＝1〜3（計測開始）／段階2＝4〜6（データが揃い始める）／段階3＝7〜9（登録手続き中）／段階4＝10〜11（登録直前）
- 男モンスター（上限6。6で「登録済み被験体」として施設側へ寝返る）：段階1＝0〜1／段階2＝2〜3／段階3＝4／段階4＝5
- 男モンスターは主人公の仲間の男（剣士・獣人など種族はいろいろ。成人）。責め手はモンスターを「同行個体」「追加被験体」などと呼ぶ。モンスターの反応は、その男が戸惑い・抵抗しつつ崩れていく声（一人称「俺」など汎用的に）。

## JSONの形
```json
{
  "techs": [
    {
      "player": [["責め手のセリフ（段階1）", "主人公の反応（段階1）"], ["…段階2", "…"], ["…段階3", "…"], ["…段階4", "…"]],
      "monster": [["責め手のセリフ（対モンスター段階1）", "モンスターの反応"], ["…"], ["…"], ["…"]]
    }
  ],
  "prep": {
    "player": [["指ほぐしのセリフ1回目（まだ固い）", "主人公の反応"], ["指ほぐしのセリフ2回目（もうすぐ入る）", "主人公の反応"]],
    "monster": ["指ほぐしのセリフ（対モンスター）", "モンスターの反応"]
  },
  "summon": ["召喚時のセリフ1", "召喚時のセリフ2"],
  "turn_end": ["自分のターン終了時のセリフ"],
  "onedari_intro": "おねだりされた時の最初のセリフ（どれがいいか自分の口で言わせる）",
  "onedari": [["選択肢の短い名前（10字以内）", "主人公がねだる言葉", "責め手の返事"]],
  "inochi_first": ["命乞い（1回目）のセリフ1", "セリフ2"],
  "inochi_again": ["命乞い（2回目以降）のセリフ1", "セリフ2"],
  "inochi_fail": "とどめを刺された時の一言",
  "inochi_trap": "迷った隙を突く一言（ここから敗北）",
  "onani_first": ["オナニーを見つけた時のセリフ1", "セリフ2"],
  "onani_again": ["2回目以降のセリフ1", "セリフ2"],
  "onani_player": "主人公の言い訳（手が止まらない）",
  "onani_desc": "主人公の自慰の様子を描く地の文（得意技の真似。ペニスは使わない。60〜110字）",
  "end": "勝った時（主人公が負けた後）の締めの一言",
  "win": "負けた時（主人公に倒された時）の一言",
  "conv": "男モンスターが収集率6に達して施設側へ寝返る時のセリフ",
  "flavor": "カードのフレーバーテキスト（100〜130字。世界観と人物が伝わる地の文）"
}
```
- `techs` は担当キャラの技の数だけ、下の順番で書く。各技は player 4段階・monster 4段階（計16セリフ）。
- `prep` は挿入技を持つキャラ（NX-00・中央制御ユニット）だけ書く。それ以外は `"prep": null`。
- `onedari` は技の数だけ（技の順番どおり）。
- `onani_*` の自慰は、そのキャラの得意技に合わせる（brief.md の「オナニーの内容」）。
- `summon` `turn_end` `conv` はマスター（NX-00）も書く（NX-00の summon は「ユニットを呼ぶ時」＝召喚宣言のセリフとして使う。NX-00の turn_end は4つ＝主人公の段階1〜4で、それぞれ下の状態異常の説明に合う内容）。

## キャラと技（この順番で techs を書く）
- **NX-00**（`m.json`）
  1. 脳波同期（★得意技）：こめかみに端子を当て、快楽信号を直接脳へ流す
  2. センサープローブ計測：アームの先のセンサーで乳首を計測しながら責める
  3. アーム拡張計測：拡張器で後ろを開いて中を計測し、前立腺を押す（【同時】拡張＋脳波同期。ほぐし済みの時だけ出る。prep は「指ほぐし」＝ローションで濡らしたアームの細い指で一本→二本）
  - turn_end（主人公の段階ごと）：1＝魔法使用不能（術式を停止）、2＝魅了（NX-00から目が離せない）、3＝攻撃指示不能（仲間に指示を出せない）、4＝魔法使用不能＋ダメージ
  - さらに `"quest"` を追加で書く（下）
- **検査ユニット**（`e1.json`）1. 乳首スキャン（★得意技。センサーの指先で乳首をつまみ感度を測る）　2. 前立腺探索プローブ（細いプローブで入口をほぐし前立腺を探す。挿入というより探るだけ）。summon は召喚時（主人公かモンスターの収集率+1）
- **搾精ユニット**（`e2.json`）1. 吸引搾精（★得意技。透明な吸引カップで吸い上げる）　2. 低周波電気刺激（乳首・会陰・下腹に貼ったパッドで痺れさせる。発情）。turn_end は「自分のターン終了時に主人公に100ダメージ（定時回収）」のセリフ
- **洗脳ユニット**（`e3.json`）1. 音声波形（★得意技。耳元の反復音声で刷り込む。魅了）　2. 反復暗示（同じ言葉を繰り返して思考を塗り替える）。summon は召喚時（男モンスター1体か主人公に魅了）
- **中央制御ユニット**（`boss.json`）1. 全ユニット同時稼働（6本のアームで乳首・頭・全身を同時に。攻撃指示不能）　2. 高速ピストン（★得意技。【同時】アームの機械ディルドで貫き一定のリズムで奥を突きながら脳波同期。ほぐし済みの時だけ出る。prep は指ほぐし）。summon は召喚時（収集率+3）、turn_end は固有効果「全ユニット同期」（主人公の収集率6以上の時、主人公を攻撃指示不能、男モンスター1体を魅了して収集率+2）のセリフ

## NX-00だけ追加：`"quest"`
```json
"quest": {
  "first": ["説明:廃墟の地下研究施設に踏み込み、NX-00が起動する情景の地の文（90〜120字）", "セリフ", "セリフ", "セリフ（勝負の申し込み。勝てば解放、負けたら被験体として登録）"],
  "won_before": ["セリフ", "セリフ"],
  "prev": {"1": "前回戦闘で負けた被験体への出迎え", "2": "前回オナニーで負けた被験体へ", "3": "前回命乞いで負けた被験体へ", "4": "前回おねだりで負けた被験体へ"},
  "prev_alert": "アラートの一文（例：前回の計測の続きを開始しますか？）",
  "choices": ["挑む", "計測を受ける", "施設を出る"],
  "decline": "引き返す時のセリフ",
  "start": ["試合開始のセリフ1", "セリフ2（収集率が12に達したら登録完了、の説明を含める）"],
  "lost_line": "NX-00が負けた時のセリフ（クエストで勝たれた時）",
  "prev_continue": "前回の続きを流す前のセリフ",
  "kaisou": ["回想バトルの最初のセリフ1（記録データから任意の計測を再現します、など）", "セリフ2"]
}
```
`first` の先頭だけは `"説明:"` で始めて地の文にする（それ以外はNX-00のセリフ）。
