## 構成（1本の合計7,000字以上。セリフ,と説明,の本文だけで数える）
ファイルは3つの部分に分け、**区切りの行 `##PLAY` と `##END` を入れる**（ゲームには入らない印）。
1. **導入（`##PLAY` の前）：400字程度（300〜600字）**。冒頭行は画像行。どう負けたか（経路）、なぜこの処置なのか、どの部屋へ連れて行かれたか。
2. **プレイ描写（`##PLAY` と `##END` の間）：6,000字以上（目標6,500〜7,500字）**。途切れさせず一連のシーンで。責め手の処置中のセリフ、主人公の喘ぎ声、快楽に対する心理描写、体や神経の反応、道具の動き（手袋のきしみ、ゼリーの冷たさと温度、指の本数と角度、奥の一点の形、電極の脈、ストップウォッチ、注入器の目盛り、カルテに書かれる所見）を細かく書く。**その責め手の得意技を主役にする**。絶頂は2〜4回（各絶頂の前に `射精` 行を置いてよい。前立腺だけで出さずに達する時は置かない）。絶頂のたびに「所見一」「検査項目」「処方」などの意味づけをする。途中で後日談に飛ばない。
3. **結び（`##END` の後）：600字以内**。責め手の締めのセリフと、その後の短い余韻（予約票、診断書、通院日など）。
- 弱点付与・GAME OVER・BGMは別処理なので書かない。
- 文章の質：五感、比喩、緩急、責め手ごとの口調の個性。同じ責め手の4本は、部屋・時刻・小道具・絶頂の区切り方・結末の印を変えて、読み比べて別物にする。

## 書式（厳守。ゲームのスクリプトとしてそのまま読み込まれる）
1行に1コマンド。使ってよい行は次だけ：
```
画像,#Clinic/Clinic_lose_<経路>_<責め手>.png,1
話者,%ミヤビ          （%アヤ %レン %ミサ %カズハ も同様。責め手が喋る前に必ず入れる）
話者,相手プレイヤー    （主人公が喋る前に入れる）
セリフ,本文
説明,本文            （地の文・情景・心の動き）
フラッシュ,ピンク
射精
ウェイト,1
##PLAY
##END
```
- **本文に半角カンマ「,」を絶対に使わない**（全角「、」を使う）。
- 本文に `$ % & # { } < > ;` を使わない。半角の `!` `?` も避け、全角「！」「？」を使う。ハートや音符などの記号は使わない。半角の ( ) も使わず全角（）。改行したい時だけ `\n` を使ってよい（1行2〜3文まで）。
- 1行の本文は長くても120字程度。セリフは「」を付けない。
- 冒頭行は必ず `画像,#Clinic/Clinic_lose_<経路>_<責め手>.png,1`。ほかの画像ファイル名は使わない。
- 空行・コメント・見出し・`@` 行は書かない。`##PLAY` `##END` はそれぞれ1回だけ。

## 経路（どう負けたか）の軸
- **btl（戦闘負け）**：処置に崩れ、治療度が満ちて倒れる。デュエル中の処置がそのまま本番の治療に続き、その責め手の流儀で「治療完了」にされる。
- **onani（オナニー負け）**：勝負の最中（または待合室で）、疼きに耐えられずその責め手の得意技を真似た自慰を始めてしまい、見つかる。自分から手を伸ばした恥が軸。見られる・記録される（カルテ・映像・計測）・管理される。**プレイ描写の最初は、下の「オナニーの内容」の自慰（ペニスは使わない）から始め、途中で責め手が引き取る。**
- **inochi（命乞い負け）**：とどめの直前に「今日は処置を中止しましょうか」「同意書にサインすれば楽になりますよ」と持ちかけられ、手が止まった。その迷いが同意・契約・通院の約束にされる。
- **onedari（おねだり負け）**：自分の口で「診てください」「奥を押してください」などと具体的に請う。それが処置の指示・予約の言葉としてカルテに記録される。
