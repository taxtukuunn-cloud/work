# N9 前立腺クリニック（v4）カード用セリフの書き方

キャラ設定・世界観・口調は `/home/claude/n9/brief.md` を読むこと（成人のみ・責め手上位・逆転なし・主人公はペニスを使う自慰をしない・後ろに器具を入れる前（ミサの注入・カズハの再教育）は手袋の指でほぐす）。
ここで書くのは、**バトル中にカードが話すセリフ**。JSONファイル1つに1キャラ分をまとめる。

## 本文の決まり（厳守）
- 半角カンマ「,」禁止（全角「、」）。`$ % & # { } < > ;` 禁止。半角の `!` `?` `(` `)` も使わず全角「！」「？」「（）」。
- 1つのセリフは40〜110字。改行したい時だけ `\\n`（JSONの中では `\\n` と書く＝画面で改行）。「」は付けない。
- セリフは責め手の口調をはっきり出す。主人公の反応は短い喘ぎ・途切れた言葉。

## 累積スタック「治療度」と段階
攻撃を受けた側が個別に持つ。セリフは**受けた側の段階**で変える。
- 主人公（上限12）：段階1＝1〜3（問診。まだ健康診断のつもり）／段階2＝4〜6（検査。所見を言われるたびに体が反応）／段階3＝7〜9（治療。処置の予定を聞くだけで奥が疼く）／段階4＝10〜11（通院確定。自分から予約を取りたくなる）
- 男モンスター（上限6。6で「通院患者」としてクリニック側へ寝返る）：段階1＝0〜1／段階2＝2〜3／段階3＝4／段階4＝5
- 男モンスターは主人公の仲間の男（剣士・獣人など種族はいろいろ。成人）。責め手はモンスターを「付き添いの方」「そちらの患者さん」などと呼ぶ。モンスターの反応は、その男が戸惑い・抵抗しつつ崩れていく声（一人称「俺」など汎用的に）。

## JSONの形
```json
{
  "techs": [
    {
      "player": [["責め手のセリフ（段階1）", "主人公の反応（段階1）"], ["…段階2", "…"], ["…段階3", "…"], ["…段階4", "…"]],
      "monster": [["責め手のセリフ（対モンスター段階1）", "モンスターの反応"], ["…"], ["…"], ["…"]]
    }
  ],
  "prep": {
    "player": [["指ほぐしのセリフ1回目（まだ固い）", "主人公の反応"], ["指ほぐしのセリフ2回目（もうすぐ入る）", "主人公の反応"]],
    "monster": ["指ほぐしのセリフ（対モンスター）", "モンスターの反応"]
  },
  "summon": ["召喚時のセリフ1", "召喚時のセリフ2"],
  "turn_end": ["自分のターン終了時のセリフ"],
  "onedari_intro": "おねだりされた時の最初のセリフ（どれがいいか自分の口で言わせる）",
  "onedari": [["選択肢の短い名前（10字以内）", "主人公がねだる言葉", "責め手の返事"]],
  "inochi_first": ["命乞い（1回目）のセリフ1", "セリフ2"],
  "inochi_again": ["命乞い（2回目以降）のセリフ1", "セリフ2"],
  "inochi_fail": "とどめを刺された時の一言",
  "inochi_trap": "迷った隙を突く一言（ここから敗北）",
  "onani_first": ["オナニーを見つけた時のセリフ1", "セリフ2"],
  "onani_again": ["2回目以降のセリフ1", "セリフ2"],
  "onani_player": "主人公の言い訳（手が止まらない）",
  "onani_desc": "主人公の自慰の様子を描く地の文（得意技の真似。ペニスは使わない。60〜110字）",
  "end": "勝った時（主人公が負けた後）の締めの一言",
  "win": "負けた時（主人公に倒された時）の一言",
  "conv": "男モンスターが治療度6に達してクリニック側へ寝返る時のセリフ",
  "flavor": "カードのフレーバーテキスト（100〜130字。世界観と人物が伝わる地の文）"
}
```
- `techs` は担当キャラの技の数だけ、下の順番で書く。各技は player 4段階・monster 4段階（計16セリフ）。
- `prep` は挿入技を持つキャラ（ミサ・カズハ）だけ書く。それ以外は `"prep": null`。
- `onedari` は技の数だけ（技の順番どおり）。
- `onani_*` の自慰は、そのキャラの得意技に合わせる（brief.md の「オナニーの内容」）。
- `summon` `turn_end` `conv` はマスター（ミヤビ）も書く（ミヤビの summon は「スタッフを呼ぶ時」＝召喚宣言のセリフとして使う。ミヤビの turn_end は4つ＝主人公の段階1〜4で、それぞれ下の状態異常の説明に合う内容）。

## キャラと技（この順番で techs を書く）
- **ミヤビ**（`m.json`。prep は null）
  1. 触診：手袋の手で陰茎・陰嚢・会陰を順に診察として触り、硬さと反応を確かめる
  2. 前立腺マッサージ（★得意技）：ゼリーをつけた手袋の中指一本から、前立腺の形をなぞり、押し、揉みほぐす（段階1は入口を撫でる程度、段階が上がるほど奥へ・指を増やす）
  3. 振動器の検査：白い医療用の振動器を会陰・下腹に外から当て、奥を外側から震わせ、達する直前で離す（寸止め。中には入れない）
  - turn_end（主人公の段階ごと）：1＝寸止め、2＝発情、3＝攻撃指示不能（仲間に指示を出す声が出ない）、4＝魔法使用不能＋ダメージ
  - さらに `"quest"` を追加で書く（下）
- **アヤ**（`e1.json`。prep は null）1. 乳首の検査（★得意技。冷たい聴診器を乳首に当て、指で摘み転がして硬さを測る）　2. アナル体温計（細い体温計をゼリーで入れて測る。発情）。summon は召喚時（男モンスター1体か主人公の治療度+1）
- **レン**（`e2.json`。prep は null）1. 電極の感度測定（★得意技。乳首と会陰に電極を貼り、弱い電気の脈で刺激しながら秒数を数え、直前で「停止」。寸止め）　2. 指での前立腺検査（手順どおり中指で、秒数を数えながら）。turn_end は「自分のターン終了時に男モンスター1体（いなければ主人公）の治療度+1」のセリフ
- **ミサ**（`e3.json`。prep あり）1. アナルゼリー注入（★得意技。ほぐした後、温めた媚薬ゼリーを細い注入器で奥へ入れ、指で馴染ませる。ほぐし済みの時だけ出る。prep は「指ほぐし」＝ゼリーで濡らした手袋の指で一本→二本。ぬるぬる）　2. 処方薬の口移し（桃色のカプセルを口に含み、口づけで飲ませる。発情）。summon は召喚時（主人公にぬるぬる）
- **カズハ**（`boss.json`。prep あり）1. 所見の宣告（耳元で所見を短く断定し、考えを止める。攻撃指示不能）　2. 前立腺の再教育（★得意技。ほぐした後、白い前立腺刺激具を入れ、会陰を外から押して内外から挟む。ほぐし済みの時だけ出る。prep は「指ほぐし」＝ゼリーで濡らした黒い手袋の指で一本→二本）。summon は召喚時（治療度+3）、turn_end は固有効果「経過観察」（主人公の治療度6以上の時、主人公を寸止め、男モンスター1体を発情させて治療度+2）のセリフ

```json
"quest": {
  "first": ["説明:街はずれの白いクリニックの扉を開け、消毒液の匂いと秒針の音に迎えられる情景の地の文（90〜120字）", "セリフ", "セリフ", "セリフ（勝負の申し込み。勝てば帰れる、負けたら通院患者に）"],
  "won_before": ["セリフ", "セリフ"],
  "prev": {"1": "前回戦闘で負けた相手への出迎え", "2": "前回オナニーで負けた相手へ", "3": "前回命乞いで負けた相手へ", "4": "前回おねだりで負けた相手へ"},
  "prev_alert": "アラートの一文（例：前回の治療の続きを受けますか？）",
  "choices": ["挑む", "処置を受ける", "帰る"],
  "decline": "引き返す時のセリフ",
  "start": ["試合開始のセリフ1", "セリフ2（治療度が12に達したら治療完了＝一生の通院、の説明を含める）"],
  "lost_line": "ミヤビが負けた時のセリフ（クエストで勝たれた時）",
  "prev_continue": "前回の続きを流す前のセリフ",
  "kaisou": ["回想バトルの最初のセリフ1（今日はお好きな担当医をお選びください、など）", "セリフ2"]
}
```
`first` の先頭だけは `"説明:"` で始めて地の文にする（それ以外はミヤビのセリフ）。
