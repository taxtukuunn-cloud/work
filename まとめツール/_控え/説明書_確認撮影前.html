1. 始め方と終わり方

  1. 先に ComfyUI を起動します（撮影や下書きづくりをするとき）。
  2. まとめツール.bat をダブルクリックします。ブラウザに画面が開きます（開かないときは http://127.0.0.1:8765/ ）。
  3. 上の「④ 構図の元絵と下書き」タブを押すと、この説明書の画面が出ます。
  4. 右上の「説明書」ボタンを押すと、この説明書が画面の中で開きます。
  5. 終わるときは、黒い画面を閉じます。
撮影中にしてはいけないこと：黒い画面を閉じる（撮影が止まり、並んでいた残りの撮影も消えます）。下書きを外す・控えから戻す・下見・範囲の作り直し（撮影中はボタンが押せないようになっています）。

2. 全体の流れ

元絵を入れる→採用→奥行き→範囲→登録→下見→確認撮影→撮影
  • 元絵を入れる：画像生成\構図下書き元\_候補 に絵を置く。
  • 採用：④の「採用」タブで、見本から選ぶか、名前を作る。
  • 奥行き・範囲：撮影が終わってから、①の「元絵を採用する」を押すと、取り込みと奥行き・範囲づくりがまとめて動く。
  • 範囲：④の「範囲の確認」タブで、青と赤を確かめて直す。
  • 登録・確認撮影：まだこの画面ではできません（Claude に頼む）。
  • 下見：④の「当たり具合」タブで結果を見る。

3. 元絵を入れる場所と、絵の選び方

元絵は 画像生成\構図下書き元\_候補 に入れます。入れた絵は、④の「採用」タブの左に並びます。

注意：①の「候補を整理する」は、c で始まらない名前の絵（m・n・x で始まる絵）の名前を付け替えます。押す前に Claude に相談してください。

通す絵

  • 相手が画面の主役で、大人の体つき（顔ではなく体で見る）
  • 主人公が映らない目線の絵か、映っていても相手より小さいか同じくらい
  • 2人の体がはっきり分かれて見える
  • 主人公の顔が写っている（主人公目線の構図は除く）
  • 裸の場面用なら、主人公にあたる人物が裸
  • 長辺 800px 以上

外す絵

  • 受け側が筋肉質で大柄。受け側が女性の体に見える。男側が相手より大柄
  • 主人公の体が画面の真ん中を占める。主人公の頭が隠れる
  • 1人だけの絵。接写（主人公目線のキスだけは可）。体が絡んで読めない絵
  • 敵上位と逆の体勢
  • 250〜500px の小さい絵

主人公目線のキスを通す条件

  • 相手が大人の顔つき。見ている側の手が相手の顔を包んでいない。相手のほうから迫る形

幼さの見方の注意

  • 主人公目線や寄りの絵では、遠近で頭が大きく見える。頭の大きさだけで幼いと決めない
  • 真横からなど、カメラから同じ距離の絵で体が小さいものは外す

この基準は「採用」タブの右にいつも出ています。

4. 採用の画面

絵を選ぶ

  1. ④の「採用」タブを押します。
  2. 左上の選択肢で「未定」を選ぶと、まだ決めていない絵だけが並びます。
  3. 左の絵を1枚押すと、真ん中に大きく出ます。

見本から選ぶ（「これと同じ形」）

  1. 真ん中の「1. 見本から選ぶ」に、登録済みの構図が見本の絵つきで並びます。
  2. 技・姿勢・視点の選択肢で絞り込めます。「見本を白黒で出す」に印を付けると、白黒の下書きで見比べられます。
  3. 同じ形の見本の「これと同じ形」を押します。採用がその構図名になります。
  4. 「全部の絵」を押すと、その構図の元絵・白黒・範囲を全部見られます。

項目を選んで名前を作る

  1. 見本に合う形が無いときは、「2. 項目を選んで名前を作る」で、人数・技・姿勢・視点・位置・同時の技を選びます。選択肢は「日本語（英字）」の形で出ます。
  2. 選ぶと、その場で名前（英字）と読み（日本語）が出ます。
  3. 同じ項目の構図がもうあるときは、その見本が出ます。
    • 同じ形なら「同じ形なので足す」を押します。
    • 形が違うなら「形が違うので別の構図にする」を押します。名前の末尾に _b・_c が付きます。
  4. 同じ項目の構図が無いときは「この名前で採用する」を押します。

切り抜き・左右反転

  1. 大きく出た絵の上を、マウスでなぞって囲みます（切り抜く範囲）。
  2. 左右を反転したいときは「左右反転」に印を付けます。
  3. 「切り抜き・反転した写しを作る」を押します。元の絵はそのまま残り、写しが新しい候補として左に並びます。
  4. 写しの方を選んで、採用を決めます。

見送り・「新しい構図」に分ける・メモ

  1. 「判定のメモ」の欄に、理由を1行書きます（採用・見送りの理由）。メモは「メモ・予定」タブにたまります。
  2. 使わない絵は「見送り」を押します。
  3. どの見本にも合わず、名前もまだ決められない絵は「「新しい構図」に分ける」を押します。「新しい構図」タブに入ります。ここに入れた絵は登録しません。
  4. 決め直したいときは「未定に戻す」を押します。

決めたあと：撮影が終わってから、「① 画像」タブの「元絵を採用する」を押すと取り込まれます（奥行きと範囲も作られます）。新しい構図名で取り込んでも、登録するまでは撮影に使われません。

5. 語の早見表と名前の読み方

  1. 右上の「語の早見表」を押すと、英字と日本語訳の一覧がいつでも開きます。
  2. 語を足す・直すときは「構図名と語」タブの上の表を使います。「語を足す」の欄に項目・英字・日本語を入れて「足す」を押します。
  3. 今ある構図名は変えません。代わりに「今ある構図名と項目の対応」の表に、名前ごとの項目を持たせます。空欄は選んで「保存」を押します。
名前読み

two_ear_sit_front相手2人・耳・座る・前から

6. 奥行きの点検

奥行き（白黒の下書き）の自動点検はまだ使えません。今は、採用の画面の「全部の絵」や、MODごとの割り当ての画面の「白黒の下書き」で、目で確かめます。見ること：2人の体が別々の形として読めるか／窓枠・黒い余白・小物・線が形として残っていないか／頭が切れていないか／翼・尻尾・触手・大きな小物が無いか。

7. 範囲の確認

  1. ④の「範囲の確認」タブを押します。絵に青（主人公）と赤（相手）が重なって出ます。
  2. 「結果」の選択肢で「判定あいまい・要確認」などに絞り込めます。
  3. 違っていたら、その絵の下のボタンを押します。
    • 入れ替え：青と赤が逆のとき
    • 主人公なし：主人公が写らない絵（主人公目線など）
    • 使わない：範囲を作らず、白黒の下書きだけで撮る
    • 直しを消す：付けた直しを取り消す
  4. 理由は「直す理由」の欄に1行書けます。
  5. 撮影が終わってから「直した分の範囲を作り直す」を押すと、絵に反映されます（グラフィックボードを使います）。

手で囲む

主人公が背中向きの絵、顔が隠れた絵、顔が相手のすぐ下にある絵、相手が2人の絵などは、顔の検出がうまくいきません。そういう絵は、自分で囲んで範囲を決めます。手で囲んだ範囲は、顔の検出より優先されます。

  1. 「範囲の確認」タブで、その絵の下の「手で囲む」を押します。絵が大きく開きます。
  2. 上で、囲む人（主人公・相手1・相手2）と形（楕円・四角）を選びます。
  3. 絵の上をなぞって囲みます。頭から胸のあたりを目安にします。続けて、ほかの人も囲みます。
  4. 細かい所は「大きさ」で 150%・200% にすると囲みやすくなります。
  5. 間違えたら「1つ戻す」、やり直すなら「全部消す」を押します。
  6. 「保存」を押します。
  7. 撮影していないときに「直した分の範囲を作り直す」を押すと、絵に反映されます。
  • 相手は少なくとも1人（相手1）を囲みます。主人公が写らない絵（主人公目線など）は、主人公を囲まずに相手だけ囲みます。
  • 主人公と相手の囲みが重なる所は、主人公の範囲になります。
  • 囲みを全部消して保存すると、その絵は顔の検出の結果に戻ります（作り直しを押したとき）。
  • 「直す」が「使わない」の絵は、囲んでも範囲を作りません。

8. 相手が複数のとき

顔の検出では、顔が3つ以上ある絵は、一番男らしい顔が主人公（青）、一番女らしい顔が相手（赤）になります。真ん中の人には範囲が付きません。相手2人の絵は、「手で囲む」で相手1・相手2 を別々に囲んでください。相手1 は画面の左の人を目安にします。

撮影で相手1・相手2 に別々の文を当てる仕組みはまだ使えません。今は、相手1と相手2を合わせた範囲に、相手の文が入ります。

9. 相手の種類

下書きごとに胸・翼・尻尾などを付けて、男の娘・女性・NH で当て分ける仕組みはまだ使えません。今は「MODごとの割り当て」の画面で、場面の文から読んだ相手の種類（男の娘・女性・NH・ふたなり、翼・尻尾・角など）を見られます。

10. 構図の登録

取り込んだ構図は、登録するまで撮影に使われません。登録は「構図の登録」タブで行います。

  1. ④の「構図の登録」タブを押します。左に、まだ登録していない構図が並びます。「新しい構図」タブの「登録する」からも開けます。
  2. 構図を押すと、右に白黒の下書きと範囲が出ます。
  3. 「1. 項目」を確かめます。直すと「構図名と語」の表も直ります。
  4. 「2. 当てる組」で、どの技の、どんな場面（寝ている・座っている・立っている など）に使うかを選びます。おすすめの組が上に開いていて、姿勢の合う行に印が付いています。行の中の構図の名前を見て、同じ仲間の行を選びます。
  5. 「3.」で視点・役の文・姿勢を確かめます。役の文は項目から自動で作ってあります。必要なら直します。
  6. 「替え専用にする」は、ふつうは印を付けたままにします。替え専用の構図は、同じ MOD で下書きが重なったときだけ使われるので、撮り済みの絵の割り当てがほとんど動きません。
  7. 「変わる所を見る」を押すと、model.json のどこが変わるかが出ます。
  8. よければ「確認した。登録する」を押します（撮影中は押せません）。書き換える前に控えを取ります。続けて下見が自動で動きます。
  9. 下見が終わったら、「当たり具合」で、割り当てが動いた場面を確かめます。
  • 合う組が無い構図は、登録できません。「新しい構図」に残して、Claude に頼みます（全 MOD の場面と照らして、当てる条件を作ります）。
  • 登録を取り消したいときは、「model.json の控え」タブで、登録前の控え（model_日時_構図〇〇登録前）に戻します。

11. 下見の見方・MODごとの割り当て

当たり具合

  1. ④の「当たり具合」タブを押します。上に、下見をいつ作ったかが出ます。「下見が古い」と出たら、撮影が終わってから「下見をやり直す」を押します（約3分）。
  2. 数の意味：
    • 組み立て失敗：その場面の指示が作れなかった。Claude に伝える。
    • 本文と下書きの姿勢の食い違い：本文は寝ているのに下書きは四つんばい、など。
    • 同じMODの中での重複：1つの MOD で同じ下書きを2回以上使っている。
    • 下書きなしの場面：合う下書きが無い（触手・機械などに多い）。
    • 割り当てが動いた場面：前の下見と比べて、下書きが変わった場面。撮り済みなら撮り直しを考える。
  3. 数が急に増えたら、何を変えたあとかを Claude に伝えます。
  4. 「構図ごとの当たり具合」の行を押すと、その構図が当たった場面が出ます。「場面を見る」で次の画面へ移ります。

MODごとの割り当て

  1. ④の「MODごとの割り当て」タブを押します。
  2. 「MOD から見る」：左の一覧で MOD を押すと、その MOD の場面が右に並びます。見出しを押すと並べ替えられます（印の多い MOD から見るなど）。
  3. 「構図から見る」：構図か下書き1枚を押すと、それが当たっている場面が MOD をまたいで並びます。
  4. 1場面ごとに、元絵／白黒の下書き／範囲／撮った絵が並びます。絵を押すと大きく見られます。
  5. 「くわしく（シチュエーション）」を押すと、相手の名前・技の名前・セリフ・前後の本文・絵の指示から読んだ内容が出ます。
印意味
下書きなし合う下書きが無い
姿勢の食い違い本文の姿勢と下書きの姿勢が違う
同じMODで重複同じ MOD で同じ下書きを使っている
撮った時と違う撮ったときの下書きと今の割り当てが違う（撮り直しの対象）
範囲なし／主人公の範囲なし下書きに人物の範囲が無い／主人公の範囲が無い
下見にまだ無い下見を作った後に増えた MOD（下見をやり直すと出る）

下書きが合わないと思ったとき

  • 本文に下書きを合わせる：「この下書きを外す…」を押す。ほかにどの場面が影響を受けるかと、model.json の変わる所が出ます。理由を書いて「確認した。外す」を押します（撮影中は押せません）。外す前に model.json の控えを取ります。外したあとは下見をやり直します。
  • 後で本文を直す：「本文を後で直す（メモ）」を押す。「メモ・予定」タブにたまり、「文章で出す」で一覧の文章になります。

12. 確認撮影

この画面からの確認撮影はまだ使えません。撮れた絵を見るところ：役が逆になっていないか／主人公が筋肉質・大柄になっていないか／主人公が女性の体になっていないか／頭が切れていないか／相手の服や翼が主人公に移っていないか／人物が幼く見えないか。だめな下書きは「MODごとの割り当て」で外します。

13. 撮り直し

  1. 「MODごとの割り当て」で、撮り直したい場面の「撮り直しの予定に入れる」を押します。「撮った時と違う」の印が付いた場面が目安です。
  2. 「メモ・予定」タブの「撮り直しの予定」で一覧を見ます。やめる場面は印を付けて「印の行を予定から外す」。
  3. 撮影が終わってから「予定の場面を撮り直す」を押します。今の割り当てで撮り直します。前の絵は消えません。

14. 控えから戻す（model.json）

  1. ④の「model.json の控え」タブを押します。
  2. 戻したい控えの「変わる内容を見る」を押します。戻すと何が変わるかが出ます。
  3. よければ「確認した。この控えに戻す」を押します（撮影中は押せません）。
  4. 戻すのは構図の選び方（pose_control）だけです。年齢に関わる設定と、人物の範囲の文はそのままです。戻す前の状態も控えに取ります。
  5. 下の「変更の記録」に、いつ・何を・どの控えから変えたかが残ります。

15. 困ったとき

16. してはいけないこと

  • 撮影中に、まとめツールの黒い画面を閉じる・設定を変える（撮影が止まる・途中から選び方が変わる）。
  • 年齢に関わる設定を変える（この画面からは変えられないようになっています）。
  • ゲーム本体のフォルダのファイルを、手で書き換える。

スマホから使う機能は、まだ使えません。
