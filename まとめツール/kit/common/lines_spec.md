# カード用セリフの書き方（N106〜N157 共通・担当者向け）

個人用・成人向けゲームMOD。登場人物は全員20歳以上の成人。
1. 担当MODの `/home/claude/work/kit106/mods/<コード>/brief.md` を**最初に全部読む**（口調・言い方・得意技・オナニー・共通仕様）。
2. 同じフォルダの `cfg.py` を読む（技の順番・攻撃タイプ・insert・カード効果・固有効果・魔法罠5種の名前と効果・stack／mstack・mon_fate）。brief の「カード効果」の章も読む。
3. 完成済みのシナリオが `/home/claude/work/kit106/mods/<コード>/scen/` にあれば、担当キャラの btl を1本読んで調子を合わせる。
4. 見本として別MODの完成例 `/home/claude/work/kit106/ref/m.json`（マスター）・`/home/claude/work/kit106/ref/e1.json`（下級）を読む（形と調子だけ。内容はまねない）。

ここで書くのは**バトル中にカードが話すセリフ**。JSONファイル1つに1キャラ分。

## 本文の決まり（厳守）
- 半角カンマ「,」禁止（全角「、」）。`$ % & # { } < > ;` 禁止。半角の `!` `?` `(` `)` も使わず全角。
- 1つのセリフは40〜110字（反応は15字以上）。改行したい時だけ `\\n`。「」は付けない。
- 責め手の口調をはっきり出す（brief の表どおり）。おちんちん／お尻の穴／前立腺はぼかさず、責め手の呼び方は「言い方」表どおり。
- **主人公（僕）の反応・ねだる言葉・言い訳には必ず❤**（1〜3個）。主人公は160cmの細身の成人男性。「小柄」「華奢」は使わない。
- 幼さを示す語は使わない。「俺」は使わない（男の娘の一人称は brief どおり。**男モンスターの反応の一人称は「僕」**）。

## 累積スタックと段階
brief の累積スタックを使う。**主人公に向けたセリフでは主人公用の名前（cfg の stack）、男モンスターに向けたセリフでは男モンスター用の名前（cfg の mstack）**を使う。攻撃を受けた側が個別に持つ。セリフは**受けた側の段階**で変え、数に触れてよい（「もう七本目」など）。
- 主人公（上限12で敗北）：段階1＝1〜3／段階2＝4〜6／段階3＝7〜9／段階4＝10〜11
- 男モンスター（上限6。6で破壊か敵側への寝返り）：段階1＝0〜1／段階2＝2〜3／段階3＝4／段階4＝5
- 男モンスターは主人公の仲間の男（剣士・獣人など種族はいろいろ。成人）。責め手は「お連れ」「お仲間」など、そのキャラらしい呼び方で。

## JSONの形
```json
{
  "techs": [
    {
      "player": [["責め手のセリフ（段階1）", "主人公の反応（段階1）❤"], ["…段階2", "…❤"], ["…段階3", "…❤"], ["…段階4", "…❤"]],
      "monster": [["責め手のセリフ（対モンスター段階1）", "モンスターの反応（僕）"], ["…"], ["…"], ["…"]]
    }
  ],
  "prep": {
    "player": [["指ほぐしのセリフ1回目（濡らした指を一本。まだ固い）", "主人公の反応❤"], ["指ほぐしのセリフ2回目（二本目・前立腺。もうすぐ入る）", "主人公の反応❤"]],
    "monster": ["指ほぐしのセリフ（対モンスター）", "モンスターの反応（僕）"]
  },
  "summon": ["召喚時のセリフ1", "召喚時のセリフ2"],
  "turn_end": ["自分のターン終了時のセリフ"],
  "onedari_intro": "おねだりされた時の最初のセリフ（どれがいいか自分の口で言わせる）",
  "onedari": [["選択肢の短い名前（10字以内）", "主人公がねだる言葉❤", "責め手の返事"]],
  "inochi_first": ["命乞い（1回目）のセリフ1", "セリフ2"],
  "inochi_again": ["命乞い（2回目以降）のセリフ1", "セリフ2"],
  "inochi_fail": "とどめを刺された時の一言",
  "inochi_trap": "迷った隙を突く一言（ここから敗北）",
  "onani_first": ["オナニーを見つけた時のセリフ1", "セリフ2"],
  "onani_again": ["2回目以降のセリフ1", "セリフ2"],
  "onani_player": "主人公の言い訳（手が止まらない）❤",
  "onani_desc": "主人公の自慰の様子を描く地の文（僕の視点。そのキャラの得意技の真似。おちんちんは使わない。60〜110字）",
  "end": "勝った時（主人公が負けた後）の締めの一言",
  "win": "負けた時（主人公に倒された時）の一言",
  "conv": "男モンスターの累積スタックが6に達した時のセリフ（cfg の mon_fate：破壊なら消えていく／寝返りなら敵側に迎える）",
  "flavor": "カードのフレーバーテキスト（100〜130字。世界観と人物が伝わる地の文）"
}
```
- `techs` は担当キャラの技の数だけ、**cfg.py の techs の順番**で書く。各技は player 4段階・monster 4段階（計16セリフ）。
- `prep` は**cfg.py で insert=True の技を持つキャラだけ**書く（マスター・上級に限らない。下級でも挿入技があれば書く）。それ以外は `"prep": null`。
- `onedari` は技の数だけ（技の順番どおり）。
- `summon`：下級・上級＝召喚時のセリフ（カード効果の内容に合わせる）。マスター＝**4つ**（召喚宣言のセリフ。主人公の段階1〜4）。
- `turn_end`：下級・上級＝自分のターン終了時の効果のセリフ（効果がないキャラも1つ書く。上級は固有効果の発動セリフ）。マスター＝**4つ**（主人公の段階1〜4。cfg の turn_end_ops のとおり、段階1・2は A、段階3は B、段階4は B＋ダメージ）。
- `onani_*` の自慰は、そのキャラの得意技に合わせる（brief の「オナニー」の表）。

## 女装ありMOD（N79・N87・N89・N104）だけ
- 技が「女装」（衣装を着せる）のキャラは `"josou_line"` を追加：男モンスターに衣装を着せて、そのモンスターが女装娘になる瞬間のセリフ（40〜110字）。
- 女装の技の player 段階のセリフは、主人公に衣装を着せていく流れ（段階が上がるほど衣装が増え、着たまま責められる）。monster 段階のセリフは、男モンスターに衣装を当てがう・着せかける流れ。
- マスターの `magic` に女装の魔法（衣装を支給して男モンスター1体を女装娘にする）があるので、そのセリフも衣装を着せる内容で。
- 主人公の反応は、着せられた衣装の恥ずかしさと、脱げない・着たままの心細さを❤付きで。

## マスターだけ追加：`"quest"`
```json
"quest": {
  "first": ["説明:主人公が舞台に着き、マスターと向かい合う情景の地の文（僕の視点。90〜120字）", "セリフ", "セリフ", "セリフ（勝負の申し込み。勝てば帰れる、負けたら累積スタックが満ちて結末へ）"],
  "won_before": ["セリフ", "セリフ"],
  "prev": {"1": "前回戦闘で負けた主人公への出迎え", "2": "前回オナニーで負けた主人公へ", "3": "前回命乞いで負けた主人公へ", "4": "前回おねだりで負けた主人公へ"},
  "prev_alert": "アラートの一文（例：前回の続きをしますか？）",
  "choices": ["勝負する", "（前回の続きを受ける選択肢名）", "（立ち去る選択肢名）"],
  "decline": "立ち去る時のセリフ",
  "start": ["試合開始のセリフ1", "セリフ2（累積スタックが12になったら結末、の説明を含める）"],
  "lost_line": "マスターが負けた時のセリフ（クエストで勝たれた時）",
  "prev_continue": "前回の続きを流す前のセリフ",
  "kaisou": ["回想バトルの最初のセリフ1（あの夜をもう一度。好きな者を呼べる、など）", "セリフ2"]
}
```
`first` の先頭だけは `"説明:"` で始めて地の文にする（それ以外はマスターのセリフ）。

## マスターだけ追加：`"magic"`（魔法・罠5枚のセリフとフレーバー。cfg.py の magic の順番どおり5つ）
```json
"magic": [
  {"name": "カード名（cfg どおり）", "line": "発動した時のマスターのセリフ（40〜90字）", "flavor": "フレーバー（80〜120字の地の文）"},
  …（5つ。永続魔法のものだけ、さらに "persist_line": "ターン終了時に効果が続く時のセリフ", "end_line": "3回目で消える時のセリフ" を足す）
]
```
