# 敗北シナリオの書き方（N76〜N157・本編踏襲）

成人向け（M男向け）カードゲーム「サキュバスデュエル」の個人用MOD。登場人物は全員20歳以上。個人利用のみ。
ゲーム本編の敗北イベントと同じ書き方で書く（2026-09-28 ユーザー決定。プロジェクト指示の「5,000字以上」より優先）。

## 長さと割合（`check4000.py` で確認）
- **1本 約4,000字**（セリフ・説明の本文だけ。`\n` は数えない。許容3,700〜4,900字。3,800〜4,300字を狙う）。
- **割合**：責め手のセリフ 約7割（55〜80%）／説明（地の文）約2割（12〜32%）／主人公のセリフ 約1割（5〜18%）。
- 区画：`#導入`（150〜700字。どう負けたか・なぜこの責めか・場所）→`#プレイ`（本体）→`#結び`（200〜900字。後日談と締め）。

## 本編の書き方
- 冒頭は短い説明1行（「〜に敗れた僕は、エナジーを奪われて〜膝をついていた。」）→主人公の短い喘ぎ→責め手が語り始める。
- **責め手がよくしゃべる**。1セリフは `\n` で2〜3行に折る（1行20〜35字くらい）。「くすくす❤」「うふふ❤」「あはっ❤」など、キャラらしい笑い。
- 主人公は短い喘ぎ（「はひぃっ❤❤」「あっ、あっ、ああっ❤」「も、もう・・・❤」）と、心の声（`（〜）` を説明の行で）。
- **ハートは❤で統一**（責め手・主人公とも。♡は使わない）。三点は「・・・」（中黒3つ）を中心に。
- 地の文は一人称「僕」。1行50〜60字。責め手の呼び方は brief どおり。

## エロさの基準（本編v2見本）
1. 序盤で主人公を脱がせる。責め手も胸をはだけ（衣装は着たまま必要な所だけ）、素肌を密着させる。勃起・先走りを最初に描く。
2. **★得意技を何段階にも重ねる**（例：口づけなら 舌を吸う→唾液を垂らして飲ませる→全身に口づけの痕→おちんちんには息だけ）。
3. 擬音を多めに（ちゅぷ・じゅるっ・ぬちゅぬちゅ・こりこり・むにゅっ・ぱちゅん）。乳首は つまむ・転がす・舐める・甘噛み。
4. **寸止めを2回**入れ、言葉を言わせる山を重ねる（例：「勝てない」→「どうでもいい」→「〇〇さんのもの」）。
5. 最後は同時責め（得意技＋手や胸＋乳首など）で**カウントダウン射精**（「３、２、１・・・ぜろ❤」）。
6. その後に**★得意技だけでの2回目**（触れずに／乳首だけで／匂いだけで など、そのキャラの★で）。
7. 責め手が精液を舐める・感想を言う。累積スタックの「印」を体に残し、日常でも反応する体にする。
8. 結び：説明で後日談（数日〜数週間の様子）→短い会話→**最後の説明2行で「〜主人公の物語はその幕を閉じた。」**（最後だけ地の文が「主人公」になる）。

## 射精と演出の行
```
射精
ウェイト,1
フェードアウト,2
フェードイン,1
フラッシュ,ピンク
画面色変化,ピンク,1
画面色解除,1
SE,&&おっぱいSE
SE,&&服を脱がすSE
```
- `射精` は2回以上（カウントダウンの1回目・★だけの2回目）。射精の直後は `ウェイト,1`。場面の切り替え（後日談の前など）に `フェードアウト,2` → `フェードイン,1`。

## ファイルの書式（`scen/<経路>_<key>.txt`）
```
#導入
画像,#<コード>/<コード>_lose_<経路>_<key>.png,1
説明,……
#プレイ
話者,%名前
セリフ,……
話者,相手プレイヤー
セリフ,……❤
#結び
説明,……
```
- 使える行：区画の目印、`画像,…`（自分のファイル名だけ）、`話者,%名前`（brief の話者名）、`話者,相手プレイヤー`（主人公）、`セリフ,`、`説明,`、上の演出行。
- 話者が変わるたびに `話者,` を入れる。セリフに「」は付けない。空行・インデント・コメント・`@` 行・BGM・GAME OVER は書かない。
- **本文の禁止文字**：半角 `, $ % & # { } < > ; ! ?`（全角「、」「！」「？」を使う）。`\n` はバックスラッシュ＋n の2文字。

## 絶対条件
- 全員20歳以上の成人。**幼さを示す語は使わない**（少年・子供・幼い・ロリ・少女・ショタ・童顔・男の子 等）。主人公は身長160cmの細身の成人男性。「小柄」「華奢」「すっぽり」は使わない。
- 責め手が常に上位。**逆転なし**。主人公は受け身だけ（挿入しない・責め返さない）。アヘ顔・凌辱・暴力・流血・痛み・死は描かない。
- 挿入（ペニバン・ふたなり・NH・尾や蔦など）の前は**必ず指でほぐす**（濡らす→一本→二本→前立腺→「もう入る」）。
- ふたなり・NHの体を笑い物にしない。NH・ふたなりの一人称に漢字の「僕」を使わない。
- オナニー負け（onani）は、その責め手の★得意技に合わせた自慰（ペニスを使わない）から始め、見つかって責められる流れ。オナニーの場面は主人公ひとりで始める。
- 女装ありMODは、4本すべてで主人公に衣装を着せる場面を入れ、着せた後は最後まで脱がさない。
