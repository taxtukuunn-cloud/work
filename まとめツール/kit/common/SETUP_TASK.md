## N106〜N157 の追加ルール（設計メモに無い部分はここで決める）
- **強さの序列 master ＞ boss ＞ e1 ＞ e2 ＞ e3**。下級は e1 atk550・hp1600／e2 atk500・hp1500／e3 atk450・hp1400。boss は atk1200・hp6000。★で積む量は設計メモどおり（master+3・boss+3・e1〜e3+2 が基本）。カード効果・固有効果も重さをこの順に（e1 が一番重く e3 が一番軽い）。
- 設計メモにはカード効果・魔法罠が書かれていない。**ここで決める**：下級3体の効果（召喚時 or ターン終了時。summon_ops／end_ops）、boss の召喚時+3 と固有効果（unique。once=True）、マスターの turn_end_ops（段階1〜4）、魔法・罠5種（std_magic の add／target／search／trap／persist を1つずつが基本。名前は世界観の道具・場所から）。状態異常は 発情・魅了・拘束・寸止め・攻撃指示不能・洗脳・麻痺 など技の内容に合うもの。決めた内容は brief.md の「カード効果」の章に表で書く（セリフ担当が読む）。
- **累積スタックは2つ**：主人公用 `stack`（設計メモの「累積スタック」）と、男モンスター用 `mstack`（設計メモの「味方モンスター（男）の累積」）。cfg に `stack="…", mstack="…"` と両方書く。explain などの文では「主人公の〇〇／男モンスターの△△」と書き分ける（std_magic の説明文は主人公側の名前になるので、作った後に `d["explain"]` を書き直してよい）。
- 男モンスターが6に達した時：設計メモが「破壊」なら `mon_fate="destroy"`、「寝返り」なら書かない。
- 攻撃タイプは1キャラ2種以上（下の補足の一覧から選ぶ）。挿入する技（尾・蔦・粘体・ペニバン・ふたなり等）は `insert=True`。
- **2人組・3人組のカード**（設計メモに「2人組」「3人1組」とあるキャラ）：カードは1枚、speakers にそれぞれの話者名を同じ key で並べる（例 `("%イゼヴェル","boss","女"), ("%メロエ","boss","女")`）。画像は1枚に2人。
- 話者名は設計メモの「話者名」欄どおり（他MODと重なる名前の注意書きがあれば従う）。
- 原作の立ち絵は使わない（すべて新規画像 `#<コード>/<コード>_<key>.png`）。speakers の4つ目・img は書かない。bg は `"#<コード>/<コード>_bg.png"`。
- **N112 のコードは `Sphinx2`**（N100 が Sphinx を使用済みのため）。フォルダ・outdir・画像名もすべて Sphinx2。設計メモのファイルは N112_Sphinx.md。
- 主人公は v5（二十歳・160cm・B80/W64/H82・細身・非筋肉質・紺髪）。「小柄」「華奢」「すっぽり」「ボウヤ」「坊や」「少年」は使わない。「いい子」「赤ちゃん」も禁止。

## 出力（`/home/claude/work/kit106/mods/<コード>/`）
### cfg.py
- 先頭：`import os, sys` → `sys.path.insert(0, "/home/claude/work/kit106/common")` → `from cfgkit import T, std_magic`。
- `code`=コード、`outdir`="N??_<コード>_MOD"、`stack`=累積スタック名、`sex`=マスターの性別（女 or その他）、`speaker_sex`="女"、`attr`（属性）。
- `bg`：`"#<コード>/<コード>_bg.png"`。
- `quest_name`（「MOD名（マスター名）」）、`quest_name_kaisou`（「MOD名【回想バトル】」）、`lose_title`（「―― MOD名　〇〇 ――」）、`player_full_desc`（主人公のスタックが12に達した時の一文。80〜110字）、`conv_desc`（男モンスターが6に達して処理される時の説明）、`magic_conv`（同じ時のマスターのセリフ）。
- 破壊方式のMODは `mon_fate="destroy"`（寝返りは書かない＝既定の conv）。
- `speakers`：`[("%話者名", "master"|"e1"|"e2"|"e3"|"boss", "女")]`（ふたなり・NH は "女" のまま。カードの sex だけ "その他"）。
- `weak`：m1〜m3・e1〜e3・boss → その技の攻撃タイプ（下級・上級は★の技の攻撃タイプ）。
- `master`：name（肩書き＋全角スペース＋名前）・race・sex・atk=500・explain（★と積む量、挿入技の指ほぐし、ターン終了時の段階効果）・techs（設計メモの m1 m2 m3 の順。★に `fav=3`、挿入技に `insert=True`。ふたなり・NHの逆アナルには `st=("発情", 1)`）・turn_end_ops（段階1〜4。段階に応じ A→B → [[A],[A],[B],[B＋("dmg_p",500)]]）。
- `race`（タイプ設定）は **「ローグ」「戦士」「獣」のどれか**（人外の種族名は書かない。獣人・人狼などは「獣」、それ以外は「ローグ」を基本に）。
- `mons`：e1〜e3（aid 4〜6・lv4・atk450〜550・hp1500〜1600・rare "R"）と boss（aid 7・lv7・atk1200・hp6000・rare "SR"）。sex は女性＝"女"、ふたなり・NH＝"その他"。techs（★は下級 fav=2・上級 fav=3）、explain、summon_ops／end_ops（上で決めたカード効果）、boss の unique（固有効果：name・min（閾値）・once（1試合1回なら True）・ops）。
  - 寝返り方式の固有効果は `("m_status_add", 状態, ターン, 6)`（6を足して処理させる）など、ops の命令で近いものを選ぶ。
- 女装ありMODは `josou=dict(name, desc, explain, flavor, turn_line, battle_line)` と、女装の技に `josou=True`。
- `magic=std_magic(S, [...])`：魔法・罠5種を、`("名前","add",2)`／`("名前","search",None)`／`("名前","trap","状態")`／`("名前","target",("状態",1))`／`("名前","josou","衣装")`／`("名前","persist",None)` で。
- 書いたら `cd /home/claude/work/kit106/mods/<コード> && python3 -c "import cfg; print(len(cfg.CFG['mons']))"` で読めることを確認。

## 守ること

- 全員20歳以上。幼さを示す語を使わない。痛み・凌辱・逆転なし。挿入は指ほぐしの後。
- 本文の禁止文字（半角 `, $ % & # { } < > ; ! ?`）は cfg の文字列にも入れない（explain 等も全角）。
