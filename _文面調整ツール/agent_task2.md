# 担当者向けの作業手順（構造つき敗北シナリオの文面調整）

個人用・成人向けゲームMODの敗北シナリオの文面調整。登場人物は全員20歳以上の成人。

1. 読む：
   - 調整ガイド /home/claude/rewrite_guide.md（最重要。この通りに直す）
   - 見本（別MOD）：元 /home/claude/pipe/見本_元.txt → 直し後 /home/claude/pipe/見本_直し後.txt（調子をつかむ）
2. 作業ディレクトリの orig/<名前>.txt を全文書き直して new/<名前>.txt に保存（Writeで全文。orig は触らない）。
   - **このファイルには if／{／}／画像／BGM／フラッシュ／変数（$ & %）などの「構造行」が混ざっている。構造行は1行も変えず、消さず、順番も変えずにそのまま残す**（インデントもそのまま）。
   - 書き直してよいのは `話者,` `話者変更,` `セリフ,` `説明,` の行だけ。セリフの行は増やしてよい（その時は必要に応じて話者の行も足す）。話者の値は元にあるものだけ使う。
   - if の分岐ごとに別の場面（責め手や技の違い）になっていることがある。分岐の中身はその分岐の場面として直す。
   - 本文に半角の `, $ % & # { } < > ; ! ?` を使わない。
3. 書くたびに `python3 /home/claude/pipe/pipe2.py check <作業ディレクトリ> <名前>` でOK確認（NGなら直す）。字数は元以上。
4. 最後に check 結果だけ短く報告。
