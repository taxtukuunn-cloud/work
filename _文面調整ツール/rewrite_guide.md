# 敗北シナリオ 文面調整ガイド（全MOD共通・2026-09-26 ユーザー承認済み）

個人用の成人向けゲームMOD（サキュバスデュエル）。登場人物は全員20歳以上の成人。
既存の敗北シナリオを**書き直す**作業。**話の大筋（展開・場所・責めの順番・絶頂の回数・結末の印・結びの約束）は変えない。**

## 直すこと
1. **主人公の喘ぎ・セリフに「♡」を付ける**（`話者,相手プレイヤー` の行）。快感が混ざった所から付ける。語尾や喘ぎの切れ目に「♡」（例：「あっ♡　そこ……っ♡」）。全部の文末に付けすぎず、1セリフに1〜4個程度。冒頭の純粋な拒否（まだ感じていない所）には付けなくてよい。責め手のセリフには付けない。
   - 主人公の喘ぎのセリフが少ない所は、短い喘ぎのセリフを足してよい（字数を増やす方向はOK）。
2. **文章をやさしく**：一文を短く。凝った比喩・難しい漢語・文学的な言い回しを減らし、読みやすい普通の言葉にする（例：「縫いとめられた」→「張りついた」、「震えるだけの肉になっていた」→削る、「帳のように」→「カーテンのように」）。特殊な用語（丹田など）には「おへその下、ここが丹田だ」のように言い換えを添える。擬音（ぬぷっ・ごりっ・ぬちゅぬちゅ・きゅうきゅう）は使ってよい。
3. **「奥」「前」「後ろ」「急所」などをぼかさず具体的に**：
   - 前・触れていないもの・彼のもの → **おちんちん**（地の文と主人公のセリフ）。責め手のセリフでは**責め手の口調・性格に合わせた言い方**（下の表）
   - 後ろ → お尻／お尻の穴
   - 奥の一点・急所・腹側のふくらみ・「あの場所」 → **前立腺**（最初に出る所で「おちんちんの付け根の裏、お尻の入り口から指の第二関節くらいの所にある、栗の実くらいのふくらみ」のように位置も書く）
   - 最奥・いちばん奥・行き止まり → お尻のいちばん奥、結腸の入り口
   - 下腹の奥・腹の奥 → おへその下／お腹の中／おへその裏あたり（何を指すかで選ぶ）
   - 頭の奥 → 頭の中
   - 胸の先 → 乳首、「先」 → おちんちんの先、など
   - 精液を「白いもの」とぼかしている所 → 「白いの」「精液」など分かる言い方
   - **責め手のセリフでの言い方は、その責め手の口調・性格に合わせて変える**（ユーザー指示）。例：古風・時代もの＝魔羅／尻の穴、威勢がいい・乱暴＝ちんちん／ケツの穴、甘い・ささやき＝おちんちん／お尻の穴、医者・研究者・機械＝陰茎・ペニス／肛門・前立腺・尿道（名前をはっきり）、無感情＝陰茎／尻、お嬢様・上品＝おちんちん／お尻、ギャル・小悪魔＝ちんぽ／お尻、など。**同じ責め手は4本とも同じ言い方でそろえる**。前立腺は全員「前立腺」と言ってよい（位置を知っている感じで）。
   - 地の文は主人公の一人称「僕」で書く（元が「主人公」「君」「自分」で書かれていたら「僕」に直す。全本でそろえる）。主人公のセリフの一人称も「僕」。
   - 責め手を指す代名詞はブリーフの設定どおり（男の娘なら「彼」、女性なら「彼女」）。
4. 責め手のセリフの**口調・一人称・呼び方はMODのブリーフどおり**に保つ（性格はそのまま、言葉だけやさしく具体的に）。

## 守ること（書式）
- ファイル構成・コマンドはそのまま：`#導入` → 2行目 `画像,...` → … `#プレイ` … `#結び`。使えるコマンドは元ファイルにあるものだけ（話者・セリフ・説明・画像・射精・フラッシュ・画面色変化・画面色解除・ウェイト など）。`話者,` の値は元どおり。
- 本文に**半角**の `, $ % & # { } < > ; ! ?` を使わない（読点は「、」、感嘆は「！」「？」全角）。改行は `\n`。「♪」は使わない。「♡」は使ってよい。
- 幼さを示す語は禁止（少年・子供・子ども・幼い・ロリ・少女・ショタ・童・童顔）。小柄さは「背が低い」「華奢」「頭ひとつ以上小さい」で。
- 字数：導入 300〜650字、**プレイ 6,000字以上**（元より減らさない。できれば元と同じか少し多め）、結び 200〜700字。
- 暴力・流血・アヘ顔・凌辱の描写はしない（元にない物を足さない）。責め手上位・逆転なしはそのまま。

## 手順
1. 見本（直し済み）を読んで調子をつかむ。
2. 担当ファイルを1本ずつ、元を読んで全文を書き直し、指定の出力先に同じファイル名で保存（元ファイルは上書きしない）。
3. チェッカーで確認し、エラーが出たら直す。
