# 担当者向けの作業手順（敗北シナリオの文面調整）

個人用・成人向けゲームMODの敗北シナリオの文面調整。登場人物は全員20歳以上の成人。

1. 読む：
   - 調整ガイド /home/claude/rewrite_guide.md（最重要。この通りに直す）
   - このMODのブリーフ（口調・世界観）：作業ディレクトリの tools/brief.md（あれば。無ければ指示文のキャラ説明を使う）
   - 見本（別MOD）：元 /home/claude/pipe/見本_元.txt → 直し後 /home/claude/pipe/見本_直し後.txt（調子をつかむ。書式はこのMODの orig に合わせる）
2. 作業ディレクトリの orig/<名前>.txt を1本ずつ全文書き直して new/<名前>.txt に保存（Writeで全文。orig は触らない）。
   - #導入/#プレイ/#結び の目印は、orig に無ければ足さない。画像行はそのまま（行も位置も変えない）。話者名も元のまま。
   - 責め手のセリフの言い方は指示文の表どおりに（同じ責め手はそろえる）。
3. 1本書くたびに `python3 /home/claude/pipe/pipe.py check <作業ディレクトリ> <名前>` でOK確認（NGなら直す）。字数は元以上。
4. 最後に担当分の check 結果だけ短く報告。
