N133_REso_MOD  2026-10-03
======================================================
サキュバスデュエル用・個人利用のみ。登場人物は全員20歳以上。
偽りのエリュシオン（冥界の審判者　ラダマンテュス）

■ 内容
- CSV\Card\  カード（REso_master／mons_e1〜e3・mons_boss／magic_1〜5／REso_recall＝回想の栞）
- CSV\Eventlist\Quest\REso.txt  クエスト登録（通常＋【回想バトル】の2行）
- N133_REso_読む用シナリオ集.txt  敗北シナリオ28本（本編の書き方・1本約4,000字、合計 約108千字。ゲームには入れない）
- 画像一覧.txt  必要な画像 46枚（まだありません。ComfyUIで作る）
- tools.zip  生成キット（cfg.py・brief.md・scen 28本・lines 5本・共通スクリプト）

■ ゲームへの入れ方
1. CSV\Card\*.txt → ゲームの CSV\Card\（REso_recall.txt も必ず一緒に）
2. CSV\Eventlist\Quest\REso.txt → ゲームの CSV\EventList\Quest\
3. 画像ができたら ゲームの Picture\REso\ へ（画像が無いと画像の行で止まる可能性あり）
4. 回想の栞の共通画像 MOD\_共通ツール\Picture\RecallUI\recall_panel.png を Picture\RecallUI\ へ（1回だけ）
   （ゲーム本体は D:\GAME\SuccubusDuel本体\RJ01149693\SuccubusDuel_sub\サキュバスデュエル。本MODのファイル以外は書き換えない）

■ 仕組み
- 累積スタック「名簿」：主人公 相手プレイヤー.$名簿（12で敗北）、男モンスター 相手.$魂抜き（6で破壊）。
  ★得意技だけ加算：冥界の審判者　ラダマンテュス「魔吸触手拘束」+3／冥界の屋敷　サキュバスメイド「メイドの嗜み」+2／黒ギャルの女王様　ラップガール「ラップ拘束」+2／リドル家の令嬢　エリザ・リドル「もう我慢できません」+2／サキュバス風俗店店主　サキ「命令ひとつめ」+3。
  攻撃時のセリフは受けた側の段階（主人公 1-3/4-6/7-9/10-11、モンスター 0-1/2-3/4/5）で4段階×主人公向け／モンスター向け。
- 指ほぐし：冥界の審判者　ラダマンテュス「魔吸触手拘束」 は受けた側の $ほぐし が2未満なら「〇〇の指ほぐし」に置き換わる。
- 回想バトル：「回想の栞」方式。敗北シナリオはマスターの @敗北_<経路>_<責め手>。
