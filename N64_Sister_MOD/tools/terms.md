# 責め手ごとの言い方（おちんちん／お尻）
- シスター（穏やかで敬虔な丁寧語・わたし／あなた）：おちんちん／お尻
- パイズリ処刑人（甘えた声で容赦ない・わたし／お兄さん・「〜ですよぉ」）：おちんちん／お尻
- ぱふぱふ処刑人（淑やか・わたし／あなた・「〜ですわ」）：ペニス／お尻
- クレリック（慈愛深いやさしい敬語・わたし／あなた）：おちんちん／お尻
- イージス（静かで威厳のある丁寧語・わたし／あなた・自分を「女神」と呼ぶことあり）：性器（見下す時は「粗末なもの」）／後ろ
- 累積スタック：首に掛けられたロザリオの「珠」。数え方は「〜粒目の珠」「珠が十二粒」。段階は告解・聖罰・洗礼・入信の誓い・信徒。一粒増えるたびに珠がぽうっと白く光り、胸の奥が温かくなる（痛みはない）
- 主人公→相手の呼び方：シスターさん／処刑人さん（パイズリ処刑人・ぱふぱふ処刑人とも。二人いる場面は「胸穴の処刑人さん」「斧の処刑人さん」）／クレリックさん／イージス様
- 見習いの修道服：黒一色・丈の長い修道服に白い襟（ウィッグなし・紺髪のまま）。着せた後は最後まで着たまま、裾をたくし上げる・胸元の留め具を外す・襟をゆるめる
- 命乞い経路（N64）：「赦しましょう」に主人公が「ありがとうございます」「はい」と答えた、その問答がそのまま入信の誓いの文言。十二粒目の珠が光って成立する
- おねだり経路（N64）：主人公が告解室の格子越しに「どの聖罰を受けたいか」を自分の口で告解する。その文言が「告解の帳面」に書き写され、以後の日課・祈りの言葉になる
- シスター（丁寧「〜ですね」）：おちんちん／お尻
- パイズリ処刑人（甘え声「〜ですよぉ」）：おちんちん／（お尻は使わない）
- ぱふぱふ処刑人（淑やか「〜ですわ」）：ペニス／（お尻は使わない）
- クレリック（やさしい敬語）：おちんちん／（お尻は使わない）
- イージス（威厳のある丁寧語）：粗末なもの・性器／（お尻は使わない）
- 戦闘経路（N64）：処刑人（パイズリ処刑人は胸の穴にしまう／摘まみ取る、ぱふぱふ処刑人は斧の刃先や腹でそっと払う）がカードを取り上げてから「聖罰」が始まる。叩く・打つ描写はしない
- オナニー経路（N64）：主人公の自慰は責め手の★得意技の形（シスター＝手を組んで腕で胸を寄せ、クッション等に顔を埋めて説法を唱える／パイズリ処刑人＝柔らかい布で乳首を円を描いて擦る／ぱふぱふ処刑人＝毛布を頭から被って胸を撫でる／クレリック＝指の腹で乳首をゆっくり撫でる／イージス＝壁に背を預けて囲まれ、指を咥えて乳首をつまむ）。見透かす言葉は「また“自己犠牲”ですか」系。自慰の記録先は話ごとに変える（懺悔録・聖歌集の余白・洗礼名簿・衣装部屋の台帳・宿帳・癒しの記録・イージスの盾に刻む光の文字）
- シスターの聖罰の儀：ペニバンは「聖具」（白く滑らか）。ほぐしは「聖油」を指に絡めて一本→二本。前立腺はシスターの言い方で「罪の芯」とも呼ぶ
- クレリックの着せ替え：両手をかざして祈りの言葉→淡い光で修道服が着せられる（【修道服を着せる】の再現）
