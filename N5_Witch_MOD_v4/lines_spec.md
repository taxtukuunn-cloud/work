# N5 魔女の薬屋（v4）カード用セリフの書き方

キャラ設定・世界観・口調は `/home/claude/n5/brief.md` を読むこと（成人のみ・責め手上位・逆転なし・主人公はペニスを使う自慰をしない・後ろに何か入れる前は指でほぐす）。
ここで書くのは、**バトル中にカードが話すセリフ**。JSONファイル1つに1キャラ分をまとめる。

## 本文の決まり（厳守）
- 半角カンマ「,」禁止（全角「、」）。`$ % & # { } < > ;` 禁止。半角の `!` `?` `(` `)` も使わず全角「！」「？」「（）」。
- 1つのセリフは40〜110字。改行したい時だけ `\\n`（JSONの中では `\\n` と書く＝画面で改行）。「」は付けない。
- セリフは責め手の口調をはっきり出す。主人公の反応は短い喘ぎ・途切れた言葉。

## 累積スタック「変化度」と段階
攻撃を受けた側が個別に持つ。セリフは**受けた側の段階**で変える。
- 主人公（上限12）：段階1＝1〜3（肌がすべすべに）／段階2＝4〜6（腰がくびれ声が高く）／段階3＝7〜9（髪が伸び筋肉が溶ける）／段階4＝10〜11（仕草まで男の娘）
- 男モンスター（上限6。6で「変化した男の娘」として薬屋側へ寝返る）：段階1＝0〜1／段階2＝2〜3／段階3＝4／段階4＝5
- 男モンスターは主人公の仲間の男（剣士・獣人など種族はいろいろ。成人）。責め手はモンスターを「お連れさん」「そっちのお兄さん」などと呼ぶ。モンスターの反応は、その男が戸惑い・抵抗しつつ崩れていく声（一人称「俺」など汎用的に）。

## JSONの形
```json
{
  "techs": [
    {
      "player": [["責め手のセリフ（段階1）", "主人公の反応（段階1）"], ["…段階2", "…"], ["…段階3", "…"], ["…段階4", "…"]],
      "monster": [["責め手のセリフ（対モンスター段階1）", "モンスターの反応"], ["…"], ["…"], ["…"]]
    }
  ],
  "prep": null,
  "summon": ["召喚時のセリフ1", "召喚時のセリフ2"],
  "turn_end": ["自分のターン終了時のセリフ"],
  "onedari_intro": "おねだりされた時の最初のセリフ（どれがいいか自分の口で言わせる）",
  "onedari": [["選択肢の短い名前（10字以内）", "主人公がねだる言葉", "責め手の返事"]],
  "inochi_first": ["命乞い（1回目）のセリフ1", "セリフ2"],
  "inochi_again": ["命乞い（2回目以降）のセリフ1", "セリフ2"],
  "inochi_fail": "とどめを刺された時の一言",
  "inochi_trap": "迷った隙を突く一言（ここから敗北）",
  "onani_first": ["オナニーを見つけた時のセリフ1", "セリフ2"],
  "onani_again": ["2回目以降のセリフ1", "セリフ2"],
  "onani_player": "主人公の言い訳（手が止まらない）",
  "onani_desc": "主人公の自慰の様子を描く地の文（得意技の真似。ペニスは使わない。60〜110字）",
  "end": "勝った時（主人公が負けた後）の締めの一言",
  "win": "負けた時（主人公に倒された時）の一言",
  "conv": "男モンスターが変化度6に達して薬屋側へ寝返る時のセリフ",
  "flavor": "カードのフレーバーテキスト（100〜130字。世界観と人物が伝わる地の文）"
}
```
- `techs` は担当キャラの技の数だけ、下の順番で書く。各技は player 4段階・monster 4段階（計16セリフ）。
- `prep` は全員 `null`（このMODに `指ほぐし` の技はない。オルガのゼリーのセリフの中で指でほぐす描写を入れる）。
- `onedari` は技の数だけ（技の順番どおり）。
- `onani_*` の自慰は、そのキャラの得意技に合わせる（brief.md の「オナニーの内容」）。
- `summon` `turn_end` `conv` はマスター（ミルティ）も書く（ミルティの summon は「手伝いを呼ぶ時」＝召喚宣言のセリフとして使う。ミルティの turn_end は4つ＝主人公の段階1〜4で、それぞれ下の状態異常の説明に合う内容）。

## キャラと技（この順番で techs を書く）
- **ミルティ**（`m.json`）
  1. 変化薬の口移し（★得意技）：唇を重ね、甘い変化薬を舌で流し込む長いキス
  2. 呪いの衣装：フリルとリボンのドレスを着せ、布越しに撫で、脱ごうとすると締まる（メロメロ）
  3. 乳首開発の薬：薬を塗った指と舌で乳首をじっくり開発する
  - turn_end（主人公の段階ごと）：1＝発情（薬で体が火照る）、2＝メロメロ（ミルティに骨抜き）、3＝攻撃指示不能（仲間に指示を出せない）、4＝魔法使用不能＋ダメージ
  - さらに `"quest"` を追加で書く（下）
- **ポーラ**（`e1.json`）1. 感度上げの塗り薬（★得意技。乳首に塗り込みくるくる転がす）　2. 試作変化薬（試作品を飲ませる。発情）。summon は召喚時（主人公かモンスターの変化度+1）
- **ドール**（`e2.json`）1. 脱げないお召し物（★得意技。呪いの衣装を一枚ずつ着せる。メロメロ）　2. リボンの締め付け（リボンで胸と腰をきゅっと締める）。summon は召喚時（男モンスター1体か主人公にメロメロ）
- **スモーカ**（`e3.json`）1. 発情の紫煙（★得意技。甘い紫の煙を吹きかけ吸わせる。発情）　2. 形を溶かす煙（煙が肌にまとわりつき体つきを溶かす）。turn_end は「自分のターン終了時に男モンスター1体（いなければ主人公）の変化度+1」のセリフ
- **オルガ**（`boss.json`）1. 変化の大儀式（魔法陣の詠唱で体を書き換える。メロメロ）　2. 変化薬のゼリー（★得意技。薬油の指でほぐした後、冷たいゼリーを後ろに注ぎ内側から作り変える）。summon は召喚時（変化度+3）、turn_end は固有効果「変化の大儀式」（主人公の変化度6以上の時、主人公をメロメロ、男モンスター1体をメロメロにして変化度+2）のセリフ

## ミルティだけ追加：`"quest"`
```json
"quest": {
  "first": ["説明:森の奥の薬屋「翠の瓶」の扉を開ける情景の地の文（90〜120字）", "セリフ", "セリフ", "セリフ（勝負の申し込み。勝てば帰れる、負けたら新薬の試飲に最後まで付き合う）"],
  "won_before": ["セリフ", "セリフ"],
  "prev": {"1": "前回戦闘で負けたお客さんへの出迎え", "2": "前回オナニーで負けたお客さんへ", "3": "前回命乞いで負けたお客さんへ", "4": "前回おねだりで負けたお客さんへ"},
  "prev_alert": "アラートの一文（例：前回の試飲の続きをしますか？）",
  "choices": ["挑む", "試飲の続きをする", "店を出る"],
  "decline": "引き返す時のセリフ",
  "start": ["試合開始のセリフ1", "セリフ2（変化度が12まで溜まったら完全に男の娘、の説明を含める）"],
  "lost_line": "ミルティが負けた時のセリフ（クエストで勝たれた時）",
  "prev_continue": "前回の続きを流す前のセリフ",
  "kaisou": ["回想バトルの最初のセリフ1（今日は好きな薬を選ばせてあげる、など）", "セリフ2"]
}
```
`first` の先頭だけは `"説明:"` で始めて地の文にする（それ以外はミルティのセリフ）。
