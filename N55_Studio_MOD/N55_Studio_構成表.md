# N55 深夜の撮影スタジオ（Studio）構成表

世界観：郊外の貸しスタジオ。モデルの代役の求人に応募した主人公が、NHのカメラマンと女性スタッフに撮られ続ける。シャッターが切られるたびに見られる快感を覚え込まされ、最後はスタジオの専属モデルになる。

- 累積スタック `$シャッター`（単位：コマ）：テスト撮影（1〜3）→本番（4〜6）→グラビア（7〜9）→写真集（10〜11）→専属モデル（12）
- 男モンスターの処理（シャッター6）：専属モデル（コントロール変更）
- 注意：撮った写真を外へ流す・脅しに使う描写はしない（スタジオの中で完結）。
