# N3 男の娘淫魔（v4）カード用セリフの書き方

キャラ設定・世界観・口調は `/home/claude/n3/brief.md` を読むこと（成人のみ・責め手上位・逆転なし・主人公はペニスを使う自慰をしない・挿入（尻尾・自身）の前は指でほぐす）。
ここで書くのは、**バトル中にカードが話すセリフ**。JSONファイル1つに1キャラ分をまとめる。

## 本文の決まり（厳守）
- 半角カンマ「,」禁止（全角「、」）。`$ % & # { } < > ;` 禁止。半角の `!` `?` も使わず全角「！」「？」。
- 1つのセリフは40〜110字。改行したい時だけ `\\n`（JSONの中では `\\n` と書く＝画面で改行）。「」は付けない。
- セリフは責め手の口調をはっきり出す。主人公の反応は短い喘ぎ・途切れた言葉。

## 累積スタック「淫紋度」と段階
攻撃を受けた側が個別に持つ。セリフは**受けた側の段階**で変える。
- 主人公（上限12）：段階1＝1〜3（紋が刻まれたばかり）／段階2＝4〜6（紋が光り始める）／段階3＝7〜9（紋が育つ）／段階4＝10〜11（ほぼ眷属）
- 男モンスター（上限6。6で「淫魔の眷属」として館側へ寝返る）：段階1＝0〜1／段階2＝2〜3／段階3＝4／段階4＝5
- 男モンスターは主人公の仲間の男（剣士・獣人など種族はいろいろ。成人）。責め手はモンスターを「そっちのお兄さん」「お連れさん」などと呼ぶ。モンスターの反応は、その男が戸惑い・抵抗しつつ崩れていく声（一人称「俺」など汎用的に）。

## JSONの形
```json
{
  "techs": [
    {
      "player": [["責め手のセリフ（段階1）", "主人公の反応（段階1）"], ["…段階2", "…"], ["…段階3", "…"], ["…段階4", "…"]],
      "monster": [["責め手のセリフ（対モンスター段階1）", "モンスターの反応"], ["…"], ["…"], ["…"]]
    }
  ],
  "prep": {
    "player": [["指ほぐしのセリフ1回目（まだ固い）", "主人公の反応"], ["指ほぐしのセリフ2回目（もうすぐ入る）", "主人公の反応"]],
    "monster": ["指ほぐしのセリフ（対モンスター）", "モンスターの反応"]
  },
  "summon": ["召喚時のセリフ1", "召喚時のセリフ2"],
  "turn_end": ["自分のターン終了時のセリフ"],
  "onedari_intro": "おねだりされた時の最初のセリフ（どれがいいか自分の口で言わせる）",
  "onedari": [["選択肢の短い名前（10字以内）", "主人公がねだる言葉", "責め手の返事"]],
  "inochi_first": ["命乞い（1回目）のセリフ1", "セリフ2"],
  "inochi_again": ["命乞い（2回目以降）のセリフ1", "セリフ2"],
  "inochi_fail": "とどめを刺された時の一言",
  "inochi_trap": "迷った隙を突く一言（ここから敗北）",
  "onani_first": ["オナニーを見つけた時のセリフ1", "セリフ2"],
  "onani_again": ["2回目以降のセリフ1", "セリフ2"],
  "onani_player": "主人公の言い訳（手が止まらない）",
  "onani_desc": "主人公の自慰の様子を描く地の文（得意技の真似。ペニスは使わない。60〜110字）",
  "end": "勝った時（主人公が負けた後）の締めの一言",
  "win": "負けた時（主人公に倒された時）の一言",
  "conv": "男モンスターが淫紋度6に達して館側へ寝返る時のセリフ",
  "flavor": "カードのフレーバーテキスト（100〜130字。世界観と人物が伝わる地の文）"
}
```
- `techs` は担当キャラの技の数だけ、下の順番で書く。各技は player 4段階・monster 4段階（計16セリフ）。
- `prep` は挿入技を持つキャラ（リリム・ヴァル）だけ書く。それ以外は `"prep": null`。
- `onedari` は技の数だけ（技の順番どおり）。
- `onani_*` の自慰は、そのキャラの得意技に合わせる（brief.md の「オナニーの内容」）。
- `summon` `turn_end` `conv` はマスター（リリム）も書く（リリムの summon は「眷属を呼ぶ時」＝召喚宣言のセリフとして使う。リリムの turn_end は4つ＝主人公の段階1〜4で、それぞれ下の状態異常の説明に合う内容）。

## キャラと技（この順番で techs を書く）
- **リリム**（`m.json`）
  1. 淫紋なぞり（★得意技）：指先で下腹部の紋をなぞり、紋を光らせて全身に快感を走らせる
  2. 精気吸いキス：唇を重ねて精気を吸い上げる。吸われるたびに紋が光る
  3. 尻尾責め：細い尻尾の先で後ろを貫き、奥で揺らしながら紋をなぞる（【同時】尻尾の挿入＋淫紋なぞり。ほぐし済みの時だけ出る。prep は「指ほぐし」＝蜜で濡らした指で一本→二本）
  - turn_end（主人公の段階ごと）：1＝発情（紋が火照る）、2＝寸止め（果てる寸前で紋が止める）、3＝攻撃指示不能（仲間に指示を出せない）、4＝魔法使用不能＋ダメージ
  - さらに `"quest"` を追加で書く（下）
- **ナギ**（`e1.json`）1. 吸精キス（★得意技。唇を吸い、舌で精気を吸い上げる）　2. 乳首吸精（乳首に吸いつき精気を吸う）。summon は召喚時（主人公かモンスターの淫紋度+1）
- **ルカ**（`e2.json`）1. 尻尾の乳首なぞり（★得意技。尻尾の先で乳首をくるくる撫で、弾き、巻きつける。発情）　2. 尻尾の先でのほぐし（尻尾の細い先で後ろの入口をほぐす。挿入はしない）。summon は召喚時（男モンスター1体か主人公に発情）
- **ピオ**（`e3.json`）1. 羽のくすぐり焦らし（★得意技。羽根で耳・首筋を撫でる。寸止め）　2. 淫紋の灯火（紋に小さな灯をともして疼かせる）。turn_end は「自分のターン終了時に男モンスター1体（いなければ主人公）を寸止めにする」時のセリフ
- **ヴァル**（`boss.json`）1. 淫紋の一斉起動（声ひとつで紋をすべて目覚めさせる。発情）　2. 王の精気吸い（★得意技。【同時】自身で貫きながら淫紋を起動させ、奥から精気を吸い上げる。ほぐし済みの時だけ出る。prep は指ほぐし）。summon は召喚時（淫紋度+3）、turn_end は固有効果「淫紋の共鳴」（主人公の淫紋度6以上の時、主人公を発情、男モンスター1体を寸止めにして淫紋度+2）のセリフ

## リリムだけ追加：`"quest"`
```json
"quest": {
  "first": ["説明:深夜の路地から淫魔の館へ入る情景の地の文（90〜120字）", "セリフ", "セリフ", "セリフ（勝負の申し込み。勝てば帰れる、負けたら眷属）"],
  "won_before": ["セリフ", "セリフ"],
  "prev": {"1": "前回戦闘で負けた相手への出迎え", "2": "前回オナニーで負けた相手へ", "3": "前回命乞いで負けた相手へ", "4": "前回おねだりで負けた相手へ"},
  "prev_alert": "アラートの一文（例：前回の続きから契約を結びますか？）",
  "choices": ["挑む", "誘いに乗る", "館を出る"],
  "decline": "引き返す時のセリフ",
  "start": ["試合開始のセリフ1", "セリフ2（淫紋度が12まで溜まったら眷属、の説明を含める）"],
  "lost_line": "リリムが負けた時のセリフ（クエストで勝たれた時）",
  "prev_continue": "前回の続きを流す前のセリフ",
  "kaisou": ["回想バトルの最初のセリフ1（今夜は好きな展開で紋を描いてあげる、など）", "セリフ2"]
}
```
`first` の先頭だけは `"説明:"` で始めて地の文にする（それ以外はリリムのセリフ）。
