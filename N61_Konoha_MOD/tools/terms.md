# 責め手ごとの言い方（おちんちん／お尻）
- コノハ（くだけた姉御口調・わたし／あなた・弟子・馬鹿弟子）：おちんちん／お尻
- サキュバスメイド（丁寧なメイド口調・私／あなた様）：おちんちん／お尻
- サムライガール（ござる口調・拙者／おぬし）：いちもつ／尻
- ヒワ（快活・わたし／弟弟子くん）：おちんちん／お尻
- シズク（やわらかい敬語・わたし／あなた）：おちんちん／お尻
- 累積スタック：修行帳に師匠が朱の筆でつける「バツ印」。数は「七つ目のバツ印」「バツ印が十二個」の形。十二個で「一生の弟子」
- 主人公→師匠の呼び方：「師匠」。姉弟子は「ヒワ姉さん」、師範は「シズク師範」、メイドは「メイドさん」、侍は「サムライガールさん」
- おねだり経路：修行帳の「稽古の順」欄に、主人公のおねだりを一字一句そのまま書き写す（「稽古の順、毎朝いちばん。〜」の形）。以後、稽古の前に主人公が自分で読み上げる
- 命乞い経路：「町へ戻っていい」の許しの証（親指の判・署名・目録・契りの口吸い・押さえ込み一本など）が、そのまま内弟子入りの証文になる
