# N6 人形師（Puppet）執筆ブリーフとツール

N6で使った、敗北シナリオ並列執筆用の共通仕様（SPEC.md）と、チェック・生成スクリプト一式。次のMODでは名前・技・口調を差し替えて使い回せる。

- `SPEC.md`：サブエージェントに渡した共通仕様（世界観・口調・書式・禁止事項・構成11項目・経路の軸）
- `count.py`：`セリフ,` `説明,` の本文だけを数える（`\n` は数えない）。5,000字未満は ★不足
- `check.py`：1行目default／ifの次が { か／単独else／括弧の対応／本文の禁止文字（, $ % & # { } < > ; ! ?）／攻撃タイプが公式名か／画像参照が `#Puppet/Puppet_…png` か
- `gen_monsters.py`：モンスターカード4枚をセリフ表から生成（段階は `$段階` を先に求めて if を平らにする。敗北後は `$敗北再生済み` で1回だけ再生）
- 使い方：責め手ごとに1エージェント×4本（7並列）。各エージェントに「SPEC.md を読む→4本書く→count.py と check.py で自己確認→字数だけ報告」と指示する

````markdown
## 敗北シナリオファイルの書式（Puppet_lose_<経路>_<責め手>.txt）
経路：btl（戦闘負け）／onani（オナニー負け）／inochi（命乞い負け）／onedari（おねだり負け）
責め手：m1／m2／m3／e1／e2／e3／boss

マスター（またはモンスター）の `@敗北後` から `外部イベント実行,Card/Puppet_lose_btl_m1,イベント` で呼ばれる。
BGM・射精・フェードアウト・ゲームオーバーは呼び出し側で行うので、このファイルには書かない。

```

@イベント
画像表示,#Puppet/Puppet_lose_btl_m1.png,1

```

- 話者：`話者変更,自分` ＝ そのシナリオの責め手、`話者変更,相手` ＝ 主人公。
  **それ以外の人物（例：モンスターのシナリオに出てくるドロテア）のセリフは `説明` の中に「ドロテアが囁く。『……』」の形で書く。**
- 使うコマンドは `画像表示` `話者変更` `セリフ` `説明` `主人公攻撃タイプ弱点付与` だけ（ほかのコマンドは使わない）。
- 画像表示は冒頭に1回。絶頂の場面の前にもう1回同じ画像を表示してよい。
- 1行は `コマンド,本文`。本文は1行につき全角40〜120字程度。長い地の文は `\n` で改行を入れる（`\n` は2文字と数えない）。
- 空行・インデント・コメントは不要。

### 本文の禁止事項（厳守）
- **半角カンマ `,` 禁止**（全角「、」を使う）。
- 半角の `$ % & # { } < > ;` を本文に書かない。
- 半角の `!` `?` は使わず全角「！」「？」。ハートは「♡」可。「♪」は使わない。
- 攻撃タイプ名（弱点付与の2番目）は公式名：魔法責め・乳首責め・耳責め・ハグ・本番 のいずれか。

### 文字数
- **各ファイル、セリフ・説明の本文だけで5,000字以上（目標5,500〜6,500字）**。コマンド名・カンマ・`\n` は数えない。
- 書いたら必ず `python3 /home/claude/Puppet/count.py <ファイル>` で数え、5,000字未満なら責めと絶頂の場面を書き足す。

### 構成（この順で必ず全部入れる）
1. 冒頭セリフ2行＋CG
2. その経路で負けた経緯の振り返り（戦闘中の状況に触れる）
3. 場所の移動と情景（工房の奥、糸の天蓋のある寝台、硝子の飾り棚、衣装部屋、オルゴールの間 など）
4. 責め手の道具・手法の提示
5. 段階的な責め（抵抗→崩れる→自分から求める）。人形化度の4段階を体で追体験させる
6. 経路特有の「言わせる・選ばせる・差し出させる」場面
7. **絶頂を3回以上**。それぞれに意味づけ（例：「一本目の糸」「二本目の糸」…／「一着目」…／「第一楽章」…）。ここに一番文字数を使う
8. 責め手の締めのセリフ（糸・衣装・巻き鍵・台座・名札の授与など）
9. 後日談（1日目・2日目・3日目…と日常が人形の暮らしに侵食されていく。日ごとに1段落）
10. 自分から館に戻る場面（責め手の出迎えで締める）
11. 最後の行：`主人公攻撃タイプ弱点付与,<その敗北の責めの攻撃タイプ>,50`

### 経路ごとの軸
- btl（戦闘負け）：糸に操られて崩れる。その責め手の流儀で堕とされる
- onani（オナニー負け）：人形なのに勝手に自慰してしまい「壊れた人形」として調整・罰を受ける。見られる・記録される・管理される恥が軸
- inochi（命乞い負け）：とどめを刺す手が止まった一瞬の情け／命乞いの言葉そのものを「人形の台詞（台本）」にされ、何度も言わされる
- onedari（おねだり負け）：自分の口から「人形にして」と具体的に請わされ、それが記録され日課になる

### 表現のルール
- 絶頂は「射精」「果てる」「白いものが溢れる」など。露骨すぎる俗語の連発は避け、官能小説の品位で。
- 主人公は責め手に触れない・責めない。挿入もしない（器具で責められる側）。
- 責め手は常に余裕と上位。自慰・受け身・自爆にしない。
- 同じ言い回しの繰り返しで字数を稼がない。場面・感覚・心理の描写で厚くする。
````

## count.py

````python
import sys, re
BODY_CMDS = ('セリフ', '説明')
def count(path):
    raw = open(path, 'rb').read()
    txt = raw.decode('utf-8-sig')
    n = 0
    for line in txt.splitlines():
        s = line.strip()
        for c in BODY_CMDS:
            if s.startswith(c + ','):
                body = s[len(c) + 1:].replace('\\n', '')
                n += len(body)
    return n
for p in sys.argv[1:]:
    c = count(p)
    print(f"{p}: {c}字 {'OK' if c >= 5000 else '★不足'}")
````

## check.py

````python
"""Puppet MOD の書式チェック。使い方: python3 check.py <ファイル...>"""
import sys, re
OFFICIAL = set('通常攻撃 おっぱい パイズリ ぱふぱふ フェラ 手コキ 足コキ 脇コキ ハグ ふとももコキ 膝コキ 尻コキ 尻尾コキ 髪コキ キス スマタ 素股 魔法責め 触手 触手コキ 耳責め 乳首責め 強制自慰 パンチラ 息 本番'.split())
TEXT_CMDS = ('セリフ', '説明', 'アラート', '技名表示')
BAD = set(',$%&#{}<>;!?')
def check(path):
    errs = []
    raw = open(path, 'rb').read()
    txt = raw.decode('utf-8-sig')
    lines = txt.split('\n')
    if lines[0].strip() != 'default':
        errs.append('1行目がdefaultでない')
    depth = 0
    prev_if = False
    for i, line in enumerate(lines, 1):
        s = line.strip()
        if prev_if and s != '{':
            errs.append(f'{i}: ifの次が {{ でない')
        prev_if = s.startswith('if,')
        if s == 'else' or s.startswith('else,'):
            errs.append(f'{i}: 単独else')
        depth += s.count('{') if not any(s.startswith(c + ',') for c in TEXT_CMDS) else 0
        depth -= s.count('}') if not any(s.startswith(c + ',') for c in TEXT_CMDS) else 0
        if depth < 0:
            errs.append(f'{i}: 閉じ括弧過多'); depth = 0
        for c in TEXT_CMDS:
            if s.startswith(c + ','):
                body = s[len(c) + 1:]
                if c == '説明' and re.fullmatch(r'（[^,]*\{\$表示用\}／24）', body):
                    continue
                bad = [ch for ch in body if ch in BAD]
                if bad:
                    errs.append(f'{i}: 本文に禁止文字 {"".join(sorted(set(bad)))} : {body[:30]}')
        m = re.match(r'(攻撃タイプランダム変更|主人公攻撃タイプ弱点付与|攻撃タイプ固定),(.*)', s)
        if m:
            parts = m.group(2).split(',')
            names = parts if m.group(1) == '攻撃タイプランダム変更' else parts[:1]
            for n in names:
                if n not in OFFICIAL:
                    errs.append(f'{i}: 非公式の攻撃タイプ {n}')
        m = re.match(r'if,攻撃タイプ,==,(.*)', s)
        if m and m.group(1) not in OFFICIAL:
            errs.append(f'{i}: 非公式の攻撃タイプ {m.group(1)}')
        for img in re.findall(r'#([^,\s]+)', s):
            if not re.fullmatch(r'Puppet/Puppet_[A-Za-z0-9_]+\.png', img):
                errs.append(f'{i}: 画像参照の形式 {img}')
    if depth != 0:
        errs.append(f'括弧の対応が取れていない（残り {depth}）')
    return errs
bad_total = 0
for p in sys.argv[1:]:
    e = check(p)
    if e:
        bad_total += 1
        print(f'NG {p}')
        for x in e[:30]:
            print('   ', x)
    else:
        print(f'OK {p}')
sys.exit(1 if bad_total else 0)
````
