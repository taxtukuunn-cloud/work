## 仕組み（gen.py）
- スタック「指名度」：主人公 `相手プレイヤー.$指名度`（12で敗北）、男モンスター `相手.$指名度`（6で `コントロール変更` して店側へ）。得意技だけ加算。効果（召喚時・魔法）は男モンスターがいればランダムに1体（`カードランダム抜き出し` → `%対象.$指名度`）、いなければ主人公。
- `@戦闘` の頭で `$主`（主人公か）・`$値`・`$ほ`・`$段階` を決め、技ごとに主人公向け4段階／モンスター向け4段階のセリフ。
- 挿入技は `$ほ<2` なら「〇〇の指ほぐし」（ほぐし+1。得意技が挿入技の暁は指ほぐしでも+1）。
- クエスト：`Eventlist/Quest/Host.txt` に `クラブ・ルクス（NO.1ホスト　レン）,Card/Host_master,クエストイベント` と `クラブ・ルクス【回想バトル】,Card/Host_master,回想バトル,$$Host_挑戦回数,>=,1`。
- 回想バトル：`@回想バトル` で `$$Host_回想中=1` → `@試合開始` と `@ターン開始`（レンのターン）で `@回想メニュー`（while で「特殊召喚させる／手札に加えさせる／ドローさせる／このまま進める」）。負けてもシナリオは流すが `$$` の記録と報酬はなし。
- 敗北シナリオはマスターの `@敗北_<経路>_<責め手>` に28本、`バトル開始` 直後の `if,is敗北,==,true` → `@敗北再生` で振り分け（N12で動いた形）。画像は `@初期設定` の変数経由。最後の責め手・負け方は `$$Host_〜` にも記録（主人公が受けた時だけ）。
- 命乞い・オナニー負けのマスター分は `$$Host_最後のマスター技`（直前に使ったレンの技、未使用なら1）のルートになる。
