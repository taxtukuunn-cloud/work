# N3 男の娘淫魔（コード Inma）MOD

## 入れ方
- `Card/` の中身 → ゲームの `CSV/Card/`
- `EventList/FieldFaces/Inma.txt` → `CSV/EventList/FieldFaces/`（街モルゲンにリリムが出る）
- 画像 → Saveと同じ階層の `Picture/Inma/`（`install_images.bat Inma "<ゲーム>\Picture"`）

## 構成（20枚デッキ）
| カード | ファイル | 攻撃（攻撃タイプ） | 効果 |
|---|---|---|---|
| マスター：男の娘淫魔リリム | Inma_master | 淫紋なぞり（魔法責め）／尻尾責め（本番）／精気吸いキス（キス） | 攻撃で淫紋度+2。ターン終了時に段階別の状態異常（発情→寸止め→攻撃指示不能→魔法使用不能＋1500） |
| 下級：精気吸いナギ ×3 | Inma_mons_e1 | 吸精キス（キス）／乳首吸精（乳首責め） | 攻撃のたびに自分プレイヤーのHPを攻撃力分回復 |
| 下級：尻尾使いルカ ×3 | Inma_mons_e2 | 尻尾の乳首なぞり（乳首責め）／尻尾の奥責め（本番） | 召喚時 淫紋度+1。乳首なぞりで発情 |
| 下級：羽の使い魔ピオ ×3 | Inma_mons_e3 | 羽のくすぐり焦らし（耳責め）／淫紋の灯火（魔法責め） | ターン終了時 男モンスター1体に寸止め。灯火で寸止め |
| 上級：淫魔の長ヴァル ×1 | Inma_mons_boss | 淫紋の一斉起動（魔法責め）／王の精気吸い（本番） | 召喚時 淫紋度+3。固有効果「淫紋の共鳴」 |
| 魔法 各×2 | Inma_magic_1〜5 | 淫紋の契約（+2・発情）／月夜の誘惑（男モンスターに発情）／精気の宴（永続：HP500回復＋淫紋度+1、3回で自壊）／眷属召喚（サーチ）／紋の反転（罠：攻撃したカードに寸止め＋1） | |

- ゲージ：`自分プレイヤー.$淫紋度`（0〜24、減らない）。24で即敗北。下級+1／上級+2／マスター+2。
- 男モンスターがHP1以下になると「淫魔の眷属」として敵側へ（`コントロール変更,相手,自分所属`）。
- 敗北シナリオ28本（各5,080〜5,670字）は、マスターと各モンスターの `@敗北後` に経路×責め手で組み込み済み。
- 2回目以降：`$$Inma_敗北回数` `$$Inma_前回敗北経路` `$$Inma_前回最後の責め手` で出迎えのセリフが変わり、「誘いに乗る」で `@前回続き` へ。

## 画像（51枚）
立ち絵5（Inma_master / e1 / e2 / e3 / boss）、技CG7（Inma_atk_m1〜m3・e1・e2・e3・boss）、魔法5（Inma_magic_1〜5）、背景1（Inma_bg）、オナニー5（Inma_onanie_master・Inma_onanie_e1/e2/e3/boss）、敗北28（Inma_lose_<btl|onani|inochi|onedari>_<m1|m2|m3|e1|e2|e3|boss>）。N1・N7と同じく命乞い・おねだりの専用CGは使わない。
生成は画像一括生成ツールで `run_mod.bat Inma all` → `install_images.bat Inma "<ゲーム>\Picture"`。場面は tools/scene_overrides.py の N3 節（淫魔の館の寝室・鏡の間・書斎・羽の部屋・玉座の間・夜の路地）。

## 実機で確認が必要な点（未検証）
1. `コントロール変更,相手,自分所属`（眷属化）と、HP1以下判定のタイミング
2. `イベント回復,自分プレイヤー,自分攻撃力`（ナギの回復）
3. `効果ターゲット設定,2,ランダム,相手モンスター.?性別:男,1`（ピオ。対象がいない時の挙動）
4. モンスターの `@敗北後` が発火するか（N1・N7と同じ確認事項）
5. 淫紋の契約は企画では装備魔法だったが、安全のため通常魔法で実装
6. ヴァルの「攻撃力+200」は攻撃力変更コマンドが未確認のため、攻撃ごとの追撃200ダメージで代替

## 2026-09-23 修正2（敗北イベントが始まらない）
- 動作確認済みのRosetta MODと同じ方式に変更：敗北シナリオは `@敗北後` ではなく、マスターの `@フィールドイベント` の `バトル開始` の直後で `if,is敗北,==,true` → `イベント実行,敗北イベント` として再生する。
