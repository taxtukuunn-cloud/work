# N5 魔女の薬屋（Witch）MOD

森の奥の薬屋「翠の瓶」。魔女ミルティの薬と衣装で、主人公の体が少しずつ男の娘へ変わっていく。
ゲージ：変化度（0〜24。24で敗北）。登場人物は全員20歳以上。個人利用のみ。

## 入れ方
- `Card/` の中身 → ゲームの `CSV/Card/`
- `EventList/FieldFaces/Witch.txt` → `CSV/EventList/FieldFaces/`
- 画像 → Saveと同じ階層の `Picture/Witch/`（install_images.bat を使う）
- 街モルゲンにミルティが出る。

| 下級1 | Witch_mons_e1 ポーラ（試作変化薬＝魔法責め／感度上げの塗り薬＝乳首責め。召喚時 変化度+1・発情） |

| 上級 | Witch_mons_boss オルガ（変化の大儀式＝魔法責め／変化薬のゼリー＝本番。召喚時 変化度+3、固有効果「変化の大儀式」） |

## 企画からの変更点
- オルガ固有効果：企画は「男モンスター全体の攻撃力を段階×100下げる」だったが、攻撃力を下げるコマンドが未確認のため「変化度12以上の時、自分ターン終了時に男モンスター全体へメロメロ2ターン（1試合1回）」に置換。
- ドールの「次のターン攻撃力低下」も同じ理由でメロメロ1ターンに置換。
- 命乞い負けの弱点「命乞いで迷いやすくなる」は実装手段がないため、責め技の攻撃タイプ弱点で代用。
- ゲージは減らさない（まとめ資料10章の方針）。
