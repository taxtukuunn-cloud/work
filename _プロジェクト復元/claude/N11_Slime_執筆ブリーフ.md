# N11 スライム調教（コード Slime）敗北シナリオ執筆ブリーフ

サキュバスデュエル（同人カードゲーム）の個人用MOD。完全M向けの成人向けフィクション。
**登場人物は全員20歳以上の成人。** スライム娘たちは「成熟した大人の女性の姿をしたスライム」として描写すること。幼い・子どもっぽい・小さい体つきを連想させる描写（幼い口調、舌足らず、ちっちゃい体、少女 など）は一切書かない。

## 絶対条件
- 責め手（スライム側）が常に上位。主人公は常に受け身で、快楽攻撃・反撃・逆転は一切しない。主人公は挿入しない。
- 責め手は責めるだけ（自慰・受け身・自爆にしない）。
- アヘ顔・暴力・流血・汚物・痛みの強調はなし。甘く、じわじわ堕とす。色仕掛けと「自分から求めてしまう」過程を大事にする。
- 主人公は「僕」。成人の男性冒険者（二十代・小柄で華奢）。カードデュエルでスライムの巣の主に挑み、負けた。

## 世界観
街モルゲンの外れ、古井戸の底から続く洞窟「翠の洞（みどりのほら）」。奥にスライムの巣がある。壁も床もうっすら光る粘液に覆われ、甘い匂いがする。ゲージ「粘液度」（0〜24）が満ちて敗北した。
段階：第一（足元に広がる／「いらっしゃい」）→第二（全身が濡れる／「気持ちいいでしょ」）→第三（体内に入り込む／「もう出られないよ」）→第四（溶け合って境目がなくなる／「私たちの一部になったね」）。

## 経路ごとの軸（導入〜転換）
- **btl（戦闘負け）**：ぬるぬるに崩れる。責めに屈して、その相手の流儀で堕とされる。
- **onani（オナニー負け）**：デュエル中、スライムの中で我慢できず自分で触ってしまった（粘液が反応して増えた）。自分から手を伸ばした恥が軸。見られる・記録される（スライムが形を覚える）・管理される。
- **inochi（命乞い負け）**：相手が命乞いをし、とどめを刺す手が一瞬止まった。その情けを「飲み込まれる」。情けが罠・契約・所有に変わる。
- **onedari（おねだり負け）**：自分から「中に入れて」と請うた。自分の口で欲しいものを具体的に言わされ、それが日課・記録になる。

## 構成（1本 5,300〜6,500字。セリフ・説明の本文だけで数える）
1. 冒頭：責め手のセリフ2行 → 敗北CG表示（`画像,#Slime/Slime_lose_<経路>_<キー>.png,1`）
2. その経路で負けた経緯の振り返り
3. 場所の移動と情景
4. 責め手の道具・手法の提示（スライムの性質：温度・とろみ・色・形を変える・体内で脈打つ 等）
5. 段階的な責め（抵抗→崩れる→自分から求める）
6. その経路特有の「言わせる・選ばせる・差し出させる」場面
7. **絶頂を2〜4回**（ここに一番字数を使う。各回に「一層目」「二杯目」「一巡目」など意味づけを与え段階を作る。`射精` やドライの絶頂を使い分ける）
8. 責め手の締め（印・道具・約束の授与。例：肌に残る色、体内に残るゼリーの核、小瓶、合図の言葉）
9. 後日談：2日目、3日目、5日目、一週間後…と日常への侵食（1段落ずつ）
10. 自分から巣へ戻る場面 → 責め手の出迎えのセリフで締める
11. 最終行：`画像全削除` → `主人公攻撃タイプ弱点付与,<攻撃タイプ>,50`

## 書式（厳守。ゲームが止まる）
使ってよい行（1行1命令、行頭にスペース不要）：
```
話者,自分            ← 責め手が話す
話者,相手            ← 主人公（僕）が話す
セリフ,本文
説明,本文            ← 地の文（僕の一人称の語り）
画像,#Slime/Slime_lose_btl_m1.png,1   ← 冒頭に1回だけ（自分のファイル名に合わせる）
画像全削除
フラッシュ,ピンク     ← 色は ピンク/白/青/緑/紫/赤
SE,&&怪しい光SE      ← または SE,&&注ぐSE
射精
主人公攻撃タイプ弱点付与,ハグ,50   ← 最終行
```
- 本文に**半角カンマ `,` 禁止**（読点は全角「、」）。本文に `$ % & # { } < > ; @` を使わない。改行は `\n`（1行に最大1〜2回）。
- 主人公の心の声は `セリフ,（……）` の形で。
- `説明` 1行は 40〜160字程度。`セリフ` 1行は 15〜90字程度。
- 最初の2行は必ず `話者,自分` → `セリフ` ×2。
- 攻撃タイプは以下のどれか（弱点付与の行で使う）：ハグ／本番／魔法責め／触手／乳首責め／キス／強制自慰
