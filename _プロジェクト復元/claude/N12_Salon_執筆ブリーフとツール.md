## 使い方
1. `brief.md` を共通ブリーフにして、責め手ごと（7人）に4本ずつ並列で書かせる → `scen/<経路>_<責め手>.txt`
2. `python3 check.py <シナリオの絶対パス>` で字数（5,000字以上）と書式を確認（カードtxtを渡すと CRLF・default・if括弧・禁止文字を確認）
3. `python3 gen.py` でカード一式（`out/N12_Salon_MOD/`）を生成。シナリオを直したら gen.py を実行し直すだけで反映

## brief.md
````markdown
# N12 乳首開発サロン（コード Salon）敗北シナリオ執筆ブリーフ

サキュバスデュエル（M向けカードゲーム）の個人用MOD。**登場人物は全員20歳以上の成人**。個人利用のみ。
主人公（プレイヤー。名前なし、二十代の小柄で華奢な男の冒険者）がサロンの女性スタッフとのカードバトルに負け、責められて堕ちていく「敗北シナリオ」を書く。

## 絶対条件
- 責め手（女性スタッフ）が常に上位。主人公は受け身のみ。**逆転なし**。主人公は挿入しない・責め返さない。
- 責め手は常に服を着たまま責める。責め手自身が自慰したり、受け身になったりしない。
- 暴力・流血・アヘ顔・凌辱的な描写はなし。色仕掛け・焦らし・言葉責め・管理が中心。優しく丁寧な口調のまま逃げ道をふさいでいく。
- 未成年を連想させる語（少年、ショタ、幼い等）は使わない。

## 世界観
街モルゲンの路地裏にある会員制の「乳首開発サロン ヴェルヴェット」。
カウンセリングから始まり、初回施術、貞操帯での管理、そして乳首だけで果てる体へ。会員証のランクは「カウンセリング会員 → 施術会員 → 鍵預かり会員 → 正式会員」。
- 部屋：受付と待合室（ラベンダーの香り、革のソファ）／カウンセリングルーム（白いテーブル、カルテ）／施術室（白いリクライニングの施術台、柔らかな照明、姿見）／器具室（吸引カップ・クリップ・貞操帯が棚に並ぶ）／支配人室（奥の深紅の部屋、天蓋つきの施術ベッド）／鍵の保管棚（小さな銀の鍵がずらりと並ぶ）
- 貞操帯：股間だけを覆う小さな金属製の檻と、腰に回す細い帯。小さな銀の鍵で開く。鍵はサロンが預かる。貞操帯の中では勃起できず、疼きだけが溜まる。
- 吸引カップ：透明な小さなカップ。ポンプで乳首を吸い上げ、ぷっくり腫れさせる。
- ゲージ「感度」：責められるたびに上がる。24で完成（敗北）。

## 登場人物（口調をはっきり書き分ける）
- **カレン**（29・オーナー）：赤茶のセミロングに緩いカール、琥珀の瞳。黒のタイトなサロンドレスに白い短いジャケット。妖艶で几帳面。落ち着いた営業スマイルの丁寧語。「〜ですね」「〜しましょうね」「カルテに書いておきますね」。何でも記録し、次回の予約を必ず入れる。
- **エマ**（26・乳首担当）：金髪ボブ、青い瞳、白い施術服に薄手の白手袋。テクニシャン。手順を説明しながら責める丁寧口調。「まずは〜。次に〜。はい、ここからが本番です」。指先の技術に誇りを持つ。
- **ココ**（25・舌担当）：ピンクブラウンのツインテール、紫の瞳、淡いピンクの施術服。甘えた小悪魔。からかう甘い口調。「〜だよ♡」「ねぇねぇ」「かわいー」。舌先を見せつける。
- **ルル**（28・器具担当）：紫の長いストレート、灰色の瞳、黒い器具係の制服と黒い手袋。冷静で道具を愛でる。淡々とした説明口調。「〜です」「〜します」「この子（器具）は優秀です」。数値や圧を読み上げる。
- **セラ**（34・会員制の支配人）：深紅の長髪をまとめ髪、金の瞳、黒いイブニングドレス、首から銀の鍵束を下げる。余裕たっぷりの支配者。低く艶のある声。「〜なさい」「〜かしら」「いい子ね」。鍵を見せて焦らす。
- **主人公**：内心の声や短い反応。「っ……」「や、やめ……」→ だんだん「もっと……」と自分から求める。

## 経路（どう負けたか）の軸
- **btl（戦闘負け）**：施術（戦闘中の責め）に崩れて、感度が満ちて倒れる。そのまま施術室へ運ばれる。
- **onani（オナニー負け）**：バトル中、貞操帯の中の疼きに耐えられず自分で触ろうとして（あるいは乳首を自分でいじって）スタッフに見つかる。自分から手を伸ばした恥が軸。見られる・記録される・管理される。
- **inochi（命乞い負け）**：とどめを刺せる場面で「鍵を返してあげる」という言葉に手が止まる。その一瞬の情けを、貞操帯の追加や鍵の契約で返される。
- **onedari（おねだり負け）**：バトル中に自分から「もっと開発して」と具体的に請う。それが記録され、日課・契約になる。

## 構成（1本5,500〜6,500字を目標。最低5,000字。セリフと説明の本文だけで数える）
1. 冒頭：責め手のセリフ2行＋CG表示（下の「画像」行）
2. その経路で負けた経緯の振り返り
3. 場所の移動と情景（部屋を具体的に）
4. 責め手の道具・手法の提示
5. 段階的な責め（抵抗 → 崩れる → 自分から求める）
6. その経路特有の「言わせる・選ばせる・差し出させる」場面
7. **絶頂を2〜4回**（ここに一番文字数を使う。乳首だけで、または貞操帯の中で漏れるように果てる。各絶頂の前に `射精` 行を置いてよい）。絶頂の1回ごとに「カルテの項目」「会員ランク」「鍵の番号」など意味づけを与えて段階を作る。
8. 責め手の締めのセリフ（会員証・鍵・次回予約の授与）
9. 後日談（2日目、3日目…と日常への侵食。日ごとに1段落）
10. 自分からサロンへ戻る場面（責め手の出迎えで締める）
- 弱点付与・GAME OVER・BGMは別処理なので書かない。

## 書式（厳守。ゲームのスクリプトとしてそのまま読み込まれる）
1行に1コマンド。使ってよい行は次だけ：
```
画像,#Salon/Salon_lose_<経路>_<責め手>.png,1
話者,%カレン          （%エマ %ココ %ルル %セラ も同様。責め手が喋る前に必ず入れる）
話者,相手プレイヤー    （主人公が喋る前に入れる）
セリフ,本文
説明,本文            （地の文・情景・心の動き。話者に関係なく出せる）
フラッシュ,ピンク
射精
ウェイト,1
画面色変化,ピンク,1
画面色解除,1
```
- **本文に半角カンマ「,」を絶対に使わない**（全角「、」を使う）。
- 本文に `$ % & # { } < > ;` と半角の `\` 以外のバックスラッシュ表現を使わない。改行したいときだけ `\n` を使ってよい（1行2〜3文まで）。
- 1行の本文は長くても120字程度。セリフは「」を付けない。
- 冒頭行は必ず `画像,#Salon/Salon_lose_<経路>_<責め手>.png,1`。途中で同じ画像行をもう一度入れてもよい。ほかの画像ファイル名は使わない。
- 空行・コメント・見出し・`@` 行は書かない。ファイルにはコマンド行だけ。
````

## check.py
```python
#!/usr/bin/env python3
"""Scenario / card checker for Salon MOD.
usage: check.py file [file...]   (scenario body files or card txt)
"""
import sys, re

ALLOWED = {"画像", "話者", "セリフ", "説明", "フラッシュ", "射精", "ウェイト", "画面色変化", "画面色解除"}
SPEAKERS = {"%カレン", "%エマ", "%ココ", "%ルル", "%セラ", "相手プレイヤー", "自分", "相手", "自分プレイヤー"}
BAD = set("$%&#{}<>;")

def count_body(lines):
    n = 0
    for l in lines:
        if l.startswith("セリフ,") or l.startswith("説明,"):
            n += len(l.split(",", 1)[1].replace("\\n", ""))
    return n

def check_scen(path):
    errs = []
    lines = [l.rstrip("\r\n") for l in open(path, encoding="utf-8-sig")]
    lines = [l for l in lines if l.strip()]
    if not lines or not lines[0].startswith("画像,#Salon/Salon_lose_"):
        errs.append("1行目が画像行ではない")
    for i, l in enumerate(lines, 1):
        cmd = l.split(",", 1)[0].strip()
        if cmd not in ALLOWED:
            errs.append(f"{i}: 使えないコマンド: {l[:40]}")
            continue
        if cmd in ("セリフ", "説明"):
            body = l.split(",", 1)[1] if "," in l else ""
            if "," in body:
                errs.append(f"{i}: 本文に半角カンマ: {l[:40]}")
            bad = [c for c in body if c in BAD]
            if bad:
                errs.append(f"{i}: 禁止文字 {''.join(set(bad))}: {l[:40]}")
            if not body.strip():
                errs.append(f"{i}: 本文が空")
        if cmd == "話者":
            sp = l.split(",", 1)[1].strip() if "," in l else ""
            if sp not in SPEAKERS:
                errs.append(f"{i}: 不明な話者 {sp}")
        if cmd == "画像" and not re.match(r"^画像,#Salon/Salon_lose_(btl|onani|inochi|onedari)_(m1|m2|m3|e1|e2|e3|boss)\.png,1$", l):
            errs.append(f"{i}: 画像行の形式: {l}")
    n = count_body(lines)
    return n, errs

def check_card(path):
    errs = []
    raw = open(path, "rb").read()
    txt = raw.decode("utf-8-sig")
    if b"\r\n" not in raw or re.search(rb"[^\r]\n", raw):
        errs.append("改行がCRLFでない箇所あり")
    lines = txt.split("\r\n")
    if lines[0].strip() != "default":
        errs.append("1行目がdefaultでない")
    depth = 0
    for i, l in enumerate(lines, 1):
        s = l.strip()
        if s.startswith("if,") or s.startswith("while,") or s.startswith("case,"):
            nxt = lines[i].strip() if i < len(lines) else ""
            if nxt != "{":
                errs.append(f"{i}: if/case の次が {{ でない: {s[:40]}")
        if s == "{":
            depth += 1
        elif s == "}":
            depth -= 1
        elif s == "}else{":
            if depth <= 0:
                errs.append(f"{i}: else の位置")
        elif s.startswith("else"):
            errs.append(f"{i}: 単独 else")
        if s.startswith("@"):
            if depth != 0:
                errs.append(f"{i}: セクション開始時に括弧が閉じていない (depth={depth})")
            depth = 0
        if depth < 0:
            errs.append(f"{i}: 閉じ括弧が多い")
            depth = 0
        for cmd in ("セリフ,", "説明,", "アラート,", "技名表示,"):
            if s.startswith(cmd):
                body = s[len(cmd):]
                if "," in body:
                    errs.append(f"{i}: 本文に半角カンマ: {s[:40]}")
                body2 = re.sub(r"\{\$[^{}]+\}", "", body)
                bad = [c for c in body2 if c in BAD]
                if bad:
                    errs.append(f"{i}: 禁止文字 {''.join(set(bad))}: {s[:40]}")
        if s.startswith("選択肢生成,"):
            pass
    if depth != 0:
        errs.append(f"末尾で括弧が閉じていない depth={depth}")
    return errs

if __name__ == "__main__":
    ok = True
    for p in sys.argv[1:]:
        if "/scen/" in p:
            n, errs = check_scen(p)
            status = "OK" if (n >= 5000 and not errs) else "NG"
            if status == "NG":
                ok = False
            print(f"{status} {p} 字数={n}")
            for e in errs[:30]:
                print("   ", e)
        else:
            errs = check_card(p)
            print(("OK " if not errs else "NG ") + p)
            for e in errs[:30]:
                print("   ", e)
            if errs:
                ok = False
    sys.exit(0 if ok else 1)
```

## gen.py（2026-09-23 敗北画像の不具合を直した最新版。実機で確認済み）
```python
#!/usr/bin/env python3
"""N12 乳首開発サロン（Salon）カード一式の生成スクリプト。
scen/<経路>_<責め手>.txt の敗北シナリオ本文を読み込んで、各カードに組み込む。
出力: out/N12_Salon_MOD/Card/*.txt, EventList/FieldFaces/Salon.txt （UTF-8・CRLF）
"""
import os

BASE = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
SCEN = os.path.join(BASE, "scen")
OUT = os.path.join(BASE, "out", "N12_Salon_MOD")
P = "#Salon/Salon_"
G = "自分プレイヤー.$感度"

ROUTES = [("btl", 1), ("onani", 2), ("inochi", 3), ("onedari", 4)]
ATTACKERS = [("m1", 1), ("m2", 2), ("m3", 3), ("e1", 4), ("e2", 5), ("e3", 6), ("boss", 7)]

# 敗北後の弱点（オナニー負けは全員 強制自慰）
WEAK = {
    "m1": {"btl": "乳首責め", "inochi": "乳首責め", "onedari": "乳首責め"},
    "m2": {"btl": "魔法責め", "inochi": "魔法責め", "onedari": "魔法責め"},
    "m3": {"btl": "ハグ", "inochi": "ハグ", "onedari": "ハグ"},
    "e1": {"btl": "乳首責め", "inochi": "乳首責め", "onedari": "魔法責め"},
    "e2": {"btl": "キス", "inochi": "キス", "onedari": "乳首責め"},
    "e3": {"btl": "魔法責め", "inochi": "魔法責め", "onedari": "手コキ"},
    "boss": {"btl": "耳責め", "inochi": "耳責め", "onedari": "乳首責め"},
}
ROUTE_JP = {"btl": "戦闘", "onani": "オナニー", "inochi": "命乞い", "onedari": "おねだり"}

SPEAKERS = [
    ("%カレン", "master"), ("%エマ", "e1"), ("%ココ", "e2"), ("%ルル", "e3"), ("%セラ", "boss"),
]


def ind(lines, n=1):
    return [(" " * n) + l if l else l for l in lines]


def block(cond, body):
    """if 条件 { body }"""
    return [f"if,{cond}", "{"] + ind(body) + ["}"]


def ifelse(cond, a, b):
    return [f"if,{cond}", "{"] + ind(a) + ["}else{"] + ind(b) + ["}"]


def stage_calc():
    return ["$段階,=,1"] + block(f"{G},>=,6", ["$段階,=,2"]) + block(f"{G},>=,12", ["$段階,=,3"]) + block(f"{G},>=,18", ["$段階,=,4"])


def gauge_show():
    return ["$表示用,=," + G, "説明,（感度 {$表示用}／24）"]


def read_scen(route, att):
    path = os.path.join(SCEN, f"{route}_{att}.txt")
    lines = [l.rstrip("\r\n") for l in open(path, encoding="utf-8-sig")]
    return [l for l in lines if l.strip()]


def scen_section(route, att):
    weak = "強制自慰" if route == "onani" else WEAK[att][route]
    body = read_scen(route, att)
    return [f"@敗北_{route}_{att}"] + ind(body, 4) + [
        "    フラッシュ,白",
        "    説明,―― 乳首開発サロン ヴェルヴェット　会員登録完了 ――",
        f"    主人公攻撃タイプ弱点付与,{weak},50",
        "",
    ]


def speaker_setup():
    return [f"話者生成,{v},{P}{img}.png,女" for v, img in SPEAKERS]


def dispatch(attackers):
    """$経路 と $責め手 から敗北シナリオを呼ぶ。attackers は [(key,id)]"""
    out = speaker_setup()
    for key, aid in attackers:
        inner = []
        for r, rid in ROUTES:
            inner += block(f"$経路,==,{rid}", [f"イベント実行,敗北_{r}_{key}"])
        out += block(f"$責め手,==,{aid}", inner)
    return out


def tech_block(tid, name, atype, cg, lines_e, lines_p, attacker_id, effect="&&セクシーエフェクト", gain=2, extra=None):
    """攻撃ブロック。lines_e/lines_p は段階1〜4のセリフ"""
    b = ["話者,自分", f"技名表示,{name}", f"画像,{cg},1"]
    for i in range(4):
        b += block(f"$段階,==,{i+1}", [f"セリフ,{lines_e[i]}"])
    b += ["話者,相手"]
    player = []
    for i in range(4):
        player += block(f"$段階,==,{i+1}", [f"セリフ,{lines_p[i]}"])
    b += ifelse("相手,==,相手プレイヤー", player, ["セリフ,ぐっ……胸の奥が……熱い……"])
    b += ["話者,自分", f"攻撃エフェクト変更,{effect}", f"自分プレイヤー.$最後の責め手,=,{attacker_id}",
          f"{G},+=,{gain}", "$今回付与,=,1"]
    if extra:
        b += extra

import re as _re
_IMG = _re.compile(r"^(\s*)画像,(#[^,]+),(.*)$")
_SPK = _re.compile(r"^(\s*)話者生成,(%[^,]+),(#[^,]+),(.*)$")


def var_images(lines):
    """コマンドに直接書いた # 画像を、@初期設定 で定義した & 変数に置き換える。
    実機で、敗北イベントの「画像,#…」「話者生成,…,#…」が表示されなかったため
    （動作確認済みのロゼッタMODは、画像をすべて @初期設定 の & 変数で使っている）。"""
    defs, out = {}, []
    def var(path):
        stem = os.path.splitext(os.path.basename(path))[0]
        name = "&画像_" + stem
        defs[name] = path
        return name
    for l in lines:
        m = _IMG.match(l)
        if m:
            sp, path, rest = m.groups()
            out.append(f"{sp}画像,{var(path)},{rest}")
            continue
        m = _SPK.match(l)
        if m:
            sp, v, path, rest = m.groups()
            out.append(f"{sp}話者生成,{v},{var(path)},{rest}")
            continue
        out.append(l)
    if defs:
        i = out.index("@初期設定") + 1
        out[i:i] = [f"    {k},{p}" for k, p in sorted(defs.items())]
    return out


def mirror_globals(lines):
    """最後の責め手・負け方を $$ にも記録する（戦闘が終わるとカード変数は読めないため）"""
    out = []
    for l in lines:
        out.append(l)
        m = _re.match(r"^(\s*)自分プレイヤー\.\$(最後の責め手|敗北経路),=,(\d+)$", l)
        if m:
            out.append(f"{m.group(1)}$$Salon_{m.group(2)},=,{m.group(3)}")
    return out


def write(rel, lines):
    lines = var_images(mirror_globals(lines))
    path = os.path.join(OUT, rel)
    os.makedirs(os.path.dirname(path), exist_ok=True)
    text = "\r\n".join(["default"] + lines) + "\r\n"
    with open(path, "w", encoding="utf-8", newline="") as f:
        f.write(text)
```
