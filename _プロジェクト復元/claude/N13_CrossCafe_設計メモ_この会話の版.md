# N13 女装喫茶のオーナー（CrossCafe）設計メモ（2026-09-23 作成・画像の修正を追記）

成果物：`N13_CrossCafe_MOD.zip`（カード一式＋敗北シナリオ28本）。画像はテスト中（修正済みプロンプトで作り直し待ち）。

裏通りの女装喫茶「カフェ・ミュゲ」（鈴蘭）。オーナーのマリアに負けると、エプロン→メイク→フルコーデ→看板娘と店の女の子に仕立てられる。責め手は全員女性（20歳以上）。
ゲージ：女装度（0〜24。24で敗北。減らない）。

## カードと技（攻撃タイプ）

- 下級 メイク担当 ユイ（Lv3 600/1600）：メイクとウィッグ＝魔法責め／リップを塗りながらキス＝キス（メロメロ）。召喚時+1
- 下級 着付け担当 リン（Lv4 700/1800）：コルセット締め＝ハグ／衣装の中での乳首責め＝乳首責め。召喚時に攻撃指示不能1
- 下級 接客指導 ノゾミ（Lv4 650/1900）：耳元での接客暗示＝耳責め（魅了）／姿勢矯正＋アナルプラグ＝本番。自ターン終了時+1
- 上級 店長代理 ミレイ（Lv7 1800/3200）：スカートの焦らし撫で＝手コキ（発情）／奥までアナル開発＝本番（メロメロ）。召喚時+3、攻撃+2。【衣装チェンジ】自ターン終了時にメロメロ→発情→攻撃指示不能を順番に（攻撃指示不能は12以上）
- 魔法：制服の支給（+2）／ウィッグ（男モンスターに魅了2・通常魔法で実装）／開店準備（永続+1、3回で自壊）／スタッフ募集（サーチ）／閉店後の指導（罠：攻撃指示不能＋1）
- 男モンスター：女装度8以上 または HP1以下で「看板ウェイトレス」として敵側へ

## 仕組み（N13で新しくした点）
- 最後の責め手・技・敗北経路を **`自分プレイヤー.$最後の責め手` `$最後の技` `$敗北経路`** で全カード共有（1〜3マリアの技／4ユイ／5リン／6ノゾミ／7ミレイ）。
- `@敗北後` は全カード同じ振り分け。自分の話は `イベント実行`、他カードの話は `外部イベント実行,Card/CrossCafe_…,敗北_…`。`$$CrossCafe_再生済`（@試合開始で0）で二重再生を防止。
- `Card/`（公式どおり `話者,` `画像,`）と `Card_旧書式/`（`話者変更,` `画像表示,`）の2版を同梱。動く方を使う。
- シナリオ本文は `tools/scen/`、戦闘セリフは `tools/lines/*.json`、`tools/build.py` でカード生成（直したら再生成）。
