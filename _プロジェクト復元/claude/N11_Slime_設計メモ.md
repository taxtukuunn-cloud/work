## 敗北シナリオの仕組み
- 経路・責め手・再生済は、すべてマスターのカード変数 `自分プレイヤー.$敗北経路` `$最後の責め手`（1〜7） `$再生済` に持たせる。どのカードの `@敗北後` が呼ばれても同じ判定になるようにするため。
- マスターの `@敗北後` が7人分すべてを振り分ける。
  - モンスター分は `外部イベント実行,Card/Slime_mons_xx,敗北_<経路>` で呼ぶ。
  - モンスター自身の `@敗北後` が呼ばれた場合も流れる（二重再生はしない）。
- 字数：28本すべて5,250〜5,380字（合計約14.9万字）。N4と同じ方法で、共通ブリーフを作り、責め手ごとに4本ずつ並列で書いた。
- 結末の印（抜粋）：
  - ジュレアのぬるぬる：胸の中心の翠の溶け跡／手の翠の手袋／手首の情けの輪／へその下の願いの核
  - アナルゼリー：翠のゼリーの核／腰の手形／指の雫痕／金の盃
  - 尿道ゼリー：三つ糸の紋／封のしずく／情けの栓（冠の鈴で動く）／目盛りの膜
  - アオ：首の青い輪／乳首の吸い口／背中の手形／青い肌着
  - アカ：赤い唇／火種の印／喉の契約痕／体内の熾火
  - モモ：桃の種の核／へその下の点の列／離れない糸／筋の入った杯
  - ヴィスカ：潮の痕（三重の輪）／見届けの紋／欠け月の痕／化石の紋

## 敗北イベントの表示の修正（2026-09-23・実機で確認済み）
- `tools/gen_cards.py` の `to_card_style` と `fix_images_and_speakers` で、生成するカードに自動で次の直しを入れる。
  - 話者・画像・背景の命令を置き換える：`話者,`→`話者変更,`、`画像,`→`画像表示,`、`背景,`→`背景変更,`
  - 画像は直接パスで出さず、`@初期設定` の `&画_<ファイル名>` 変数にしてから出す。モンスター分の敗北CGの変数は、マスターにも置く。

  - 敗北シナリオ（`@敗北_〜` と `@前回続き`）の中は `話者変更,相手`→`話者変更,相手プレイヤー` にする。
- `@敗北後` の頭を `BGM,&BGM_敗北` → `画像表示,&カード画像,1` → `フェードイン,3` にした。
- `check.py --card` は、カード内に `話者,` と `画像,` が残っていたら警告する。
