## 結論（N11で直ったことをユーザーが確認済み）
敗北イベントでアイコンと敗北CGを出すには、次の5つがそろっていればよい。

1. **カード内の書式は `話者変更` `画像表示` `背景変更` にする**（本編 `10021.txt` と同じ）。
2. **`@敗北後` の最初に、立ち絵を出してから `フェードイン,3`**：`BGM,&BGM_敗北` → `画像表示,&カード画像,1` → `フェードイン,3`。戦闘後の画面は暗転しているため。
3. **画像はすべて `@初期設定` で `&変数,#フォルダ/ファイル.png` と定義してから使う**：直接パス（`画像表示,#Slime/…png,1`）は出なかった。これが「敗北CGではなく立ち絵のまま」になった原因。
4. **敗北CGを出した直後に `フェードイン,1`**。
5. **敗北シナリオの中の主人公の話者は `話者変更,相手プレイヤー`**：戦闘の外では `相手` が決まらないため。

- 下の構成は、N11ではこのままで動いた。
  - 敗北シナリオは各カードの `@敗北_〜` に置く。
  - マスターの `@敗北後` から `イベント実行`（モンスター分は `外部イベント実行`）で呼ぶ。
  - モンスター分の敗北CGの変数は、マスターの `@初期設定` にも置いた。

## N3（Inma）でも確認（2026-09-23・ユーザー確認済み「直った」）
N3は別の構成（ロゼッタMODと同じ）で動いた。**画像を `&変数` で定義する（上の3）が決め手**という点はN11と同じ。
- 敗北の再生：マスターの `@フィールドイベント` の `バトル開始` 直後に `if,is敗北,==,true` → `イベント実行,敗北イベント`（`@敗北後` は使わない。モンスターの `@敗北後` は削除）。
- 最後の責め手・負け方はグローバル変数（`$$Inma_最後の責め手`・`$$Inma_敗北経路`）で記録。オナニー負けは `死亡理由,==,オナニー`。
- `@敗北イベント` の頭：`BGM,&&敗北BGM` → `背景変更,&&豪華な寝室背景` → `画像,&カード画像,1` → `フェードイン,2`。
- 28本は全部マスターの `@敗北_<経路>_<責め手>`。モンスターが責め手の話は `話者生成,%ナギ,&立ち絵_e1,女` → `話者,%ナギ`。
- 敗北CGは `&敗北CG_<経路>_<責め手>` をマスターの `@初期設定` で定義し、`画像,&敗北CG_…,1` で表示。
- この構成では、フィールドイベント内の話者・画像は `話者,` `画像,`（ロゼッタと同じ）でも表示された。

## N11の経過
1. 最初の状態：戦闘中の技CGは出たが、敗北イベントではアイコンも敗北CGも出なかった。
2. 対策1（書式を置き換え）：変わらなかった。
3. 対策2（`フェードイン,3` を追加）：絵は出るようになったが、立ち絵のままだった。
4. 対策3（画像を変数に・`フェードイン,1`・`相手プレイヤー`）：**直った**。
