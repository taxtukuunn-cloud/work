## 敗北シナリオの型（厳守）
ファイルは3つの区切りで書く。**区切り行は必ずこの3行**：
```
区切,導入
画像,#Prison/Prison_lose_<経路>_<key>.png,1
（導入：300〜600字。目安400字）
区切,本編
（プレイ描写：一連のシーンで 6,000字以上。目安6,300〜7,000字）
区切,結び
（結び：150〜700字）
```
1. **導入（400字程度）**：どう負けたか（カードバトルの経緯、刑期の目盛り）、なぜこの責めなのか、場所と情景。短くまとめる。
2. **本編＝プレイ描写（6,000字以上・一連で途切れさせない）**：責め手の責め中のセリフ、主人公の喘ぎ声（「っ……」「あ、ぁ……」など）、快楽への心理描写、体や神経の反応（背筋を走る痺れ、腰の跳ね、つま先の反り、内ももの震え、檻の中の脈打ち）、道具の動き（鍵の回る音、珠が一つずつ沈む感触、ゼリーの冷たさ）を細かく長く書く。**その責め手の★得意技を主役**にし、もう一つの技も混ぜる。場面転換や後日談で字数を稼がない。絶頂は2〜4回。あらすじ表の「区切り」で段階をつける。
3. **結び（600字程度まで）**：責め手の締めのセリフ（あらすじ表の「印」を授ける）と、その後の短い余韻（日常への侵食を数行で）。
- 弱点付与・GAME OVER・BGMは別処理なので**書かない**。

### 負け方ごとの軸
- **btl（戦闘負け）**：責めに崩れて刑期が満ちる。その責め手の流儀で堕とされる。
- **onani（オナニー負け）**：**本編の冒頭は、主人公がその責め手の★得意技に合わせた自慰をしてしまう場面から始める（下の表）。ペニスを使う自慰は書かない**。それが見つかり規則違反として記録され、責めに移る。最後に貞操帯が付く（またはすでに付いている）。
- **inochi（命乞い負け）**：看守が「減刑してあげる」「釈放してあげる」と持ちかけ、主人公の手が止まる。減刑の取引が、鍵を渡す（管理を委ねる）契約だった。
- **onedari（おねだり負け）**：自分から責めをねだる。**「外してください」ではなく「点検してください」「検査してください」と言わされ**、それが記録され日課・規則になる。

## 書式（厳守。ゲームのスクリプトとしてそのまま読み込まれる）
使ってよい行は次だけ：
```
区切,導入 ／ 区切,本編 ／ 区切,結び
画像,#Prison/Prison_lose_<経路>_<key>.png,1
話者,%イザベル        （%ケイ %ドーラ %ヴィオラ %マグダレーナ も同様。その人物が喋る前に必ず入れる）
話者,相手プレイヤー    （主人公が喋る前に入れる）
セリフ,本文
説明,本文            （地の文。主人公「僕」の一人称視点）
フラッシュ,白
射精
ウェイト,1
画面色変化,ピンク,1
画面色解除,1
```
- ほかの責め手を脇役で出してよい（`話者,%名前`）。責めは主役の責め手が中心。
- **本文に半角カンマ「,」を絶対に使わない**（全角「、」）。半角の `$ % & # { } < > ; ! ?` も使わない（全角「！」「？」は可）。「♡」可、「♪」不可。改行したい時だけ `\n`（1行2〜3文まで）。1行の本文は長くても150字程度。セリフに「」は付けない。
- 画像行はファイル名と同じ名前だけ。本編の絶頂の前にもう一度同じ画像行を入れてよい。
- 空行・コメント・見出し・`@` 行は書かない。
- 絶頂は「果てる」「白いものが溢れる」「檻の隙間から漏れる」など。官能小説の品位で、露骨な俗語の連発は避ける。五感（音・匂い・温度・湿り気）、比喩、緩急。同じ言い回しの繰り返しで字数を稼がない。

## 戦闘セリフ JSON（`/home/claude/prison/lines/<key>.json`）
シナリオと同じ口調。**本文の禁止事項はシナリオと同じ**。1セリフ全角15〜70字。
**段階は「攻撃を受けた側の刑期」**で決まる。主人公向け（未決・収監・懲罰房・無期）と、**仲間の男モンスター向け**（刑期1／2〜3／4／5。6で模範囚にされる）の2組を書く。男モンスターの反応はそのモンスターの声（名前は出さない。「ぐっ……」「俺が……こんな……」など成人男性の声）。得意技以外の技でも、段階が進むほど「刑期がもう積み上がっている」ことに触れる。
書いたら `python3 -c "import json;json.load(open('<ファイル>'))"` で確認し、全文字列に半角カンマや禁止記号がないことも確かめる。
