## 1. 同時攻撃ルール

1つの技で**2〜3か所を同時に**責める。表では【同時】と書く。

- **同じ部位どうしは組み合わせない**（例：アナル舐め＋逆アナル、脳イキ＋洗脳、足コキ＋貞操帯は不可）。例外：乳首舐め＋乳首責め（指・ローター）は、左右の乳首で分ければ可。
- **相性のよい組み合わせを優先する**（プロジェクト指示の技の説明より）：
  - キス（口が塞がる）＋上半身（乳首・脇腹）、キス＋挿入。
  - 乳首責め＋アナル責め（指・逆アナル・ペニバン）。
- 攻撃タイプは主になる責めの型を1つ（逆アナルを含むなら本番）。`技名表示` で技名を出し、セリフで両方の責めを描写する。
- CGは両方の責めが見える構図にする（1人で足りない時は、触手・尾・分身・配下の手を使う）。
- 配置：各MODで**マスターの技③と上級の技1つは【同時】**。下級は単独技が基本。
- v4で組み合わせを見直したもの：N18シェスカ技③（洗脳→**キス**＋ふたなり）、N19リリ＆ララ技③（淫紋→**乳首舐め**＋ふたなり）、N20ノクティア技③（脳イキ→**キス**＋ふたなり）。

## 4. 得意技と累積スタック（v4で作り直し）

### 4-1. 得意技
- 各キャラの攻撃タイプは2種以上（マスターは3種）。そのうち**1つを得意技（★）**にする。**累積スタックを積むのは得意技だけ**。
- ほかの技はスタックを積まない。ダメージ・状態異常・前戯（指ほぐし）の役目を持たせる。
- 得意技は、そのキャラの代名詞になる責め。敗北シナリオの主役、オナニー負けの自慰の元、回想バトルの見せ場にする。
- 積む量：**マスター・上級の得意技＝+3**、**下級の得意技＝+2**。魔法・罠の「+n」は、下の対象ルールで1人に加える。

### 4-2. スタックは受けた側が個別に持つ
- **主人公**：`相手プレイヤー.$<スタック名>`（例：`相手プレイヤー.$苗床度`）
- **男モンスター**：そのモンスター自身のカード変数 `相手.$<スタック名>`（1体ずつ別々。場を離れたらそのモンスターの分は消える）
- 攻撃・効果の対象になった者にだけ加える。魔法・罠・召喚時の「+n」は、**主人公側に男モンスターがいればそのうち1体（スタックが一番多い者）、いなければ主人公**に加える。
- スタックは減らさない。
- 表示：加えるたびに `説明,（<対象名>の<スタック名> {値}／<上限>）`。主人公とモンスターで上限が違うので、表示も別々にする。

### 4-3. 上限と到達した時
| 対象 | 上限 | 段階1 | 段階2 | 段階3 | 段階4 | 上限に達したら |
|---|---|---|---|---|---|---|
| 主人公 | **12** | 1〜3 | 4〜6 | 7〜9 | 10〜11 | その場で `とどめダメージ,相手プレイヤー,9999`（敗北） |
| 男モンスター | **6** | 1 | 2〜3 | 4 | 5 | そのMODの処理（破壊／敵側へ寝返り／女装娘）をその場で行う |

- v3までの「ゲージ0〜24を全員で共有・全技で加算」「男モンスターはゲージ8以上かつHP1以下で処理」は**廃止**。
- 上級の固有効果の「〇〇度18以上」「12以上」は、**主人公のスタック9以上／6以上**と読み替える（各MODの表は書き換え済み）。
- 数値（12・6・+3・+2）は実機で試して調整してよい（遅すぎる・早すぎる時）。

### 4-4. 攻撃時のセリフはスタック段階で変える
- 技ごとに、**主人公向け4段階**と**男モンスター向け4段階**のセリフを用意する（責め手のセリフと、受けた側の反応の両方）。段階は**攻撃を受ける側のスタック**で決める。
- 男モンスターが受けた時の反応は、そのモンスターの声で書く（名前は `相手` のカード名を使う）。
- 得意技以外の技でも、受ける側のスタックに応じてセリフを変える（「もうこんなに溜まっている」と得意技の積み上がりに触れる）。
- 書き方：`@戦闘` の頭で `$段階` を決める（`相手,==,相手プレイヤー` なら主人公の表、そうでなければモンスターの表）→ `if,$段階,==,1` で分ける。

## 5. 挿入の前戯ルール（指でほぐす）

- ペニバン逆アナル・ふたなり逆アナル・男の娘逆アナルは、**対象の `$ほぐし` が2以上の時だけ**出せる。`$ほぐし` もスタックと同じく受けた側が個別に持つ（`相手プレイヤー.$ほぐし`／`相手.$ほぐし`）。
- `$ほぐし` を増やす技：アナル開発・前立腺責め（指）＝+1。そのほか、各責め手の挿入技が選ばれた時に `$ほぐし` が足りなければ、**同じ責め手がその場で「指ほぐし」をする**（技名は「〇〇の指ほぐし」、攻撃タイプは本番、`$ほぐし`+1、スタックは積まない。ただし得意技が挿入技のキャラは+1だけ積む）。
- セリフ・シナリオでも、挿入の前には必ず**指でほぐす前戯**を描く（ローションや蜜で濡らす→一本→二本→前立腺を探す→「もう入る」と確かめる）。前戯なしでいきなり貫く描写は書かない。
- アナル舐め・ゼリー・パール・バイブ・触手は前戯の気分を高めるが、`$ほぐし` は増やさない（指でほぐすことが条件のため）。

## 6. バトル形式：クエストと回想バトル

### 6-1. クエスト（通常の戦闘）
- マスターを街のフィールドには出さない（FieldFacesは作らない）。**クエストとして登録する**。
- 登録ファイル：`EventList/Quest/<コード>.txt` に1行（末尾改行なし・BOMなし）
  `<表示名>,Card/<コード>_master,クエストイベント`
  （`Eventlist/` の直下に置くと出ない。`Quest` サブフォルダに置く。`Project_Knowledge.md` 1章）
- マスターの入口は `@クエストイベント`（v3までの `@フィールドイベント` の中身をここへ移す）。初回／前回勝った／前回負けた で出迎えを変え、前回負けていれば「挑む／誘いに乗る（前回の続き）／引き返す」を出す。
- 戦闘は `バトル開始,&背景,&&戦闘BGM`。敗北シナリオは `バトル開始` の直後の `if,is敗北,==,true { … }` で流す（N12で動作確認済みの形。`claude/実機確認_敗北シナリオの呼び方.md`）。
- 勝敗の記録（`$$<コード>_敗北回数` など）はクエストでだけ行う。

### 6-2. 回想バトル（新規）
クエストとは別に、同じ相手と**好きな展開で戦える**練習試合を用意する。
- 登録：クエスト一覧にもう1行 `<表示名>【回想バトル】,Card/<コード>_master,回想バトル,$$<コード>_挑戦回数,>=,1`（一度戦った相手だけ出す）。マスターの `@回想バトル` を呼ぶ。
  - クエストから出せない場合の予備：回想メニュー `EventList/Renoun/<コード>.txt` に同じ行を置く。
- `@回想バトル` の流れ：`自分.$回想バトル,=,1` → 主人公・男モンスターのスタックとほぐしは0から → `デッキ設定` → `バトル開始,&背景,&&戦闘BGM`。
- **敵のターン開始ごと（マスターの `@ターン開始`）と試合開始時**に、プレイヤーへ次の選択肢を出す（`自分.$回想バトル,==,1` の時だけ）：
  1. **カードを選んで特殊召喚させる**：`%候補,=,自分デッキ.?isモンスター:true` → `カード選択,%候補,1,1` → `特殊召喚,選択カード,味方`
  2. **カードを選んで手札に加えさせる**（魔法・罠を使わせたい時）：`%候補,=,自分デッキ` → `カード選択,%候補,1,1` → `効果サーチ,選択カード,自分所属`
  3. **ドローさせる**：`効果ドロー,自分プレイヤー`
  4. **このまま進める**
  - 1〜3は何回でも選べる（4を選ぶまで繰り返す）。
- 回想バトルで負けた時も、そのルートの敗北シナリオを流す（`&&敗北BGM`）。ただし `$$` の記録（敗北回数・前回の負け方）は更新しない（`Now回想` なら `回想モードOFF`→処理→`回想モードON` が必要な点に注意）。勝っても報酬はなし。
- 未検証：`カード選択` で相手（敵）のデッキを表示できるか、`特殊召喚,選択カード,味方` の書き方、クエスト一覧の独自種別 `回想バトル` が通るか。

## 8. オナニー（得意技に合わせた自慰）

- オナニーは、プレイヤーがオナニーを選んだ時に**指定した相手の得意技**に合わせた自慰にする。**安易にペニスを使う自慰にしない**。
- 戦闘中の `@オナニー`（そのカードのセリフと画像）と、オナニー負けの敗北シナリオの冒頭の両方で、この自慰を描く。キャラごとの内容はキャラクター設定シートの「オナニーの内容」。
- 得意技の種類ごとの基本形：

| 得意技 | 自慰の内容 |
|---|---|
| 乳首開発・乳首舐め・乳首ローター・触手での乳首 | 乳首だけを指でつまむ・転がす・唾で濡らして舐められたように撫でる。胸だけで達する |
| アナル開発（指）・アナル舐め・パール・バイブ・ゼリー・触手でのアナル | 濡らした指で後ろをほぐし、前立腺を探して押す（舐め＝入口を撫でる／パール＝一本ずつ出し入れ など責め手の動きを真似る） |
| 逆アナル（ペニバン・ふたなり・男の娘） | 指二本で奥までほぐし、貫かれる直前の感覚を自分で作る（挿入物は使わない） |
| 尿道責め・尿道ゼリー・尿道とアナル | ペニスには触れず、会陰を押し込んで内側から前立腺を圧す（＋後ろに指） |
| キス責め | 自分の指を咥えて舌を絡め、濡れた指で乳首・首筋をなぞる |
| 洗脳・常識改変・脳イキ | 手を使わず、相手の声や言葉を頭の中で繰り返して触れずに達する |
| 淫紋 | 下腹部の紋を指でなぞるだけで達する |
| 貞操帯 | ペニスには触れず（封印・許可なし）、会陰と後ろだけで達する |
| 足コキ | ペニスには触れず、踏まれる姿勢をとり、床に擦れる乳首と踏まれる想像で達する |
| 女装 | 着せられた衣装のまま、布越しに太もも・後ろを撫でる |
| 機械 | 機械のリズムを真似て、指で乳首・後ろを一定の間隔で刺激する |

- オナニーCG：主人公を主役（手前）、指定した責め手は奥で見ているだけ（触れない）。自慰の動作は上の表のとおり。
