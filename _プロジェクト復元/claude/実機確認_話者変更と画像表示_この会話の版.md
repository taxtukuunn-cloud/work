## 起きたこと
N11（Slime）をゲームで試したところ、戦闘中の画像は出た。しかし敗北イベントでは、キャラのアイコンも敗北CGも出なかった。画像ファイル（`Picture/Slime/` の51枚）とカードは、どちらも正しく入っていた。

## 対策1：カード内は `話者変更` と `画像表示`
- 本編カード `CSV/Card/10021.txt`（エンジェル）は、`@終了時一言` と `@敗北後` の中で次の書式を使っている。
  - 話者：`話者変更,自分` と `話者変更,相手プレイヤー`
  - 画像：`画像表示,&カード画像` と `画像表示,&パイズリ画像,1`
- 見本MOD `kuruMOD_TSuccu_cloth_*.txt` もカード内では `話者変更,` を使う。`話者,` は、クエストイベントや `話者生成` の後（`話者,%キャラ,true,2`）で使われている。
- 決まり：カードtxtの中では、次の書式にする。
  - 話者：`話者変更,〜`
  - 画像：`画像表示,<ファイル>,1`
  - 背景：`背景変更,<ファイル>`
- N11はこれに置き換えた。**それでも出なかった**（2026-09-23 ユーザー確認）。

## 対策2：`@敗北後` の最初に絵を出してからフェードインする（未確認）
- 本編 `10021.txt` の `@敗北後` は、先頭の処理が次の順になっている。
  1. `BGM,&&敗北BGM`
  2. `話者変更,相手プレイヤー`
  3. `説明,…`
  4. `画像表示,&カード画像`
  5. **`フェードイン,3`**
- 戦闘が終わった時点で画面が暗転しているため、フェードインしないと画像もアイコンも見えない可能性が高い。文字の枠だけは表示される。
- N11は、全カードの `@敗北後` の最初（`BGM` の直後）に `画像表示,&カード画像,1` → `フェードイン,3` を入れた（`gen_cards.py` に反映済み）。
- **ほかのMODも同じ症状が出るはずなので、`@敗北後` の最初に `フェードイン,3` を入れる。** これで直ったかどうかは、ユーザーの確認結果をここに書く。

## 対応状況
- N11：対策1・対策2とも済み。ゲームの `CSV/Card/Slime_*.txt`（`SuccubusDuel_sub`）を上書きし、`N11_Slime_MOD.zip` も更新した。
  - 対策2の版は、`SuccubusDuel - コピー` には入っていない。フォルダへの接続が切れていたため。
- `話者,` と `画像,` で書いたほかのMOD（N4・N8・N13の `Card/` 版・N18 など）：対策1と対策2の両方が必要。
  - 行頭の命令だけ置き換える：`話者,`→`話者変更,`、`画像,`→`画像表示,`、`背景,`→`背景変更,`。`画像全削除` と `話者生成` はそのまま。
- もともと `話者変更` `画像表示` で書いたMOD（N6・N1・N7・N3 など）：対策2（フェードイン）だけ確認する。
