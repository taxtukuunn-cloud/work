## 1. 同時攻撃ルール（新規・全MOD共通）

1つの技で**2〜3か所を同時に**責める。表では【同時】と書く。

- **同じ部位どうしは組み合わせない**（例：アナル舐め＋逆アナル、脳イキ＋洗脳、足コキ＋貞操帯は不可）。
- **例外**：乳首舐め＋乳首責め（指・ローター）は、左右の乳首で分ければ同時に行ってよい。
- ゲージ：通常の技は+2、【同時】の技は+3。
- 攻撃タイプは主になる責めの型を1つ設定する（逆アナルを含むなら本番）。`技名表示` で技名を出し、セリフで両方の責めを描写する。
- CGは両方の責めが見える構図にする（責め手が1人で足りない時は、触手・尾・分身・配下の手を使う）。
- 配置：各MODで**マスターの技③と上級の技1つは必ず【同時】**。下級は単独技が基本。
- 双子（N19）と忍者（N30）は、マスターの技を多めに【同時】にしてMODの売りにする。

## 2. 女装娘ルール（v2.1から継続）

- 対象：女装のプレイを持つ **N23・N24・N25**。
- 主人公側の男モンスターが女装化系の技・魔法を**受けた時点で即**、破壊扱い→主人公側に「女装娘」カード（`<コード>_josou`）として特殊召喚。
- 女装娘カード（案）：攻撃力500・HP1500・性別その他。攻撃は `通常攻撃` のみ。場にいる間、敵ターン終了時にゲージ+1。
- 主人公が女装させられた後は、シーン画像もシナリオも最後まで女装姿のまま（脱がさず、責める部分だけずらす）。女装ありMODは敗北28本すべてに女装させる場面を入れる。

## 次に作るときの手順
1. 作るMODを1つ選び、`claude/<No>_<コード>_設計メモ.md` を作る（28ルートのあらすじ表まで）。
2. `N13_CrossCafe_MOD.zip` の `tools/build.py` をコピーし、名前・技・効果・ゲージ名を差し替える。【同時】技はゲージ+3。女装ありのMODは女装娘カードも作る。
3. セリフ（4段階）と敗北28本を責め手ごとに並列で書き、`check.py` で5,000字以上・禁止文字・if括弧を確認。
4. `scene_overrides.py` に場面を追加して画像を生成（【同時】技のCGは両方の責めが見える構図）。
