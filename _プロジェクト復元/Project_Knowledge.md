## 1. ゲームとMODの仕組み
- Unity製のカードバトル。カード・イベント・敵マスターは**テキストスクリプト**で定義。
- フォルダ：`Card/`（カード・敵マスター）、`Eventlist/`（イベント登録）、`Picture/<MOD名>/`（画像）、`CSV/…`（本体データ）、`BGM/`、`SE/`。
- **イベント登録**（1行・末尾改行なし・BOMなし）：`表示名,Card/<ファイル名(拡張子なし)>,クエストイベント`。
  - **クエストの登録ファイルは `EventList/Quest/` の中に置く**（既存MODは `CSV/EventList/Quest/`。MOD用の `Eventlist/` でも同じく `Quest` サブフォルダ）。**`Eventlist/` の直下に置くと出なかった**。
  - 種別は実行する節に対応：`クエストイベント`→`@クエストイベント`／`イベント`→`@イベント`（ディアナは `@イベント`）。他に `戦闘前イベント`・`Cocktailクエストイベント` などの独自種別もある。
  - 一覧（`Quest.txt`）では `表示名,Card/…,クエストイベント,条件…` と、後ろに表示条件（ランク・場所など）を付けられる。条件なしなら常に表示。
- 敵の**デッキ**：`デッキ設定,<Cardファイル名>,…`（同名を複数書くと複数枚）。
- 画像指定：`#フォルダ/ファイル.png`（例：`#Rosetta/Elsa.png`）。

## 2. スクリプト書式（既存MOD「kuruMOD メスイキ」「ディアナ」等で確認済み）
**ファイル構造**：1行目 `default`／`@初期設定`／`@効果`／`@効果_街バトル`（`イベント実行,効果`）／敵マスターは `@クエストイベント` と戦闘フック。
**@初期設定**：`&カード名` `&カード画像` `属性設定` `タイプ設定`（悪魔／通常魔法／永続魔法／装備魔法／通常罠 等）`レベル設定` `攻撃力設定` `最大HP設定` `レアリティ設定` `性別設定` `攻撃エフェクト設定` `効果設定,ID,種別,説明`（種別：通常／play／強制誘発／永続効果／explain）`誘発効果設定,ID,タイミング`（通常召喚時／エンドフェイズ開始時／メインフェイズ開始時／onOtherSummon）`効果条件設定` `永続効果設定,自分,seal攻撃宣言,(true)`。
**敵マスターのフック**：`@試合開始` `@戦闘`（攻撃宣言時）`@戦闘後` `@ターン終了宣言` `@オナニー` `@終了時一言` `@相手特殊召喚後`。
**主なコマンド（確認済み）**
- 表示：`セリフ` `説明` `話者,自分/相手/相手プレイヤー/自分プレイヤー/%変数` `画像,ファイル,位置` `画像削除` `画像全削除` `背景変更` `BGM` `SE` `フラッシュ,ピンク` `エフェクト,名前,対象` `エフェクト拡大表示,名前,サイズ` `フェードアウト/フェードイン` `技名表示/技名削除` `アラート` `選択肢生成`
- 戦闘：`イベントダメージ,対象,値` `とどめダメージ` `ループダメージ,対象,値,間隔,SE` `ループダメージ停止` `イベントヒール` `状態異常付与,対象,名前[,ターン]` `状態異常解除` `攻撃タイプ変更` `攻撃エフェクト変更` `攻撃力加算` `HP加算` `射精`
- カード操作：`効果除外` `効果破壊` `特殊召喚,%カード,味方（＝敵側）/相手所属（＝主人公側）` `効果生成デッキ内,&ID,味方` `%x,=,自分デッキ.?ID:&ID` `外部カードイベント実行,イベント名,%カード` `カードランダム抜き出し,相手モンスター,1,%x` `カード抜き出し`
- 制御：`if / else / while / switch,case` `乱数生成,1,N` 変数（`$`グローバル・`%`ローカル・`&`文字列・`対象.$変数`）
- 敵イベント：`デッキ設定` `デッキ報酬設定,金,経験,ランク経験` `バトル設定,相手先攻` `バトル開始,背景,BGM` `if,is敗北,==,true`
**状態異常（確認済み）**：寸止め（HPを1で止める＝HP0判定に使う）／魅了／発情／ぬるぬる／攻撃不能／攻撃指示不能／魔法使用不能／隠密／メロメロ／おっぱいに弱い。
**素材キー**：背景 `&&街背景` `&&路地裏背景` `&&豪華な寝室背景`／BGM `&&戦闘BGM` `&&敗北BGM` `&&南の村BGM`／SE `&&怪しい光SE` `&&行為SE` `&&行為はげしめSE` `&&服を脱がすSE`／エフェクト `&&セクシーエフェクト` `&&セクシーエフェクト2` `&&フェロモンエフェクト` `&&ハートスタンプエフェクト` `&&魔法攻撃エフェクト`。
**参照した既存ファイル**：`Card/夢見咲.txt`（モンスター）`Card/催眠香.txt`（永続魔法）`Card/dianatest.txt`（敵イベント）／`kuruMOD_Mesuiki_master.txt`（クエスト敵マスターの手本）`…_trap_TrapDildo`（罠）`…_mons_FallenIntoGirl`（堕ちたキャラの特殊召喚）。※kuruMODの「少女」系カードは成人条件に合わないため流用しない。

**おねだり**：プレイヤー／味方カードが敵に「おねだり」すると、敵の `@おねだり` が呼ばれる（`相手`＝おねだりした側）。選択肢を出し、選んだ責めを指定して、そのまま敵が攻撃する（既存MOD「ショタ攫いサキュバス」の作り。`攻撃タイプ固定` を使う）。やめるなら `おねだり中断`。攻撃後は `@おねだり後`（`直前攻撃タイプ` で感想）。ロゼッタMODは、独自の攻撃タイプ名が `攻撃タイプ固定` で使えるか不明なため、`$おねだり指定`（ファイル内の変数）に責めの番号を入れ、`@戦闘` がそれを見て `攻撃タイプ変更` する方式にした。`@戦闘` は「攻撃タイプを決める（通常は段階／乱数、おねだり時は指定）→ 攻撃タイプごとに台詞」の2段構成。おねだりの対象にできないようにするには、`永続効果設定,自分,sealターゲット,(ターゲットモード,==,ターゲットモードおねだり)`（メス奴隷に設定）。

**ドロー／サーチのバランス調整**：ドローが強すぎたため、黒薔薇のオイル／女王の命令／黒薔薇の調教部屋は**モンスターサーチ**に変更（`%サーチ候補,=,自分デッキ.?NamePart:従者エルザ` のように `?NamePart` でデッキから候補を集め、`カード選択,%候補,1,1` → `効果サーチ,選択カード,自分所属`）。**メス堕ち完成の儀だけドローを維持**、2枚→**1枚**に減量。

**メス堕ち度で台詞が変わる**：攻撃宣言（`@戦闘`）と攻撃後（`@戦闘後`）は、`if,相手プレイヤー.$メス堕ち度,<=,6`／`>=,7,&&,<=,13`／`>=,14`（モンスター相手は `相手.$メス堕ち度`）で低・中・高の3段階に分ける。ロゼッタは攻撃タイプ（=段階）の中で前半／後半に分ける（胸 ≦3/≧4、尻尾 ≦10/≧11、ペニバン ≦16/≧17）。
**台詞の方針**：攻撃宣言（`@戦闘`）・攻撃後の効果（`@戦闘後`）・魔法罠の効果・メス堕ち変換の台詞は**長め**（1つの`セリフ`が2〜3行、1場面で敵と相手が複数往復）。**攻撃宣言の台詞は全キャラにある**（マスター含む）。攻撃宣言は攻撃の相手（モンスター／主人公）で出し分ける。ターン終了宣言の台詞だけは短いまま。

**フレーバーテキスト**：`@初期設定` に `フレーバーテキスト,本文`（`&`なし。kuruMODのモンスターと同じ書き方）。全カード（マスター・モンスター・魔法・罠・メス奴隷）に、館の世界観が伝わる100〜130字程度で入れている。改行は `\\n`、本文にASCIIカンマは使わない。

**状態異常について（調査で判明）**：状態異常はゲーム本体に組み込み（MODで新しい名前は作れない）。同じ状態異常を重ねると別々に並び、`対象.?状態異常:名前.Count` で個数を数えられる（nuufarm「雪女の施し」）。ただし各状態異常にはゲーム側の効果がある（例：`洗脳` は `コントロール変更` と組み合わせて使われる）。また、カード自身が実行中に `&カード名,文字列` で自分の名前を書き換える例がある（Aiforce「The Arcana VIII - 力」）。フレーバーテキストは、マスターは `&フレーバーテキスト,`（&付き）、モンスターは `フレーバーテキスト,`（&なし）の実例がある。

**メス堕ち度ゲージ**：`@ゲージ表示`（各カードとマスターに同じものを持つ）を `イベント実行,ゲージ表示` で呼ぶ。呼ぶ前に `$表示値`（メス堕ち度）・`$表示番号`（0＝主人公、1以上＝モンスターの並び順）・`&表示名` を設定。ハートは `&ゲージ,+=,(♥)` の文字列連結で作り、`アラート,{&表示名}のメス堕ち度 {$表示値}／20 …\\n{&ゲージ}` で表示（既存MODの `アラート,…{$変数}`・`説明,{&文字列}`・`&文字列,+=,(…)` の書き方を流用。実機では未確認）。表示は、試合開始時・メス堕ち度が増えた時・ロゼッタのターン終了時。**常時表示のHUDは作っていない**（確認済みコマンドがないため）。

**公式MODドキュメント**（Google Drive「サキュバスデュエルMODドキュメント」）にコマンド・Enum一覧がある。困ったらまずここを見る。
- **`@命乞い`**：そのキャラ／モンスターの**HPが0になった時**に呼ばれる（`相手`＝とどめを刺す相手）。**`命乞い失敗` を呼ばないと、そのキャラは不死身になる**。見逃される（成功）場合は、`イベントヒール,自分,自分最大HP/2` などで回復して `イベント終了`。回数は整数Enum `命乞い回数`（台詞の出し分けに使う）。**回数による強制失敗は入れない**（要望）。代わりに「倒せる経路」を残す：ロゼッタも従者（エルザ・ヴィヴィアン・ミレーユ）も、毎回プレイヤーに選択肢（とどめを刺す／見逃して誘惑に身を任せる）を出す。とどめを選べば `命乞い失敗`。
- **ドロー**：`効果ドロー,自分プレイヤー`（敵カードでは敵マスターがドロー）。
- **状態異常はEnumで固定**（魅了・寸止め・発情・洗脳…の一覧）。MODで新しい状態異常（例：メス堕ち）は作れない。`状態異常付与,カード,状態異常,持続,Value`。
- 公式ドキュメントに「テキストの頭に `default` を付けたままだとアップデートで上書きされる」とある。ゲーム更新後にMODが消えたら、バックアップから戻す。

**変数の範囲（公式ドキュメント／実機で判明）**：`$` `&` `%` は**そのテキストファイル内でしか有効でない**ローカル変数。**別のファイル（別カード）と値を共有したい場合は、グローバル変数 `$$`（セーブされる）を使う**。名前は他のMODと被らないよう `$$ペンネーム_変数名` の形にする。今回のバグ：`$最後の責め手` をカードごとに書いていたため、マスター側は初期値のまま → ロゼッタの敗北シナリオしか出なかった。→ `$$ロゼッタ_最後の責め手` に変更。（`相手プレイヤー.$メス堕ち度` のような「カードの持ち物としての変数」は、別ファイルからも見える。）

**回想モード**：ゲームの回想メニューは `EventList/Renoun/` のイベントリスト（`名前,Card/ファイル,セクション名,条件…`）から作られる（`Func.txt` の `@イベント回想` → `中央メニュー生成,回想,EventList/Renoun`）。項目は**指定ファイルの任意のセクション**を呼べる。回想中は `Now回想`＝true で、セーブに関わる変数（`$$`）の書き換えは `回想モードOFF` → 処理 → `回想モードON` が必要。バトル外から敗北後イベントを呼ぶ時は `自分プレイヤー設定` を使う場合がある（ドキュメント）。ロゼッタMODは、敗北シナリオを `@敗北_○○` に独立させ、実際の敗北時（`イベント実行,敗北_○○`）と回想（`@回想_○○敗北`）で共有。ダメージ演出の対象は `%ダメージ対象` 変数で、戦闘後は `相手`、回想では `相手プレイヤー` に切り替える。

**書き方の注意（実機テストで判明）**
- **モンスターの責めは既存MODと同じ `@戦闘`／`@戦闘後` のフックで書く**（kuruMODの「乳首イタズラ少女」と同じ）。`相手` が攻撃対象。プレイヤー判定は `if,相手,==,相手プレイヤー`／`if,相手,!=,相手プレイヤー`。攻撃タイプは `乱数生成,1,2` → `攻撃タイプ変更,名前`。
- **サブフォルダの画像は `@初期設定` で `&変数` に定義して使う**（例：`&画像_Elsa_nipple,#Rosetta/Elsa_nipple.png` → `画像,&画像_Elsa_nipple,1`）。効果内で `画像,#フォルダ/ファイル.png,1` と直接パス指定すると出なかった。
- **「対象がいるか」は枚数で判定する**：`if,相手モンスター.Count,>,0 { カードランダム抜き出し,相手モンスター,1,%x … }else{ （相手プレイヤーへ） }`。`%x,=,0` のあとに `if,%x,!=,0` で判定する書き方は、**対象がいないのに「いる」と判定され**、空の対象でメス奴隷が召喚された。
- 登録ファイルは `Eventlist/Quest/` の中（直下だと出ない）。

## 3. 現在の成果物：黒薔薇の館（ロゼッタ）MOD（`Rosetta_MOD.zip`）
- 敵マスター：**黒薔薇の調教師ロゼッタ**（26）＝乳首（指と舌）→**尻尾**で前立腺→ペニバン。従者3人：
  - **エルザ**（24）＝**乳首責め**（指と舌）／攻撃タイプ：乳首指責め・乳首舐め
  - **ヴィヴィアン**（28）＝**指でアナル責め**（前立腺診察）／攻撃タイプ：触診・前立腺マッサージ
  - **ミレーユ**（27・洗脳担当）＝目隠しをして**背後から抱きしめ**、**ニップルドーム**（**白い不透明の円錐形カップ＋ピンクのアクセント**。透明ドームやクリップにしない。**吸引しながら舐め回す**）と**アナルパール（太め）**で乳首とアナルを同時に責めながら**耳元で洗脳**／攻撃タイプ：耳元洗脳・二点責め
- **マスターとモンスター（エルザ・ヴィヴィアン・ミレーユ）の責めは「攻撃時の効果」**（`@戦闘`で攻撃タイプを乱数で2種から選び、`@戦闘後`で攻撃対象にメス堕ち度・ダメージ・メス奴隷化を処理）。召喚時・ターン終了時の効果は使わない。魔法・罠は従来どおり効果（モンスター優先）。
- デッキ（3枚ずつ計24枚）：従者エルザ／調教医ヴィヴィアン／洗脳調教師ミレーユ／黒薔薇のオイル／調教ペニバン（罠）／女王の命令／黒薔薇の調教部屋（永続）／メス堕ち完成の儀。
- 進行：主人公の `$メス堕ち度` が 1〜6 乳首／7〜13 前立腺（ロゼッタは尻尾）／14〜19 ペニバン／20 完成（即敗北）。
- **モンスター優先**：対象を `カードランダム抜き出し,相手モンスター` で決定。モンスターごとに `$メス堕ち度`。**13以上**、またはHP≦1（寸止めで維持）で `♥メス奴隷♥`（`Rosetta_mons_Slave`）を敵側に特殊召喚（元の攻撃力・HPを引継ぎ）。
- モンスターの攻撃タイプ・責めの段階は主人公と同じ（メス堕ち度 1〜6 乳首／7〜13 前立腺／14〜19 ペニバン）。**変換しきい値は13**（前立腺段階の終わり＝ペニバンに入る前）。メス堕ち完成の儀は14以上で即変換、14未満でも被弾後に13に達すれば変換。
- **メス奴隷**：性別＝男。中性的・小柄・華奢・筋肉なし。攻撃・守備不可。ロゼッタのターン開始時に精気を吸われ、ロゼッタHP+300。

## 5. 判明したトラブルと対処
| 症状 | 原因・対処 |
|---|---|
| `Python was not found` | Pythonなし → ComfyUI同梱の `python_embeded\python.exe` を使う（batに設定済み） |
