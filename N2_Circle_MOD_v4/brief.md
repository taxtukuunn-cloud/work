# N2 男の娘サークルの先輩（コード Circle）敗北シナリオ執筆ブリーフ（v4・2026-09-24）

サキュバスデュエル（M向けカードゲーム）の個人用MOD。**登場人物は全員20歳以上の成人**（大学生だが全員成人。主人公も成人）。個人利用のみ。
あなたはベストセラー作家として書く。主人公（プレイヤー。名前なし）が大学のカードゲームサークルの男の娘の先輩・部員たちとのカードバトルに負け、責められて堕ちていく「敗北シナリオ」を書く。

## 絶対条件
- 責め手（男の娘の部員たち）が常に上位。主人公は受け身のみ。**逆転なし**。主人公は挿入しない・責め返さない。
- 責め手は服を着たまま責める。責め手自身が自慰したり、受け身になったりしない。
- **このMODでは責め手自身のペニスでの挿入はない**（指・舌・キス・アナルパールまで）。
- 暴力・流血・アヘ顔・凌辱的な描写はなし。甘え・からかい・キス・焦らし・言葉責めで逃げ道をふさぐ。
- 未成年を連想させる語（少年、ショタ、幼い、子ども、高校 等）は使わない。全員が成人の大学生・OB。
- 指を後ろに入れる時は、ローションで濡らし、一本ずつ丁寧にほぐす描写にする。
- 主人公のペニスを使う自慰は書かない（オナニー負けは下の「オナニーの内容」の自慰から始める）。

## 構成（1本の合計7,000字以上。セリフ,と説明,の本文だけで数える）
ファイルは3つの部分に分け、**区切りの行 `##PLAY` と `##END` を入れる**（ゲームには入らない印）。
1. **導入（`##PLAY` の前）：400字程度（300〜600字）**。冒頭行は画像行。どう負けたか（経路）、なぜこの責めなのか、どこへ連れて行かれたか。
2. **プレイ描写（`##PLAY` と `##END` の間）：6,000字以上（目標6,500〜7,500字）**。途切れさせず一連のシーンで。責め手の責め中のセリフ、主人公の喘ぎ声、快楽に対する心理描写、体や神経の反応、道具の動き（リップ、唾液の糸、パーカーの紐、ローション、指の本数と角度、パールの一粒一粒、砂時計の砂）を細かく書く。**その責め手の得意技を主役にする**。絶頂は2〜4回（各絶頂の前に `射精` 行を置いてよい。触れずに達するなら置かない）。途中で後日談に飛ばない。
3. **結び（`##END` の後）：600字以内**。責め手の締めのセリフと、その後の短い余韻。
- 弱点付与・GAME OVER・BGMは別処理なので書かない。
- 文章の質：五感（苺のリップ、夕日の色、古いソファの軋み、濡れた音、本のページの匂い）、比喩、緩急、責め手ごとの口調の個性。同じ責め手の4本は、場所・時刻・小道具・絶頂の区切り方・結末の印を変えて、読み比べて別物にする。

## 経路（どう負けたか）の軸
- **btl（戦闘負け）**：勝負の最中の責めに崩れ、キス度が満ちて倒れる。責めに屈して、その責め手の流儀で堕とされる。
- **onani（オナニー負け）**：勝負の最中、我慢できずにその責め手の得意技を真似た自慰を始めてしまい、見つかる。自分から手を伸ばした恥が軸。見られる・記録される・管理される。**プレイ描写の最初は、下の「オナニーの内容」の自慰（ペニスは使わない）から始め、途中で責め手が引き取る。**
- **inochi（命乞い負け）**：とどめを刺せる場面で甘い言葉や泣き真似に手が止まる。その一瞬の情けが、約束・契約・所有に変えられる。
- **onedari（おねだり負け）**：勝負の中で自分から具体的に「〜してください」と請う。それが記録され、日課・約束になる。

## オナニーの内容（onani ルートの冒頭。ペニスは使わない）
- ハルカ（長いキス）：自分の指を咥えて舌を絡め、先輩の長いキスを思い出しながら、唾で濡れた指で唇と首筋をなぞる
- ミオ（キスしながら乳首）：指を咥えて濡らし、その指で乳首を転がす。キスと乳首を同時にされた感覚を自分で再現する
- ツバサ（抱きつきキス）：ツバサのパーカー（または部室のクッション）を抱きしめ、顔を埋めて手の甲に唇を押し当てながら、胸を擦りつける
- カイト（耳舐めと囁き）：手を使わない。耳に残ったカイトの囁きを頭の中で再生し、言われたとおりに体の力を抜いていくうちに触れずに達しそうになる
- シズク（キスしながらアナルパール）：指を咥えながら、濡らした指で後ろを一本ずつほぐし、珠を一粒ずつ入れられる感覚を再現しようとする

## 書式（厳守。ゲームのスクリプトとしてそのまま読み込まれる）
1行に1コマンド。使ってよい行は次だけ：
```
画像,#Circle/Circle_lose_<経路>_<責め手>.png,1
話者,%ハルカ          （%ミオ %ツバサ %カイト %シズク も同様。責め手が喋る前に必ず入れる）
話者,相手プレイヤー    （主人公が喋る前に入れる）
セリフ,本文
説明,本文            （地の文・情景・心の動き）
フラッシュ,ピンク
射精
ウェイト,1
##PLAY
##END
```
- **本文に半角カンマ「,」を絶対に使わない**（全角「、」を使う）。
- 本文に `$ % & # { } < > ;` を使わない。半角の `!` `?` も避け、全角「！」「？」を使う。ハートなどの記号は使わない。改行したい時だけ `\n` を使ってよい（1行2〜3文まで）。
- 1行の本文は長くても120字程度。セリフは「」を付けない。
- 冒頭行は必ず `画像,#Circle/Circle_lose_<経路>_<責め手>.png,1`。ほかの画像ファイル名は使わない。
- 空行・コメント・見出し・`@` 行は書かない。`##PLAY` `##END` はそれぞれ1回だけ。
