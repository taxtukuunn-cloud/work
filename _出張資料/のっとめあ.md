## 1. フォルダ構成

| 項目 | 結果 |
|---|---|
| エンジン | **RPGツクールMZ**（`package.json` の name は "rmmz-game"、セーブの拡張子は .rmmzsave） |
| data フォルダ | `data/` あり（www フォルダ無し）。**平文JSON**（Enemies／Skills／Troops／CommonEvents／Map約240個） |
| 画像 | `img/**/*.png` は**暗号化されていない**。ただし今回のルール（読むのはテキストのみ）に従い、**画像は開いていません** |
| 音声 | 大半は .ogg（平文）だが、`*.ogg_`（86個、一部のH音声）は**暗号化**。どちらも開いていません |
| System.json | encryptionKey 無し（暗号化フラグも無し）。`.ogg_` は別の仕組みで暗号化されている |
| セーブ | `.rmmzsave` は開いていません |

- 主人公: **リード**（Actors.json）。敵からは「勇者様」「お兄さん」などと呼ばれます。
- 作品の特徴: 敵の多くが「夢魔（サキュバス）」。戦闘中の誘惑・屈服（「くっぷくイベ」）でHシーンに入ります。

### データの読み方メモ
- Skills.json の技名は**内部名**です（例: 「ヘル技１」「シャオ太腿」「クイン大技足」）。表示用の技名や説明文は空欄で、実際の演出はコモンイベント側にあります。下の「技」欄は内部名をそのまま載せています。
- セリフの話者は、メッセージの「名前欄」に入っています。
