## 1. フォルダ構成

| 項目 | 結果 |
|---|---|
| エンジン | **RPGツクールMV**（NW.js版、816×624） |
| data フォルダ | `www/data/` あり。**平文JSON**。ただし `Map001.json` が1枚だけで、**ゲームのほぼすべてが CommonEvents.json（約2.4MB）** にあります |
| 画像 | `www/img/**/*.rpgmvp`（3,967個）→ **暗号化**。開いていません（平文の .png は system の2個だけで、これも開いていません） |
| 音声 | `www/audio/**/*.rpgmvo`（460個）→ **暗号化**。開いていません |
| System.json | `hasEncryptedImages: true` / `hasEncryptedAudio: true` |
| セーブ | `www/save/` は開いていません |
| 過去の展開跡 | 見つかりませんでした |

- 主人公: Actors.json の1番は**名前が空欄**で、開始時に名前入力（`\N[1]`）。職業は**勇者**。敵からの呼ばれ方は「勇者くん」「勇者さま」「\N[1]さん」「兄様」「勇者先輩」「男くん／M男くん」など、キャラによってバラバラです。
- 設定: 魔王を倒した勇者パーティ（主人公、義妹メテル、幼馴染アドニス、僧侶マティア）が「魔王の呪い」にかかります。主人公の呪いは「**射精すると魔力が流れ出し、3回で死ぬ**」というもの。町ごと異世界「エリュシオン」に飛ばされ、4つの秘宝を集める話です。
- Enemies.json（こうもり／スライム／オーク／ミノタウロス）と Skills.json はツクールの初期データのままで、**実際の敵データには使われていません**。

### データの読み方メモ（MOD作成用）
- 戦闘はリアルタイム式を**コモンイベントで自作**しています。敵1体につき、コモンイベントが4つセットになっています。
  - `■〇〇戦闘`（立ち絵の表示と初期設定）／`☆〇〇ステート`（能力値）／`●〇〇行動`（技）／`▲〇〇犯され`（敗北時のHシーン）
  - Troops.json は「名前 ＋ 上の■を呼ぶだけ」の器です（敵は全部ダミーのこうもり2体）。
- **技名**は `●〇〇行動` の中で、変数57「敵スキル名」に文字列で入っています（下の表はここから拾いました）。表示用の名前なので、内部名ではありません。
- **図鑑**は CE106「図鑑各キャラ表示用」。`D_TEXT` プラグインコマンドで「名前／種族／出身／説明文」を書いています（Items.json ではありません）。
- **セリフ**は「1行目に【話者名】、2行目以降に「本文」」という形式です。Hシーンの中では話者が `【\V[8]】`（変数8「敵の名前」）になっていて、`■〇〇戦闘` で名前を入れています。
- 背景は ピクチャー1番の `haikei〇_場所名`、敵の立ち絵は ピクチャー6番（会話中）・20番（戦闘中）です。
