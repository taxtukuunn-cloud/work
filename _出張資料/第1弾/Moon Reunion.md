## 1. フォルダ構成

| 項目 | 結果 |
|---|---|
| エンジン | **RPGツクールMV**（NW.js版） |
| data フォルダ | `hontai/www/data/` あり。**平文JSON**（CommonEvents.json 約4MB、Map001〜052）。`MV_Project.json` は画像ファイル名の一覧でした |
| 画像 | `www/img/**/*.rpgmvp`（12,613個）→ **暗号化**。開いていません（平文の .png は system の2個だけで、これも開いていません） |
| 音声 | `www/audio/**/*.rpgmvo`（359個）→ **暗号化**。開いていません |
| System.json | `hasEncryptedImages: true` / `hasEncryptedAudio: true` |
| セーブ | `www/save/` は開いていません |
| 過去の展開跡 | 見つかりませんでした（`チュートリアル画像` フォルダは開いていません） |

- 主人公: **ナツル**（Actors.json。本文では `\N[1]`）。現実世界から異世界に転生した青年で、相棒の「勇者の剣」（ユウ）を手に入れて勇者になります。一人称は「僕」。敵からは「**勇者さん**」「**お兄さん**」「あなた」「\N[1]」と呼ばれます。
- 戦闘はリアルタイム式で、負けるとステータスを**ドレイン**（永続的に奪われる）されます。奪われた分は「ステータス返却場」で取り戻せます。
- 公式の改造方針（Read me.txt）: 「改造等については禁止は致しませんが、配布は行わずに個人でお楽しみください」。

### データの読み方メモ（MOD作成用）
- Enemies.json／Troops.json／Skills.json はツクールの初期データのままで、**敵データには使われていません**。戦闘はすべてコモンイベントで自作されています。
- 敵1体につきコモンイベントが4つあります: `☆〇〇ステータス`（表示名は変数231）／`■〇〇詠唱開始`（技名は変数383、ログ文は変数384）／`●〇〇行動`（技のかけ声は変数525）／`▲〇〇犯し`（敗北時のHシーン）。
- **CE名の内部名と表示名が違う**キャラがいます: ゴーレム→**マニュ**、ゴスロリ→**ロシィ**、テクニック→**スノウ**、ケミカル→**ミコル**、マーチヘア→**マーチ**、狂信者→**ゼアロ**、マグネ→**ネティ**、いじめ→**フロッツ**、エＭ→**エイル**、リＭ→**リヤ**。
- 敵番号（変数201〜203に入れる値）: 1スライム 2エルフ 3ダークエルフ 4アルラウネ 5ハイインプ 6シルク 7ライン 8マニュ 9マリー 10リーゼ 11ソレイユ 12ハル 13ノワール 14ミュカス 15ロシィ 16スノウ 17ミコル 18タキリ 19モルペー 20エリーネ 21キリエ 22マーチ 23ゼアロ 24テトニナ 25ミム 26睡魔 27クロノム 28ネティ 29ナンシー 30フロッツ 31エイル 32リヤ 33UPユウ 34UPハイインプ 35UPテトニナ 39トレーニングさん。
- **図鑑**は CE530「図鑑描画」の `D_TEXT`。図鑑の並び順と敵番号の対応は CE531 にあります。
- セリフは「1行目に【話者名】、2行目以降に「本文」」。Hシーンでは話者が `【\V[540]】` になっています。
- `各敵行動パターン.txt`（同梱）に、各敵の行動パターンと攻略のヒントが書かれています。

## 5. 世界観メモ

- 空に「普通の月」と「青い月（魔月）」の2つの月がある世界。魔月が人類と魔族に魔力を与えていて、その取り合いで戦争が起きた。
- 約300年前、勇者**フィーナ**が当時の魔王を倒したが、自分が魔王になった。フィーナは主人公の幼なじみで、子供のころに事故で亡くなり、過去に転生していた（エンディング付近で判明）。魔王（フィーナ）とは戦闘はありません。
- 主人公の相棒**ユウ**は、キリエが作った「勇者の剣」の呪いが人の姿になったもの。主人公の記憶から姿が作られ、意図せず「想い人」の姿になった。
- 仲間: エイル（先輩冒険者）、リヤ（エイルの幼なじみ）、ノルン（未来が視える）。エイルとリヤは途中で敵として戦います。ノルン・フィーナ・受付の人・巫女は敵として戦いません。
