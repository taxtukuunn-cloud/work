## 入れ方（ゲーム：D:\GAME\SuccubusDuel本体\RJ01149693\SuccubusDuel_sub\サキュバスデュエル）
1. `Card\` の10ファイル → ゲームの `CSV\Card\`（旧版と同じ名前なので上書き）
