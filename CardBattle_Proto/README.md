# 淫魔の誘惑デッキ（仮）試作版

成人向けの男性受けカードバトルの試作です。Godot 4.6 で作っています。登場人物はすべて成人です。

DLsite の男性受けゲームの傾向調査（`../reports/DLsite 男性受けゲーム傾向.md`）と、桜井政博氏の「ゲーム作るには」をまとめた非公式スキル [kociden/sakurai-skill](https://github.com/kociden/sakurai-skill) を元に設計しました。下の対応表の番号は、そのスキルの動画の通し番号です。

## 遊び方

- 主人公（成人の剣士）が、淫魔3体に順番に挑みます。
- 攻撃カードで相手の「余裕」を0にすれば勝ちです。
- 主人公の「興奮」が100に届くと絶頂して、「精」を1つ失います。精が3つとも尽きると負けです。
- **興奮が40を超えると「火照り」、70を超えると「限界寸前」になり、攻撃が1.3倍・1.7倍に強くなります。** 限界ぎりぎりで戦うほど強くなりますが、一歩間違えると絶頂します。
- 負けると敗北シーンが見られます。ペナルティはなく、同じ相手にすぐ挑み直せます。2回目に負けると、1回目の続きのシーンになります。
- 「おねだり」で、自分から負けを選べます。
- 勝つと、報酬カードを3枚のうち1枚デッキに加えられます。勝ったときの見送りシーンも回想に入ります。

| 操作 | キーボード | コントローラー |
|---|---|---|
| 選ぶ | 矢印キー | 十字キー・左スティック |
| 決定 | Enter / Space | Ⓐ（設定で Ⓑ と入れ替えられる） |
| 戻る・シーンを飛ばす | Esc | Ⓑ |
| ターン終了 | E | Ⓨ |
| おねだり | Q | Back |
| デッキを見る | D | Ⓧ |
| 早送り（押している間） | Ctrl | RB |

開発用の操作（書き出した製品版では効きません）：F2 相手の余裕を1にする、F3 興奮+30、F4 気力+3、F5 data/*.json を読み直す。

## フォルダの中身

| 場所 | 中身 |
|---|---|
| `data/params.json` | 調整する数値。【日本語名】で書いてある |
| `data/cards.json` | カード（効果は `effects` に並べる） |
| `data/enemies.json` | 敵と行動の順番（`pattern`、余裕が半分を切ったら `pattern2`） |
| `data/scenes.json` | 会話とシーンの本文。差し替えればそのまま反映される |
| `scripts/battle/battle.gd` | 戦闘の計算だけ（画面に触らない） |
| `scripts/ui/` | 画面 |
| `scripts/autoload/` | データの読み込み・進み具合と設定・効果音 |
| `tests/` | 自動テストと、自動で遊ぶボット |
| `tools/autoshot.gd` | コントローラーの入力を送りながら画面を撮る道具 |
| `assets/portraits/<敵のid>.png` | ここに立ち絵を置くと、仮の図形の代わりに表示される |

## 動かし方

```
# テスト（失敗があれば終了コード1）
godot --headless --path . res://tests/test_runner.tscn -- --no-save
# 勝率の測定（--sim は敵×強さ×デッキ、--cardsim はカード1枚ごとの勝率の変化）
godot --headless --path . res://tests/test_runner.tscn -- --no-save --sim --cardsim
# 画面を撮る
xvfb-run godot --path . --rendering-driver opengl3 -- --no-save --autoshot=/出力先
# Windows 用に書き出す
godot --headless --path . --export-release "Windows Desktop" build/windows/InmaDeck.exe
```

## 調査から取り入れたこと

| 調査で分かったこと | このゲームでの形 |
|---|---|
| レビューで一番評価されるのは「逆転なし」の徹底 | 勝っても相手は余裕を崩さずに去る。主人公が攻め返す場面はない |
| 「わざと負けないと見られない」が不満の上位 | おねだりボタン、負けても損をしない、回想の全開放スイッチ |
| 敗北後の続きの作り込みが評価される | 同じ相手に2回目に負けると、1回目の続きのシーン |
| 回想の欠如が不満の上位 | 勝利・敗北の全シーンが回想に入る |
| M度を選べる設計が評価される | 責めの強さ（あまあま／ふつう／はげしい） |
| 主人公が喋らない方が好まれる | 主人公の台詞はなく、地の文だけ |
| 逆アナルは供給が少なく、1本あたりの売上が高い | ボスの敗北シーンに入れた（単独の主題にはしない） |
| デッキ構築は本数が少ないのに2万本級のヒットがある | デッキ構築型のカードバトル |
| 地雷は消すより事前に知らせる | （まだ）販売ページと起動時の注意書きで知らせる予定 |

## 桜井スキルとの対応

### 芯（ゲーム性）

| 原則 | 動画 | このゲームでの形（場所） |
|---|---|---|
| リスクとリターンを近くに、釣り合った大きさで | #006 | 興奮が高いほど攻撃が強い（高揚）。限界寸前なら1.7倍だが、次の責めで絶頂しかねない（`battle.gd` の `tier()` / `damage_value()`、params の【高揚が上がる興奮】【高揚の削りの倍率】） |
| ギュッとしてパッと解消 | #009 | 責めで溜まる興奮（ストレス）を、高揚の一撃で余裕を崩して解消する |
| 勝っても負けても面白い | #097 | 負けると敗北シーン。勝つと見送りシーンと報酬カード |
| 一言で特性を言えるまで尖らせる | #204 | ミルダ＝甘い誘惑カードを混ぜる、セルペナ＝巻きついて手札を減らし大技で締める、ヴェルザ＝予告つきの大技と第2形態 |
| どれだけ良いことをしたか | #236 | 報酬カードのうち、取ると損になるものがないよう、カード1枚ごとの勝率の変化を測って直した（`tests/test_runner.gd` の `_card_sim`） |
| 開発者は思ったより下げる | #254 | 調整は完璧に打つボットで行い、人が遊ぶと勝率が下がる前提で、ボットの勝率は高めに置いた |

## 別の係のレビューで直したこと

作った本人とは別の係に桜井スキルを渡してレビューさせ、指摘14項目と不具合7件をすべて直した。

| 指摘 | 動画 | 直し方 |
|---|---|---|
| 守らず攻撃を連打するのが一番強かった（ボス：考えて打つ54%、攻撃だけ67%） | #006 / #236 | 絶頂すると相手の余裕が大きく戻る、絶頂のあとは平常まで落ちる、我慢・深呼吸を強くした。今は考えて打つ74%、攻撃だけ52%、守り優先3%。`--policy` のテストで常に確かめる |
| 高揚が勝手に上がるだけで、自分で選べなかった | #191 / #006 | 最初のデッキに「身を委ねる」（興奮+12、1枚引く）を入れた。使うと「→火照りに上がる」「絶頂する！」の見込みを出す |
| 褒め言葉が毎回出ていた | #095 / #236 | 限界寸前で余裕の4割以上を削ったか、限界寸前でとどめを刺したときだけ。褒められたら報酬のレアが1枚確定 |
| おねだりで戦わずにご褒美が手に入った | #236 / #009 | 火照り以上か、一度果てたあとにだけ押せる |
| 進み具合が保存されなかった | #248 / #116 | 「つづきから」と「相手を選ぶ」 |
| 高揚で強くなったことがヒットで見えなかった | #130 | 数字に「×1.7」を付け、段階で大きく・色を変える。ヒットマークと振動も段階で大きく |
| ヒットストップ中も呼吸が止まらず、相手の顔が変わらなかった | #003 / #047 / #164 | 止まっている間は呼吸を止め、体を傾けて＞＜の顔に。余裕が減ると、頬を赤らめる→口が開く |
| 音楽がなかった | #069 / #202 | 戦闘は心音のループで、高揚に合わせて70→95→130BPM。シーンは場所ごとの環境音 |
| 興奮の危ない帯が分かりにくかった | #145 / #252 | メーターの背面に3色の帯、下に倍率 |
| 戻るボタンが効かない画面があった | #104 | 設定・回想・相手選びは戻る、報酬は「加えない」へ |
| 回想の「？？？」の条件が分からなかった | #023 | 「ミルダにあと1回負ける」などを出す |
| シーンがⒷ一発で消えた | #178 / #209 | 飛ばすのはⒷ長押し、Ⓧで自動送り、↑で1行戻る |
| カードを押してから効くまで遅かった | #049 / #073 | 飛ぶ演出の終わりを待たずに効かせる |
| 不具合：予告と実際の興奮がずれる、連打が次の画面に流れる、記録欄があふれる、ほか | — | 直した。予告と実際の一致はテストで確かめる |
