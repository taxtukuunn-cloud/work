## 構成（1本の合計7,000字以上。セリフ,と説明,の本文だけで数える）
ファイルは3つの部分に分け、**区切りの行 `##PLAY` と `##END` を入れる**（ゲームには入らない印）。
1. **導入（`##PLAY` の前）：400字程度（300〜600字）**。冒頭行は画像行。どう負けたか（経路）、なぜこの責めなのか、どこへ連れて行かれたか。
2. **プレイ描写（`##PLAY` と `##END` の間）：6,000字以上（目標6,500〜7,500字）**。途切れさせず一連のシーンで。責め手の責め中のセリフ、主人公の喘ぎ声、快楽に対する心理描写、体や神経の反応、道具の動き（薬の味と色、小瓶の数、塗り薬のぬめり、衣装のレースとリボンの締め付け、紫煙の甘さ、ゼリーの冷たさ、体の変化の一つ一つ）を細かく書く。**その責め手の得意技を主役にする**。絶頂は2〜4回（各絶頂の前に `射精` 行を置いてよい。触れずに達するなら置かない）。途中で後日談に飛ばない。
3. **結び（`##END` の後）：600字以内**。責め手の締めのセリフと、その後の短い余韻。
- 弱点付与・GAME OVER・BGMは別処理なので書かない。
- 文章の質：五感（薬草と蜜の匂い、大釜の湯気、ランプの灯り、布の擦れる音、濡れた音）、比喩、緩急、責め手ごとの口調の個性。同じ責め手の4本は、場所・時刻・小道具・絶頂の区切り方・結末の印を変えて、読み比べて別物にする。

## 書式（厳守。ゲームのスクリプトとしてそのまま読み込まれる）
1行に1コマンド。使ってよい行は次だけ：
```

##END
```
- **本文に半角カンマ「,」を絶対に使わない**（全角「、」を使う）。
- 本文に `$ % & # { } < > ;` を使わない。半角の `!` `?` も避け、全角「！」「？」を使う。ハートや音符などの記号は使わない。半角の ( ) も使わず全角（）。改行したい時だけ `\n` を使ってよい（1行2〜3文まで）。
- 1行の本文は長くても120字程度。セリフは「」を付けない。
- 冒頭行は必ず `画像,#Witch/Witch_lose_<経路>_<責め手>.png,1`。ほかの画像ファイル名は使わない。
- 空行・コメント・見出し・`@` 行は書かない。`##PLAY` `##END` はそれぞれ1回だけ。

## 経路（どう負けたか）の軸
- **btl（戦闘負け）**：薬と衣装の責めに崩れ、変化度が満ちて倒れる。その責め手の流儀で男の娘に仕上げられる。
- **onani（オナニー負け）**：勝負の最中、薬の副作用の疼きに耐えられず、その責め手の得意技を真似た自慰を始めてしまい、見つかる。自分から手を伸ばした恥が軸。見られる・記録される・管理される。**プレイ描写の最初は、下の「オナニーの内容」の自慰（ペニスは使わない）から始め、途中で責め手が引き取る。**
- **inochi（命乞い負け）**：追い詰めた時、相手が「解毒薬をあげる」などと取引を持ちかけ、手を止めてしまう。それは罠で、情けを代償に薬を飲まされ、約束・契約にされる。
- **onedari（おねだり負け）**：自分の口で「もっと変えてください」と具体的に請う。それが記録され、日課・常連の約束になる。
