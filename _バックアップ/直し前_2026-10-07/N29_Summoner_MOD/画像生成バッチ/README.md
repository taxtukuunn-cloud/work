# N29 触手使いの魔導塔（Summoner）画像一括生成バッチ

N26（Kitsune）と同じ仕組み・同じ設定（Anima 3ローダー／832×1216／er_sde・simple／36step／CFG4.5／seed_base 20260926）。
LoRA は `Downloads\Lora用\lora_settings.json` があれば自動で使う（外す時は `--no-lora`）。
全51枚を、カードが参照するファイル名（`Summoner_atk_m1.png` など）のまま `output\Summoner\` に保存する。登場人物は全員20歳以上。

## 使い方
1. **`gen_summoner_all.bat` をダブルクリック**（ComfyUIが起動していなければ起動し、準備を待ってから51枚を順に生成。1枚約20秒・全部で約20分。途中で止めても、もう一度実行すれば続きから）
2. 崩れた画像の撮り直し：`run_summoner.bat Summoner_atk_m3 --random --batch 4` → `output\Summoner\_candidates\` から選んで `run_summoner.bat --pick Summoner_atk_m3 2`
3. ゲームへ：`install_summoner.bat "D:\GAME\SuccubusDuel本体\RJ01149693\SuccubusDuel_sub\サキュバスデュエル\Picture"`（`Picture\Summoner\` にコピー）

## 51枚の内訳
立ち絵5（白背景→背景除去）／背景 `Summoner_bg`／技CG7／敗北28／オナニー5（`onanie_master` `_e1` `_e2` `_e3` `_boss`）／魔法・罠5

## 見た目
- 主人公：紺色の短髪・前髪で目が隠れた顔なし、小柄で華奢（150cm）・非筋肉質。場面の画像では裸。
- ルーク：紫のロング・金の瞳・深紫に金縁の召喚術師のローブ・細く長い指
- ピノ：橙のくせ毛・緑の瞳・袖の余る薄茶の見習いローブ・チョーク
- リック：桃のショート・赤い瞳・黒と桃のフリルの衣装・肩に小さな紫の触手の使い魔
- エド：茶のボサボサ髪・琥珀の瞳・深緑の作業エプロン・肘までの黒いゴム手袋
- ヴェルナー：白のロング・紫の瞳・長身・白と銀の大召喚士の法衣・銀の指輪
- 触手：紫がかった半透明・繊毛・薄紫の粘液。**魔法陣から生えて術師の指で操られる**（術師の体からは生やさない）。
- 責め手は男の娘（胸は平ら・ローブは着たまま）。挿入はルーク技③（m3）とヴェルナーの本番の場面だけ責め手の性器を出す。
- リック（e2）の場面は触手タグを外し、使い魔の舌だけにしてある。
- オナニーCGは責め手の得意技に合わせた自慰（ペニスには触れない）。責め手は奥で小さく見ているだけ。

## 崩れやすそうなもの（候補を出して選ぶ）
- 触手が責め手の体（背中・髪）から生える／青や緑になる（ネガティブに入れてある）
- 尿道責め（`atk_e1` `lose_*_e1` `atk_boss` `lose_*_boss`）：細い触手の先が描かれないことがある
- 乳首＋尿道＋挿入の3か所同時（`lose_btl_boss` `lose_onedari_boss`）
- リックの使い魔（小さな丸い体）が大きく描かれる／2人目の人間になる
- 主人公がローブやエプロンを着てしまう

## プロンプトを直すとき
`build_prompts.py` を書き換えて実行 → `summoner_prompts.json` が作り直される。撮り直す画像は `output\Summoner\` から消すか `--random` を付ける。
