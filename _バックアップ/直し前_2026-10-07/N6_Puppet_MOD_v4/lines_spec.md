# N6 人形師（v4）カード用セリフの書き方

キャラ設定・世界観・口調は `/home/claude/n6/brief.md` を読むこと（成人のみ・責め手上位・逆転なし・主人公はペニスを使う自慰をしない・後ろに入れる前（人形の芯）は指でほぐす）。
ここで書くのは、**バトル中にカードが話すセリフ**。JSONファイル1つに1キャラ分をまとめる。

## 本文の決まり（厳守）
- 半角カンマ「,」禁止（全角「、」）。`$ % & # { } < > ;` 禁止。半角の `!` `?` `(` `)` も使わず全角「！」「？」「（）」。
- 1つのセリフは40〜110字。改行したい時だけ `\\n`（JSONの中では `\\n` と書く＝画面で改行）。「」は付けない。
- セリフは責め手の口調をはっきり出す。主人公の反応は短い喘ぎ・途切れた言葉。

## 累積スタック「人形化度」と段階
攻撃を受けた側が個別に持つ。セリフは**受けた側の段階**で変える。
- 主人公（上限12）：段階1＝1〜3（手首に糸）／段階2＝4〜6（手足が勝手に動く）／段階3＝7〜9（自分を人形だと思い始める）／段階4＝10〜11（意思のない人形）
- 男モンスター（上限6。6で「新しい人形」として館側へ寝返る）：段階1＝0〜1／段階2＝2〜3／段階3＝4／段階4＝5
- 男モンスターは主人公の仲間の男（剣士・獣人など種族はいろいろ。成人）。責め手はモンスターを「お連れさん」「そちらの方」などと呼ぶ。モンスターの反応は、その男が戸惑い・抵抗しつつ崩れていく声（一人称「俺」など汎用的に）。

## JSONの形
```json
{
  "techs": [
    {
      "player": [["責め手のセリフ（段階1）", "主人公の反応（段階1）"], ["…段階2", "…"], ["…段階3", "…"], ["…段階4", "…"]],
      "monster": [["責め手のセリフ（対モンスター段階1）", "モンスターの反応"], ["…"], ["…"], ["…"]]
    }
  ],
  "prep": {
    "player": [["指ほぐしのセリフ1回目（まだ固い）", "主人公の反応"], ["指ほぐしのセリフ2回目（もうすぐ入る）", "主人公の反応"]],
    "monster": ["指ほぐしのセリフ（対モンスター）", "モンスターの反応"]
  },
  "summon": ["召喚時のセリフ1", "召喚時のセリフ2"],
  "turn_end": ["自分のターン終了時のセリフ"],
  "onedari_intro": "おねだりされた時の最初のセリフ（どれがいいか自分の口で言わせる）",
  "onedari": [["選択肢の短い名前（10字以内）", "主人公がねだる言葉", "責め手の返事"]],
  "inochi_first": ["命乞い（1回目）のセリフ1", "セリフ2"],
  "inochi_again": ["命乞い（2回目以降）のセリフ1", "セリフ2"],
  "inochi_fail": "とどめを刺された時の一言",
  "inochi_trap": "迷った隙を突く一言（ここから敗北）",
  "onani_first": ["オナニーを見つけた時のセリフ1", "セリフ2"],
  "onani_again": ["2回目以降のセリフ1", "セリフ2"],
  "onani_player": "主人公の言い訳（手が止まらない）",
  "onani_desc": "主人公の自慰の様子を描く地の文（得意技の真似。ペニスは使わない。60〜110字）",
  "end": "勝った時（主人公が負けた後）の締めの一言",
  "win": "負けた時（主人公に倒された時）の一言",
  "conv": "男モンスターが人形化度6に達して館側へ寝返る時のセリフ",
  "flavor": "カードのフレーバーテキスト（100〜130字。世界観と人物が伝わる地の文）"
}
```
- `techs` は担当キャラの技の数だけ、下の順番で書く。各技は player 4段階・monster 4段階（計16セリフ）。
- `prep` は挿入技を持つキャラ（エリスだけ）だけ書く。それ以外は `"prep": null`。
- `onedari` は技の数だけ（技の順番どおり）。
- `onani_*` の自慰は、そのキャラの得意技に合わせる（brief.md の「オナニーの内容」）。
- `summon` `turn_end` `conv` はマスター（ドロテア）も書く（ドロテアの summon は「人形を呼ぶ時」＝召喚宣言のセリフとして使う。ドロテアの turn_end は4つ＝主人公の段階1〜4で、それぞれ下の状態異常の説明に合う内容）。

## キャラと技（この順番で techs を書く）
- **ドロテア**（`m.json`。prep は null）
  1. 操り糸の舞（★得意技）：手首・足首・乳首にかけた銀の糸を指先で操り、体を勝手に踊らせ、糸の張りで乳首を責める
  2. 着せ替えの指先：人形の服を着せながら、指先で乳首をなぞる
  3. 耳元の暗示：耳元で「あなたは人形」と囁き続け、耳を甘く責める（魅了）
  - turn_end（主人公の段階ごと）：1＝魅了（ドロテアに見とれる）、2＝魅了（糸に身を任せたくなる）、3＝攻撃指示不能（仲間に指示を出せない）、4＝魔法使用不能＋ダメージ
  - さらに `"quest"` を追加で書く（下）
- **イト**（`e1.json`）1. 乳首の糸結び（★得意技。乳首に細い糸を結び、引いては緩める）　2. 四肢の糸引き（手足の糸を引いて動きを止める。攻撃指示不能）。summon は召喚時（男モンスター1体か主人公に攻撃指示不能）
- **ネル**（`e2.json`）1. お人形の着せ替え（★得意技。人形の服を一枚ずつ着せ、留め具で締める。魅了）　2. 関節固定の矯正（関節を押さえて姿勢を固定し抱きしめる）。summon は召喚時（主人公かモンスターの人形化度+1）
- **リラ**（`e3.json`）1. 子守唄の暗示（★得意技。耳元の子守唄で「あなたは人形」と刷り込む）　2. 旋律の乳首弾き（旋律に合わせて乳首を指で弾く）。turn_end は「自分のターン終了時に男モンスター1体（いなければ主人公）の人形化度+1」のセリフ
- **エリス**（`boss.json`。prep あり）1. 人形化の総仕上げ（金の針で光る縫い目を刻む。攻撃指示不能）　2. 人形の芯（★得意技。油の指でほぐした後、象牙色の芯を後ろに沈め、人形の中身にする。ほぐし済みの時だけ出る。prep は「指ほぐし」＝油で濡らした指で一本→二本）。summon は召喚時（人形化度+3）、turn_end は固有効果「最後の一針」（主人公の人形化度6以上の時、主人公を攻撃指示不能、男モンスター1体を魅了して人形化度+2）のセリフ

## ドロテアだけ追加：`"quest"`
```json
"quest": {
  "first": ["説明:街外れの糸繰り館の扉を開け、硝子の飾り棚の人形たちに見下ろされる情景の地の文（90〜120字）", "セリフ", "セリフ", "セリフ（勝負の申し込み。勝てば帰れる、負けたら人形として飾り棚へ）"],
  "won_before": ["セリフ", "セリフ"],
  "prev": {"1": "前回戦闘で負けた相手への出迎え", "2": "前回オナニーで負けた相手へ", "3": "前回命乞いで負けた相手へ", "4": "前回おねだりで負けた相手へ"},
  "prev_alert": "アラートの一文（例：前回の手入れの続きを受けますか？）",
  "choices": ["挑む", "手入れを受ける", "館を出る"],
  "decline": "引き返す時のセリフ",
  "start": ["試合開始のセリフ1", "セリフ2（人形化度が12に達したら完全な人形、の説明を含める）"],
  "lost_line": "ドロテアが負けた時のセリフ（クエストで勝たれた時）",
  "prev_continue": "前回の続きを流す前のセリフ",
  "kaisou": ["回想バトルの最初のセリフ1（今日は好きな糸で踊らせてあげる、など）", "セリフ2"]
}
```
`first` の先頭だけは `"説明:"` で始めて地の文にする（それ以外はドロテアのセリフ）。
