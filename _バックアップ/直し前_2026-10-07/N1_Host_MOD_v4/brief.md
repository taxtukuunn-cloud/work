# N1 男の娘ホストクラブ（コード Host）敗北シナリオ執筆ブリーフ（v4・2026-09-24）

サキュバスデュエル（M向けカードゲーム）の個人用MOD。**登場人物は全員20歳以上の成人**。個人利用のみ。
あなたはベストセラー作家として書く。主人公（プレイヤー。名前なし）がホストクラブの男の娘ホストたちとのカードバトルに負け、責められて堕ちていく「敗北シナリオ」を書く。

## 絶対条件
- 責め手（男の娘ホスト）が常に上位。主人公は受け身のみ。**逆転なし**。主人公は挿入しない・責め返さない。
- 責め手は服を着たまま責める（自身で貫く場面だけ前を開ける）。責め手自身が自慰したり、受け身になったりしない。
- 暴力・流血・アヘ顔・凌辱的な描写はなし。色仕掛け・甘い言葉・焦らし・言葉責め・指名という「営業」で逃げ道をふさぐ。
- 未成年を連想させる語（少年、ショタ、幼い、子ども等）は使わない。責め手も主人公も成人。
- **挿入（男の娘逆アナル）を書く時は、必ずその前に指でほぐす前戯を丁寧に書く**（ローションで濡らす→指一本→二本→前立腺を探り当てる→「もう入るね」と確かめる）。前戯なしで貫かない。
- 主人公のペニスを使う自慰は書かない（オナニー負けは下の「オナニーの内容」の自慰から始める）。

## 構成（1本の合計7,000字以上。セリフ,と説明,の本文だけで数える）
ファイルは3つの部分に分け、**区切りの行 `##PLAY` と `##END` を入れる**（ゲームには入らない印）。
1. **導入（`##PLAY` の前）：400字程度（300〜600字）**。冒頭行は画像行。どう負けたか（経路）、なぜこの責めなのか、どこへ連れて行かれたか。
2. **プレイ描写（`##PLAY` と `##END` の間）：6,000字以上（目標6,500〜7,500字）**。途切れさせず一連のシーンで。責め手の責め中のセリフ、主人公の喘ぎ声、快楽に対する心理描写、体や神経の反応（背骨を駆ける痺れ、腰の跳ね、前立腺の奥の熱など）、道具の動き（ローション、指の本数と角度、鍵の音、グラスの氷）を細かく書く。**その責め手の得意技を主役にする**。絶頂は2〜4回（各絶頂の前に `射精` 行を置いてよい。ドライで達する場合は置かない）。途中で後日談に飛ばない。
3. **結び（`##END` の後）：600字以内**。責め手の締めのセリフ（指名・専属・鍵・契約などの授与）と、その後の短い余韻（日常が店に侵食されていく一、二文）。
- 弱点付与・GAME OVER・BGMは別処理なので書かない。
- 文章の質：五感（香水、シャンパンの泡、ネオンの色、布の擦れ、濡れた音）、比喩、緩急、責め手ごとの口調の個性。同じ責め手の4本は、部屋・時刻・小道具・絶頂の区切り方・結末の印を変えて、読み比べて別物にする。

## 経路（どう負けたか）の軸
- **btl（戦闘負け）**：勝負の最中の責めに崩れ、指名度が満ちて倒れる。そのまま奥の部屋へ。責めに屈して、その責め手の流儀で堕とされる。
- **onani（オナニー負け）**：勝負の最中、我慢できずにその責め手の得意技を真似た自慰を始めてしまい、見つかる。自分から手を伸ばした恥が軸。見られる・記録される・管理される。**プレイ描写の最初は、下の「オナニーの内容」の自慰（ペニスは使わない）から始め、途中で責め手が引き取る。**
- **inochi（命乞い負け）**：とどめを刺せる場面で「延長しない？」などの甘い言葉に手が止まる。その一瞬の情けが、延長・契約・所有に変えられる。
- **onedari（おねだり負け）**：勝負の中で自分から具体的に「〜してください」と請う。それが記録され、日課・指名の約束になる。

## オナニーの内容（onani ルートの冒頭。ペニスは使わない）
- レン（キス）：自分の指を咥えて舌を絡め、レンの舌を思い出しながら、唾で濡れた指で首筋と乳首をなぞる
- ヒナタ（舌での乳首）：唾をたっぷり乗せた指の腹で、乳首を舌のように下から上へ舐め上げ続ける
- ユウ（囁き）：手を使わない。耳に残ったユウの囁きを頭の中で再生し、言われたとおりに復唱していくうちに触れずに達しそうになる
- ソラ（貞操帯）：前には触れない（貞操帯の上から触りかけて止められる、または触れない決まり）。会陰と後ろだけを指で押す
- 暁（逆アナル＋乳首）：乳首をつまみながら、指二本で後ろを奥までほぐし、貫かれる直前の感覚を自分で作ろうとする

## 書式（厳守。ゲームのスクリプトとしてそのまま読み込まれる）
1行に1コマンド。使ってよい行は次だけ：
```
画像,#Host/Host_lose_<経路>_<責め手>.png,1
話者,%レン          （%ヒナタ %ユウ %ソラ %暁 も同様。責め手が喋る前に必ず入れる）
話者,相手プレイヤー   （主人公が喋る前に入れる）
セリフ,本文
説明,本文            （地の文・情景・心の動き）
フラッシュ,ピンク
射精
ウェイト,1
##PLAY
##END
```
- **本文に半角カンマ「,」を絶対に使わない**（全角「、」を使う）。
- 本文に `$ % & # { } < > ;` を使わない。半角の `!` `?` も避け、全角「！」「？」を使う。改行したい時だけ `\n` を使ってよい（1行2〜3文まで）。
- 1行の本文は長くても120字程度。セリフは「」を付けない。
- 冒頭行は必ず `画像,#Host/Host_lose_<経路>_<責め手>.png,1`。ほかの画像ファイル名は使わない。
- 空行・コメント・見出し・`@` 行は書かない。`##PLAY` `##END` はそれぞれ1回だけ。

## ファイル
- 出力先：`/home/claude/host/scen/<経路>_<責め手>.txt`（例 `btl_m1.txt`）。UTF-8。
- 書いたら `python3 /home/claude/host/check.py /home/claude/host/scen/<ファイル>` で確認。**導入300〜600字、プレイ描写6,000字以上、結び600字以内、書式エラーなし**になるまで直す（短ければプレイ描写を書き足す）。
