# 月影の焦らし館 MOD（ルーインドオーガズム → 潮吹き）

個人利用専用。登場人物はすべて成人（20歳以上）。完全M向け・女性上位。主人公サイドの責めや逆転は一切なし。

## 1. 中身

**敵マスター：月影の焦らし女王 リュシア（27）** ＝ 手コキで焦らして寸止め。溜まったら「許可」を出して解放。

| 区分 | カード | 枚数 | 役割 |
|---|---|---|---|
| 下級 | じらしメイドのミオ（22・猫耳メイド） | 3 | 指先と耳元で寸止め。召喚時とターン終了時に寸止め+1 |
| 下級 | 寸止めナースのカレン（25・ナース） | 3 | 診察で寸止め。召喚時に発情（2T）も付与 |
| 下級 | ぬるぬる嬢のシズク（23・水の精霊） | 3 | ローションで寸止め。召喚時にぬるぬる（2T）も付与 |
| 上級 | 解放の女帝ヴァイオレット（31・聖職者） | 2 | 寸止めが3以上の相手を「許可」して潮吹き→倒す。足りなければ寸止め+ |
| 永続魔法 | 月影の焦らし寝室 | 2 | 自分のターン終了時に寸止め+1（3ターンで自壊） |
| 通常魔法 | 寸止めの合図 | 2 | 寸止め+2、攻撃不能（1T）、ドロー1枚 |
| 通常魔法 | 潮吹きの許可 | 2 | 寸止め2以上なら解放（潮吹き）して倒す。未満なら寸止め+2 |
| 罠 | ぬるぬる寸止めの罠 | 3 | 主人公側の攻撃を無効にし、攻撃者に寸止め+1とぬるぬる |

合計20枚（下級9＋上級2＋魔法6＋罠3）。マスター（リュシア）はデッキ外のクエスト敵。

## 2. 仕組み（寸止め → 潮吹き）

1. 敵の効果は、**主人公側の男性モンスターがいればそちらに優先**（いなければ主人公本人）。女性モンスターは対象外。攻撃（@戦闘）も、相手が男性でなければ寸止め処理をしない。
2. 対象に状態異常「寸止め」（HPが1で止まる）を付け、`寸止め回数` を+1。
3. 回数が溜まった対象に、リュシア（4以上）／ヴァイオレット（3以上）／潮吹きの許可（2以上）で解放。
4. 解放＝「寸止め」を解除して とどめダメージ（99999）＋射精演出。敵マスターは500回復。
5. 主人公が倒された時は、最後に責めた敵（`$$Ruin_last`：1リュシア／2ミオ／3カレン／4シズク／5ヴァイオレット）で**敗北シナリオを分岐**。いずれも最後は `ゲームオーバー`。

## 2.5 攻撃タイプ（各キャラ3種・攻撃ごとにランダム）

| キャラ | 攻撃タイプ |
|---|---|
| リュシア | 手コキ／足コキ／尻尾コキ |
| ミオ | 手コキ／耳責め／乳首責め |
| カレン | 手コキ／乳首責め／魔法責め |
| シズク | 手コキ／ふとももコキ／触手コキ |
| ヴァイオレット | 手コキ／耳責め／ハグ |

タイプごとに専用のセリフがあります。タイプごとに専用のシーン画像があります（新規10枚）。

## 2.6 セリフの構成

- **ターン終了時の効果**（ミオ・カレン・シズク・ヴァイオレットの効果2、寝室）は、テンポ重視で短いまま。
- **敗北シナリオは1本あたり約5000文字**（場面ごとに画像を切り替え、暗転で区切る。各キャラ、焦らし3段階→懇願→解放→日常化）。
- それ以外（召喚時・攻撃時・魔法と罠・解放の演出・クエスト導入・敗北シナリオ）は長文化。
- 攻撃時は、タイプごとの4行セリフ＋反応3パターン（ランダム）＋寸止め3回以上の追い打ちセリフで、同じ展開が続かないようにしてあります。

## 2.7 命乞い（敵のHPが少なくなった時）

5人とも `@命乞い` を持ち、選択肢（5秒の時限）が出ます。

| キャラ | 選択肢1 | 選択肢2 | 時間切れ | 3番目 |
|---|---|---|---|---|
| リュシア | 手コキ | 足コキ | 尻尾コキ | こうげき（命乞い失敗＝倒せる） |
| ミオ | 耳責め | 乳首責め | 手コキ | 同上 |
| カレン | 聴診 | 魔法治療 | 触診 | 同上 |
| シズク | ふとももコキ | 触手コキ | 手コキ | 同上 |
| ヴァイオレット | 囁き | 抱擁 | 手 | 同上 |

- 命乞いに乗る（1・2・時間切れ）と、寸止め+1・敵は全回復。すでに寸止めが2以上なら、そのまま解放（潮吹き）で倒されます。
- 攻撃を選ぶと命乞い失敗となり、敵は倒れます。
- 攻撃してきた相手が男性でなければ命乞いは発生せず、そのまま倒れます。

## 3. ゲームへの入れ方（Windows）

1. `Ruin_MOD` フォルダの中の `Card` `Eventlist` `Picture` の3つを、`SuccubusDuel.exe` があるフォルダへ**フォルダごとコピー（統合）**。
2. `Picture\Ruin\` に画像（下の手順で作る28枚）を入れる。画像が無くてもスクリプトは動くが、表示は出ない。
3. ゲームを起動 → 街のクエスト（赤い旗）に「月影の焦らし館」が出る。

## 4. 画像の作り方（ComfyUI）

1. ComfyUI を**通常のbatから起動**（`run_nvidia_gpu.bat`）。
2. `tools\run_ruin.bat --list-models` でモデル名を確認（違えば `Ruin_prompts.json` の settings を直す）。
3. `tools\run_ruin.bat --list` で28枚の名前を確認。
4. `tools\run_ruin.bat Ruin_Lucia` のように1枚ずつ、または `tools\run_ruin.bat all` で全部生成。立ち絵5枚は背景除去つき。
5. `tools\candidates\` に候補が出る。気に入ったものを `Picture\Ruin\Ruin_Lucia.png` のように**名前を合わせて**コピー。
6. 気に入らなければ `--random` や `--seed 123`。メモリ不足は `--batch 1`。
7. ノード名のエラーが出たら、動いているワークフローを「Save (API Format)」で保存し、`--workflow ファイル名.json` を付ける。

### 画像が作られない時

1. ComfyUI の黒い画面に `To see the GUI go to: http://127.0.0.1:8188` と出ているか確認（出ていなければ通常のbatで起動し直す）。
2. `tools\run_ruin.bat --check` を実行。接続・必要ノード・モデル名を診断します。
3. 背景除去ノードが無い場合は、自動で背景除去なしにやり直します（白背景のまま保存）。
4. モデル名が違う場合は `--check` の表示に合わせて `Ruin_prompts.json` の settings（unet / clip / vae）を直す。
5. それでもエラーになる場合、**以前ロゼッタMODで動いた `Rosetta_workflow_api.json` を `tools` フォルダに置く**と、自動でそれを土台にして生成します（プロンプト・サイズ・シードだけ差し替え）。

画像名は `Ruin_prompts.json` の name と、スクリプト内の `#Ruin/名前.png` が完全一致するようにしてあります（検証済み）。

## 6. 未検証（実機テスト前の仮の部分）

- `@命乞い` は既存MOD（ディアナ）の書式（時限選択肢／選択肢==-1／命乞い失敗）に合わせて実装。発生するHPの条件はゲーム側の仕様に依存。

- `攻撃タイプランダム変更` は既存MOD（ディアナ）と同じ書式。`触手コキ` `ふとももコキ` `尻尾コキ` `ハグ` `魔法責め` `耳責め` `乳首責め` は公式ドキュメントの攻撃タイプ一覧にあるが、実機表示は未確認。

- 男性限定の対象決定：`%男候補,=,相手モンスター.?性別:男`（既存MODの `%x,=,自分デッキ.?ID:…` と同形式）と `%男候補.Count`（カード変数へのCountは未確認）。

- `%標的.$寸止め回数` のように**カード変数に付けた自作変数**の読み書き（`相手プレイヤー.$ご奉仕カウンター` は既存MODで確認済みだが、`%変数.$名前` 形式は未確認）。動かない場合は連絡してください。
- `攻撃無効`（罠）の効き方、`状態異常付与,対象,寸止め,99` の第3引数（持続ターン）の意味。
- 寸止め状態のHP1止め動作（既存MODの使い方に合わせて実装）。
- 敗北シナリオの分岐用 `$$Ruin_last` は「最後に寸止め／解放を発生させた敵」を記録します。それ以外の要因（通常戦闘ダメージ等）で倒された場合は、直前の記録のシナリオになります。
- ComfyUIの一括生成スクリプト（ノード名 `EmptySD3LatentImage` `InspyrenetRembg` など）は未実行。
- 数値（寸止めの閾値・ダメージ・回復500・デッキ20枚）は仮。

## 7. 数値を変えたい時

- 解放の閾値：リュシア＝`Ruin_master.txt` の `if,$回数,>=,4`／ヴァイオレット＝`Ruin_mons_Violet.txt` の `>=,3`／許可＝`Ruin_magic_Permit.txt` の `>=,2`
- 解放時の回復：`イベントヒール,自分プレイヤー,500`
- 1回のダメージ：各ファイルの `イベントダメージ`
