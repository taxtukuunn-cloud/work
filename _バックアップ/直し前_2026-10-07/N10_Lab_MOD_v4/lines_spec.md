# N10 開発ラボ（v4）カード用セリフの書き方

キャラ設定・世界観・口調は `/home/claude/n10/brief.md` を読むこと（成人のみ・責め手上位・逆転なし・主人公はペニスを使う自慰をしない・後ろに器具を入れる前（シオリのプローブ・LX-01のロッド）は指でほぐす）。
ここで書くのは、**バトル中にカードが話すセリフ**。JSONファイル1つに1キャラ分をまとめる。

## 本文の決まり（厳守）
- 半角カンマ「,」禁止（全角「、」）。`$ % & # { } < > ;` 禁止。半角の `!` `?` `(` `)` も使わず全角「！」「？」「（）」。
- 1つのセリフは40〜110字。改行したい時だけ `\\n`（JSONの中では `\\n` と書く＝画面で改行）。「」は付けない。
- セリフは責め手の口調をはっきり出す。主人公の反応は短い喘ぎ・途切れた言葉。

## 累積スタック「開発度」と段階
攻撃を受けた側が個別に持つ。セリフは**受けた側の段階**で変える。
- 主人公（上限12）：段階1＝1〜3（初期計測。まだ検査のつもり）／段階2＝4〜6（開発中。数値を読まれると体が反応）／段階3＝7〜9（反応固定。合図の音だけで疼く）／段階4＝10〜11（完成間近。自分から実験を望む）
- 男モンスター（上限6。6で「登録被験体」としてラボ側へ寝返る）：段階1＝0〜1／段階2＝2〜3／段階3＝4／段階4＝5
- 男モンスターは主人公の仲間の男（剣士・獣人など種族はいろいろ。成人）。責め手はモンスターを「そちらの個体」「追加の被験体」などと呼ぶ。モンスターの反応は、その男が戸惑い・抵抗しつつ崩れていく声（一人称「俺」など汎用的に）。

## JSONの形
```json
{
  "techs": [
    {
      "player": [["責め手のセリフ（段階1）", "主人公の反応（段階1）"], ["…段階2", "…"], ["…段階3", "…"], ["…段階4", "…"]],
      "monster": [["責め手のセリフ（対モンスター段階1）", "モンスターの反応"], ["…"], ["…"], ["…"]]
    }
  ],
  "prep": {
    "player": [["指ほぐしのセリフ1回目（まだ固い）", "主人公の反応"], ["指ほぐしのセリフ2回目（もうすぐ入る）", "主人公の反応"]],
    "monster": ["指ほぐしのセリフ（対モンスター）", "モンスターの反応"]
  },
  "summon": ["召喚時のセリフ1", "召喚時のセリフ2"],
  "turn_end": ["自分のターン終了時のセリフ"],
  "onedari_intro": "おねだりされた時の最初のセリフ（どれがいいか自分の口で言わせる）",
  "onedari": [["選択肢の短い名前（10字以内）", "主人公がねだる言葉", "責め手の返事"]],
  "inochi_first": ["命乞い（1回目）のセリフ1", "セリフ2"],
  "inochi_again": ["命乞い（2回目以降）のセリフ1", "セリフ2"],
  "inochi_fail": "とどめを刺された時の一言",
  "inochi_trap": "迷った隙を突く一言（ここから敗北）",
  "onani_first": ["オナニーを見つけた時のセリフ1", "セリフ2"],
  "onani_again": ["2回目以降のセリフ1", "セリフ2"],
  "onani_player": "主人公の言い訳（手が止まらない）",
  "onani_desc": "主人公の自慰の様子を描く地の文（得意技の真似。ペニスは使わない。60〜110字）",
  "end": "勝った時（主人公が負けた後）の締めの一言",
  "win": "負けた時（主人公に倒された時）の一言",
  "conv": "男モンスターが開発度6に達してラボ側へ寝返る時のセリフ",
  "flavor": "カードのフレーバーテキスト（100〜130字。世界観と人物が伝わる地の文）"
}
```
- `techs` は担当キャラの技の数だけ、下の順番で書く。各技は player 4段階・monster 4段階（計16セリフ）。
- `prep` は挿入技を持つキャラ（シオリ・LX-01）だけ書く。それ以外は `"prep": null`。
- `onedari` は技の数だけ（技の順番どおり）。
- `onani_*` の自慰は、そのキャラの得意技に合わせる（brief.md の「オナニーの内容」）。
- `summon` `turn_end` `conv` はマスター（シオリ）も書く（シオリの summon は「研究員や機体を呼ぶ時」＝召喚宣言のセリフとして使う。シオリの turn_end は4つ＝主人公の段階1〜4で、それぞれ下の状態異常の説明に合う内容）。

## キャラと技（この順番で techs を書く）
- **シオリ**（`m.json`。prep あり＝技2の前立腺プローブ用。ゼリーの手袋の指で一本→二本）
  1. 吸引装置での乳首開発（★得意技）：透明な吸引カップを乳首に付け、圧と間隔を段階的に変えて吸い、数値を読み上げる
  2. 前立腺プローブ：ほぐした後、白い細身のプローブを入れ、目盛りの周期で前立腺を押す（ほぐし済みの時だけ出る）
  3. 電気刺激による前立腺開発：会陰と下腹に電極を貼り、弱く心地よい電気の脈で奥を震わせる（寸止め）
  - turn_end（主人公の段階ごと）：1＝発情、2＝寸止め、3＝攻撃指示不能（仲間に指示を出す声が数値の読み上げに変わる）、4＝魔法使用不能＋ダメージ
  - さらに `"quest"` を追加で書く（下）
- **ミナセ**（`e1.json`。prep は null）1. 乳首センサーでの計測（★得意技。センサーを貼った乳首を指で弾き転がし、百分率を読み上げる）　2. 反応データの焦らし（手袋の手で扱きながら数値を見て、直前で止める。寸止め）。summon は召喚時（男モンスター1体か主人公の開発度+1）
- **クロエ**（`e2.json`。prep は null）1. 誘導音声の暗示（★得意技。耳にスピーカーを当て、一定の調子で指示を流し、耳を指でなぞる）　2. 拘束具での固定（柔らかいベルトで手足を固定する。攻撃指示不能）。summon は召喚時（主人公に攻撃指示不能）
- **ハク**（`e3.json`。prep は null）1. 検体採取の指（★得意技。ゼリーの手袋の中指一本から後ろに沈め、前立腺を押して搾る。段階1は入口を撫でるだけ、段階が上がるほど奥・二本に）　2. 検体タグの電極（タグ型の小さな電極を乳首や腰に付けて弱い脈。寸止め）。turn_end は「自分のターン終了時に男モンスター1体（いなければ主人公）の開発度+1」のセリフ
- **LX-01**（`boss.json`。prep あり＝細い指型アームで一本→二本。合成音声・カタカナ混じり）1. 複数アームの同時責め（吸引アームと撫でるアームで同時に。攻撃指示不能）　2. 前立腺刺激ロッド（★得意技。ほぐした後、白いロッドを沈め一定の周期で前立腺を押し、同時に乳首を吸う。ほぐし済みの時だけ出る）。summon は召喚時（開発度+3）、turn_end は固有効果「自動運転」（主人公の開発度6以上の時、主人公を魔法使用不能、男モンスター1体を寸止めにして開発度+2）のセリフ

## シオリだけ追加：`"quest"`
```json
"quest": {
  "first": ["説明:廃棄予定の第七開発ラボの長い白い廊下を進み、青白い蛍光灯と機械の唸りに迎えられる情景の地の文（90〜120字）", "セリフ", "セリフ", "セリフ（勝負の申し込み。勝てば帰れる、負けたら被験体として登録）"],
  "won_before": ["セリフ", "セリフ"],
  "prev": {"1": "前回戦闘で負けた相手への出迎え", "2": "前回オナニーで負けた相手へ", "3": "前回命乞いで負けた相手へ", "4": "前回おねだりで負けた相手へ"},
  "prev_alert": "アラートの一文（例：前回の実験の続きを受けますか？）",
  "choices": ["挑む", "実験の続きを受ける", "引き返す"],
  "decline": "引き返す時のセリフ",
  "start": ["試合開始のセリフ1", "セリフ2（開発度が12に達したら開発完了、の説明を含める）"],
  "lost_line": "シオリが負けた時のセリフ（クエストで勝たれた時）",
  "prev_continue": "前回の続きを流す前のセリフ",
  "kaisou": ["回想バトルの最初のセリフ1（今日は好きな装置を選ばせてやる、など）", "セリフ2"]
}
```
`first` の先頭だけは `"説明:"` で始めて地の文にする（それ以外はシオリのセリフ）。
