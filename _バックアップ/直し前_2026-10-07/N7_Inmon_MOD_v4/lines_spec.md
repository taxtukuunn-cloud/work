# N7 淫紋の神官（v4）カード用セリフの書き方

キャラ設定・世界観・口調は `/home/claude/n7/brief.md` を読むこと（成人のみ・責め手上位・逆転なし・主人公はペニスを使う自慰をしない・後ろに触れる時は聖油の指で一本ずつ）。
ここで書くのは、**バトル中にカードが話すセリフ**。JSONファイル1つに1キャラ分をまとめる。

## 本文の決まり（厳守）
- 半角カンマ「,」禁止（全角「、」）。`$ % & # { } < > ;` 禁止。半角の `!` `?` `(` `)` も使わず全角「！」「？」「（）」。
- 1つのセリフは40〜110字。改行したい時だけ `\\n`（JSONの中では `\\n` と書く＝画面で改行）。「」は付けない。
- セリフは責め手の口調をはっきり出す。主人公の反応は短い喘ぎ・途切れた言葉。

## 累積スタック「淫紋度」と段階
攻撃を受けた側が個別に持つ。セリフは**受けた側の段階**で変える。
- 主人公（上限12）：段階1＝1〜3（へその下に小さな紋）／段階2＝4〜6（紋が腰と太ももの付け根へ蔓のように伸びる）／段階3＝7〜9（紋が胸まで伸び乳首を縁取る）／段階4＝10〜11（全身に紋が結ばれかけ、祈りなしでは静まらない）
- 男モンスター（上限6。6で紋が完成し「神殿の信徒」として神官側へ寝返る）：段階1＝0〜1／段階2＝2〜3／段階3＝4／段階4＝5
- 男モンスターは主人公の仲間の男（剣士・獣人など種族はいろいろ。成人）。責め手はモンスターを「お連れの方」「そちらの方」などと呼ぶ（リツは「そこの者」、セレスは「そこな者」）。モンスターの反応は、その男が戸惑い・抵抗しつつ崩れていく声（一人称「俺」など汎用的に）。

## JSONの形
```json
{
  "techs": [
    {
      "player": [["責め手のセリフ（段階1）", "主人公の反応（段階1）"], ["…段階2", "…"], ["…段階3", "…"], ["…段階4", "…"]],
      "monster": [["責め手のセリフ（対モンスター段階1）", "モンスターの反応"], ["…"], ["…"], ["…"]]
    }
  ],
  "prep": {
    "player": [["指ほぐしのセリフ1回目（まだ固い）", "主人公の反応"], ["指ほぐしのセリフ2回目（もうすぐ入る）", "主人公の反応"]],
    "monster": ["指ほぐしのセリフ（対モンスター）", "モンスターの反応"]
  },
  "summon": ["召喚時のセリフ1", "召喚時のセリフ2"],
  "turn_end": ["自分のターン終了時のセリフ"],
  "onedari_intro": "おねだりされた時の最初のセリフ（どれがいいか自分の口で言わせる）",
  "onedari": [["選択肢の短い名前（10字以内）", "主人公がねだる言葉", "責め手の返事"]],
  "inochi_first": ["命乞い（1回目）のセリフ1", "セリフ2"],
  "inochi_again": ["命乞い（2回目以降）のセリフ1", "セリフ2"],
  "inochi_fail": "とどめを刺された時の一言",
  "inochi_trap": "迷った隙を突く一言（ここから敗北）",
  "onani_first": ["オナニーを見つけた時のセリフ1", "セリフ2"],
  "onani_again": ["2回目以降のセリフ1", "セリフ2"],
  "onani_player": "主人公の言い訳（手が止まらない）",
  "onani_desc": "主人公の自慰の様子を描く地の文（得意技の真似。ペニスは使わない。60〜110字）",
  "end": "勝った時（主人公が負けた後）の締めの一言",
  "win": "負けた時（主人公に倒された時）の一言",
  "conv": "男モンスターが淫紋度6に達して神殿側へ寝返る時のセリフ",
  "flavor": "カードのフレーバーテキスト（100〜130字。世界観と人物が伝わる地の文）"
}
```
- `techs` は担当キャラの技の数だけ、下の順番で書く。各技は player 4段階・monster 4段階（計16セリフ）。
- `prep` はこのMODでは全員 `"prep": null`（リツの躾は指そのものが一本ずつほぐす動きなので、技のセリフの中で一本→二本と進める）。
- `onedari` は技の数だけ（技の順番どおり）。
- `onani_*` の自慰は、そのキャラの得意技に合わせる（brief.md の「オナニーの内容」）。
- `summon` `turn_end` `conv` はマスター（ヴェルミナ）も書く（ヴェルミナの summon は「巫女を呼ぶ時」＝召喚宣言のセリフとして使う。ヴェルミナの turn_end は4つ＝主人公の段階1〜4で、それぞれ下の状態異常の説明に合う内容）。

## キャラと技（この順番で techs を書く）
- **ヴェルミナ**（`m.json`）
  1. 聖印の口づけ（★得意技）：長くゆっくりした口づけで唾液の祈りを流し込み、口づけのたびに下腹の紋が光って色が濃くなる
  2. 紋なぞり：紋の線を指先でなぞり、胸まで伸びた紋の先で乳首を摘み、転がす
  3. 神具の儀式：銀の鈴・聖杖・白檀の数珠を肌に当て、鈴の震えで紋に祈りを注ぐ（発情）
  - turn_end（主人公の段階ごと）：1＝発情（紋が熱を帯びる）、2＝発情（祈りの言葉だけで疼く）、3＝攻撃指示不能（仲間に指示を出す声が祈りに変わる）、4＝魔法使用不能＋ダメージ
  - さらに `"quest"` を追加で書く（下）
- **ベニ**（`e1.json`）1. 紅墨の描紋（★得意技。紅墨の筆で紋の線を一本ずつ描き足す）　2. 筆先の乳首なぞり（筆先で乳首の周りを円く描き、先をくすぐる）。summon は召喚時（男モンスター1体か主人公の淫紋度+1）
- **シオン**（`e2.json`）1. 囁きの香（★得意技。甘い香を吸わせながら耳元で囁き、数を数えて沈める。発情）　2. 香の口移し（香を含んだ口で口づけ、煙ごと吐息を流し込む）。turn_end は「自分のターン終了時に男モンスター1体（いなければ主人公）の淫紋度+1」のセリフ
- **リツ**（`e3.json`）1. 後ろの躾（★得意技。前を貞操帯で封じたまま、聖油の指を一本ずつ後ろに沈め、奥の一点で「正しい果て方」を覚えさせる。段階1は入口を撫でるだけ、段階2で一本、段階3で二本、段階4で二本で一点を押さえる、のように段階ごとに進める）　2. 貞操帯の封印（金属の檻を前に着けて銀の鍵をかける。魔法使用不能）。summon は召喚時（主人公に魔法使用不能）
- **セレス**（`boss.json`）1. 銀の細管（銀の細い管を祈りの言葉とともに当てる儀式。セリフでは「細管」「祈りの管」とだけ言い、具体的な挿入描写はしない。攻撃指示不能）　2. 完成の抱擁（★得意技。衣ごと全身で包み込み、掌と胸と腿で全身の紋を重ね合わせて一つに結ぶ）。summon は召喚時（淫紋度+3）、turn_end は固有効果「完成の儀」（主人公の淫紋度6以上の時、主人公を魔法使用不能、男モンスター1体を発情させて淫紋度+2）のセリフ

## ヴェルミナだけ追加：`"quest"`
```json
"quest": {
  "first": ["説明:丘の上の月紋神殿の石段を上り、燭台の灯る拝殿で神官に迎えられる情景の地の文（90〜120字）", "セリフ", "セリフ", "セリフ（勝負の申し込み。勝てば帰れる、負けたら紋が完成するまで神殿の信徒に）"],
  "won_before": ["セリフ", "セリフ"],
  "prev": {"1": "前回戦闘で負けた相手への出迎え", "2": "前回オナニーで負けた相手へ", "3": "前回命乞いで負けた相手へ", "4": "前回おねだりで負けた相手へ"},
  "prev_alert": "アラートの一文（例：前回の祈りの続きを受けますか？）",
  "choices": ["挑む", "祈りを受ける", "神殿を出る"],
  "decline": "引き返す時のセリフ",
  "start": ["試合開始のセリフ1", "セリフ2（淫紋度が12に達したら紋が完成、の説明を含める）"],
  "lost_line": "ヴェルミナが負けた時のセリフ（クエストで勝たれた時）",
  "prev_continue": "前回の続きを流す前のセリフ",
  "kaisou": ["回想バトルの最初のセリフ1（今宵は好きな巫女を呼んであげましょう、など）", "セリフ2"]
}
```
`first` の先頭だけは `"説明:"` で始めて地の文にする（それ以外はヴェルミナのセリフ）。
