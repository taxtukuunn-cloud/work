# N2 男の娘サークル（v4）カード用セリフの書き方

キャラ設定・世界観・口調は `/home/claude/n2/brief.md` を読むこと（成人のみ・責め手上位・逆転なし・主人公はペニスを使う自慰をしない・このMODでは責め手のペニスでの挿入はない）。
ここで書くのは、**バトル中にカードが話すセリフ**。JSONファイル1つに1キャラ分をまとめる。

## 本文の決まり（厳守）
- 半角カンマ「,」禁止（全角「、」）。`$ % & # { } < > ;` 禁止。半角の `!` `?` も使わず全角「！」「？」。
- 1つのセリフは40〜110字。改行したい時だけ `\\n`（JSONの中では `\\n` と書く＝画面で改行）。「」は付けない。
- セリフは責め手の口調をはっきり出す。主人公の反応は短い喘ぎ・途切れた言葉。

## 累積スタック「キス度」と段階
攻撃を受けた側が個別に持つ。セリフは**受けた側の段階**で変える。
- 主人公（上限12）：段階1＝1〜3（新入部員）／段階2＝4〜6（キスに慣らされる）／段階3＝7〜9（部室から帰れない）／段階4＝10〜11（もう部員）
- 男モンスター（上限6。6で「サークル部員」として部室側へ寝返る）：段階1＝0〜1／段階2＝2〜3／段階3＝4／段階4＝5
- 男モンスターは主人公の仲間の男（剣士・獣人など種族はいろいろ。成人）。責め手はモンスターを「そっちのお兄さん」「付き添いの人」などと呼ぶ。モンスターの反応は、その男が戸惑い・抵抗しつつ崩れていく声（一人称「俺」など汎用的に）。

## JSONの形
```json
{
  "techs": [
    {
      "player": [["責め手のセリフ（段階1）", "主人公の反応（段階1）"], ["…段階2", "…"], ["…段階3", "…"], ["…段階4", "…"]],
      "monster": [["責め手のセリフ（対モンスター段階1）", "モンスターの反応"], ["…"], ["…"], ["…"]]
    }
  ],
  "prep": null,
  "summon": ["召喚時のセリフ1", "召喚時のセリフ2"],
  "turn_end": ["自分のターン終了時のセリフ"],
  "onedari_intro": "おねだりされた時の最初のセリフ（どれがいいか自分の口で言わせる）",
  "onedari": [["選択肢の短い名前（10字以内）", "主人公がねだる言葉", "責め手の返事"]],
  "inochi_first": ["命乞い（1回目）のセリフ1", "セリフ2"],
  "inochi_again": ["命乞い（2回目以降）のセリフ1", "セリフ2"],
  "inochi_fail": "とどめを刺された時の一言",
  "inochi_trap": "迷った隙を突く一言（ここから敗北）",
  "onani_first": ["オナニーを見つけた時のセリフ1", "セリフ2"],
  "onani_again": ["2回目以降のセリフ1", "セリフ2"],
  "onani_player": "主人公の言い訳（手が止まらない）",
  "onani_desc": "主人公の自慰の様子を描く地の文（得意技の真似。ペニスは使わない。60〜110字）",
  "end": "勝った時（主人公が負けた後）の締めの一言",
  "win": "負けた時（主人公に倒された時）の一言",
  "conv": "男モンスターがキス度6に達して部室側へ寝返る時のセリフ",
  "flavor": "カードのフレーバーテキスト（100〜130字。世界観と人物が伝わる地の文）"
}
```
- `techs` は担当キャラの技の数だけ、下の順番で書く。各技は player 4段階・monster 4段階（計16セリフ）。
- `prep` は全員 `null`（このMODに挿入技はない）。
- `onedari` は技の数だけ（技の順番どおり）。
- `onani_*` の自慰は、そのキャラの得意技に合わせる（brief.md の「オナニーの内容」）。
- `summon` `turn_end` `conv` はマスター（ハルカ）も書く（ハルカの summon は「部員を呼ぶ時」＝召喚宣言のセリフ。ハルカの turn_end は4つ＝主人公の段階1〜4で、それぞれ下の状態異常の説明に合う内容）。

## キャラと技（この順番で techs を書く）
- **ハルカ**（`m.json`）
  1. 長いキス（★得意技）：唇を離さない長いディープキス、苺のリップ、唾液を流し込む
  2. 耳キスと乳首：後ろから抱いて耳にキスし甘噛みしながら、乳首をつまむ・転がす
  3. キスしながらの指：キスで口を塞いだまま、ローションの指で後ろをほぐし前立腺を探る（指だけ。挿入はない）
  - turn_end（主人公の段階ごと）：1＝発情（体が火照る）、2＝魅了（先輩に見とれる）、3＝攻撃指示不能（仲間に指示を出せない）、4＝魔法使用不能＋ダメージ
  - さらに `"quest"` を追加で書く（下）
- **ミオ**（`e1.json`）1. 軽いキス　2. キスしながらの乳首（★得意技。唇を重ねたまま指で乳首を転がす）。summon は召喚時（主人公かモンスターのキス度+1）
- **ツバサ**（`e2.json`）1. 抱きつきキス（★得意技。パーカーごと抱きしめて離さないキス）　2. 首筋のキスマーク（首筋を吸って痕をつける。発情）。summon は召喚時（男モンスター1体か主人公に発情）
- **カイト**（`e3.json`）1. 耳舐めと囁き（★得意技。本を読み聞かせるように耳を舐め囁く）　2. 指でのアナル責め（ローションの指で後ろをほぐす。挿入はしない）。turn_end は「自分のターン終了時に男モンスター1体（いなければ主人公）のキス度+1」時のセリフ
- **シズク**（`boss.json`）1. 長いディープキス（魅了）　2. キスしながらのアナルパール（★得意技。唇を塞いだまま、ほぐした後ろに大きな珠を一粒ずつ沈める）。summon は召喚時（キス度+3と主人公に魅了）、turn_end は固有効果「公認のキス」（主人公のキス度6以上の時、主人公を魅了、男モンスター1体を魅了してキス度+2）のセリフ

## ハルカだけ追加：`"quest"`
```json
"quest": {
  "first": ["説明:部室棟三階の奥の部室に入る情景の地の文（90〜120字）", "セリフ", "セリフ", "セリフ（勝負の申し込み。勝てば帰れる、負けたら入部）"],
  "won_before": ["セリフ", "セリフ"],
  "prev": {"1": "前回戦闘で負けた後輩への出迎え", "2": "前回オナニーで負けた後輩へ", "3": "前回命乞いで負けた後輩へ", "4": "前回おねだりで負けた後輩へ"},
  "prev_alert": "アラートの一文（例：前回の続きから部活に参加しますか？）",
  "choices": ["挑む", "部活に参加する", "部室を出る"],
  "decline": "引き返す時のセリフ",
  "start": ["試合開始のセリフ1", "セリフ2（キス度が12まで溜まったら入部、の説明を含める）"],
  "lost_line": "ハルカが負けた時のセリフ（クエストで勝たれた時）",
  "prev_continue": "前回の続きを流す前のセリフ",
  "kaisou": ["回想バトルの最初のセリフ1（今日は好きな展開で部活してあげる、など）", "セリフ2"]
}
```
`first` の先頭だけは `"説明:"` で始めて地の文にする（それ以外はハルカのセリフ）。
