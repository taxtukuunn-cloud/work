# N28 パーソナルトレーナー（Gym）画像一括生成バッチ

N26（Kitsune）と同じ仕組み・同じ設定（Anima 3ローダー／832×1216／er_sde・simple／36step／CFG4.5。LoRA は `Downloads\Lora用\lora_settings.json` があれば自動で使う）。
全51枚を、カードが参照するファイル名（`Gym_atk_m1.png` など）のまま `output\Gym\` に保存する。登場人物は全員20歳以上。

## 使い方
1. **`gen_gym_all.bat` をダブルクリック**（ComfyUIが起動していなければ起動し、準備を待ってから51枚を順に生成。1枚約20秒・全部で約20分。途中で止めても、もう一度実行すれば続きから）
2. 崩れた画像の撮り直し：`run_gym.bat Gym_atk_m3 --random --batch 4` → `output\Gym\_candidates\` から選んで `run_gym.bat --pick Gym_atk_m3 2`
3. ゲームへ：`install_gym.bat "D:\GAME\SuccubusDuel本体\RJ01149693\SuccubusDuel_sub\サキュバスデュエル\Picture"`（`Picture\Gym\` にコピー）
