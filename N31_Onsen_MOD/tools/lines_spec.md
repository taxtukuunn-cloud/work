# N31 湯守の宿 カード用セリフの書き方（担当者向け）

個人用・成人向けゲームMOD。登場人物は全員20歳以上の成人。
キャラ設定・世界観・口調・責め手ごとの言い方は `/home/claude/n3x/onsen/brief.md` を**最初に全部読む**こと（責め手上位・逆転なし・主人公はおちんちんを使う自慰をしない・ペニバンの前は指でほぐす）。
文体を合わせるため、完成済みのシナリオ `/home/claude/n3x/onsen/scen/btl_<自分のkey>.txt`（マスター担当は btl_m2.txt）にも目を通す。
ここで書くのは、**バトル中にカードが話すセリフ**。JSONファイル1つに1キャラ分をまとめる。

## 本文の決まり（厳守）
- 半角カンマ「,」禁止（全角「、」）。`$ % & # { } < > ;` 禁止。半角の `!` `?` `(` `)` も使わず全角「！」「？」「（）」。
- 1つのセリフは40〜110字（反応は短くてよい：15字以上）。改行したい時だけ `\\n`。「」は付けない。
- 責め手の口調をはっきり出す（brief の表どおり。ミヤコ＝京ことば混じりの敬語、ハル＝はきはき丁寧語の「ボク」、ツバキ＝短く低い、コウ＝江戸っ子の「オレ」、セツ＝古風な「妾」）。
- **主人公（僕）の反応・ねだる言葉・言い訳には必ず♡を付ける**（1〜3個）。主人公は160cmの細身の成人男性。「小柄」「華奢」など体の小ささを言う語は使わない。
- おちんちん／お尻の穴／前立腺はぼかさずに。責め手のセリフでの呼び方は brief の「言い方」表どおり。
- 幼さを示す語（少年・子供・子ども・幼い・ロリ・少女・ショタ 等）は使わない。

## 累積スタック「逗留日数」と段階
宿帳に一泊ずつ書き足される夜の数。攻撃を受けた側が個別に持つ。セリフは**受けた側の段階**で変える（「もう〇泊目どすなあ」のように数に触れてよい）。
- 主人公（上限12で「湯守」＝敗北）：段階1＝1〜3（湯けむり）／段階2＝4〜6（のぼせ）／段階3＝7〜9（湯治）／段階4＝10〜11（長逗留）
- 男モンスター（上限6。6で宿の「下足番」として宿の側へ寝返る）：段階1＝0〜1／段階2＝2〜3／段階3＝4／段階4＝5
- 男モンスターは主人公の仲間の男（剣士・獣人など種族はいろいろ。成人）。責め手は「お連れさま」「お供の方」「連れの兄さん」などと呼ぶ。**モンスターの反応の一人称は「僕」**（戸惑い・抵抗しつつ崩れていく声。♡は付けなくてよいが、段階3〜4では付けてもよい）。

## JSONの形
```json
{
  "techs": [
    {
      "player": [["責め手のセリフ（段階1）", "主人公の反応（段階1）♡"], ["…段階2", "…♡"], ["…段階3", "…♡"], ["…段階4", "…♡"]],
      "monster": [["責め手のセリフ（対モンスター段階1）", "モンスターの反応（僕）"], ["…"], ["…"], ["…"]]
    }
  ],
  "prep": {
    "player": [["指ほぐしのセリフ1回目（椿油の指を一本。まだ固い）", "主人公の反応♡"], ["指ほぐしのセリフ2回目（二本目・前立腺。もうすぐ入る）", "主人公の反応♡"]],
    "monster": ["指ほぐしのセリフ（対モンスター）", "モンスターの反応（僕）"]
  },
  "summon": ["召喚時のセリフ1", "召喚時のセリフ2"],
  "turn_end": ["自分のターン終了時のセリフ"],
  "onedari_intro": "おねだりされた時の最初のセリフ（どれがいいか自分の口で言わせる）",
  "onedari": [["選択肢の短い名前（10字以内）", "主人公がねだる言葉♡", "責め手の返事"]],
  "inochi_first": ["命乞い（1回目）のセリフ1", "セリフ2"],
  "inochi_again": ["命乞い（2回目以降）のセリフ1", "セリフ2"],
  "inochi_fail": "とどめを刺された時の一言",
  "inochi_trap": "迷った隙を突く一言（ここから敗北）",
  "onani_first": ["オナニーを見つけた時のセリフ1", "セリフ2"],
  "onani_again": ["2回目以降のセリフ1", "セリフ2"],
  "onani_player": "主人公の言い訳（手が止まらない）♡",
  "onani_desc": "主人公の自慰の様子を描く地の文（僕の視点。得意技の真似。おちんちんは使わない。60〜110字）",
  "end": "勝った時（主人公が負けた後）の締めの一言",
  "win": "負けた時（主人公に倒された時）の一言",
  "conv": "男モンスターの逗留日数が6に達して宿の下足番になる時のセリフ",
  "flavor": "カードのフレーバーテキスト（100〜130字。世界観と人物が伝わる地の文）"

```
- `techs` は担当キャラの技の数だけ、下の順番で書く。各技は player 4段階・monster 4段階（計16セリフ）。
- `prep` はペニバンの技を持つキャラ（ミヤコ・セツ）だけ書く。それ以外は `"prep": null`。
- `onedari` は技の数だけ（技の順番どおり）。
- `onani_*` の自慰は、そのキャラの得意技に合わせる（brief の「オナニー」の表）。
- `summon` `turn_end` `conv` はマスター（ミヤコ）も書く（ミヤコの summon は「宿の者を呼ぶ時」＝召喚宣言のセリフ。**4つ＝主人公の段階1〜4**。ミヤコの turn_end も4つ＝主人公の段階1〜4で、下の状態異常の説明に合う内容）。

## キャラと技（この順番で techs を書く）
- **ミヤコ**（`m.json`）
  1. 千夜の湯歌（耳責め）：耳元で湯歌を歌い、歌詞で帰り道を忘れさせる。節の終わりに口づけ。魅了
  2. 湯船の口づけ（★得意技）：湯の中で長い口づけ。唇→舌→上顎、唾を飲ませる
  3. 湯の中で胸を撫でながら：湯で温めた指で乳首を撫で・つまみながら、藤色の帯で結んだペニバンで貫く（ほぐし済みの時だけ出る。prep は「指ほぐし」＝温めた椿油の指で一本→二本）
  - turn_end（主人公の段階ごと）：1＝発情（湯あたりのように体が火照る）、2＝発情、3＝魅了（女将から目が離せない）、4＝魅了＋ダメージ（婿入り直前）
  - さらに `"quest"` を追加で書く（下）
- **ハル**（`e1.json`）1. 洗い場の指（★得意技。泡の指でお尻へ「内側まで洗う」、前立腺をこする）　2. 泡の手で（泡の手で乳首を洗うように撫でる）。summon は召喚時（主人公かお連れの逗留日数+1）
- **ツバキ**（`e2.json`）1. ツボ押し（★得意技。下腹・内もも・会陰のツボを指一本で押し、触れずに達させる）　2. 足裏の按摩（足の裏で陰茎を揉むように踏む）。summon は召喚時（男モンスター1体に攻撃不能＝湯あたり）
- **コウ**（`e3.json`）1. 湯の華（★得意技。湯の華を溶かした温いゼリーを細い竹の管で尿道へ少しずつ。痛みなし）　2. 湯船の中で（湯の中で乳首を舐める）。turn_end は「自分のターン終了時に逗留日数+1」のセリフ
- **セツ**（`boss.json`）1. 湯船の抱擁（★得意技。抱きしめて口づけで口を、指で乳首を同時に塞ぐ）　2. 婿入りの儀（黒漆のペニバンで貫く。寸止め。ほぐし済みの時だけ出る。prep は指ほぐし＝椿油の指）。summon は召喚時（逗留日数+3）、turn_end は固有効果「長逗留」（主人公の逗留日数6以上の時、自分のターン終了時、男モンスター1体を発情強2ターン）のセリフ

  "won_before": ["セリフ", "セリフ"],
  "prev": {"1": "前回戦闘で負けた客への出迎え", "2": "前回オナニーで負けた客へ", "3": "前回命乞いで負けた客へ", "4": "前回おねだりで負けた客へ"},
  "prev_alert": "アラートの一文（例：前回の湯治の続きをしますか？）",
  "choices": ["勝負する", "湯治の続き", "宿を出る"],
  "decline": "宿を出る時のセリフ",
  "start": ["試合開始のセリフ1", "セリフ2（逗留日数が12になったら湯守＝婿として宿に住む、の説明を含める）"],
  "lost_line": "ミヤコが負けた時のセリフ（クエストで勝たれた時）",
